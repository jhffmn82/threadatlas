# ThreadAtlas wiki

A static wiki rendered from the ThreadAtlas knowledge graph: every entity, work and claim links to the verbatim quote it came from, and every quote opens the source text where it was taken.

Built by `notebooks/threadatlas-wiki.py` in the project repository from the 0.6 store. Nothing here is edited by hand; to change a page, change the generator or the store and rebuild.

Public-domain literature and CC BY papers; each paper's page carries its licence line.
