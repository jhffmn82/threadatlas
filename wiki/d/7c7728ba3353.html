Retrieval-Augmented Generation with Estimation of Source Reliability

Jeongyeon Hwang, Junyoung Park, Hyejin Park, Dongwoo Kim, Sangdon Park, Jungseul Ok · 2025 · 23 sections
"Retrieval-Augmented Generation with Estimation of Source Reliability" by Jeongyeon Hwang, Junyoung Park, Hyejin Park, Dong‐Woo Kim, Sangdon Park, Jungseul Ok (2025), licensed CC BY. Shown here as extracted text, with facts drawn from it. https://doi.org/10.18653/v1/2025.emnlp-main.1738

Abstract written by a model

This paper introduces Reliability-Aware RAG (RA-RAG), a multi-source retrieval-augmented generation framework by Jeongyeon Hwang, Junyoung Park, Hyejin Park, Dongwoo Kim, Sangdon Park, and Jungseul Ok. It addresses the problem that standard RAG retrieves documents mainly by relevance and can therefore be misled by unreliable or adversarial sources, even when their documents resemble the query. RA-RAG first estimates each source’s reliability through cross-checking: it generates fact-checking queries, collects source-specific answers, aggregates them with weighted majority voting (WMV), and updates source weights according to agreement with estimated answers. At inference, it retrieves from reliable, relevant sources rather than all sources. Its κ-Reliable and Relevant Source Selection (κ-RRSS) ranks sources by reliability, retains up to κ useful answers, and lowers cost. RA-RAG also filters answers not grounded in retrieved material using AlignScore/falign; low-scoring outputs become IDK. Remaining semantically equivalent answers are clustered and combined through WMV, allowing a correct answer from highly reliable sources to outweigh a more frequent incorrect answer. The paper situates RA-RAG among adaptive retrieval, reranking, query reformulation, majority voting, credibility assessment, source reputation, and learning from noisy sources, arguing that prior approaches do not sufficiently handle heterogeneous source reliability. It formulates multi-source RAG, identifies hallucination, paraphrase, missing ground truth, and scaling challenges, and then presents the reliability-estimation and source-selection methods. Experiments use a multi-source benchmark built from Natural Questions, TriviaQA, and HotpotQA, with factual and misleading documents and sources that vary in truthfulness and relevance. Across Llama3-8B-Instruct, GPT-4o-mini, Phi3-mini-Instruct, and Llama2-7B, RA-RAG generally exceeds Vanilla RAG, MV, Robust RAG, and other baselines, often approaching Oracle WMV, including under adversarial settings. Filtering reduces ungrounded answers from misinformation or irrelevant documents, and κ-RRSS retains near-all-source accuracy while reducing token use, API calls, cost, and computation. Inference remains efficient as source counts rise, while offline reliability estimation is presented as a one-time preprocessing cost. For real-world claims, estimated reliability closely tracks oracle reliability for Politician A, Politician B, and User A; augmented User A results show strong correlation. The paper concludes that RA-RAG can extend beyond short-form question answering through decomposition and aggregation, while noting difficulties in specialized domains with limited cross-verification and the need for online updates as source reliability changes.

front matter .. Retrieval-Augmented Generation with Estimation of Source Reliability / Abstract front matter

Jeongyeon Hwang, Junyoung Park, Hyejin Park, Dongwoo Kim, Sangdon Park, and Jungseul Ok introduce Reliability-Aware RAG (RA-RAG), a multi-source framework for Retrieval-Augmented Generation. RA-RAG estimates source reliability by cross-checking information across multiple sources, then retrieves documents from the top-κ reliable and relevant sources. It aggregates information with weighted majority voting and is designed to improve factual accuracy and scalability when source reliability is heterogeneous. Experiments show that RA-RAG outperforms baselines and can estimate the reliability of real-world sources.

Introduction body

The unit concerns large language models and retrieval-augmented generation, focusing on the risks of incorrect information from unreliable sources. It introduces Reliability-Aware RAG (RA-RAG), which estimates source reliability, performs source-level retrieval, and aggregates information using Weighted Majority Voting. RA-RAG uses κ-reliable and relevant source selection to consult a small number of reliable and relevant sources while maintaining scalability. Experiments are reported to show improved robustness against conflicting or unreliable information and practical applicability to real-world sources.

Related Works body

This unit reviews methods for improving retrieval-augmented generation (RAG), including adaptive retrieval, document reranking, and query reformulation, but notes that these methods remain vulnerable to misinformation because they rely on query-document relevance. It discusses robust RAG methods that use majority voting, LLM-based credibility assessment, or source reputation, while identifying limitations in each approach. It presents RA-RAG as a method that explicitly estimates source reliability and incorporates it into RAG systems. It also connects RAG to prior work on learning from noisy sources, which estimates data-provider reliability to aggregate trustworthy information.

Problem Formulation / Standard RAG .. Multi-source RAG with source reliability body

The unit introduces the standard retrieval-augmented generation (RAG) framework, which uses a database, a retriever, and the large language model G to generate responses from retrieved documents. It explains that standard RAG overlooks differences in source reliability and can be manipulated by adversarial sources that produce misleading but highly similar documents. The multi-source RAG framework partitions documents by source, generates source-specific responses, and aggregates them using weighted majority voting based on estimated source reliability. The unit identifies challenges involving LLM hallucinations and paraphrasing, limited access to ground truth, and computational scalability as the number of sources grows.

Method: RA-RAG .. Iterative reliability estimation body

Reliability-Aware RAG (RA-RAG) addresses challenges in multi-source RAG by estimating source reliability before deployment and weighting source responses during inference. Its aggregation process filters misaligned responses with AlignScore, clusters semantically equivalent responses, and applies weighted majority voting. Its iterative reliability estimation algorithm generates fact-checking queries, aggregates responses with WMV, and updates source weights based on agreement with estimated answers. RA-RAG also introduces κ-Reliable and Relevant Source Selection to reduce inference costs by selecting reliable sources with relevant information.

Experiments / Experimental setups .. Ablation studies and analysis body

The unit evaluates RA-RAG on a multi-source RAG benchmark built from Natural Questions, TriviaQA, and HotpotQA, using sources with heterogeneous reliability and coverage. RA-RAG generally outperforms MV, Vanilla RAG, Robust RAG, and other baselines, approaches Oracle WMV performance, and is especially robust to adversarial sources. Ablation studies show that κ-RRSS improves accuracy and substantially reduces token consumption, API calls, inference cost, and computation as the number of sources increases. The experiments use Llama3-8B-Instruct, GPT-4o-mini, Phi3-mini-Instruct, and Llama2-7B with Contriever retrieval, and evaluate performance primarily using accuracy.

Real-world Application / Setup .. Experimental results body

The iterative reliability estimation method is evaluated on real-world claims from PolitiFact sources Politician A and Politician B, and on social-media posts from User A. The study uses Google News to retrieve the top 20 relevant documents and GPT-4o-mini to generate responses to yes/no fact-checking queries. Estimated reliability closely matches oracle reliability for all three sources, with accuracies of 0.949 for Politician A, 0.932 for Politician B, and 0.795 for User A. Under augmented reliability levels for User A, estimated and oracle reliability show strong correlation, with a PCC of 0.991 and an SRCC of 0.992.

Conclusion body

The paper examines how RAG systems are vulnerable to heterogeneous source reliability because they may retrieve incorrect documents from unreliable sources. It proposes RA-RAG, a multi-source RAG framework that estimates source reliability and uses it during retrieval and answer generation. Although the work focuses on short-form question answering, RA-RAG is described as applicable to long-form and multi-hop question answering through task decomposition and answer aggregation. The paper identifies datasets containing diverse sources with heterogeneous reliability as a promising direction for future evaluation and development.

Limitations body

The reliability estimation method estimates the reliability of real-world sources effectively, particularly for news-related claims with abundant fact-checking sources. Its application to specialized topics remains challenging because there are limited references for cross-verification, although expert knowledge may offer an alternative. The framework operates in an offline setting and therefore requires periodic updates to reflect changes in source reliability over time. Future work could develop an online framework that updates estimates continuously and responds adaptively to the evolving information landscape.

References references

A appendix

The unit describes misalignment filtration using AlignScore, a factual consistency evaluation method from Zha et al. (2023). A sequence-to-sequence model from Song (2022), previously used by Zha et al. (2023), converts LLM outputs into declarative sentences before evaluation. Outputs with an AlignScore below the threshold are replaced with IDK, while others are retained. The threshold is set to 0.1 in all experiments, following Lei et al. (2023), with an ablation study reported in Section L.

B appendix

The κ-Reliable and Relevant Source Selection (κ-RRSS) algorithm ranks sources by reliability score, queries the language model using a retriever, filters the resulting answers with falign, and selects up to κ non-IDK answers. The filtering ablation study reports answer-type distributions for factual, misinformation, and irrelevant retrieved documents on Llama3-8B-Instruct and TQA. With filtering, correct answers associated with misinformation and irrelevant documents decrease, while IDK answers increase. In the reliability-estimation ablation, Ours with filtering achieves accuracy 0.537, compared with 0.490 for Ours without filtering and 0.541 for Oracle WMV.

C appendix

The unit analyzes the effectiveness of falign filtering across factual, misinformation, and irrelevant retrieved documents using 1,600 TQA dataset queries. Without filtering, LLMs frequently produce responses that are not grounded in misinformation or irrelevant documents, while falign substantially reduces these responses by replacing them with IDK responses. The unit also examines how such misaligned responses distort reliability estimation under an adversary-hammer prior with four low-reliability adversaries and one higher-reliability hammer. Filtering mitigates this distortion and brings performance close to Oracle WMV.

D appendix

The unit reports experimental results using the Llama2-7B model. The experiments evaluate methods on the beta prior and the adversary-hammer, including Self-RAG for comparison because it was fine-tuned on the Llama2-7B architecture. Across both priors, RA-RAG achieves performance comparable to the optimal Oracle WMV and outperforms all other evaluated methods.

E appendix

Additional Experimental Results reports results for beta and adversary-hammer priors across different sources, adversaries, models, and datasets. An ablation study of κ-RRSS finds that RA-RAG has stable performance from κ = 4 across the NQ, TQA, and HotpotQA datasets with 9 sources. The study also shows that κ-RRSS selects a small subset of sources while achieving performance close to using all sources. An ablation of κ-RRSS in RA-RAG finds only marginal accuracy differences while substantially reducing computational overhead.

F appendix

The unit concerns RA-RAG's aggregation of information from multiple sources using WMV, as shown in Figure A5. RA-RAG can estimate the correct answer accurately even when it appears less frequently than incorrect answers by assigning higher weights to more reliable sources. MV fails in such cases, demonstrating the importance of considering source reliability.

G appendix

The Benchmark of Multi-source RAG evaluates retrieval-augmented generation under heterogeneous source reliability using closed-ended queries from Natural Questions, HotpotQA, and TriviaQA. It constructs factual and misleading documents from Wikipedia retrievals, paraphrases, and generated incorrect answers using GPT-4o-mini, then independently constructs sources with varying relevance and truthfulness. Accuracy is compared across aggregation and retrieval methods under different numbers of adversaries and sources, using Llama2-7B, Llama3-8B-Instruct, Phi3-mini-Instruct, and GPT-4o-mini. RA-RAG generally remains competitive as adversaries or sources vary, while Oracle WMV provides a closely matching upper-bound comparison.

H / H.1 .. H.2 appendix

This unit describes the Multi-Source Benchmark prompts for generating factual contexts, misinformation, and answers. The factual data generation prompt asks for paraphrased contexts that contain enough information to answer a question. The misinformation generation process creates plausible but incorrect counterfactual answers and filters out cases where correct information is reintroduced. GPT-4o-mini is used to generate misinformation, while example outputs compare majority voting with RA-RAG and demonstrate answer generation from provided contexts.

I appendix

Figure A8 illustrates an instruction prompt. The prompt is used for answer generation. The unit concerns the relationship between Figure A8, the instruction prompt, and answer generation.

J / Inference phase / Reliablity estimation phase appendix

The unit evaluates computational efficiency using wall-clock time for inference and source reliability estimation on the NQ dataset with a Beta prior and a single RTX 6000 Ada GPU. The method maintains efficient inference as the number of sources increases, with times ranging from 1.21 seconds for 5 sources to 1.82 seconds for 1,000 sources. Source reliability estimation takes from 4.65 minutes for 5 sources to 14.81 hours for 1,000 sources and is described as a practical one-time preprocessing step. The results also report reliability estimation performance on real-world sources for Politician A, Politician B, and User A under augmented variation.

K appendix

The unit reports experimental results on estimating the reliability of real-world sources. Figure A9 presents results for Politician A, Politician B, and User A. The results concern reliability estimation under data augmentation.

L appendix

The unit reports an extended ablation study of the filtering threshold  across NQ, TQA, and HotpotQA. The study evaluates Llama3-8B-Instruct, Phi3-mini-Instruct, and GPT-4o-mini using the falign filtering method. Across models and datasets, higher  improves filtering of misaligned responses but also increases information loss by incorrectly filtering aligned responses. Tables A7A15 show answer-type distributions by retrieved document type and threshold.
