Retrieval augmented text-to-SQL generation for epidemiological question answering using electronic health records

Angelo Ziletti · 2024-06-21 · 9 sections
"Retrieval augmented text-to-SQL generation for epidemiological question answering using electronic health records" by Angelo Ziletti, Leonardo D'Ambrosi (2024), licensed CC BY. Shown here as extracted text, with facts drawn from it. https://doi.org/10.18653/v1/2024.clinicalnlp-1.4

Abstract written by a model

This unit presents an end-to-end method for answering epidemiological questions about patient health status and healthcare utilization from electronic health records and claims data. It targets databases compliant with the Observational Medical Outcomes Partnership Common Data Model and combines large-language-model text-to-SQL generation, medical-entity normalization, and retrieval augmented generation (RAG). Questions are translated into SQL with placeholders for medical entities, which are mapped to precise clinical ontology terms; the resulting coded SQL is executed, and an LLM may optionally formulate an answer from retrieved data. A central contribution is a manually curated dataset of 306 question/SQL pairs, developed with epidemiological-study specialists. Covering 13 tables and 44 columns, it includes complex population selection, temporal relations, aggregation, and mathematical operations. Each pair received two paraphrases, though evaluations used one version per question because of budget limits. Zuzanna Krawczyk-Borysiak created 27 pairs, while A.Z. Jared Worful, Melanie Hackl, and Krawczyk-Borysiak curated the remainder. The evaluation tests GPT-3.5 Turbo, GPT-4 Turbo, GeminiPro 1.0, Claude 2.1, Mixtral 8x7B, and Mixtral Medium on the DE-SynPUF synthetic claims dataset. It compares simple and advanced prompts, RAG, normalization, and SQL execution. Advanced prompts generally improve executability, but relevant retrieved examples provide larger gains, particularly for GPT-4 Turbo and Mistral Medium. GPT-4 Turbo performs best overall; GPT-3.5 Turbo leads in the RAG-top1-oracle setting by closely copying supplied SQL. The unit concludes that RAG is promising and outperforms static prompting, but current models are not reliable enough for unsupervised use. The approach is therefore experimentally deployed at Bayer under monitoring and supervision.

Abstract body

The unit concerns using electronic health records (EHR) and claims data to answer epidemiological questions about patient health status and healthcare utilization. It introduces an end-to-end methodology that combines text-to-SQL generation with retrieval augmented generation (RAG). The approach integrates medical coding into the text-to-SQL process and performs significantly better than simple prompting. The findings indicate that current language models are not accurate enough for unsupervised use, while RAG shows promise in a realistic industry setting.

1 body

The unit introduces an end-to-end approach for answering epidemiological questions using real-world data from EHR and claims databases. It presents a manually annotated question-SQL pairs dataset aligned with the Observational Medical Outcomes Partnership Common Data Model, integrates medical coding into text-to-SQL, and reports that retrieval augmented generation improves performance over static instruction prompting with large language models. The approach is deployed experimentally at Bayer, where epidemiologists and data analysts use it under careful monitoring and supervision.

2 body

The dataset was manually curated with specialists in epidemiological studies who contributed typical questions from their work. It contains 306 question/SQL pairs using 13 tables and 44 columns, with substantial query complexity involving population selection, temporal relationships, aggregation, and mathematical operations. Each question-SQL pair was augmented with two paraphrased versions, although one version per question was used in subsequent evaluations due to budget limits. The dataset uses the OMOP-CDM to support applicability across real-world data databases with differing data models.

3 body

The methodology uses LLM prompting to translate natural language questions into SQL queries for retrieving information from an OMOP CDM-compliant database. It extends EHR text-to-SQL methods by having an LLM generate SQL with placeholders for medical entities, which are mapped to precise clinical ontology terms. The approach uses the dataset as an external knowledge base by incorporating relevant question-SQL pairs into the prompt through RAG. Completed SQL queries containing medical codes are executed for data retrieval, and an LLM can optionally articulate an answer from the retrieved data.

4 / 4.1 .. 4.2 body

This unit evaluates text-to-SQL generation for epidemiological question answering using GPT-3.5 Turbo, GPT-4 Turbo, GeminiPro 1.0, Claude 2.1, Mixtral 8x7B, and Mixtral Medium. The experiments compare simple and advanced prompts, retrieval augmented generation, medical entity normalization, and SQL execution on the DE-SynPUF synthetic claims dataset. Advanced prompting usually improves executability, while relevant retrieved examples substantially improve performance, especially for GPT-4 Turbo and Mistral Medium. GPT-4 Turbo performs best overall, although GPT-3.5 Turbo performs best in the RAG-top1-oracle scenario by closely copying the provided SQL.

5 body

The unit reviews text-to-SQL datasets for EHRs, including MIMIC-SQL, emrKBQA, EHRSQL, and the OMOP query library. It notes that MIMIC-SQL, emrKBQA, and EHRSQL are based on MIMIC-III or eICU and do not adhere to OMOP-CDM, while the OMOP query library contains OMOP-CDM queries. It also discusses LLM prompting and in-domain demonstrations for text-to-SQL, noting that these methods have not been extensively explored on small biomedical datasets. The work concludes that RAG improves performance when answering epidemiological questions using real-world data, although the dataset is limited in size and scope.
