Crafting Personalized Agents through Retrieval-Augmented Generation on Editable Memory Graphs

Zheng Wang, Zhongyang Li, Zeren Jiang, Dandan Tu, Wei Shi · 2024 · 11 sections
"Crafting Personalized Agents through Retrieval-Augmented Generation on Editable Memory Graphs" by Zheng Wang, Zhongyang Li, Zeren Jiang, Dandan Tu, W. Shi (2024), licensed CC BY. Shown here as extracted text, with facts drawn from it. https://doi.org/10.18653/v1/2024.emnlp-main.281

The paper introduces personalized large-language-model agents for smartphone AI assistants, using users’ personal memories to improve question answering, autofill forms, and user services, with related uses such as reminders and travel navigation. Its central problem is how to collect practical memory data, let users’ changing memories be edited, and selectively retrieve and combine the relevant memories for each task. The proposed framework, EMG-RAG, combines Retrieval-Augmented Generation with an Editable Memory Graph (EMG) and reinforcement learning. Memory data are gathered from conversations and screenshots; GPT-4 is used for memory and question-answer-pair generation. The EMG organizes hierarchical memory types and entity relationships, while an RL agent treats graph traversal and memory choice as an MDP, selecting memories for a frozen base language model to use in answering requests. The framework also supports dynamic edits and online learning to mitigate cold start. The work situates itself alongside personalized dialogue, knowledge-graph RAG, and model-editing research, including PersonaChat and P2BOT, but focuses on practical memories collected by smartphone AI assistants and on deployment into an AI assistant product. Experiments use a real-world business dataset with about 11.35 billion raw text items and 0.35 billion memories. Across GPT-4, ChatGLM3-6B, and PanGu-38B, EMG-RAG consistently surpasses RAG baselines on the three applications and on continuous edits; GPT-4 generally produces the strongest results. The paper reports roughly a 10% improvement over the best existing approach, supported by ablation, parameter, online A/B, and data-quality studies, and reports improved usability after transfer to a real smartphone assistant. A limitation is that only the RL agent is trained while LLMs stay fixed. Training is no more efficient than Naive RAG because optimization requires querying the LLM for answers.

Abstract body

The paper introduces personalized agents powered by large language models that use a user’s smartphone memories to improve downstream applications. It presents EMG-RAG, which combines Retrieval-Augmented Generation with an Editable Memory Graph and uses Reinforcement Learning to address data collection, editability, and selectability. Experiments on a real-world dataset show that EMG-RAG improves performance by approximately 10% over the best existing approach. The personalized agents were also transferred to a real smartphone AI assistant, enhancing usability.

1 body

The unit examines personalized agents that use personal memories from smartphones to enhance AI assistants with large language model capabilities. It identifies challenges in collecting, editing, and selectively retrieving personal memories, and proposes EMG-RAG to address them. EMG-RAG uses an Editable Memory Graph for structured memory management and an RL agent for adaptive memory selection. Experiments on a real-world business dataset show improvements in question answering, autofill forms, and user services, and the agents were transferred into an AI assistant product.

2 body

This unit reviews personalized dialogue systems, retrieval-augmented generation on knowledge graphs, and model editing. It describes how PersonaChat supports research on personalized dialogue, including mutual persona perception, persona sparsity, and long-term persona memory, and how P2BOT enriches dialogue through mutual persona perception. The study constructs user-personalized agents from practical memory data gathered by smartphone AI assistants for question answering, autofill forms, and user services. It also introduces an EMG structure for managing users’ personal memories, applies reinforcement learning to optimize graph-based memory selection, and supports dynamic edits with retrieval-augmented generation using a frozen large language model.

3 body

The unit concerns developing personalized agents for users on smartphone AI assistant platforms such as Apple’s Siri and Samsung’s Bixby. These agents are intended to perform personalized tasks while supporting editability, allowing responses to change with users’ dynamic memory data. They must also provide selectability by identifying relevant memories and combining multiple memories through a base language model when needed. The agents support applications including question answering, autofill forms, reminders, and travel navigation.

4 / 4.1 .. 4.4 body

This unit presents EMG-RAG, a framework for personalized agents integrated with smartphone AI assistants. It describes data collection from conversations and screenshots, GPT-4-based memory and question-answer pair generation, and construction of an Editable Memory Graph with hierarchical memory types and entity relationships. An MDP uses reinforcement learning to traverse the graph and select memories for a large language model to answer questions. The unit also discusses question answering, autofill forms, user services, and online learning to address the cold-start problem.

5 / 5.1 .. 5.2 body

The experiments evaluate EMG-RAG on a real-world business dataset containing approximately 11.35 billion raw text items and 0.35 billion memories collected from an AI assistant product. EMG-RAG is compared with RAG baselines across question answering, autofill forms, user services, and continuous edits using GPT-4, ChatGLM3-6B, and PanGu-38B. It consistently outperforms the baselines, with the strongest results generally obtained using GPT-4. Ablation, parameter, online A/B, and data-quality evaluations examine the sources of its effectiveness and deployment performance.

6 body

The paper presents a novel task of creating personalized agents powered by LLMs. These personalized agents leverage users' personal memories to enhance three downstream applications. The proposed solution, EMG-RAG, combines RAG techniques with an EMG to address challenges in data collection, editability, and selectability, and extensive experiments confirm its effectiveness.

7 body

The limitations concern a setup in which only the RL agent's parameters are trained while the parameters of the LLMs remain fixed. Its training efficiency is not higher than that of a Naive RAG setup. This inefficiency results from querying the LLM during training to obtain answers for optimization.
