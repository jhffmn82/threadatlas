Ragas: Automated Evaluation of Retrieval Augmented Generation

Shahul Es, Jithin James, Luis Espinosa-Anke, Steven Schockaert · 2025-04-28 · 12 sections

Abstract written by a model

The document presents Ragas, a reference-free framework for evaluating Retrieval Augmented Generation (RAG) pipelines, which retrieve passages from a textual database and use them with a large language model to generate answers. RAG is important because language models may not reliably answer questions about post-training events or rarely mentioned information, but assessing such systems is difficult when reference answers are unavailable, model probabilities are inaccessible, or standard short-answer datasets are unrepresentative. Ragas evaluates three central dimensions: Faithfulness, Answer Relevance, and Context Relevance. Faithfulness tests whether each statement in a generated answer can be inferred from retrieved context, using a prompting-based process that decomposes answers into statements and verifies them. Answer Relevance estimates how well an answer addresses the question by generating questions from the answer and comparing them with the original through embeddings. Context Relevance measures the share of context sentences useful for answering the question. The paper introduces WikiEval, built from 50 Wikipedia pages about events since the start of 2022; ChatGPT generated questions from introductory sections, and human annotators judged answers and context fragments. Experiments compare Ragas with GPT Score and GPT Ranking. With high inter-annotator agreement, Ragas more closely matched human judgments, reporting accuracies of 0.95 for faithfulness, 0.78 for answer relevance, and 0.70 for context relevance. Context relevance was hardest for ChatGPT, particularly for long contexts. The conclusion positions Ragas and WikiEval as tools for faster automated evaluation cycles, especially strong on faithfulness and answer relevance.

Ragas: Automated Evaluation of Retrieval Augmented Generation front matter

Abstract body

The abstract introduces Ragas (Retrieval Augmented Generation Assessment), a framework for evaluating Retrieval Augmented Generation (RAG) pipelines without reference annotations. RAG systems combine a retrieval module with an LLM-based generation module and use knowledge from a reference textual database. Ragas evaluates retrieval relevance and focus, the faithful use of retrieved passages, and generation quality. The framework is intended to support faster evaluation cycles as large language models are adopted quickly.

Introduction body

The unit explains that Language Models capture broad world knowledge and can answer questions without external sources, but they cannot reliably handle post-training events or rarely mentioned information. Large Language Models perform strongly on many question answering benchmarks, yet Retrieval Augmented Generation is commonly used to address these limitations by retrieving relevant passages and providing them to the model. Evaluating retrieval-augmented systems is difficult because perplexity may not predict downstream performance, closed models may not expose probabilities, and short-answer question answering datasets may be unrepresentative. The paper introduces Ragas as a framework for automated assessment.

2 .. Faithfulness body

The unit describes Ragas, a framework for evaluating retrieval augmented generation systems when reference answers may be unavailable. It reviews prior approaches to estimating factuality and evaluating generated text with large language models, including prompting, token probabilities, hidden states, and sampling multiple answers. It defines Faithfulness, Answer Relevance, and Context Relevance as three reference-free quality aspects for RAG systems. It then explains a prompting-based method for measuring Faithfulness by decomposing a generated answer into individual statements and checking whether those statements can be inferred from the retrieved context.

opening .. The WikiEval Dataset body

The text describes metrics for evaluating faithfulness, answer relevance, and context relevance in question-context-answer systems. Faithfulness is computed from statements supported by a large language model using a verification function, while answer relevance is estimated by comparing generated questions with the original question through embeddings. Context relevance measures the proportion of context sentences extracted as useful for answering the question. The WikiEval Dataset was created from 50 Wikipedia pages about events since the start of 2022, with ChatGPT generating questions from their introductory sections.

opening .. Experiments body

The experiments evaluate Ragas metrics against GPT Score and GPT Ranking using human assessments from the WikiEval dataset. Human annotators compared answers and context fragments for faithfulness, answer relevance, and context relevance, with high inter-annotator agreement. Table 1 reports that Ragas aligned more closely with human judgements than the two baseline methods, achieving accuracies of 0.95, 0.78, and 0.70 for the three dimensions respectively. Context relevance was the most difficult dimension for ChatGPT to evaluate, especially with longer contexts.

Conclusions body

The conclusions highlight the need for automated reference-free evaluation of RAG systems. They propose an evaluation framework covering faithfulness, answer relevance, and context relevance. The authors introduce WikiEval, a dataset containing human judgements of these aspects, and Ragas, an implementation of them. Evaluation on WikiEval shows that predictions from Ragas closely align with human predictions, especially for faithfulness and answer relevance.
