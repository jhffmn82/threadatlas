Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory

Neural Information Processing Systems (NeurIPS) · 2023-12-23 · 18 sections
"Lift Yourself Up: Retrieval-augmented Text Generation with Self Memory" by Xin Cheng, Di Luo, Xiuying Chen, Lemao Liu, Dongyan Zhao, Rui Yan (2023), licensed CC BY. Shown here as extracted text, with facts drawn from it. https://doi.org/10.48550/arxiv.2305.02437

Abstract written by a model

This document presents Selfmem, a retrieval-augmented text-generation framework designed to address the limitation of bounded memory. It is built on the linked ideas that better memory can improve generation and that better generation can in turn produce better memory. Rather than relying only on retrieved training examples, Selfmem lets a retrieval-augmented generator create candidate outputs, forming an unbounded self-generated memory pool. A memory selector then chooses useful outputs as memory for the next generation round, so selected candidates are reused for subsequent retrieval-augmented generation rather than merely reranked as final answers. The method is motivated by the observation that model-generated outputs may resemble inference-time data more closely than retrieved examples, while beam outputs alone add little information. The generator produces candidate pools and the selector uses model-free measures such as BLEU or ROUGE; it is trained with a KL-divergence objective. The work evaluates Selfmem with fine-tuned small models and few-shot prompted LLMs across machine translation, abstractive summarization, and dialogue generation, on seven datasets including JRC-Acquis, XSum, BigPatent, and DailyDialog. Results show improvements for fixed-parameter Transformer-based translation generators in four JRC-Acquis directions, where self-memory is closer to references and more useful than retrieval memory. For summarization, Selfmem improves XSum and BigPatent performance, reporting state-of-the-art results with BRIO and BART, including 50.3 ROUGE-1 on XSum and 62.9 ROUGE-1 on BigPatent. It also raises dialogue BLEU scores and can optimize diversity through Distinct metrics; BARTjoint with self-memory performs strongly on DailyDialog. Few-shot XGLM translation benefits from larger models and more similar demonstrations, though it remains below supervised baselines. Further analysis on JRC-Acquis En→De finds that better selector quality improves translation, and an oracle selector indicates that candidate pools improve across iterations. Token-frequency results suggest retrieval-augmented models, especially Selfmem, better handle long-tail inputs. The document concludes that Selfmem outperforms strong baselines and identifies bottlenecks for future work, while noting greater memory-selection cost on long-context datasets such as BigPatent and reliance on transformer-based generator and selector architectures. The work was supported by the listed China grants; Dongyan Zhao and Rui Yan are corresponding authors.

Abstract body

The abstract concerns retrieval-augmented generation and introduces Selfmem, a framework that improves generation by iteratively creating and selecting self-generated memory. Selfmem uses a retrieval-augmented generator to produce an unbounded memory pool and a memory selector to choose an output for the next generation round. It is evaluated on neural machine translation, abstractive text summarization, and dialogue generation using fine-tuned small models and few-shot LLMs. The framework achieves state-of-the-art results in four directions on the JRC-Acquis translation dataset, 50.3 ROUGE-1 on XSum, and 62.9 ROUGE-1 on BigPatent.

Introduction body

This unit concerns retrieval-augmented text generation and the Selfmem framework for improving generation through iterative self-generated memory. It explains the primal problem, in which better memory prompts better generation, and the dual problem, in which better generation prompts better memory. Selfmem combines a retrieval-augmented generator with a memory selector to create an unbounded memory pool and select outputs for subsequent rounds. Experiments cover neural machine translation, abstractive text summarization, and dialogue generation, with reported gains on JRC-Acquis, XSum, and BigPatent.

Related Work / Retrieval-augmented Text Generation .. Neural Text Reranking body

Retrieval-augmented text generation equips models with external memory to provide additional knowledge or demonstration examples, with applications including machine translation, dialogue, summarization, code generation, and question answering. In machine translation, retrieval has been used in statistical and neural systems, while in-context example retrieval supports few-shot generation and on-the-fly adaptation. Neural text reranking uses a second stage to select better outputs and has been applied to machine translation, parsing, and summarization. The described framework differs from conventional reranking by using selected candidates as memory for a subsequent retrieval-augmented generation round.

Experimental Results / Machine Translation .. Dialogue Generation body

The unit evaluates Selfmem for machine translation, summarization, and dialogue generation using trainable models and few-shot prompted LLMs. On JRC-Acquis translation, Selfmem improves fixed-parameter Transformer-based generators across four directions, while self-memory is more similar to references and more effective than retrieval memory. Self-memory also improves summarization on XSum and BigPatent, achieving state-of-the-art results with BRIO and BART, and improves dialogue BLEU scores while allowing optimization for diversity through Distinct metrics. In-context translation with XGLM improves with model size and increasingly similar demonstrations, but remains below supervised baselines.

Further Analysis body

The unit analyzes Selfmem by studying the effects of its memory selector Sθ and generator Gξ, with experiments on the JRC-Acquis En→De dataset. It finds that improved memory selection raises translation quality, while an oracle selector also shows that the candidate pool improves over successive iterations. Token-level frequency analysis indicates that retrieval-augmented models, especially Selfmem, better handle long-tail inputs. Results on DailyDialog show that BARTjoint with self-memory achieves strong dialogue-generation performance.

Conclusion body

The unit investigates the fundamental limitation of bounded memory in current retrieval-augmented literature. It introduces Selfmem, a general framework for retrieval-augmented text generation that enhances a generation model with its own output by combining primal and dual problems. Comprehensive experiments cover various text generation tasks and generation paradigms, including trainable small models and few-shot prompted LLMs. Selfmem surpasses strong baselines, improves state-of-the-art performance on several datasets, and helps identify system bottlenecks for future research.

Limitations body

The unit discusses limitations of Selfmem and the paper’s retrieval-augmented generation framework. Selfmem improves generation quality compared with other retrieval-augmented generation models but requires more computational resources for memory selection, especially on large datasets with long contexts such as BigPatent. The paper experiments only with transformer-based architectures for both the generator and memory selector, using the same architecture across all text generation tasks. The authors believe task-specific architectures, training objectives, and generation methods could further improve performance.
