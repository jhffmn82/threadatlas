Syntax-Aware Retrieval Augmented Code Generation

Xiangyu Zhang, Yu Zhou, Guang Yang, Taolue Chen · 2023 · 13 sections
"Syntax-Aware Retrieval Augmented Code Generation" by Xiangyu Zhang, Yu Zhou, Guang Yang, Taolue Chen (2023), licensed CC BY. Shown here as extracted text, with facts drawn from it. https://doi.org/10.18653/v1/2023.findings-emnlp.90

Abstract written by a model

This document presents kNN-TRANX, a syntax-aware retrieval-augmented neural code-generation method by Xiangyu Zhang, Yu Zhou, Guang Yang, and Taolue Chen. It maps natural-language descriptions to code by generating abstract syntax trees (ASTs), rather than directly producing code strings. The work addresses shortcomings of directly applying kNN-MT to code generation: retrieval noise, syntactic errors, and expensive searches over large datastores. The paper begins by situating kNN-TRANX in neural code generation, kNN-MT retrieval, and seq2tree models. It describes BertranX, a state-of-the-art seq2tree architecture using BERT, a grammar-based decoder, and ASDL-based action sequences. Building on this architecture, kNN-TRANX separates retrieved knowledge into syntactic and semantic datastores. During datastore construction, training code is parsed into ASTs and decoder representations are stored with target rules or primitives. At inference time, the model produces a context representation and neural distribution, retrieves nearest-neighbor distributions under ASDL grammar and syntax constraints, and combines retrieval and neural probabilities. A meta-k network selects weights for different retrieval sizes, while a confidence network balances kNN and neural predictions. Experiments on CoNaLa and Django evaluate BLEU, CodeBLEU, and exact match against BertranX and other code-generation systems. kNN-TRANX outperforms the listed baselines, with particularly clear gains on CoNaLa. Analyses examine grammar-based noise filtering, the confidence network, separate datastores, datastore size, and choices of Krule and Kpri; on CoNaLa, Krule=4 and Kpri=64 yield 37.29 BLEU, 39.04 CodeBLEU, and 7.4 exact match. A central result is datastore-switching incremental adaptation: external or mined data can update both datastores, or only the semantic datastore, without fine-tuning the neural model. This uses 17k trainable parameters rather than 122,205k for full fine-tuning while attaining comparable performance. The document closes by reviewing related AST, pre-training, and retrieval-based work; noting that retrieval at each inference step and datastore storage remain costs; and acknowledging support from listed Chinese foundations and grants.

Syntax-Aware Retrieval Augmented Code Generation / Abstract body

Xiangyu Zhang, Yu Zhou, Guang Yang, and Taolue Chen present Syntax-Aware Retrieval Augmented Code Generation, a method for generating code from natural-language descriptions. They propose kNN-TRANX, which uses token-level retrieval with syntax constraints and smaller datastores tailored to code generation. The approach is designed to reduce retrieval noise, syntactic errors, and the time required for datastore searches. Experiments on two public datasets confirm its effectiveness.

1 body

This unit concerns neural code generation and the proposed kNN-TRANX approach for mapping natural-language descriptions to code. It explains that directly applying kNN-MT introduces retrieval noise, syntactic errors, and costly datastore searches. kNN-TRANX instead generates abstract syntax trees using separate syntactic and semantic datastores, grammar-based filtering, and a combination of neural and kNN probabilities. On CoNaLa and Django, kNN-TRANX improves exact match or BLEU over compared models, and its datastore-switching adaptation reduces trainable parameters by 7,000 times while achieving performance comparable to fully fine-tuned models.

2 / 2.1 .. 2.2 body

This unit introduces the kNN-MT paradigm and seq2tree models. kNN-MT enhances NMT model generation by retrieving knowledge from a datastore of decoder hidden states paired with target tokens. Seq2tree models generate abstract syntax trees (ASTs) rather than code snippets, helping ensure syntactic correctness. BertranX is presented as a state-of-the-art seq2tree architecture that uses BERT, a grammar-based decoder, and ASDL-based action sequences.

3 / 3.1 .. 3.2 body

kNN-TRANX is a seq2tree-based approach with separate datastore building and model inferring components. During datastore building, it parses the training dataset's code snippets into abstract syntax trees and stores decoder representations with target rules or primitives in separate syntactic and semantic datastores. During inference, kNN-TRANX generates a context representation and neural network distribution, retrieves a k-nearest-neighbor distribution using syntax constraints and ASDL grammar, and combines the distributions. The meta-k network dynamically weights different retrieval sizes, while the confidence network estimates how to weight the kNN and neural network distributions.

4 / 4.1 .. 4.3 body

This unit reports experiments evaluating kNN-TRANX on the CoNaLa and Django code-generation datasets using BLEU, CodeBLEU, and exact match. It describes kNN-TRANX’s implementation with BertranX, separate syntactic and semantic datastores, and retrieval settings, and compares it with several code-generation models. kNN-TRANX outperforms BertranX and other listed systems, with especially clear gains on the challenging CoNaLa dataset. The unit also analyzes retrieval filtering, datastore composition and size, and model canonical incremental adaptation through datastore-only updates to avoid parameter adaptation.

opening body

This unit evaluates BertranX and kNN-TRANX on the CoNaLa dataset and Django dataset, including ablations of noise filtering, the Confidence Network, and separate datastores. It studies how different Krule and Kpri values affect CoNaLa results, with kNN-TRANX reaching 37.29 BLEU, 39.04 CodeBLEU, and 7.4 EM at Krule=4 and Kpri=64. In an incremental learning scenario, the datastore is updated with 0k, 10k, 50k, or 95k mined data, requiring 17k trainable parameters instead of 122,205k for fine-tuning all parameters. The text reports that updating the datastores improves performance, including when only the semantic datastore is updated.

5 body

This unit reviews code generation and retrieval-augmented models. Yin and Neubig (2018) propose TRANX for generating ASTs, while later work introduces grammar-based decoding, reliability improvements, and test-case-based code selection. It also describes pre-training as a way to incorporate external knowledge and improve downstream performance. Retrieval-based methods include REDCODER, kNN-MT, and Fast kNN-MT, and Figure 5 examines how reducing datastore size affects BLEU and CodeBLEU on the CoNaLa and Django datasets.

6 body

The paper proposes kNN-TRANX, a seq2tree model supported by syntactic and semantic datastores. It reports that kNN-TRANX outperforms the baselines and can switch datastores to provide additional knowledge without fine-tuning the neural network. Experiments show competitive performance against learning-based methods through incremental learning. Table 5 evaluates model canonical incremental adaptation by updating both datastores or only the semantic datastore with external data.

Limitations body

The proposed approach enhances the generalizability of the seq2tree model and enables rapid updates by switching datastores. Incorporating extra datastores requires a similarity search at each inference time step, although only one of the two datastores needs to be retrieved. Additional datastores consume storage space, potentially increasing with more training data, while datastore-pruning approaches can reduce datastore content but degrade model performance.
