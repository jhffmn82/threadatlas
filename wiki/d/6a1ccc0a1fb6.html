GRAG: Graph Retrieval-Augmented Generation

Yuntong Hu, Zhihan Lei, Zheng Zhang, Bo Pan, Chen Ling, Liang Zhao · 2025-07-12 · 14 sections

Abstract written by a model

This document presents Graph Retrieval-Augmented Generation (GRAG), by Yuntong Hu, Zhihan Lei, Zheng Zhang, Bo Pan, Chen Ling, and Liang Zhao of the Department of Computer Science at Emory University. GRAG extends Retrieval-Augmented Generation for networked documents represented as textual graphs, whose nodes and edges carry text. Rather than retrieving isolated documents by text similarity, it retrieves query-relevant textual subgraphs so that Large Language Models can use both content and graph topology for multi-hop reasoning. The paper first situates GRAG among prompt tuning, LLM-based graph work, and graph retrieval methods, arguing that text-trained LLMs do not inherently capture complex graph structure. It formalizes the task as finding an optimal textual subgraph for a query and supplying it to an LLM to improve output relevance. GRAG’s retrieval uses a divide-and-conquer approach: it indexes and ranks K-hop ego-graphs with a pre-trained language model, selects the top-N neighborhoods by cosine similarity to the query, merges them, and applies soft pruning. Soft pruning uses two Multilayer Perceptrons to assign query-dependent scaling factors to nodes and edges; elements less relevant to the query are masked toward zero. This produces a tailored subgraph with linear complexity. For generation, GRAG creates complementary views. Its text view turns retrieved ego-graphs into hierarchical descriptions using BFS and pre-order traversal while retaining extra edges. Its graph view uses a Graph Neural Network and learned relevance scaling factors to encode the pruned subgraph, then aligns graph embeddings with the language model token space. These graph embeddings are combined with query and description text embeddings to guide generation through hard and soft prompts. Experiments on GraphQA, using WebQSP and ExplaGraphs, report that GRAG outperforms standard RAG retrievers, LLM baselines, and fine-tuned Llama2-7b models on reported metrics. Ablations indicate that graph-aware retrieval, graph encoding, pruning, and descriptions matter; 2-hop ego-graphs generally beat 1-hop graphs, while excessive retrieval adds irrelevant information. The conclusion emphasizes stronger detailed multi-hop reasoning and lower training cost because frozen LLMs can outperform fine-tuned models. The main limitation is dependence on effective initial node ranking and pruning when graph structure or node importance is hard to estimate.

Abstract front matter

The abstract introduces Graph Retrieval-Augmented Generation (GRAG) as an approach for handling networked documents that Naive Retrieval-Augmented Generation overlooks. GRAG retrieves textual subgraphs using a divide-and-conquer strategy that finds the optimal subgraph structure in linear time. It integrates textual graphs into Large Language Models through complementary text and graph views for graph context-aware generation. On graph reasoning benchmarks, GRAG significantly outperforms current state-of-the-art RAG methods in scenarios requiring multi-hop reasoning on textual graphs.

Introduction body

The introduction concerns how Large Language Models can use networked documents through Graph Retrieval-Augmented Generation (GRAG). It explains that traditional Retrieval-Augmented Generation retrieves individual documents by text similarity, whereas GRAG retrieves relevant textual subgraphs and incorporates both textual and topological information into generation. GRAG addresses retrieval through ego-graph retrieval followed by graph soft pruning, and addresses generation through hierarchical text descriptions, hard prompts, and soft prompts. Experiments on graph multi-hop reasoning tasks show that GRAG outperforms RAG-based retrievers and LLM baselines, with frozen LLMs using GRAG outperforming fine-tuned LLMs on all tasks.

Related Work / Prompt Tuning .. Retrieval on Graphs body

The unit reviews prompt tuning, LLM applications in graph-related tasks, and retrieval on graphs. Prompt tuning modifies inputs or learns soft prompt embeddings while preserving the original model parameters, with later work extending it to multimodal contexts. LLMs support graph tasks through text embedding and contextual reasoning, but their training on text does not inherently provide understanding of complex graph structure or explicit topology. Graph prompt tuning and retrieval methods address these limitations by incorporating topological information, relevant nodes, triples, paths, or communities.

Problem Formalization body

The unit defines Textual Graphs as graphs with text-attributed nodes and edges. It defines Textual Subgraphs as subgraph structures formed from subsets of a textual graph’s nodes and edges. Graph Retrieval Augmented Generation integrates graph context into retrieval and generation, aiming to retrieve an optimal textual subgraph for a given query and graph. The retrieved subgraph is provided with the query to LLMθ to improve the relevance of generated output.

Methodology .. Textual Subgraph Ranking. The same PLM en- body

GRAG addresses textual subgraph retrieval by searching for important ego-graphs, merging the top-N relevant ones, and applying soft pruning to reduce redundant nodes and edges. Its divide-and-conquer strategy approximates subgraph selection by ranking node-centered neighborhoods and combining the neighborhoods of selected key nodes. GRAG preserves textual and topological information through a graph view of textual graphs using soft prompts and a text view of textual graphs using hierarchical text descriptions. Textual subgraph indexing encodes K-hop ego-graphs with a pre-trained language model, while textual subgraph ranking retrieves the top-N candidates by cosine similarity to the query.

Textual Subgraph Soft Pruning reduces the influence of irrelevant nodes and edges in subgraphs retrieved from graph G. It uses two Multilayer Perceptrons to compute scaling factors from the element-wise distance between node or edge representations and the query. Entities farther from the query receive scalar values closer to zero, effectively masking them. The adaptively masked subgraphs are merged into an optimal subgraph structure tailored to the query with linear complexity.

Textual Graph Augmented Generation / Text View of Textual Graphs. LLMs demonstrate .. Generation Phase. The generation is guided by body

Textual Graph Augmented Generation provides large language models with complementary text and graph views of a textual graph. Text View of Textual Graphs converts retrieved ego-graphs into hierarchical descriptions by using BFS to construct a tree and pre-order traversal to organize node and edge texts, while preserving additional edges. Graph View of Textual Graphs uses a Graph Neural Network with learned relevance scaling factors to encode a soft pruned subgraph and an MLPϕ3 to align its embeddings with the language model’s token space. During the Generation Phase, the model combines the graph embeddings with text embeddings of the query and hierarchical description to produce the generation output.

The experiments evaluate GRAG on the GraphQA benchmark using WebQSP for knowledge graph question answering and ExplaGraphs for common-sense reasoning. GRAG outperforms standard RAG retrievers and LLM baselines, including fine-tuned Llama2-7b models, across the reported metrics. Conclusion body

The paper introduces Graph Retrieval-Augmented Generation (GRAG), extending Retrieval-Augmented Generation (RAG) to graph-based scenarios. GRAG retrieves query-relevant textual subgraphs to enhance the generation capabilities of Large Language Models (LLMs). Its divide-and-conquer retrieval strategy uses K-hop ego-graphs and soft pruning to approximate optimal textual subgraphs, providing graph and text views of a textual graph. Experiments show that GRAG outperforms LLM and RAG-based baselines, especially for detailed, multi-hop reasoning, while enabling a frozen LLM to outperform fine-tuned LLMs at lower training cost.

Limitations body

The unit describes a limitation of GRAG, a framework for graph context-aware generation. GRAG's textual subgraph retrieval depends on the quality of the initial node ranking and pruning mechanism. When graph structure or node importance is difficult to estimate, retrieval performance may be suboptimal. The work was supported by several National Science Foundation and NIH grants.
