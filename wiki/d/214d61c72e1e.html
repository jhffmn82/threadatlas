CausalRAG: Integrating Causal Graphs into Retrieval-Augmented Generation

Nengbo Wang, Xiaotian Han, Jagdip Singh, Jing Ma, Vipin Chaudhary · 2025 · 11 sections
"CausalRAG: Integrating Causal Graphs into Retrieval-Augmented Generation" by Nengbo Wang, Xiaotian Han, Jagdip Singh, Jing Ma, Vipin Chaudhary (2025), licensed CC BY. Shown here as extracted text, with facts drawn from it. https://doi.org/10.18653/v1/2025.findings-acl.1165

Abstract written by a model

The document presents CausalRAG, a retrieval-augmented generation framework for large language models that adds causal reasoning to document retrieval. It begins by situating RAG as a way to supplement LLMs’ pre-trained knowledge with external, dynamically updated information, particularly for academic research. It argues that conventional RAG often breaks contextual integrity through text chunking, relies too heavily on semantic similarity, and can select superficially related but causally irrelevant documents, contributing to bias and hallucinations. Graph-based RAG methods such as GraphRAG can improve context precision through graph ranking and summarization, but may omit relevant material and reduce context recall. CausalRAG addresses these problems by constructing a text-based graph from uploaded documents, with nodes and edges representing entities, concepts, and relationships. It matches a user query to initial nodes, expands through graph edges to locate causal paths, and uses an LLM to estimate paths and refine a causal graph. From this graph it creates a causal summary, which is combined with the query in a refined prompt for the final retrieval-augmented response. Experiments compare CausalRAG with Regular RAG, GraphRAG, and HippoRAG2 on academic papers sampled from OpenAlex. Using answer faithfulness, context recall, and context precision, the reported results show CausalRAG has the strongest overall balance: the highest answer faithfulness and context precision with competitive recall. A case study finds that it better identifies links among influence tactics, buyer attention, and sales contract award than semantic or community-based retrieval. Performance rises as k and s increase, though gains diminish at higher values; k = s = 3 remains competitive. The document concludes that CausalRAG improves retrieval, contextual continuity, response quality, interpretability, and hallucination mitigation, while noting future work on scalable long-context causal retrieval and limitations from LLM knowledge, specialized domains, and causal-path computation costs.
