Limitations The proposed BlendFilter framework introduces a hyper-parameter K to control how many docu- ments we need to retrieve, which might require additional effort to tune. Fortunately, we observe that the model performance is not very sensitive to the hyper-parameter and we set it to a fixed value to achieve a good performance in this paper.
