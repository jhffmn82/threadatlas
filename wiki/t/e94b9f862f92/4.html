This section, in brief. RAG consists of a ranking system R and a parametric generative language model θ. The ranking system first builds a search index I from a collection and then searches it at request time using the user input x. This search produces relevant context segments c, which may be sentences, passages, or entire documents, although the work focuses on passages. The language model generates a response r from x and c embedded in a model-specific instruction template i.

Task Definition RAG consists of a ranking system R and a paramet- ric generative language model θ, where the ranking system can be multi-staged. First, the ranking sys- tem builds a search index I based on a collection. Then, at request time, the index I is searched yield- ing context segments1 c that are relevant to the user input x: c = fI,R(x). Next, the LLM generates a response r based on the context c and user input x both embedded in a model-specific instruction template i: r = fθ(i, x, c). 1The segments can be at different granularities for instance sentences, passages, or entire documents. In this work, we focus on passages. 4
