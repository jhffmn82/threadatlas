This section, in brief. The heterogeneous document question answering task concerns answering a user question using extensive documents. These documents contain textual contents and tabular components. The task defines a function F that takes the combined textual and tabular context along with the question and produces the correct answer.

2 Task Formulation In the context of the heterogeneous document ques- tion answering task, we define the task input as extensive documents, denoted as (T , D) where T denotes the textual contents and D refers to the tabular components. Given a user question q, the objective of this task is to optimize a function F that, given the combined textual and tabular con- text, can produce the correct answer A: F(D, T , q) →A. (1)
