This section, in brief written by a model
The unit reports statistics for MKQA, Tydi QA, XOR-Tydi QA, and Wikipedia, including example counts and median question, answer, or passage lengths across languages. It describes experiments with a multilingual RAG application and Mixtral-8x7B, an instruction-tuned model pretrained on multilingual data with five languages. The researchers observed that models sometimes answered non-English queries in English, so they studied system-prompt strategies that explicitly request replies in the user’s language. The evaluation uses MKQA and XOR-TyDi QA as multilingual QA datasets.

In our preliminary experiments we noticed that models sometimes reply in English even for non-English user queries. This is not an expected behavior and substantially reduces met- rics, calculated over groundtruth answers in user languages. To tackle this, we study various strate- gies for defining the system prompt, e.g. including an explicit instruction to reply in the user language, see Table 2 for all the system prompts that we consider.
