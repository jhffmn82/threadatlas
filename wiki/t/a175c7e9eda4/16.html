  27. Correct language rate (CRL)
This section, in brief. The unit concerns the 9NQ dataset in the KILT benchmark and the evaluation of model-generated responses. Character n-gram recall is computed by splitting ground-truth labels into tokens, extracting character 3-grams, and measuring how many appear in the generated response. The evaluation also controls for correct language rate, which measures the percentage of outputs written in the user's language. Language detection uses the fasttext library and its lid.176.bin model, but language-rate evaluation is limited to responses longer than 20 characters because short sequences produce many errors.

9NQ dataset in KILT benchmark available at https:// huggingface.co/datasets/kilt_tasks recall on character n-gram level. We first split ground-truth labels into tokens, extract all charac- ter 3-grams from each token and evaluate which percentage of such ngrams is present in the model- generated response, see Table 3 for illustration. In addition to the task metric, we also control the correct language rate, CLR, which measures which percentage of model outputs are written in the user language. We detect languages using fasttext library (Joulin et al., 2017, 2016) and its lid.176.bin model10. Due to high erroneous level of language identification for short sequences, we only evaluate the CRL metric for model re- sponses longer than 20 characters.
