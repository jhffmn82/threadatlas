Appendix S3 Glossary of Technical Terms Tokens: In language models, tokens are small units of text (often words or subwords) used by the model to process, represent, or generate text. For example, the sentence “MRI is a diagnostic tool” might be split into tokens like [“MRI”, “is”, “a”, “diagnostic”, “tool”]. Vector Representations: A vector representation (sometimes called an “embedding”) is a way to translate text, images, or other data into a series of numerical values—often stored as a list or “vector”—such that similar content has similar numerical patterns. This allows algorithms to mathematically compare the semantic meaning of different inputs. Text Embedding: A text embedding is a type of vector representation specifically designed for linguistic content. It encodes each text chunk into a fixed-dimensional vector space such that texts with related meanings end up closer together in that space Vector Database: A vector database is a specialized data management system optimized for storing and retrieving vector representations. Traditional databases store and index discrete data types (like numbers or strings), whereas a vector database is designed to handle operations like similarity search (for instance, retrieving the closest vectors to a particular query vector). 39
