This unit presents a method for calculating the FLOPS of a large language model while omitting the lm_head because of its relatively small proportion. It defines the model parameters L, H, K, dh, d, and dmlp, along with per-token costs for QKV transformation, attention, output projection, and the MLP. For a large language model using the Swiglu activation function, total FLOPS are calculated as ninput multiplied by L and the sum of these four costs.

G Computational Load Calculation Here, we present the method for calculating the FLOPS, while omitting the computation of the lm_head (due to its relatively small proportion). Let ninput denote the number of input tokens and ncontext the context length. For a large language model (LLM) employing the Swiglu activation function, the key parameters are: L, H, K, dh, d, dmlp, where • L is the number of layers, • H is the number of attention heads, • K is the number of key-value heads, • dh is the head dimension, • d is the hidden size, and • dmlp is the intermediate (MLP) size. For each token, the per-layer computational costs are defined as follows: 1. QKV Transformation: The cost Cqkv is given by Cqkv = 2 d  H + 2K  dh. 2. Attention Mechanism: The cost Cattn is expressed as Cattn = 2 H dh ncontext. 3. Output Projection: The cost Co is given by Co = 2 d2. 4. Multilayer Perceptron (MLP): The cost Cmlp can be represented as Cmlp = 6 d dmlp. Therefore, the total computational cost (FLOPS) is expressed as: FLOPS = ninput L  Cqkv + Cattn + Co + Cmlp  . 6601
