G Compatibility with Open-weight Models GEAR Results As shown in Table 10, we eval- uate GEAR using popular 7-8B parameter open- weight models, comparing them against a closed- source alternative. On HotpotQA, Llama-3.1-7B surpasses the closed-source alternative, achiev- ing higher recall rates at R@10 and R@15. For MuSiQue and 2Wiki, while the closed-source model maintains a slight superior edge in per- formance, the margin is narrow. Importantly, all tested open-weight models consistently out- perform the previous state-of-the-art, HippoRAG w/IRCoT. This decouples GEAR from the need to use closed-source models, suggesting that state-of- the-art multi-step retrieval can be achieved using more accessible models. Diverse Beam Search Results Expanding upon Table 4, Table 11 demonstrates that diverse beam search consistently improves retrieval performance across both closed-source and open-weight models when using our proposed Hybrid + SyncGE setup. This further confirms the broader applicability of this approach.
