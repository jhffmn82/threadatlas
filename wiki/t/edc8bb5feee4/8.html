The work proposes CODERAG-BENCH, a benchmark for retrieval-augmented code generation across various coding tasks and retrieval sources. Experiments with top-performing retrieval and generation models show that retrieving external documents can greatly benefit code generation. The work finds that retrieval models struggle to find useful documents, while generation models have limited context capacity and RAG abilities, resulting in suboptimal retrieval-augmented code generation results. CODERAG-BENCH is intended to support future advances in this area.

6 Conclusion In this work, we propose CODERAG-BENCH, a benchmark for retrieval-augmented code genera- tion with various coding tasks and retrieval sources. With our experiments with top-performing retrieval and generation models, we show that retrieving external documents can greatly benefit code gener- ation. However, current retrieval models struggle to find useful documents, and generation models have limited context capacity and RAG abilities, both leading to suboptimal RACG results. We hope CODERAG-BENCH can serve as a solid testbed to advance future endeavors in this direction. 3206
