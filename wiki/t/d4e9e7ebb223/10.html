This section, in brief. The unit describes Table Linearization for representing tables as sequences. In the retriever component, the input table is linearized with separation tokens interleaved among table elements to preserve structure. In the reader component, the TaPEx tokenizer linearizes the table with structure-aware separators such as [HEAD] and [ROW]. Examples show how table titles, headers, rows, and cell values are serialized.

A Table Linearization In the retriever component, the input table is lin- earized into a sequence with separation tokens interleaving the table elements to make the in- put structure-aware, e.g. “<SOT> [table title] <EOT> <BOC> mountain peak <SOC> eleva- tion <EOC> <BOR> red slate mountain <SOR> 13,162 ft <EOR> <BOR> ...”. In the reader component, the TaPEx tokenizer linearizes the table with structure-aware separation, for example, “[HEAD] mountain peak | elevation [ROW] 1 : red slate mountain | 13 , 162 ft [ROW] 2 ...”.
