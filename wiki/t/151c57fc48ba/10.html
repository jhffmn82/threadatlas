A Detailed Experiment Settings Training Cost Our experiments are built on top of the RAG research project provided on Hug- gingFace9. We use pytorch-lightning (Falcon and team, 2019) for fine-tuning the model, and use ray (Moritz et al., 2018) and FAISS (Johnson et al., 2019) for distributed retrieval with HNSW index (Malkov and Yashunin, 2020). All the models are trained under FP16 for memory and time efficiency. We use 4 NVIDIA A100 80G GPUs for fine-tuning the retrieve-generate models and 1 NVIDIA A100 9https://github.com/huggingface/transformers/ tree/main/examples/research_projects/rag 1024 80G GPU for inference. Specially, since the ex- periment requires fast retrieval using FAISS, it re- quires approximately 200GB CPU memory for run- ning MSMARCO experiments, and 300GB CPU memory for running KILT-WoW experiments (both training and inference). The memory requirement can be reduced by compressing the HNSW index. Table 10 shows the average runtime for the experi- ments. Since the fine-tuning runtime varies during training as the retriever training on CPU gets faster and faster, we only report the runtime of the first epoch. Note that the training runtime is not very comparable, as it depends largely on the FAISS retrieval. Table 7 shows the trainable parameters of our models.
