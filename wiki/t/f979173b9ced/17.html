This section, in brief. The Locating simulator calculates profits for every country in database D. Algorithm 1 first uses trading_power_estimate to initialize TPcountry(n, c) and TPtotal(n), then repeatedly selects nodes with find_top_n and updates flows with flow_estimation. After all nodes have been simulated, the algorithm calculates profit(c) using LV, IV, and the node's trading-power values. The simulator returns the updated database D.

Locating simulator algorithm Algorithm 1 describes the mechanism of Locating simulator. There are three different functions in the Locating simulator: ‘trading_power_estimate’, ‘flow_estimation’, and ‘find_top_n’. • trading_power_estimate takes the database D as an input, calculates and updates TPcountry(n, c) and TPtotal(n) for all n, c ∈ NodeCountry, and returns updated D. • flow_estimation takes the database D and an objective node obj_n as inputs, calculates and updates flow(obj_n, dest) and IV(dest) for all dest such that (obj_n, dest) ∈F by using Eq. (2), and returns updated D. • find_top_n takes the database D and Sim- ulated_n as inputs and returns a node n ∈ Nodes −Simulated_n such that ∀n’∈Nodes-Simulated_n(n, n’) /∈F. If Nodes − Simulated_n = ∅, it returns NULL.
