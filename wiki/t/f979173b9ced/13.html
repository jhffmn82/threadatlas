The extracted data is stored according to the DB schema for each scenario, and Q is generated by applying components of D to predefined question formats. To control benchmark quality, the Locating scenario includes one problem per country while omitting countries with low TPcountry. The Building scenario excludes problems with multiple answers.

A Appendix A.1 Data collection To collect D, we first select the provided savefile from each game and extract related data by game savefile parser. The extracted data was stored in D according to the DB schema of each scenario. Next, we generate Q by applying components of D into pre-defined question format for each scenario. To control the quality of our benchmark, we consider the following points: • For the Locating scenario, we create one problem for each country. As profit is de- termined by TPcountry, we omit countries with low TPcountry due to their minimal impact on decisions. • For the Building scenario, we filtered prob- lems which have multiple answers.
