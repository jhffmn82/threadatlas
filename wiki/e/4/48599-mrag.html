mRAG in Retrieval-augmented generation in multilingual settings

Association for Computational Linguistics · 2024 · the work’s page · read it where mRAG first appears

Abstract written by a model

mRAG is a multilingual retrieval-augmented generation setting and pipeline, studied with user queries and a datastore in 13 languages. It retrieves context for a query and generates a response from the query and retrieved context, using monolingual English or user-language collections and multilingual collections. The work begins by positioning mRAG as a little-studied setting for evaluating zero-shot systems with off-the-shelf components; multilingual open question answering is its closest line of work, and the NoMIRACL dataset supports robustness evaluation across 18 typologically diverse languages. It then examines open question answering, task-specific prompt engineering, and language-dependent model capabilities. Multilingual-by-design models work across a broad set of languages, while English-centric models work in particular languages. The work develops a strong baseline, emphasizes reliable cross-language and cross-culture information access, and ends by identifying irrelevant retrieval and other limitations as future improvements.

7 sections; each heading opens the text

Abstract

Multilingual retrieval-augmented generation is studied with user queries and a datastore in 13 languages. The work investigates which components and adjustments are needed to build a well-performing mRAG pipeline and identifies several remaining limitations.

Related Work

mRAG is described as not well studied in the literature. The closest line of work to it is multilingual open question answering.

opening .. opening

The unit examines mRAG as a setting in which zero-shot systems can be evaluated using off-the-shelf components. The NoMIRACL dataset provides an evaluation resource for LLM robustness in mRAG across 18 typologically diverse languages.

Multilingual RAG pipeline

The multilingual RAG pipeline retrieves context for a user query and generates a response based on the query and retrieved context. It is evaluated with monolingual collections in English or the user language, as well as multilingual collections.

opening .. opening

The unit concludes that multilingual retrieval-augmented generation capabilities are enabled by multilingual-by-design models across a broad set of languages. English-centric models also show mRAG capabilities in particular languages.

Conclusion

Multilingual RAG is presented as a setting in which reliable information access across different languages and cultures is needed. The work develops a strong baseline pipeline and identifies directions for improving it.

Limitations

mRAG is described as the broader setting for which this evaluation serves as a first step.
