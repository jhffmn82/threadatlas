Abstract

Visual question answering with external data is the task setting represented by the datasets used for the experiments. These experiments assess the appropriateness of the approach.

2. Related Work

Knowledge-based visual question answering has become more difficult through benchmarks such as Encyclopedic-VQA and InfoSeek, which ask about specific entities and often require external knowledge. The described approach retrieves an entity and relevant passages before providing them to a multimodal large language model for answer generation.

4. Experiments / 4.1. Datasets .. 4.5. Limitations and Future Works

Visual question answering accuracy is evaluated on the Encyclopedic-VQA test set and InfoSeek validation set using official evaluation scripts. Retrieved context improves results most when it is relevant, with InfoSeek benefiting from two or three textual chunks and oracle retrieval yielding substantially higher accuracy.
