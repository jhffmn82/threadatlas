Code-switching is a frequent limitation in non-Latin alphabet languages: models insert English named entities or text into user-language responses; instructing user-language names slightly improves character 3-gram recall but does not eliminate it.

Results and discussion .. opening

Code-switching remains a generation problem in which models insert English named entities or other English text into responses in user languages. Adding an instruction to write named entities in the user language slightly improves character 3-gram recall in many cases but does not fully solve the issue.
