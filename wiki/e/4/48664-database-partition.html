database partition in M-RAG: Reinforcing Large Language Model Performance through Retrieval-Augmented Generation with Multiple Partitions

Zheng Wang, Shu Xian Teo, Jieer Ouyang, Yongjun Xu, Wei Shi · 2024

A database partition is a basic entity for RAG execution and retrieval in M-RAG. It supports partition selection for more specific memories, index construction and maintenance, distributed architectures, and privacy protection through access-controlled storage. M-RAG creates multiple homogeneous partitions from a single-source homogeneous dataset and studies partitioning strategies and partition numbers.

Abstract

Introduction

A database partition is treated as a basic entity for executing RAG. The unit examines partitioning strategies and numbers of partitions, and uses partition selection to target more specific memories.

Related Work

A partition serves as a fundamental entity for retrieval in M-RAG instead of the entire database. M-RAG explores partitioning strategies to create multiple homogeneous partitions from a single-source homogeneous dataset.
