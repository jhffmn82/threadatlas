system prompt in Retrieval-augmented generation in multilingual settings

Association for Computational Linguistics · 2024

The system prompt guides a generator LLM and defines response language. It is studied to prevent English replies to non-English queries and affects RAG performance through its formulation. Researchers compare prompts, including explicit instructions to reply in the user’s language and translated versions checked by speakers. The strongest configuration requests a short reply in the user language and translates the prompt into that language, raising Correct Language Rate and overall recall; named-entity instructions only partly reduce code-switching.

Narrative, section by section

3 sections; each heading opens the text

opening

The system prompt is studied as a way to prevent models from replying in English to non-English user queries. The researchers test strategies including an explicit instruction to reply in the user’s language, with some prompts translated using Google Translate and checked by native or fluent speakers.

opening .. opening

System prompts are compared in Table 5. The strongest configuration explicitly requests a short reply in the user language and translates the system prompt into that language.

Results and discussion .. opening

The system prompt substantially affects the language of generated responses and overall recall. Explicitly naming the user language and translating the system prompt into that language raises Correct Language Rate, while instructions to write named entities in the user language only partly resolve code-switching.
