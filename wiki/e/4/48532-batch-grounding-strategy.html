Batch grounding strategy is a grounding strategy for retrieved documents that divides lengthy reference lists into batches, examines them sequentially, and revises an answer when relevant evidence can be cited. 3 .. 3.3

The batch grounding strategy divides retrieved documents into batches and examines them sequentially. Grounding stops for the current iteration when a batch provides relevant evidence; if no batch does, the original generated answer is output as a backup.

6 / 6.1 .. 6.3

The batch grounding strategy helps the model handle reference document lists containing irrelevant information. Removing it lowers F1 from 52.26 to 47.27 and Acc from 47.27 to 45.03.
