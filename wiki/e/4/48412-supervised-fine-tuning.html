Zhenrui Yue, Huimin Zeng, Yimeng Lu, Lanyu Shang, Yang Zhang, and Dong Wang · 2024

Supervised fine-tuning teaches a pretrained language model initial counter-misinformation responses, producing a reference model before potentially unstable reinforcement learning for complex tasks.

supervised fine-tuning in VISA: Retrieval Augmented Generation with Visual Source Attribution

Xueguang Ma, Shengyao Zhuang, Bevan Koopman, Guido Zuccon, Wenhu Chen, Jimmy Lin · 2025

Supervised fine-tuning uses a dedicated VISA task dataset because VISA is challenging for zero-shot prompting with existing instruction-tuned VLMs; fine-tuning on crafted data substantially improves visual source attribution, source grounding, answer generation, and task execution.

Supervised fine-tuning is needed because VISA remains challenging when performed through zero-shot prompting with existing instruction-tuned VLMs. It is applied using a dedicated VISA task dataset.

Fine-tuning on crafted training data enables models to execute visual source attribution more effectively. It produces substantial gains over zero-shot prompting and improves both source grounding and answer generation.
