Abstract written by a model

In “Evidence-Driven Retrieval Augmented Response Generation for Online Misinformation,” supervised fine-tuning teaches a pretrained language model initial counter-misinformation responses and produces a reference model before reinforcement learning. In “Reducing hallucination in structured outputs via Retrieval-Augmented Generation,” standard LLM supervised fine-tuning trains the LLM on retriever-augmented examples with short prompts and expected workflow JSON outputs. In “VISA: Retrieval Augmented Generation with Visual Source Attribution,” supervised fine-tuning uses a dedicated VISA task dataset to improve visual source attribution, source grounding, answer generation, and task execution.
