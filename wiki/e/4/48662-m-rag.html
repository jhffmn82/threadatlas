M-RAG in M-RAG: Reinforcing Large Language Model Performance through Retrieval-Augmented Generation with Multiple Partitions

Zheng Wang, Shu Xian Teo, Jieer Ouyang, Yongjun Xu, Wei Shi · 2024

M-RAG is a novel multiple partition paradigm and framework for retrieval-augmented generation across multiple database partitions. It treats each partition as a retrieval entity and addresses three central challenges: database partitioning, partition selection, and memory quality. The database can be partitioned through Randomization, Clustering, Indexing, or Category; Indexing is used for summarization, Randomization for translation, and Category for dialogue generation. M-RAG then follows Retrieval-then-Generation with two agents: Agent-S selects database partitions, while Agent-R selects and refines retrieved memories. Built on multi-agent reinforcement learning, it collaboratively trains Agent-S and Agent-R end to end, aligning the training objective with text generation tasks; during inference, it supports large language model use with the refined database. Experiments use three language model architectures, 4-bit quantization, Python 3.7, and LlamaIndex, with four partitions for Agent-S and a candidate pool of three for Agent-R. Across seven datasets and three language generation tasks—text summarization, machine translation, and dialogue generation—M-RAG consistently outperforms baseline methods including Naive RAG, Self-RAG, and Selfmem. Reported improvements over the best baseline are 11% for summarization, 8% for translation, and 12% for dialogue generation, including results on XSum, JRC-Acquis, DailyDialog, and models such as Mixtral 8 × 7B, Gemma 7B, and Mistral 7B.

Narrative, section by section

6 sections; each heading opens the text

Abstract

M-RAG is the proposed multiple partition paradigm for RAG. It consistently outperforms various baseline methods, improving performance by 11% for text summarization, 8% for machine translation, and 12% for dialogue generation.

Introduction

M-RAG is introduced as a solution for RAG across multiple database partitions. It addresses partitioning, partition selection, and memory quality through Agent-S, Agent-R, and multi-agent reinforcement learning, and improves results across summarization, machine translation, and dialogue generation.

Related Work

M-RAG is introduced as a framework built upon multi-agent reinforcement learning for a multiple partition setting. It uses two agents, Agent-S and Agent-R, to focus on retrieval and generation, respectively, and supports text summarization, machine translation, and dialogue generation.

Methodology .. 3.4 / The M-RAG Framework

M-RAG partitions a database into multiple subsets, uses Agent-S for partition selection, and uses Agent-R to refine retrieved memories. It trains both agents collaboratively with multi-agent reinforcement learning and uses the refined database during inference.

Experiments / Experimental Setup .. Experimental Results

M-RAG is evaluated across summarization, machine translation, and dialogue generation tasks and generally outperforms Naive RAG, Self-RAG, and Selfmem. It achieves strong results with Mixtral 8×7B, improves over Selfmem by 8% in XSum R-1, 11% in BigPatent R-1, 8% in Es→En translation, and 12% in dialogue B-1, and also outperforms Selfmem on Gemma 7B and Mistral 7B.

Conclusion and Limitations

M-RAG is a novel framework with multi-agent reinforcement learning for handling RAG across multiple partitions. Its training objective is aligned with text generation tasks, and experiments on seven datasets validate its effectiveness.
