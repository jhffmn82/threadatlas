StarCoderBase

object · 1 work · 4 quoted facts · 2 connections
Also called: StarCoderBase (15.5B), StarCoderBase-1B, StarCoderBase-3B, StarCoderBase-7B

Abstract written by a model

StarCoderBase is an LLM family with 1B, 3B, 7B, and 15.5B parameter variants, selected for pretraining on JSON and multiple programming languages. After fine-tuning, it produces valid JSON. Evaluation with and without retrieval shows larger models generally improve RAG; 7B offers the best trade-off near 15.5B performance, while 3B suits limited infrastructure.

StarCoderBase is in one work on this site, Reducing hallucination in structured outputs via Retrieval-Augmented Generation. This is the abstract a model wrote of it from that work.

StarCoderBase is fine-tuned in 1B, 3B, 7B, and 15.5B parameter variants to measure the impact of model size on final metrics. It is selected because it was pretrained on JSON and multiple programming languages.

5 / 5.1 .. 5.5

StarCoderBase models from 1B to 15.5B parameters are evaluated with and without a retriever. Larger StarCoderBase models generally improve RAG performance, with StarCoderBase-7B providing the best trade-off because its performance is close to that of the 15.5B model.
