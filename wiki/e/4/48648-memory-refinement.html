Abstract written by a model

is_performed_by Agent-R [within a selected partition] Memory refinement generates a candidate pool of responses for a retrieved input and evaluates each candidate by using it to produce a hypothesis. A candidate is retained when it improves the task metric, and the corresponding memory response and current hypothesis are updated.
