Real-time Information Needs Detection in DRAGIN: Dynamic Retrieval Augmented Generation based on the Information Needs of Large Language Models

Weihang Su, Yichen Tang, Qingyao Ai, Zhijing Wu, Yiqun Liu · 2024

Real-time Information Needs Detection is DRAGIN’s retrieval activation method and timing module, deciding when to retrieve during generation. It uses Transformer-based LLM self-attention and evaluates each generated token’s uncertainty, semantic contribution, and influence on following context. It quantifies uncertainty with entropy, influence with maximum following-token attention, and semantic significance through a binary stopword filter. Multiplying these factors yields a comprehensive token score; retrieval is activated when the score exceeds a predefined threshold. In DRAGIN, it provides timely activation. Threshold changes yield relatively stable HotpotQA performance, while higher thresholds reduce retrieval frequency and can trade efficiency against output accuracy.

Introduction

Real-time Information Needs Detection is DRAGIN's strategy for deciding when to retrieve. It considers the language model's uncertainty about generated content, each token's influence on subsequent tokens, and each token's semantic significance.

3 .. 3.3

Real-time Information Needs Detection identifies when retrieval should be activated by evaluating token uncertainty, semantic contribution, and influence on subsequent context. It computes a score by multiplying token entropy, maximum following-token attention, and a binary indicator that filters stopwords, and triggers retrieval when the score exceeds a threshold.

RIND is used to determine when DRAGIN activates retrieval. Varying its threshold produces relatively stable performance on HotpotQA, while higher thresholds reduce retrieval frequency and can balance efficiency against output accuracy.
