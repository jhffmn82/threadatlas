Hybrid Retriever

object · 1 work · 5 quoted facts · 2 connections
Also called: hybrid retriever, retriever, retriever R

Abstract written by a model

Hybrid Retriever is a retrieval component that segments long-context paragraphs into overlapping chunks, merges short final chunks, then recalls relevant chunks using E5-large for coarse retrieval, mMiniLM for fine-grained retrieval, and FAISS efficiently.

Hybrid Retriever is in one work on this site, LongRAG: A Dual-Perspective Retrieval-Augmented Generation Paradigm for Long-Context Question Answering. This is the abstract a model wrote of it from that work.

The Hybrid Retriever segments long-context paragraphs into overlapping chunks, merges short final chunks with preceding chunks, and recalls relevant chunks for a question. It uses an E5-large dual encoder for coarse retrieval, an mMiniLM cross encoder for fine-grained retrieval, and FAISS for efficient implementation.
