hierarchical retrieval

process · 1 work · 4 quoted facts · 2 connections
Also called: hierarchical retrieval approach, hierarchical retrieval method, hierarchical retrieval pipeline

Abstract written by a model

The hierarchical retrieval pipeline gives Wiki-LLaVA access to an external knowledge source, supplying relevant passages as additional LLM context for questions needing precise external information. It first searches for entities using visual features, then retrieves textual chunks associated with selected entities, using approximate k-nearest-neighbor search through a Faiss HNSW index with 32 links per vertex.

Abstract

The hierarchical retrieval pipeline provides access to the external knowledge source and retrieves relevant passages for use as additional context for the LLM.

1. Introduction

Hierarchical retrieval is used by Wiki-LLaVA to identify relevant passages from retrieved documents. The approach supports the model in obtaining more precise information for questions requiring external knowledge.

4. Experiments / 4.1. Datasets .. 4.5. Limitations and Future Works

The hierarchical retrieval method first searches for entities using visual features and then retrieves textual chunks associated with the selected entities. It uses approximate k-nearest-neighbor search with a Faiss HNSW index containing 32 links per vertex.
