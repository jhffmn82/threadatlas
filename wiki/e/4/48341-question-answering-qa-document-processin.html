Question-Answering (QA) document processing system in Retrieval-Augmented Generation Approach: Document Question Answering using Large Language Model

Kurnia Muludi, Kaira Milani Fitria, Joko Triloka, Sutedi · 2024

The Question-Answering (QA) document processing system is a document question-answering system designed to reduce the time, errors, and inefficiency of manual document reading and processing. Users upload multiple PDF or other external documents, which the system converts into embedded vector representations. Using Retrieval-Augmented Generation, GPT-3.5, LangChain, FAISS, and ChatGPT, it retrieves relevant document and supplementary information to answer questions through a chatbot. Answers are based on the submitted source documents, and the chatbot stores communication history. Reported results include 96% accuracy on its dataset and 95.5% on the SQuAD dev dataset, outperforming another document QA application in accuracy on both datasets. It also reports ROUGE-L, BERTScore, BLEU precision, and Retrieval-Augmented Generation Jaccard-similarity results across both datasets.

The Question-Answering (QA) document processing system is introduced to reduce the time, errors, and inefficiency involved in manually reading and processing documents. It allows users to ask questions about processed documents and receive answers based on the document text.

The question-answering system processes external documents and answers user questions through a chatbot interface. It uses Retrieval Augmented Generation, LangChain, FAISS, and ChatGPT to retrieve relevant information and generate responses.

The proposed document QA system accepts multiple PDF documents, converts them into vector representations with embeddings, and provides document-based answers through a chatbot that stores the communication history. It achieved 96% accuracy on our dataset and 95.5% on the SQuAD dev dataset, while also outperforming the other document QA application on ROUGE-L, BERTScore, BLEU precision, and Jaccard Similarity.

proposed document QA system in Retrieval-Augmented Generation Approach: Document Question Answering using Large Language Model

Kurnia Muludi, Kaira Milani Fitria, Joko Triloka, Sutedi · 2024

The proposed document QA system is a Question-Answering document-processing model that uses Retrieval-Augmented Generation, with LangChain, FAISS, and a Streamlit web interface. It loads documents, splits them into text chunks, converts chunks to embeddings, stores them in a vector database, and semantically searches for user queries. Retrieved context is sent to ChatGPT, and generated answers are delivered through Streamlit. It achieved 96% accuracy on its dataset and 95.5% on the SQuAD dev dataset, outperforming tested commercial QA applications across accuracy, ROUGE-L, BERTScore, BLEU precision, Jaccard similarity, keyword extraction, and text similarity, with superior precision, recall, and F1-Score. Its scalability could be improved for broader applications.

The proposed document QA system loads documents, divides them into text chunks, converts the chunks into embeddings, stores them in a vector database, and performs semantic searches for user queries. Retrieved context is sent to ChatGPT, whose generated answers are delivered to the user through a Streamlit interface.

V.

The proposed QA system integrates Retrieval-Augmented Generation for document processing. It achieved 96% accuracy on our dataset and 95.5% accuracy on the SQuAD dev dataset, outperforming other tested QA applications in accuracy, ROUGE-L, BERTScore, BLEU precision, and Jaccard Similarity.
