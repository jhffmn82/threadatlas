method · 2 works · 8 quoted facts · 2 connections
Also called: SR-RAG, Single-round RAG (SR-RAG)

Abstract written by a model

In "DRAGIN: Dynamic Retrieval Augmented Generation based on the Information Needs of Large Language Models," SR-RAG retrieves relevant passages before generation using the initial input as the query and adds them to the LLM's input. In "DioR: Adaptive Cognitive Detection and Contextual Retrieval Optimization for Dynamic Retrieval-Augmented Generation," Single-round RAG is described as a single-turn retrieval method that retrieves passages from external corpora using an initial query and appends them to the LLM input.
