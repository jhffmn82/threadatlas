character 3-gram recall in BERGEN: A Benchmarking Library for Retrieval-Augmented Generation

David Rau, Hervé Déjean, Nadezhda Chirkova, Thibault Formal, Shuai Wang, Stéphane Clinchant, Vassilina Nikoulina · 2024

Character 3-gram recall is a multilingual evaluation metric for named-entity transliterations, extracting ground-truth character 3-grams and checking generated responses; it outperforms word-level matching and correlates better with LLMeval.

Narrative, section by section

1 section; each heading opens the text

H

Character 3-gram recall is proposed to handle transliterations of named entities that word-level matching misses. It is computed by extracting character 3-grams from ground-truth tokens and measuring their presence in the generated response, and it correlates better with LLMeval than several other surface-based metrics.

character n-gram recall in Retrieval-augmented generation in multilingual settings

Association for Computational Linguistics · 2024

Character n-gram recall is an evaluation metric for generator models and retrieval settings, designed for possible transliterations of named entities. It measures the percentage of ground-truth character n-grams present in responses; character 3-gram recall varies by model, language, retrieval, and prompts.
