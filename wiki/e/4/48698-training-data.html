Abstract written by a model

The entity is LLM training data considered as a potential source of privacy leakage in RAG systems. Pre-training and fine-tuning datasets may contain private information that models memorize and reproduce, including targeted information or text following known prefixes; extraction attacks demonstrate this risk. The records examine whether retrieval data changes such leakage. Incorporating retrieval data reduces models’ tendency to output memorized training-data information, while W3C-Email retrieval data increases their tendency to output retrieval data instead. The work concludes that using retrieval-augmented generation to safeguard training data remains an open research question.

Abstract

LLM training data is found to experience reduced leakage when large language models use retrieval-augmented generation.

1 / Introduction

The pre-training/fine-tuning dataset is identified as a potential source of private information that an LLM may memorize and leak. The unit finds that incorporating retrieval data can reduce the LLM's tendency to output memorized information from this dataset.

2 / Related Work / 2.1 / Retrieval-Augmented Generation (RAG) .. 2.2 / Privacy Risk of Large Language Models

Pre-training corpora can contain information that large language models memorize and inadvertently reveal. Data extraction attacks have demonstrated that models can recall and reproduce segments of these corpora.

3 / Method / 3.1 / Background and Threat Model .. 3.3 / Privacy Leakage on LLM Training Data

Training data is examined as a possible source of information leakage from LLMs. The unit focuses on targeted private information and memorized text reproduced after providing known prefixes.

5 / RQ2: Can retrieval data affect the / 5.1 / Evaluation setup .. 5.4 / Discussions & Practical Implications

The unit investigates whether retrieval data changes the model's tendency to reproduce information from its training data. Retrieval integration makes the model less likely to output training data, while W3C-Email retrieval data makes it more likely to output retrieval data instead.

7 / Limitations

Using retrieval-augmented generation systems to safeguard training data is identified as an open research question.
