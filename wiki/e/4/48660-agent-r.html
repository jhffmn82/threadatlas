Agent-R in M-RAG: Reinforcing Large Language Model Performance through Retrieval-Augmented Generation with Multiple Partitions

Zheng Wang, Shu Xian Teo, Jieer Ouyang, Yongjun Xu, Wei Shi · 2024

Agent-R is a memory-refinement agent in M-RAG that improves retrieved memories after Agent-S selects a partition. It iteratively uses LLMs to generate a pool of candidate memories or responses, selects memories that improve hypothesis generation, and triggers boosting when it finds a higher-quality hypothesis. Its reward is improvement in a task-specific metric such as ROUGE or BLEU, and its cumulative reward is shared with Agent-S. Agent-R is a two-layer feedforward neural network with a 25-neuron tanh first layer and a K-neuron linear second layer; K is set to 3. It is trained with Deep Q-Network replay memory, while LLM parameters remain fixed; LLM queries limit training efficiency.

Narrative, section by section

4 sections; each heading opens the text

Introduction

Agent-R iteratively generates a pool of candidate memories using Large Language Models after a partition has been selected. It evaluates candidates by using them to generate hypotheses and triggers a boosting process when a higher-quality hypothesis is identified.

Methodology .. 3.4 / The M-RAG Framework

Agent-R refines memories within the partition selected by Agent-S by generating candidate responses and selecting candidates that improve the hypothesis. Its reward is the improvement in a task-specific metric, such as ROUGE or BLEU, and its cumulative reward is shared with Agent-S.

Experiments / Experimental Setup .. Experimental Results

Agent-R is a two-layer feedforward neural network that selects memories from a candidate pool, with K empirically set to 3. Replacing it with a greedy rule reduces XSum R-1 from 48.13 to 45.75, while performance improves through K=3 and then remains relatively stable.

Conclusion and Limitations

Only the parameters of Agent-S and Agent-R are trained, while the parameters of the LLMs remain fixed. Training efficiency is limited because the LLMs must be queried during the training process.
