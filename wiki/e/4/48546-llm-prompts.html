Abstract written by a model

In "BERGEN: A Benchmarking Library for Retrieval-Augmented Generation," LLM prompts use one general prompt to reduce variation and simplify experiments, instructing a large language model to extract relevant information and answer briefly from retrieved passages or without document context. In "Retrieval augmented text-to-SQL generation for epidemiological question answering using electronic health records," LLM prompting translates natural-language questions into SQL queries with medical-entity placeholders and, when needed, articulates answers from retrieved data. In "RetrievalQA: Assessing Adaptive Retrieval-Augmented Generation for Short-form Open-Domain Question Answering," prompt templates (also called prompts) work well in reported experiments but may be sensitive to LLMs, while optimal templates could improve performance. In "RAG LLMs are Not Safer: A Safety Analysis of Retrieval-Augmented Generation for Large Language Models," the template (also called L) combines instruction, retrieved documents, and a user query into structured model input.
