BERTScore in Retrieval-Augmented Generation Approach: Document Question Answering using Large Language Model

Kurnia Muludi, Kaira Milani Fitria, Joko Triloka, Sutedi · 2024

BERTScore is a performance metric for text generation evaluation based on contextual embeddings. It evaluates semantic similarity between candidate and reference text despite differing sentence order, using cosine-similarity token matching to calculate precision, recall, and F1-Score. In evaluation, it showed the proposed QA system consistently higher scores than other applications.
