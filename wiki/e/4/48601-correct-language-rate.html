Correct Language Rate in Retrieval-augmented generation in multilingual settings

Association for Computational Linguistics · 2024

Correct Language Rate (CLR) is an evaluation metric that measures the percentage of model outputs written in the user’s language, evaluated only for responses longer than 20 characters because language identification is highly erroneous for short sequences. It is reported for generator models and retrieval settings. CLR improves when prompts explicitly request the user language and are translated into it; Command-R-35B and SOLAR-10.7B often exceed 95%, and English is always 100% in Table 6. High CLR is necessary but not sufficient for high overall performance.

opening .. opening

Correct language rate measures whether responses use the intended language. It improves substantially when prompts explicitly request a reply in the user language and are translated into that language, with Command-R-35B reaching near-perfect or perfect scores in many settings.

Results and discussion .. opening

Correct Language Rate measures how often a model replies in the user's language. Command-R-35B and SOLAR-10.7B generally achieve rates above 95% in most cases when the system prompt is translated and explicitly specifies the user language, but high Correct Language Rate alone does not guarantee high overall performance.
