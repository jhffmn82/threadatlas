In Wiki-LLaVA: Hierarchical Retrieval-Augmented Generation for Multimodal LLMs, CLIP is a pre-trained visual model that encodes images and text to compute image–title similarity, retrieves target entities from query images, and provides LLaVA’s visual encoder. CLIP in Wiki-LLaVA: Hierarchical Retrieval-Augmented Generation for Multimodal LLMs

Davide Caffagni · 2024 · the work’s page · read it where CLIP first appears

Abstract written by a model

CLIP is a pre-trained visual model used in a hierarchical retrieval pipeline. With the CLIP ViT-L/14@336 backbone, it encodes images and text to compute image–title similarity, retrieve target entities from query images, and provide LLaVA’s visual encoder. It retrieves more successfully from the 100k-entry InfoSeek knowledge base than the 2M-entry Encyclopedic-VQA knowledge base; errors can yield irrelevant passages.

CLIP in Ask in Any Modality

Mohammad Mahdi Abootorabi, Amirhosein Zobeiri, Mahdi Dehghani, Mohammadali Mohammadkhani, Bardia Mohammadi, Omid Ghahroodi, Mahdieh Soleymani Baghshah, Ehsaneddin Asgari · 2025 · the work’s page · read it where CLIP first appears

Abstract written by a model

CLIP is a multimodal encoder that aligns visual and textual modalities through contrastive learning, embedding images and queries in a shared space. Early methods faced retrieval-precision and computational-cost trade-offs; later it supports retrieval and score fusion in named approaches.

Narrative, section by section written by a model

1 section; each heading opens the text

3.2

CLIP is used to embed images and queries into a shared space in Wiki-LLaVA, C3Net, Riedler and Langer, and MegaPairs. It also contributes to score fusion in the interleaved image-text approach of Sharifymoghaddam et al. (2024), while MegaPairs combines CLIP-based retrieval with MLLM-based retrieval.
