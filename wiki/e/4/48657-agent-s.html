Agent-S in M-RAG: Reinforcing Large Language Model Performance through Retrieval-Augmented Generation with Multiple Partitions

Zheng Wang, Shu Xian Teo, Jieer Ouyang, Yongjun Xu, Wei Shi · 2024

Agent-S is a partition-selection agent in M-RAG that iteratively selects one database partition for training inputs, inference queries, and retrieval. It uses reinforcement learning in a Markov Decision Process and a bandit setting to optimize its policy. Its state uses the maximum semantic similarity between an input and memories in each partition, and it shares a reward with Agent-R based on improvements in the generated hypothesis. Trained with Deep Q-Network and replay memory, it is a two-layer feedforward neural network with a 25-neuron tanh layer and an M-neuron linear layer. Experiments set M=4; removing Agent-S reduces XSum R-1. Only Agent-S and Agent-R parameters are trained, while fixed LLM queries limit training efficiency.

Narrative, section by section

4 sections; each heading opens the text

Introduction

Agent-S iteratively selects one partition from several available partitions. It is optimized through reinforcement learning within a Markov Decision Process to select suitable partitions for input queries.

Methodology .. 3.4 / The M-RAG Framework

Agent-S selects a database partition for a training input or inference query. Its state is based on the maximum semantic similarity between the input and memories in each partition, and its shared reward reflects improvements in the generated hypothesis.

Experiments / Experimental Setup .. Experimental Results

Agent-S is a two-layer feedforward neural network that selects among partitioning actions, with M empirically set to 4. Removing Agent-S and using a single database reduces XSum R-1 from 48.13 to 44.20, while M=4 provides the best reported effectiveness and reasonable runtime.

Conclusion and Limitations

Only the parameters of Agent-S and Agent-R are trained, while the parameters of the LLMs remain fixed. Training efficiency is limited because the LLMs must be queried during the training process.
