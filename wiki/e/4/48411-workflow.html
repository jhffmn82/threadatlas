Narrative, section by section

3 sections; each heading opens the text

Abstract

Structured output represents the workflows produced from natural language requirements. Retrieval-Augmented Generation improves its quality.

3 .. 3.2

The workflow is generated from a user request and consists of related steps represented in structured JSON. Its required steps and, when applicable, table names are included among the retriever suggestions during LLM training.

5 / 5.1 .. 5.5

The generated workflow must follow the expected JSON schema and contain steps and tables consistent with the user query. Workflow failures arise when retrieval omits crucial components or when the LLM does not generate the desired structure for logic-related steps.
