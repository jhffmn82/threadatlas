LLaVA

object · 1 work · 7 quoted facts · 2 connections
Also called: LLaVA family of models, LLaVA model, MLLM, reference MLLM

Abstract written by a model

LLaVA is a reference multimodal large language model. It introduces multimodal instruction tuning using a GPT-4-collected curated dataset, combining a pre-trained Vicuna large language model with a CLIP-based visual encoder through an MLP adapter. It extracts image features and prepends visual tokens to the system prompt.

LLaVA is in one work on this site, Wiki-LLaVA: Hierarchical Retrieval-Augmented Generation for Multimodal LLMs. This is the abstract a model wrote of it from that work.
