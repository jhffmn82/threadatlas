LLaVA in Wiki-LLaVA: Hierarchical Retrieval-Augmented Generation for Multimodal LLMs

Davide Caffagni · 2024

LLaVA is a reference multimodal large language model. It introduces multimodal instruction tuning using a GPT-4-collected curated dataset, combining a pre-trained Vicuna large language model with a CLIP-based visual encoder through an MLP adapter. It extracts image features and prepends visual tokens to the system prompt.

2. Related Work

LLaVA introduced instruction tuning in the multimodal domain using a curated dataset collected with GPT-4. Its approach is described as one of the most promising recipes for building multimodal large language models.

3. Proposed Method .. 3.2. Training

LLaVA is used as the reference multimodal large language model in the method. It combines a pre-trained Vicuna large language model with a CLIP-based visual encoder through an MLP adapter.
