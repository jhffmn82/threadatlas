Wiki-LLaVA

approach · 1 work · 27 quoted facts · 12 connections
Also called: Wiki- LLaVA, our approach, our model, proposed approach, proposed solution

Abstract written by a model

Wiki-LLaVA is a retrieval-augmented multimodal large language model and an approach for augmenting an existing MLLM, specifically LLaVA, with an external knowledge source of multimodal documents. It is designed to answer questions requiring external knowledge without significantly changing the MLLM’s structure. Its architecture comprises a visual encoder, a knowledge base, and a hierarchical retrieval module. The pipeline uses CLIP-based retrieval to identify relevant entities and Contriever-based passage retrieval to find textual chunks; selected document parts are then supplied as additional MLLM input context. Wiki-LLaVA uses Vicuna-7B as its language model and can be fine-tuned on Encyclopedic-VQA and InfoSeek, with LLaVA-Instruct as supplementary data. Extensive experiments evaluate it on visual-question-answering datasets with and without retrieved Wikipedia context, including settings using oracle entities. Results show improved effectiveness for questions and dialogues while maintaining proficiency across tasks; oracle retrieval improves performance substantially, and multiple textual chunks particularly benefit InfoSeek. Its main limitation is entity-retrieval quality, since irrelevant retrieved content can be passed to the MLLM.

Abstract

Wiki-LLaVA is an approach for integrating an external knowledge source of multimodal documents into multimodal LLMs. It uses a hierarchical retrieval pipeline to retrieve relevant passages and employ them as additional context for the LLM.

1. Introduction

Wiki-LLaVA is an MLLM augmented with retrieval capabilities from external sources. It uses a hierarchical retrieval pipeline to provide relevant passages to the MLLM without changing its structure, improving answers to questions that require external knowledge.

2. Related Work

Wiki-LLaVA augments a multimodal large language model with external knowledge through a hierarchical retrieval pipeline. Its architecture uses a visual encoder, CLIP-based retrieval, Contriever-based passage retrieval, and an adapter, with knowledge drawn from a multimodal document base.

3. Proposed Method .. 3.2. Training

Wiki-LLaVA augments LLaVA with external knowledge retrieved from an external memory and supplied as additional input context. It comprises a visual encoder, a knowledge base, and a hierarchical retrieval module.

4. Experiments / 4.1. Datasets .. 4.5. Limitations and Future Works

Wiki-LLaVA is evaluated with and without retrieved Wikipedia context, using CLIP to retrieve entities and textual chunks or using oracle entities. Its performance improves substantially with oracle retrieval, while multiple textual chunks particularly benefit InfoSeek.

5. Conclusion

Wiki-LLaVA is an architecture for augmenting an existing MLLM with external knowledge. It uses a hierarchical architecture to retrieve documents and elicit selected parts for inclusion in the MLLM input context, improving effectiveness on questions and dialogues while maintaining proficiency across different tasks.
