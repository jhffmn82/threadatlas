Abstract written by a model

In "An Information Bottleneck Perspective for Effective Noise Filtering on Retrieval-Augmented Generation," supervised fine-tuning trained a noise filter on pseudo-SFT tuples using negative log-likelihood. In "LongRAG: A Dual-Perspective Retrieval-Augmented Generation Paradigm for Long-Context Question Answering," supervised fine-tuning improved component instruction following and helped fine-tuned small models outperform larger non-fine-tuned online models in ablations. In "TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text," SFT was the lightweight supervised fine-tuning process used to adapt a base large language model to TurboRAG’s independent-mask, reordered-position cache layout.

SFT in TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text

Songshuo Lu · 2025 · the work’s page · read it where SFT first appears

Abstract written by a model

SFT is the lightweight supervised fine-tuning process used by TurboRAG to adapt a base large language model to its independent-mask, reordered-position cache layout. It replaces standard SFT attention masks and position embeddings with those required for cache-concatenation inference. TurboRAG trains Qwen2-7B models on an equal mix of document-QA and general-task data, using AdamW, 32 NVIDIA A100 80GB GPUs, batch size 256, and about 888 GPU-hours.

Narrative, section by section written by a model

3 sections; each heading opens the text

1 / Introduction .. Contributions

TurboRAG performs lightweight supervised fine-tuning so the base large language model can seamlessly consume its independent-mask and reordered-position cache layout.

3 / Methodology .. 3.4 / The TurboRAG Pipeline

Supervised fine-tuning normally uses the standard attention mask and position embeddings. TurboRAG instead uses the attention masks and position embeddings expected during its cache-concatenation inference process.

4 / Experiments .. 4.5 / Batch Scaling

SFT is used to train TurboRAG models based on Qwen2-7B with a dataset containing 50% document-QA data and 50% general tasks. The training uses 32 NVIDIA A100 80GB GPUs, a batch size of 256, and approximately 888 GPU-hours.
