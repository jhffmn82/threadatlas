Narrative, section by section

3 sections; each heading opens the text

Abstract

RAG evaluation is described as challenging because unified evaluation criteria and annotated datasets are lacking. The unit presents RAGBench and TRACe as resources for holistic, explainable, and actionable evaluation, and reports that LLM-based evaluation methods struggle to match a finetuned RoBERTa model.

Introduction

RAG evaluation is presented as necessary for comparing and tuning multiple system configurations for particular applications. Existing evaluation work lacks unified benchmarks, uses varying metric definitions, and often relies on small, application-specific datasets.

Related Work .. Finetuned RAG evaluation models

RAG evaluation includes assessing context relevance, answer relevance, faithfulness, hallucination, attribution, retriever relevance, adherence, and completeness. The unit reviews LLM-judge, heuristic, and fine-tuned NLI approaches to this task.
