JSON output document in Reducing hallucination in structured outputs via Retrieval-Augmented Generation

Patrice Béchard · 2024

JSON documents represent workflows as JSON objects for steps, relationships, triggers, and sometimes required database tables. Retrieved JSON objects are supplied to an LLM so it can generate valid, executable structured output by copying relevant objects. The documents serve as expected workflow ground truth for evaluating generation and retriever coverage, while a siamese transformer encoder converts them into fixed-length vectors.

Narrative, section by section

4 sections; each heading opens the text

1

JSON documents represent workflows, including workflow steps and properties that identify relationships between steps. They may also include a trigger step and, in some cases, a database table name required by that trigger.

2

The JSON output document is generated from retrieved JSON objects rather than only retrieved factual information. Its validity and executability are important goals of the approach.

3 .. 3.2

JSON objects represent steps or tables for retriever training and retrieval. The LLM is given relevant JSON objects in its prompt so it can copy them during structured output generation.

4 / 4.1 .. 4.3

JSON documents represent the expected workflows and contain triggers, steps, and, when required, tables. They are used as ground truth for evaluating generation and retriever coverage.
