Abstract written by a model

In Retrieval-Augmented Controllable Review Generation, automatic evaluation compares models using BLEU-based content similarity and rating classification accuracy, with GEN-C-F (RL) performing best on rating accuracy and both GEN variants outperforming baselines in generation quality. In BERGEN: A Benchmarking Library for Retrieval-Augmented Generation, LLM-based evaluation is presented as semantic evaluation that can assess answer quality beyond surface-matching metrics and should be used more extensively for RAG. In FACTS About Building Retrieval Augmented Generation-based Chatbots, LLM-as-a-judge is described as an increasingly used evaluation approach for generative AI solutions that requires caution as a human proxy because it can reinforce biases and self-fulfilling evaluations. In FACTS About Building Retrieval Augmented Generation-based Chatbots, automated evaluations are described as scalable testing options using LLMs that supplement rather than replace human evaluation and oversight. In HyPA-RAG: A Hybrid Parameter Adaptive Retrieval-Augmented Generation System for AI Legal and Policy Applications, LLM-as-a-judge methods are used for RAGAS metrics and refined correctness evaluation, with prompt-based correctness judgments compared with human judgment using Spearman coefficients. In RAGAS: Automated Evaluation of Retrieval Augmented Generation, text generation evaluation uses LLMs to assess generated text beyond factuality, including fluency and overall answer quality, by scoring individual answers or selecting the best among candidates. In Retrieval-augmented generation in multilingual settings, LLM-based evaluation is described as capturing semantic similarities better than lexical matching metrics and as a promising, underexplored direction for multilingual settings. In RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems, LLM Judges are described as an automated RAG evaluation approach that assesses context relevance, answer relevance, faithfulness, hallucination, and utilization.

LLM Judges in RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems

Robert Friel · 2025-01-16 · the work’s page · read it where LLM Judges first appears

Abstract written by a model

LLM Judges are an automated RAG evaluation approach and LLM evaluator. They use prompted models such as GPT-3.5 to assess context relevance, answer relevance, faithfulness, hallucination, and utilization. Benchmarks compare zero-shot and framework-based judges with fine-tuned models; a RAGBench-trained NLI model outperforms fine-tuned judges for hallucination and attribution detection.

Narrative, section by section written by a model

2 sections; each heading opens the text

Related Work .. Finetuned RAG evaluation models

LLM judges are used in RAGAS to evaluate context relevance, answer relevance, and faithfulness, with GPT-3.5 queried through a curated prompt. Fine-tuned LLM judges are also described as a common approach to LLM evaluation, but the RAGBench-trained NLI model outperforms them in hallucination and attribution detection.

RAG Case Study .. Estimating Context Relevance is Difficult

The LLM Judge experiments benchmark zero-shot GPT-3.5-judge, RAGAS, and TruLens for evaluating hallucination, Context Relevance, and, where supported, Utilization. These evaluators are compared with a fine-tuned DeBERTa model.
