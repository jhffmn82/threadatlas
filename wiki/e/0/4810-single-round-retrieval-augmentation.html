Abstract written by a model

In Active Retrieval Augmented Generation, Single-time ret. uses the user input as one retrieval query and then generates a complete answer at once. In DRAGIN: Dynamic Retrieval Augmented Generation based on the Information Needs of Large Language Models, single-round retrieval augmentation uses the initial input to query an external corpus and adds retrieved knowledge to the model input. In Rationale-Guided Retrieval Augmented Generation, single-step retrieval is used by Medical RAG to improve runtime performance and avoid expensive iterative retrieval and decision-making processes.
