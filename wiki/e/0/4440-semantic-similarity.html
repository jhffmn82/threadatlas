semantic similarity

method · 2 works · 4 quoted facts · 7 connections
Also called: cosine similarity, embedding similarity, similarity, similarity scores

Abstract written by a model

In RACE: Retrieval-Augmented Commit Message Generation, cosine similarity measures similarity between pooled semantic vectors produced by the code diff encoder and is used by the retrieval module to rank candidate code diffs in the large parallel training corpus. In Document Segmentation Matters for Retrieval-Augmented Generation, semantic similarity is computed between each sentence and the document summary using cosine similarity between embeddings; its score, compared with a threshold, guides dynamic grouping of adjacent sentences into relevant or irrelevant chunks aligned with the document’s key themes.
