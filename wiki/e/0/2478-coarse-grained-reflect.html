Relevance Pseudo-Supervision .. Fine-Grained REFLECT

Coarse-Grained REFLECT matches input attributes with candidate attributes using encoded attribute features and an inner-product relevance score. It has O(N) time complexity and is fully parallelizable, narrowing the candidate set to M references.
