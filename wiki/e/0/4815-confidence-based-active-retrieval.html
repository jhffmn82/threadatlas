confidence-based active retrieval in Active Retrieval Augmented Generation

Zhengbao Jiang · 2023

Confidence-based active retrieval is an active retrieval method that first generates a temporary next sentence without retrieved documents. It accepts that sentence if every token probability meets θ; if any token is below θ, it uses the upcoming sentence to formulate queries, retrieves relevant documents, and regenerates the sentence. This iterative forward-looking design is central to FLARE and outperforms past-context-based retrieval in ablation experiments.

Narrative, section by section

3 sections; each heading opens the text

3 .. 3.3

Confidence-based active retrieval first generates a temporary next sentence without retrieved documents. It accepts the sentence when all token probabilities meet the threshold and otherwise retrieves documents before regenerating it.

6 .. 6.2

Forward-looking active retrieval is presented as the central design of FLARE. Retrieving with the next sentence is clearly better than retrieving with the previous sentence, supporting the claim that future-aware retrieval is effective.

8

Forward-looking active retrieval iteratively uses the upcoming sentence to retrieve relevant information when the sentence contains low-confidence tokens, then regenerates the next sentence.
