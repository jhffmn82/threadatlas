Phase I: Information retrieval

process · 1 work · 11 quoted facts · 6 connections
Also called: Phase I
  • In Semantic Embeddings for Arabic Retrieval Augmented Generation: Phase I: Information retrieval uses a corpus and a user text query. It identifies a semantic embedding model, embeds the query into a feature vector, segments the corpus into m disjoint or overlapping text chunks, and indexes them in a Vector DB store. It compares the query vector with indexed vectors using cosine similarity, euclidean, or inner product scores, then retrieves the top k relevant chunks as context for the next phase.
