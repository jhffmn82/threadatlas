embedding dimensionality (context window)

topic · 1 work · 11 quoted facts · 1 connection
Also called: Embedding Dimensions, context window, context-window limitations, dimensionality of the context window, embedding dimension, embedding dimension limits, embedding dimensions, embedding size, reduced embedding dimensions, window size

Abstract written by a model

Embedding dimensionality, also called embedding size or context window, shapes retrieval and model performance. Across evaluated models it ranges from 384 to 1536; higher dimensions capture more semantic context but raise storage and latency costs. E5-small shows strong performance at 384 dimensions, and the study’s overall model score combines retrieval accuracy with embedding dimension. Reduced dimensions improve computational efficiency and data storage, yet extensive contexts can exceed limits, causing truncation and reduced effectiveness. The records conclude that embedding dimensionality is a critical area for further investigation.
