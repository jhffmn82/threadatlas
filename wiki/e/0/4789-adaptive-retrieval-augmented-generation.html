Abstract written by a model

In Active Retrieval Augmented Generation, adaptive retrieval is described as a single-time retrieval approach based on question popularity or generation probabilities, contrasted with FLARE’s active information access during long-form generation. In RetrievalQA: Assessing Adaptive Retrieval-Augmented Generation for Short-form Open-Domain Question Answering, adaptive retrieval is described as dynamically deciding whether to use a model’s parametric knowledge or retrieve documents for question answering. In RetrievalQA: Assessing Adaptive Retrieval-Augmented Generation for Short-form Open-Domain Question Answering, adaptive retrieval-augmented generation is described as a retrieval-augmented generation approach that dynamically retrieves information only when necessary for open-domain question answering. In SEAKR: Self-aware Knowledge Retrieval for Adaptive Retrieval Augmented Generation, Adaptive Retrieval Augmented Generation is described as an adaptive retrieval strategy and form of retrieval-augmented generation that retrieves external knowledge only when needed to reduce hallucination.

adaptive retrieval-augmented generation in RetrievalQA: Assessing Adaptive Retrieval-Augmented Generation for Short-form Open-Domain Question Answering

Zihan Zhang, Meng Fang, Ling Chen · 2024 · the work’s page · read it where adaptive retrieval-augmented generation first appears

Abstract written by a model

Adaptive retrieval-augmented generation is a retrieval-augmented generation approach and framework for open-domain QA tasks that retrieves only when necessary, dynamically determining retrieval necessity for queries rather than retrieving indiscriminately. Its central goal is to improve efficiency and the relevance of sourced information. It includes calibration-based and model-based methods, but its effectiveness has been understudied because suitable benchmarks and evaluations were lacking. The work formalizes and evaluates existing approaches, compares TA-ARE results, finds vanilla prompting unreliable for retrieval decisions, and proposes TA-ARE to improve this capability without calibration or additional training.

Adaptive Retrieval Augmented Generation in SEAKR: Self-aware Knowledge Retrieval for Adaptive Retrieval Augmented Generation

Zijun Yao · 2025 · the work’s page · read it where Adaptive Retrieval Augmented Generation first appears

Abstract written by a model

Adaptive Retrieval Augmented Generation is an adaptive, dynamic retrieval strategy and form of retrieval augmented generation for large language models. It aims to alleviate hallucination by determining whether external or retrieved knowledge is needed for generation, then invoking retrieval accordingly rather than retrieving at every reasoning step or following a fixed strategy. Its central challenges are deciding when to retrieve and how to integrate retrieved knowledge, including multiple retrieved items. Existing approaches use low-probability tokens, LLM retrieval decisions, or factuality classification, but may depend on unreliable output-level decisions and insufficiently optimize multiple items. The work SEAKR: Self-aware Knowledge Retrieval for Adaptive Retrieval Augmented Generation proposes SEAKR for this setting; it outperforms existing adaptive baselines on complex and simple QA tasks. Results particularly support adaptive retrieval for complex QA.
