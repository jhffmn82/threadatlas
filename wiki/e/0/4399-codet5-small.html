Abstract written by a model

CodeT5-small is a Seq2Seq-based, source code pre-trained model fine-tuned on commit message generation data and MCMD as a comparison baseline. It performs below CodeT5-base among pre-trained approaches, then gains 15% BLEU, 14% Meteor, 11% Rouge-L, and 26% Cider when enhanced with RACE.
