external knowledge in Wiki-LLaVA: Hierarchical Retrieval-Augmented Generation for Multimodal LLMs

Davide Caffagni · 2024

External knowledge is retrieved as textual input context to augment multimodal large language models. Because long-tail information is scarce in training data, it is difficult to encode internally. Retrieval supplies needed details for highly specific, external-knowledge questions, enabling more precise answers beyond image and pre-trained knowledge alone.

2 sections; each heading opens the text

1. Introduction

External knowledge is presented as necessary for answering highly specific queries and questions involving long-tail information. The unit describes retrieval from external sources as a way to improve MLLM performance on such questions.

3. Proposed Method .. 3.2. Training

External knowledge is incorporated into the model as retrieved textual data added to the input context. It enables more specific answers to questions that cannot be addressed using only the image and pre-trained knowledge.
