Abstract written by a model

In "Enhancing Retrieval-Augmented Large Language Models with Iterative Retrieval-Generation Synergy," external knowledge can ground LLM outputs and reduce hallucinations, with ITER-RETGEN gathering and using additional external knowledge based on intermediate model generations. In "Wiki-LLaVA: Hierarchical Retrieval-Augmented Generation for Multimodal LLMs," external knowledge is retrieved as textual input context to augment multimodal large language models and provide details for highly specific external-knowledge questions. In "A Survey of Graph Retrieval-Augmented Generation for Customized Large Language Models," external knowledge is the foundation of GraphRAG effectiveness and may include multimodal information, enriched through web crawling, authoritative database APIs, expert feedback, machine learning, images, and videos.

Davide Caffagni · 2024 · the work’s page · read it where external knowledge first appears

Abstract written by a model

External knowledge is retrieved as textual input context to augment multimodal large language models. Because long-tail information is scarce in training data, it is difficult to encode internally. Retrieval supplies needed details for highly specific, external-knowledge questions, enabling more precise answers beyond image and pre-trained knowledge alone.

1. Introduction

External knowledge is presented as necessary for answering highly specific queries and questions involving long-tail information. The unit describes retrieval from external sources as a way to improve MLLM performance on such questions.

3. Proposed Method .. 3.2. Training

External knowledge is incorporated into the model as retrieved textual data added to the input context. It enables more specific answers to questions that cannot be addressed using only the image and pre-trained knowledge.
