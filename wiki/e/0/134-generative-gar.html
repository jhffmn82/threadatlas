Generative GAR in Generation-Augmented Retrieval for Open-Domain Question Answering

Generative GAR is a generative reader for question answering: using BART-large, it concatenates a question with top-10 retrieved passages within 1,024 tokens to generate the desired answer.

Narrative, section by section

1 section; each heading opens the text

Generation-Augmented Retrieval / Task Formulation .. Generative Reader

The generative reader uses a sequence-to-sequence framework whose input concatenates the question and top-retrieved passages and whose output is the desired answer. GAR implements this setup with BART-large.
