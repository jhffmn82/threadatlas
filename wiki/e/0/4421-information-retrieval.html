Abstract written by a model

An information-retrieval approach to commit-message generation finds similar code changes and reuses their messages. Early work uses syntax, semantic, or bag-of-words similarity and BLEU-based selection; evaluated IR approaches, including NNGen and Lucene, generally outperform end-to-end neural models because retrieved similar commits provide important generation information.

Related Work

Information retrieval techniques have been applied to commit message generation by finding similar code diffs and reusing their commit messages. ChangeDoc uses syntax or semantic similarity, while NNGen retrieves candidates using cosine similarity between bag-of-words vectors and selects among them using BLEU scores.

Experimental Results / How does RACE perform compared with .. 5.4

IR-based approaches generally outperform end-to-end neural models on average, indicating that retrieved similar results provide important information for commit-message generation. NNGen and Lucene are the two IR-based approaches evaluated.
