Abstract written by a model

In Retrieval-augmented Generation across Heterogeneous Knowledge, WebQuestions is an open-domain question-answering benchmark used in heterogeneous retrieval experiments and collected mostly from Freebase. In Retrieving, Rethinking and Revising: The Chain-of-Verification Can Improve Retrieval Augmented Generation, WebQuestions is an open-domain question-answering dataset used in evaluation. In Unified Active Retrieval for Retrieval Augmented Generation, WebQuestions is a downstream dataset for a self-aware task. In Unsupervised Information Refinement Training of Large Language Models for Retrieval-Augmented Generation, WebQuestions is used as an open-domain question-answering dataset evaluated with Exact Match accuracy. In Mitigating the Privacy Issues in Retrieval-Augmented Generation (RAG) via Pure Synthetic Data, WebQuestions is used for evaluating open-domain question answering.
