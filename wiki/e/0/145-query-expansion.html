Narrative, section by section

3 sections; each heading opens the text

Introduction

The unit distinguishes GAR from existing unsupervised query expansion methods. GAR improves queries through generated, heuristically discovered contexts and does not require external resources or downstream reinforcement-learning feedback.

Related Work

Query expansion methods based on pseudo relevance feedback expand queries with relevant terms without external supervision. GAR shares this property but differs by using knowledge stored in PLMs and learning expanded terms through text generation.

Experiment Setup / Datasets .. Implementation Details

Query expansion is evaluated for open-domain question answering through GAR and the unsupervised RM3 baseline. GAR generates query contexts that augment the original queries for retrieval.
