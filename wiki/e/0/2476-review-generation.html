review generation in Retrieval-Augmented Controllable Review Generation

Jihyeok Kim · 2020-12-08/2020-12-13

Review generation is a difficult natural language generation task in the review domain. It automatically produces a review from review-specific attributes, including user, product, and rating identifiers, to help digest users' opinions and obtain expressive textual opinions about products. The work studies it as a data-to-text problem, especially where inputs lack text for direct lexical matching. It formulates generation as using selected, syntactically and semantically similar reference documents. Evaluations on Amazon Books reviews report that references improve content similarity and rating accuracy, while human evaluations find greater informativeness and grammaticality.

Narrative, section by section

5 sections; each heading opens the text

Abstract

Review generation is studied given user ID, product ID, and rating. It is made easier by providing references that are syntactically and semantically similar to the desired output.

Introduction

Review generation automatically produces review text from attributes such as user, product, and rating. It is presented as necessary for obtaining expressive textual opinions about products.

opening .. Augmenting context using references

Review generation is evaluated as a data-to-text task using Amazon Books reviews aligned with user, product, and rating attributes. The reported experiments find that references improve content similarity and rating accuracy, while human evaluations find improvements in informativeness and grammaticality.

AT2T .. SL-REFLECT

Review generation is formulated as producing a review from review-specific attributes and selected references. The task addresses settings in which the available inputs do not contain text contents for direct lexical matching.

Conclusion

It is studied as the problem of generating reviews guided by reference documents.
