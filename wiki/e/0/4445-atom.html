ATOM is a hybrid model combining neural and IR techniques for commit messages. It encodes AST paths from code diffs with BiLSTM, generates messages with a decoder, retrieves messages via TF-IDF and cosine similarity, then hybrid-ranks both results without refining them.

Related Work

ATOM ensembles a neural-based model and an information retrieval technique through hybrid ranking. It encodes AST paths with BiLSTM, generates commit messages with a decoder, retrieves messages using TF-IDF and cosine similarity, and prioritizes generated and retrieved messages with a hybrid ranking module. It does not learn to refine the retrieved or generated results.
