Self-Ask in Enhancing Retrieval-Augmented Large Language Models with Iterative Retrieval-Generation Synergy

Zhihong Shao, Yeyun Gong, Yelong Shen, Minlie Huang, Nan Duan, Weizhu Chen · 2023

Self-Ask is a structured reasoning method that generates and answers retrieved follow-up questions before the original question, but ITER-RETGEN is generally more efficient, accurate, and robust.

Narrative, section by section

1 section; each heading opens the text

4 / 4.1 .. 4.7

Self-Ask generates follow-up questions, retrieves information for them, and answers the follow-ups before answering the original question. ITER-RETGEN is generally more accurate or competitive while using fewer API calls and retrieved paragraphs, and it better preserves performance on questions solvable by CoT without retrieval.
