WoW in BERGEN: A Benchmarking Library for Retrieval-Augmented Generation

David Rau, Hervé Déjean, Nadezhda Chirkova, Thibault Formal, Shuai Wang, Stéphane Clinchant, Vassilina Nikoulina · 2024 · the work’s page · read it where WoW first appears

Abstract written by a model

WoW is a dataset and knowledge-powered conversational dialogue task with medium reference labels. Across analyses, adding retrieved context worsens generation performance, and even Oracle retrieval does not help; closed-book systems outperform retrieval-based ones. Its 3k-example development evaluation shows near-zero Match values but substantial LLMeval variation by model and retrieval system.

Experiments .. 5.6

WoW is a medium-reference dataset whose generation performance deteriorates when retrieved context is added. Oracle retrieval also does not improve its performance in the reported analysis.

B

WoW is analyzed as a potential RAG evaluation dataset. The Closed Book setting outperforms systems using retrieval, including Oracle retrieval, and it is unclear why the dialogue task should rely on retrieved Wikipedia knowledge.
