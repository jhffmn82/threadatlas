AT2T in Retrieval-Augmented Controllable Review Generation

Jihyeok Kim · 2020-12-08/2020-12-13

AT2T is a data-to-text and text-to-text generation task that generates reviews from attribute identifiers, whose input lacks textual context. It augments context with retrieved candidate references: REFLECT selects useful ones and GEN produces the review. It unfolds through SL pseudo-supervision or RL for reference retrieval, reporting improved content similarity, rating accuracy, informativeness, and grammaticality.

Narrative, section by section

2 sections; each heading opens the text

opening .. Augmenting context using references

AT2T generates reviews from attribute identifiers while additionally using retrieved references as context. The unit presents SL and RL approaches for retrieving useful references and reports improvements in content similarity, rating accuracy, informativeness, and grammaticality.

AT2T .. SL-REFLECT

AT2T reformulates review generation as text-to-text generation by conditioning on attributes and a set of candidate references. It uses REFLECT to select relevant references and GEN to generate the output review.
