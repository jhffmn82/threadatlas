The retrieval module trains a code diff encoder with a commit message generator, maps code diffs into a high-dimensional semantic space, measures cosine similarity, and searches a large parallel training corpus. Proposed Approach / Retrieval module .. Generation module

The retrieval module trains a code diff encoder with a commit message generator, maps code diffs into a high-dimensional semantic space, and retrieves the most similar code diff and paired commit message from a large parallel training corpus. It uses the second-ranked result for code diffs in the training dataset because the first-ranked result is the code diff itself.
