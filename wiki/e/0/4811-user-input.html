Abstract written by a model

In Active Retrieval Augmented Generation, the user input is combined with retrieved documents to condition answer generation and serves as the initial query for active retrieval augmented generation and the direct query in single-time retrieval augmented generation. In BERGEN: A Benchmarking Library for Retrieval-Augmented Generation, the user input x is used by the ranking system to retrieve relevant context segments c and is provided to the language model with c to generate r. In TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text, the user query is encoded into a vector using the same BERT-based model used for document encoding; that vector retrieves relevant documents, after which the query is processed with the combined contextual KV cache.
