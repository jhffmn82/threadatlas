commit message generation in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

Commit message generation is an automated software engineering task that creates messages from code diffs, supporting software evolution when developers lack time, motivation, or experience and messages may be empty or difficult to write. It has been approached with rule-based, information-retrieval, neural, Seq2Seq, and hybrid methods. Neural approaches show promising results, while RACE uses retrieved information to improve readability and enhance Seq2Seq models, reporting improvements of 7% to 73%.

Abstract

Automatic commit message generation has been addressed by many neural network-based approaches, which have shown promising results.

opening

Commit message generation is presented as an important task because developers often lack the time, motivation, or experience to write concise and informative messages. Existing rule-based, information-retrieval, and Seq2Seq approaches have limitations, while RACE improves generation performance and readability.

Related Work

Commit message generation is presented as an important software evolution task. Existing approaches include information retrieval, neural-based, and hybrid methods that generate messages from code diffs.
