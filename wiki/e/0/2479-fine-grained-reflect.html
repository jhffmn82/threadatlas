Fine-Grained REFLECT in Retrieval-Augmented Controllable Review Generation

Jihyeok Kim · 2020-12-08/2020-12-13

Fine-Grained REFLECT is a model that accepts M narrowed reference candidates after coarse filtering, uses expensive textual features, BiLSTM attention pooling and self-attention, estimates relevance by inner product, and selects the final K references from relevance scores.

Narrative, section by section

1 section; each heading opens the text

Relevance Pseudo-Supervision .. Fine-Grained REFLECT

Fine-Grained REFLECT accepts the M narrowed reference candidates and uses expensive textual input features to score them. It encodes each candidate with a BiLSTM and attention pooling, contextualizes the candidate representations with self-attention, and estimates relevance using an inner product.
