Retrieval-Augmented Controllable Review Generation

document · 1 work · 0 quoted facts · 0 connections

Abstract written by a model

This paper presents AT2T, a review-generation framework that produces product reviews from user ID, product ID, and rating while augmenting these sparse attribute identifiers with retrieved reference reviews. The central problem is that attributes alone contain little semantic information, whereas reviews offer richer, more expressive opinion text. AT2T therefore retrieves reviews written by the user or reviews for the product, selects a relevant subset, and uses them as guidance for generation. The system consists of REFLECT for reference selection and GEN for generation. REFLECT first applies Coarse-Grained attribute-based parametric matching to narrow a large candidate pool. Fine-Grained REFLECT then encodes candidate texts, uses attention and cross-reference contextualization, and estimates their relevance. In SL-REFLECT, pseudo-supervision labels references using lexical similarity to the gold review and rating accuracy. In RL-REFLECT, the system samples references, generates a review with fixed pretrained GEN, and updates retrieval using rewards based on the relationship between generated and ground-truth reviews; BLEU-1 prioritization and baseline-reward subtraction stabilize training. GEN is an encoder-decoder with bidirectional-LSTM reference encoding, attention over references and attributes, aggregation, and a copying mechanism that can copy words from selected reviews. It is pretrained using top-K BLEU-1 references and cross-entropy on gold reviews; directly training it with REFLECT-retrieved references substantially reduces performance. Experiments on Amazon Book reviews evaluate content similarity, rating classification accuracy, informativeness, and grammaticality. Retrieval improves attribute-specific content but can retain rating-inconsistent information. Rating-aware relevance estimation improves rating consistency and sometimes lexical similarity. GEN-C-F (RL) obtains the best rating accuracy and strongest human-evaluation result, while GEN-C-F (SL) has the highest BLEU-4 score. The paper concludes that attribute-specific references provide useful inductive biases and can guide generated reviews through copying, and proposes future guidance through keywords or topic distributions. Abstract

This paper studies review generation from user ID, product ID, and rating. It proposes using references selected from a large pool of texts labeled with one of these attributes to enrich the information available for generation. The framework treats review generation as text-to-text generation and addresses reference selection without textual context and model complexity. Experiments show improvements over previous approaches on automatic and human evaluation metrics.

Introduction

Opinion mining and sentiment analysis aim to digest users’ opinions about products to support decision making. Existing methods such as aspect-based sentiment analysis and recommendation systems provide less expressive outputs than textual reviews. Review generation addresses this problem by producing reviews from attributes such as users, products, and ratings, but A2T systems struggle because attribute identifiers lack semantic information. The proposed AT2T approach augments attributes with matching reference reviews that provide inductive biases for generating text.

opening .. Augmenting context using references

The unit introduces AT2T, a framework that augments review generation with retrieved textual references in addition to attribute identifiers. It proposes pseudo-supervised learning (SL) for efficient candidate retrieval and reinforcement learning (RL) to select references that improve rating accuracy and lexical similarity in generated reviews. The approaches are evaluated on Amazon Books product reviews aligned with user, product, and rating attributes. Experiments report gains in content similarity, rating accuracy, informativeness, and grammaticality.

AT2T .. SL-REFLECT

This unit describes AT2T, a review generation task that uses user, product, and rating attributes to generate a review. AT2T introduces references, which are reviews written by the user or for the product, and selects a smaller set of relevant references before generation. Its architecture contains REFLECT, with Coarse-Grained and Fine-Grained components, and a pretrained GEN model. The unit introduces SL-REFLECT, which uses pseudo-supervised learning to train reference-selection models when only identifiers are available, and contrasts it with reinforcement learning.

Relevance Pseudo-Supervision .. Fine-Grained REFLECT

This unit describes Relevance Pseudo-Supervision and the Coarse-Grained and Fine-Grained REFLECT models for selecting references relevant to an input rating and review generation. Relevance Pseudo-Supervision assigns each reference candidate a pseudo-label based on lexical similarity to a ground-truth review and rating accuracy. Coarse-Grained REFLECT uses attribute-based parametric matching to reduce a large candidate set, while Fine-Grained REFLECT uses textual encoding, attention, and cross-reference contextualization to score the remaining candidates. The unit concerns REFLECT, T2T reference selection, reference candidates, reviews, ratings, and the components used to estimate relevance.

RL-REFLECT .. Stabilizing Training of RL

RL-REFLECT uses reinforcement learning to train retrieval models to select or compose references whose partial contributions improve a generated review. It samples references, generates a review with GEN, computes a reward from the ground-truth and generated review, and adapts reference sampling using the likelihood-ratio trick. The method uses filtered references from Coarse-Grained REFLECT and keeps the pretrained GEN weights fixed. To stabilize training, it prioritizes references with BLEU-1 lexical similarity and subtracts a baseline reward from the reward signal.

GEN .. Training GEN

GEN is an encoder-decoder model with a copying mechanism for generating reviews. It encodes reference texts with a bidirectional LSTM, contextualizes and aggregates them with attention, and also attends over input attributes. During decoding, GEN combines reference and attribute representations and can copy words from references. GEN is pretrained with top-K BLEU-1 references and cross-entropy on gold reviews, while training with REFLECT-retrieved references significantly reduces performance.

Experiments .. Analysis on Rating Consistency

The experiments evaluate GEN, REFLECT, and baseline systems on the Amazon Book reviews dataset using BLEU-based content similarity and rating classification accuracy. GEN-C-F (RL) achieves the best rating accuracy and strongest human-evaluation score, while GEN-C-F (SL) achieves the highest BLEU-4 score. Retrieval improves attribute-specific content but can preserve rating-inconsistent information, whereas rating-aware relevance estimation improves both rating consistency and, in some cases, lexical similarity. Ablation results show that lexical similarity alone may fail to capture Amazon Book review rating semantics.

Conclusion

The work studies review generation guided by reference documents. It finds that attribute-specific reference reviews provide useful inductive biases about given attributes, which can be delivered to generated reviews through a copying mechanism. As future work, it will investigate alternative guidance methods, including keywords or topic distributions of attributes.
