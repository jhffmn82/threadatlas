Related Works

Retrieval augmented generation with LLMs uses retrieved passages, and in some cases knowledge graph triples, to address hallucination and improve factuality. The discussed methods use retrieval to help rethink or post-edit decomposed reasoning steps produced through chain-of-thought prompting.

Conclusion

The work introduces a training framework for retrieval augmented generation models to train more robust retrievers. The proposed methods improve both retrieval and generation metrics compared with the baseline model.
