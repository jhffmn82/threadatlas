Abstract written by a model

Retrieval-augmented keyphrase generation is a method for multilingual keyphrase generation that uses relatively rich English datasets as external knowledge. It first retrieves a semantically related English passage for a non-English passage, mining parallel passages through retriever-generator iterative training. It then supplies the original passage and retrieved English keyphrases as code-mixed input to a generator, which predicts keyphrases in the original language. Retrieved keyphrases provide supplementary hints based on shared topics or concepts, while the generator can emphasize informative content and tolerate retrieval noise.

Introduction

Retrieval-augmented keyphrase generation retrieves related English passages for a passage written in another language and uses their English keyphrases as hints. Its generator receives code-mixed inputs containing the non-English passage and retrieved English keyphrases, then predicts keyphrases in the original language.

Model .. 4.3

The retrieval-augmented approach uses relatively rich English resources to support multilingual keyphrase generation. Given a passage in one language, it retrieves a semantically similar English passage and uses its associated English keyphrases as hints for generating keyphrases in the source language.
