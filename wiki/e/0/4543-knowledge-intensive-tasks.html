Abstract written by a model

In "Retrieval-augmented Generation across Heterogeneous Knowledge," knowledge-intensive NLP tasks have been addressed by existing retrieval-augmented generation models. In "ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems," knowledge-intensive NLP tasks assess LLM attribution and factuality, with LongEval, Hagrid, and ALCE providing analysis guidelines or datasets. In "BERGEN: A Benchmarking Library for Retrieval-Augmented Generation," knowledge-intensive tasks are discussed as an area for which standard benchmarks used in retrieval-augmented generation should be reviewed. In "RE-RAG: Improving Open-Domain QA Performance and Interpretability with Relevance Estimator in Retrieval-Augmented Generation," knowledge-intensive tasks are identified as an area in which retrieval-augmented generation has shown promising progress. In "Retrieval-augmented generation in multilingual settings," knowledge-intensive tasks include open-domain question answering and fact-checking, where retrieval-augmented generation can especially improve LLM factuality. In "RetrievalQA: Assessing Adaptive Retrieval-Augmented Generation for Short-form Open-Domain Question Answering," knowledge-intensive tasks include open-domain question-answering and are identified as applications in which retrieval-augmented generation has become increasingly popular. In "A Survey of Graph Retrieval-Augmented Generation for Customized Large Language Models," knowledge-intensive tasks expose language-model weaknesses because specialized information, multi-step reasoning, and domain constraints require expertise rarely seen in pre-training. In "CausalRAG: Integrating Causal Graphs into Retrieval-Augmented Generation," knowledge-intensive tasks motivate evaluation settings requiring more than explicit fact retrieval, including answers involving discourse, mechanisms, and causal explanations.
