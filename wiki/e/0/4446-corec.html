CoRec in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

CoRec is a hybrid, pre-trained-based model that combines neural and IR-based approaches for message generation. During inference only, it uses a trained encoder to retrieve the most similar training code diff, combines decoder probability distributions for the input and retrieved diff, and generates a message step by step; it is not trained to use retrieved information. It outperforms NNGen on C++ and JavaScript but trails it on Java, C#, and Python, while RACE surpasses it on all human-evaluation aspects.

2 sections; each heading opens the text

Related Work

CoRec uses retrieval only during inference. It retrieves the most similar training code diff with a trained encoder, combines probability distributions from decoders processing the input and retrieved diffs, and generates the final message step by step. It is not trained to utilize information from retrieval results.

5.5

CoRec is evaluated as a pre-trained-based baseline against RACE. RACE outperforms CoRec on all three human-evaluation aspects.
