commit message in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

A commit message is a description of a code change’s content or intent, important for software development and maintenance because high-quality messages help developers understand software evolution without inspecting implementation details. It may be empty, insufficiently informative, repetitive, redundant, or difficult to read; in SourceForge projects it can be empty. Messages are paired with code diffs in training data, generated from diffs or reused from similar commits, and limited to 50 tokens. RACE retrieves a similar commit message as an exemplar and uses an exemplar guider to reduce incorrect or irrelevant influence, then generates the message token by token with cross-entropy training. Generated messages are assessed for semantic similarity to code diffs and scored for informativeness, conciseness, and expressiveness, aiming for accurate, readable output.

Narrative, section by section

8 sections; each heading opens the text

Abstract

Commit messages are important for software development and maintenance. Neural approaches may generate messages that are repetitive or redundant.

Introduction

They summarize what code changes are or why the code is changed. High-quality messages help developers understand software evolution without diving into implementation details.

opening

A commit message describes the content or intent of a code change, but it may be empty, insufficiently informative, repetitive, or difficult to read. RACE treats a retrieved similar commit message as an exemplar while using an exemplar guider to reduce the influence of incorrect or irrelevant information.

Related Work

Commit messages are generated from code diffs or reused from similar commits. Retrieval-based methods can reuse messages that are usually readable and understandable.

Proposed Approach / Retrieval module .. Generation module

A commit message is paired with a code diff in the training corpus and can be retrieved as an exemplar. The generation module produces a commit message token by token using cross-entropy training.

Experimental Setup / Dataset .. Evaluation metrics / Baselines

Commit messages are used as the generated output and are limited to a maximum length of 50. Their quality is evaluated with BLEU, Meteor, Rouge-L, and Cider.

5.5

Generated commit messages from RACE, NNGen, NMTGen, CommitBERT, and CoRec are evaluated for semantic similarity to their code diffs. The messages receive scores from 0 to 4 for Informativeness, Conciseness, and Expressiveness.

Conclusion .. Limitations

The commit message is generated to be accurate and readable, with a retrieved similar commit message serving as an exemplar.
