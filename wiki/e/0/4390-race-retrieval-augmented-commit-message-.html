RACE retrieves a semantically similar code diff and its paired commit message from a large training corpus. Its retrieval module uses a trained code-diff encoder and cosine similarity. Across all five languages and all four metrics, RACE outperforms 11 baseline approaches. Its exemplar guider improves results over an ablated version, performance remains generally stable when retrieving one to nine relevant commits, and the framework improves NMTGen, CommitBERT, CodeT5-small, and CodeT5-base, with reported gains of 7% to 73%. The paper notes limitations: coverage of only five languages, dependence on a code base, roughly 35 hours of training, and truncation of diffs beyond 512 tokens. Abstract

The paper concerns automatic commit message generation, where neural network-based approaches have shown promising results but may produce repetitive or redundant messages. It proposes RACE, a retrieval-augmented method that uses a retrieved similar commit as an exemplar for generating accurate commit messages. RACE includes an exemplar guider that learns the semantic similarity between the retrieved and current code diff and guides message generation accordingly. Experiments on a large public dataset covering five programming languages show that RACE outperforms all baselines and improves existing Seq2Seq models.

Introduction

Software development and maintenance frequently involves changes to source code. Code changes are often documented through natural language commit messages that summarize what changed or why it changed. High-quality commit messages help developers understand software evolution without examining implementation details.

This unit concerns automatic commit message generation and the RACE (Retrieval-Augmented Commit mEssage generation) model proposed to improve it. RACE retrieves a semantically similar code diff and its commit message, then uses an exemplar guider to help a neural model generate informative and readable commit messages while reducing the impact of irrelevant retrieved information. Evaluated on the MCMD dataset across Java, C#, C++, Python, and JavaScript, RACE outperforms 11 state-of-the-art approaches on BLEU, Meteor, Rouge-L, and CIDEr. RACE also improves four existing neural models, including NMTGen, CommitBERT, CodeT5-small, and CodeT5-base.

Related Work

The unit reviews code intelligence methods for software engineering, focusing on commit message generation from code diffs. It describes information retrieval methods such as ChangeDoc and NNGen, neural-based approaches such as NMTGen, CommitGen, CoDiSum, PtrGNCMsg, and CommitBERT, and hybrid methods including ATOM and CoRec. The unit explains that ATOM and CoRec combine retrieval with neural generation but do not fully exploit retrieved results. It presents exemplar-based commit message generation as an approach that trains a model to use retrieved similar commits to improve generation.

Proposed Approach / Retrieval module .. Generation module

RACE is a two-module approach for generating understandable and concise commit messages from code diffs. Its retrieval module uses a trained code diff encoder and cosine similarity to find a semantically similar code diff and paired commit message from a large parallel training corpus. Its generation module encodes the input code diff, retrieved code diff, and retrieved commit message, then uses an exemplar guider to weight their representations before a Transformer-based decoder generates the commit message. The encoder is trained with an encoder-decoder neural network on about 0.9 million code diff and commit message pairs.

Experimental Setup / Dataset .. Evaluation metrics / Baselines

This unit describes the experimental setup for evaluating RACE on the MCMD commit-message generation dataset. MCMD contains 450,000 sampled commits for each of Java, C#, C++, Python, and JavaScript, with further filtering for multi-file and unparsable files. Code diffs are converted into token-level change actions, and CodeT5-base initializes the encoders and decoder. Generated commit messages are evaluated with BLEU, Meteor, Rouge-L, and Cider, using multiple neural, information-retrieval, hybrid, and pre-trained baselines.

Experimental Results / How does RACE perform compared with .. 5.4

This unit evaluates RACE against 11 baseline approaches for commit-message generation across Java, C#, C++, Python, and JavaScript using BLEU, Meteor, Rouge-L, and Cider. RACE achieves the best results across all five programming languages and all four metrics, while its exemplar guider improves performance over an ablated version. Experiments show that performance remains generally stable when retrieving between 1 and 9 relevant commits. Applying the framework improves four existing Seq2Seq models, with reported gains ranging from 7% to 73%.

5.5

The human evaluation assesses the semantic similarity of commit messages generated by RACE, NNGen, NMTGen, CommitBERT, and CoRec. Four volunteers with excellent English ability and more than three years of software development experience scored 250 code diff–commit message pairs from 50 randomly selected test-set code diffs. They rated each pair on Informativeness, Conciseness, and Expressiveness using scores from 0 to 4. RACE outperformed the four baselines on all three aspects, with high evaluator agreement and statistically significant improvements according to Wilcoxon signed-rank tests.

Conclusion .. Limitations

The paper proposes a retrieval-augmented neural commit message generation method that uses a retrieved similar commit message as an exemplar to guide generation. Experiments show that the method outperforms recent baselines and significantly improves four neural network models. The study is limited by its evaluation on five programming languages, dependence on a code base, approximately 35 hours of training time, and truncation of code diffs longer than 512 tokens.
