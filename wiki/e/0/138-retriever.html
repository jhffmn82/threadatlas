  • In Generation-Augmented Retrieval for Open-Domain Question Answering, the retriever selects a small relevant subset of documents or passages and receives queries augmented with generated contexts to improve retrieved passage quantity and quality.
  • In Retrieval-augmented Generation across Heterogeneous Knowledge, the document retriever takes source input and a document reference set, narrows the search to relevant documents without full enumeration, and yields relevance scores for the top-K documents.
  • In Active Retrieval Augmented Generation, the retriever retrieves a list of documents for a query.
  • In Enhancing Retrieval-Augmented Large Language Models with Iterative Retrieval-Generation Synergy, retrievers struggle to capture relevance for queries involving complex information needs, and ITER-RETGEN uses a model’s generated response to help retrieve more relevant knowledge.
  • In TRACE the Evidence: Constructing Knowledge-Grounded Reasoning Chains for Retrieval-Augmented Generation, the retriever obtains question-associated documents by estimating question-document relevance, using bi-encoders, cross-encoders, or IRCoT.
  • In BlendFilter: Advancing Retrieval-Augmented Large Language Models via Query Generation Blending and Knowledge Filtering, retrievers provide knowledge to Large Language Models, while recent methods enable the models to interact with retrievers to improve relevance modeling.
  • In Rationale-Guided Retrieval Augmented Generation, the retriever searches document snippets from a rationale via query and document encoders in a shared latent space, while limited input and incorrect rationales can produce distracting evidence and expose source-corpus bias.
  • In VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation, retrieval is evaluated through evidence extraction using ANLCS and document identification in a multi-document setting.
  • In RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems, the retriever queries domain-specific corpora for context relevant to an input query, with Context Relevance measuring the average relevance of retrieved documents per query.

retriever in RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems

Retriever queries domain-specific corpora for context relevant to an input query. Its key measure is Context Relevance, the average relevance of retrieved documents per query. Evaluations compare sparse TF-IDF and dense retrievers; inefficient retrieval can return excessive information, raising costs and potentially harming response quality.

Narrative, section by section

2 sections; each heading opens the text

TRACe Evaluation Framework .. Adherence

The retriever is evaluated according to the relevance of the context documents it returns for the user query. An inefficient retriever may supply excessive information, increasing costs and potentially compromising response quality.

RAG Case Study .. Estimating Context Relevance is Difficult

The case study compares sparse TF-IDF and dense retrievers as configurable components of the simulated RAG systems. It finds that the choice of retriever affects the average relevance of retrieved context documents per query.
