Experimental Setup / Dataset .. Evaluation metrics / Baselines

Token-level change actions represent code changes using keep, insert, delete, and replace operations. Each action contains a span of tokens, and replace is extended into replace_old and replace_new to distinguish old and new token spans; difflib is used to extract the action sequence.
