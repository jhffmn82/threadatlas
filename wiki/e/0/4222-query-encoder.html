query encoder

object · 1 work · 4 quoted facts · 3 connections
Also called: question encoder

Abstract written by a model

The query encoder is a BERT model that independently encodes queries, comparing its outputs with passage representations through inner products. It is trained with the passage encoder for slot filling, then injected into RAG for Natural Questions, where retrieval-driven training updates it without disrupting generation.

query encoder is in one work on this site, Robust Retrieval Augmented Generation for Zero-shot Slot Filling. This is the abstract a model wrote of it from that work.
