Abstract written by a model

In "Generation-Augmented Retrieval for Open-Domain Question Answering," PLMs generate contexts that provide background and search intent, expand queries, enrich semantics, and support text retrieval or matching. In "Retrieval-augmented Generation across Heterogeneous Knowledge," PLMs function as parameterized implicit knowledge bases, storing substantial knowledge in their parameters and predicting downstream outputs without external memory or raw text. In "Retrieval-augmented Generation across Heterogeneous Knowledge," conventional pre-trained generation models are presented as having fewer advantages than retrieval-augmented generation methods in knowledge acquisition, scalability, and training cost. In "GRAG: Graph Retrieval-Augmented Generation," PLM converts node and edge text attributes into embeddings and encodes queries as vectors for semantic relevance calculations. In "GRAG: Graph Retrieval-Augmented Generation," PLM converts node and edge text attributes into embeddings for textual subgraph indexing and encodes the query with the same encoder. In "Knowledge Graph Retrieval-Augmented Generation for LLM-based Recommendation," the pre-trained language model captures semantic information from node attributes, relation attributes, item text attributes, and recommendation prompts, and is used for indexing, retrieval, and re-ranking.

Abstract written by a model

PLMs are pre-trained language models that generate contexts for Generation-Augmented Retrieval. Using stored knowledge without external supervision, they provide background and search intent, expand queries, enrich semantics, and support text retrieval or matching.

Narrative, section by section written by a model

3 sections; each heading opens the text

Introduction

A pre-trained language model generates contexts for Generation-Augmented Retrieval. These contexts provide background information and explicitly express search intent that may not appear in the original question.

Related Work

PLMs store knowledge that GAR uses to expand queries with relevant contexts. The unit also states that factual knowledge can be extracted from PLMs in contexts beyond answers.

Conclusion .. Future Extensions

Pretrained language models generate relevant contexts without external supervision by using knowledge contained in the models. Their generated contexts can enrich query semantics and support further text retrieval or matching.

PLMs in Retrieval-augmented Generation across Heterogeneous Knowledge

Wenhao Yu · 2022 · the work’s page · read it where PLMs first appears

Abstract written by a model

PLMs are large pre-trained language models that function as parameterized implicit knowledge bases. Usually trained offline on general-domain pre-training corpora, they store substantial knowledge in parameters and predict outputs on downstream tasks without external memory or raw text. Their later-information awareness, interpretability, and domain-specific effectiveness are limited, and pre-training can be prohibitively expensive. RAG methods significantly outperform them on three open-domain question answering tasks with far fewer parameters.

Narrative, section by section written by a model

2 sections; each heading opens the text

1

Large pre-trained language models have revolutionized natural language processing and achieved remarkable performance on various downstream tasks. They learn substantial knowledge from pre-training corpora and can predict downstream outputs without external memory or raw text.

opening

Large-scale pre-trained language models are usually trained offline, which makes them unaware of later information, and they rely on knowledge stored in their parameters. They are described as having limited interpretability, reduced effectiveness on domain-specific tasks, and prohibitively expensive pre-training phases for many academic research groups. The figure indicates that RAG methods significantly outperform large-scale PLMs on three open-domain question answering tasks while using far fewer parameters.
