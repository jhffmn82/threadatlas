exemplar guider in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

The exemplar guider is a guider for commit message generation. It learns semantic similarity between an input or current code diff and a retrieved code diff, uses that value to weight the input code diff and retrieved commit message representations, concatenates the code diff with the similar commit message representation, and guides decoding of a commit message.

Narrative, section by section

2 sections; each heading opens the text

Abstract

The exemplar guider learns the semantic similarity between the retrieved and current code diff. It then guides the generation of a commit message based on that similarity.

Proposed Approach / Retrieval module .. Generation module

The exemplar guider learns a semantic similarity value between the input code diff and the retrieved code diff. It uses this value to weight the input code diff and retrieved commit message representations before decoding.
