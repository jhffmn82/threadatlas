Also called: SL method, pseudo-supervised learning

Abstract written by a model

SL is a pseudo-supervised learning scheme and retrieval-stage approach that uses attribute identifiers, including ratings, for parametric coarse filtering and reference matching. It enables constant-time matching per candidate-pool instance and efficient reference selection through lexical and rating similarity. It constructs trainable SL-REFLECT models without text inputs, but generated documents may not preserve those similarities. It resembles reinforcement learning when one document dominates, yet is less effective when multiple references contribute collaboratively.

SL is in one work on this site, Retrieval-Augmented Controllable Review Generation. This is the abstract a model wrote of it from that work.

3 sections; each heading opens the text

opening .. Augmenting context using references

SL uses attribute identifiers for parametric coarse filtering, enabling efficient matching with constant time complexity for each instance in a candidate pool. It is proposed as a pseudo-supervised approach to expedite reference retrieval.

AT2T .. SL-REFLECT

Pseudo-supervised learning is used to construct trainable SL-REFLECT models without text contents as inputs. It is presented as one of two learning approaches for the retrieval stage.

RL-REFLECT .. Stabilizing Training of RL

SL efficiently selects references using lexical and rating similarity, but it cannot guarantee that generated documents preserve those similarities. It is comparable to RL when one document dominates all aspects, but is less effective when multiple references contribute collaboratively.
