A2T is a review generation problem that takes user, product, and rating attribute identifiers as input, producing review text while learning rich representations from non-semantic identifiers.

Narrative, section by section

1 section; each heading opens the text

Introduction

A2T frames review generation as producing review text from non-linguistic attribute data. Its central challenge is learning rich attribute representations from identifiers that lack semantic content.
