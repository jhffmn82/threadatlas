retrieval-augmented neural commit message generation method in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

The retrieval-augmented neural commit message generation model retrieves similar code diffs and commit messages during training, encodes them, and treats the closest commit message as an exemplar to guide generation of accurate, readable messages. Applied to NMTGen, CommitBERT, CodeT5-small, and CodeT5-base, it boosts performance and outperforms recent baselines. It requires a code base, inherits this IR-based limitation, and has approximately 35 hours of training time.

RACE in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

RACE is a retrieval-augmented neural commit message generation method and model. It has a retrieval module and a generation module: first, it retrieves from a large parallel corpus the most semantically similar code diff paired with a commit message, using vector-distance similarity; then it uses that retrieved message as an exemplar to guide generation for the current diff. Its exemplar guider learns similarity between the retrieved and current code diffs, helping use the exemplar without letting retrieved samples dominate generation. RACE supports using k relevant commits and has stable performance across different k values. In experiments run three times with random seeds 0, 1, and 2 and reported as means, it outperforms 11 state-of-the-art approaches and all evaluated baselines on Java, C#, C++, Python, and JavaScript across BLEU, Meteor, Rouge-L, and Cider. The guider improves results over RACE without it. The framework also boosts NMTGen by more than 20% on all programming languages and improves CommitBERT, CodeT5-small, and CodeT5-base. In human evaluation, RACE scores 2.49 (±1.10) for informativeness, 3.08 (±0.96) for conciseness, and 2.85 (±0.84) for expressiveness, exceeding NNGen, NMTGen, CommitBERT, and CoRec on all three measures. It generates concise, readable commit messages with more comprehensive semantics.

Abstract

RACE is a retrieval-augmented neural commit message generation method. It uses a retrieved similar commit as an exemplar and outperforms all baselines in experiments, while also boosting existing Seq2Seq models.

opening

RACE is a model that retrieves a similar code diff paired with a commit message and uses that commit message as an exemplar for neural commit message generation. Its exemplar guider learns the semantic similarity between the retrieved and current code diffs and uses the exemplar accordingly. Experiments show that RACE outperforms existing approaches and improves several Seq2Seq models.

Proposed Approach / Retrieval module .. Generation module

RACE consists of a retrieval module and a generation module. It retrieves a semantically similar code diff and commit message, then uses the retrieved commit message to guide commit message generation.

Experimental Setup / Dataset .. Evaluation metrics / Baselines

RACE is compared with end-to-end neural, information-retrieval, hybrid, and pre-trained models on the commit message generation task. The experiments are run three times with random seeds 0, 1, and 2, and the reported results use the mean value.

Experimental Results / How does RACE perform compared with .. 5.4

RACE outperforms all evaluated approaches on Java, C#, C++, Python, and JavaScript across BLEU, Meteor, Rouge-L, and Cider. Its exemplar guider improves results over RACE without the guider, and the framework also improves NMTGen, CommitBERT, CodeT5-small, and CodeT5-base.

opening

RACE is evaluated in the human evaluation on informativeness, conciseness, and expressiveness. It scores 2.49 (±1.10) for informativeness, 3.08 (±0.96) for conciseness, and 2.85 (±0.84) for expressiveness.

5.5

RACE generates commit messages that score higher than NNGen, NMTGen, CommitBERT, and CoRec in Informativeness, Conciseness, and Expressiveness. Its improvements over the other approaches are statistically significant according to Wilcoxon signed-rank tests.
