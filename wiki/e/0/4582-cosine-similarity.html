cosine similarity

metric · 3 works · 6 quoted facts · 4 connections
Also called: Cosine similarity, cosine, cosine similarity distance, cosine similarity distance metric, cosine similarity metric, cossim(vq, vs)

Abstract written by a model

In Semantic Embeddings for Arabic Retrieval Augmented Generation, it is a distance metric between query and context-paragraph semantic features that ranks context paragraphs by similarity. In Reducing hallucination in structured outputs via Retrieval-Augmented Generation, it compares a query embedding with step or table embeddings to retrieve the maximum K associated relevant steps and database tables. In MEGA-RAG: a retrieval-augmented generation framework with multi-evidence guided answer refinement for mitigating hallucinations of LLMs in public health, it compares answer, answer-sentence, and retrieved-evidence embeddings to measure semantic divergence, calculate evidence coverage, and cluster responses at the sentence level.
