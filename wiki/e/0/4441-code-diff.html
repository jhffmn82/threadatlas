code diff in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

A code diff is the input to RACE for commit message generation. Originally represented at the line level in MCMD, it is converted into a sequence of token-level change-action spans with a maximum length of 200 tokens. A trained encoder maps it to contextual representations and a pooled vector in a high-dimensional semantic space. That vector is compared, including by cosine similarity, with other code diffs to retrieve a semantically similar commit. The current and retrieved diffs, along with similar commit messages in the generation module, guide generation. Generated messages from randomly selected testing diffs are also used in human-evaluation pairs. When a diff exceeds 512 tokens, it is truncated; this can lose information, particularly for longer diffs with more complex semantics or behaviors.

Abstract

The current code diff is compared semantically with the retrieved code diff by the exemplar guider. This similarity helps guide commit message generation.

opening

A code diff is encoded by a trained encoder into a high-dimensional semantic space, where it is compared with other code diffs to retrieve a semantically similar example. RACE uses the current and retrieved code diffs to guide commit message generation.

Related Work

Code diffs are used as the input for commit message generation and are represented through syntax, semantics, bag-of-words vectors, TF-IDF vectors, AST paths, or learned semantic representations. Retrieval-based methods compare code diffs to find similar examples.

Proposed Approach / Retrieval module .. Generation module

A code diff is encoded into contextual representations and a pooled semantic vector. Its semantic similarity to another code diff is used for retrieval and for guiding generation.

Experimental Setup / Dataset .. Evaluation metrics / Baselines

The code diff is originally represented at the line level in MCMD. The study converts it into a sequence of token-level change actions and limits its maximum length to 200.

Experimental Results / How does RACE perform compared with .. 5.4

The code diff is used to retrieve relevant commits through cosine similarity between semantic vectors. It is also encoded together with similar code diffs and similar commit messages in the generation module.

5.5

Fifty code diffs are randomly selected from the testing sets. Their generated commit messages are used to form 250 code diff–commit message pairs for human evaluation.

Conclusion .. Limitations

The model retrieves and encodes similar code diffs. Diffs longer than 512 tokens are truncated, which can cause information loss because longer diffs may contain more complex semantics or behaviors.
