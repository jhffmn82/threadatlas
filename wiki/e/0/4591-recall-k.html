Abstract written by a model

In LI-RAGE: Late Interaction Retrieval Augmented Generation with Explicit Signals for Open-Domain Table Question Answering, Recall@K measures whether the gold table appears among the top-K retrieved tables and is reported for both datasets with K=5. In Semantic Embeddings for Arabic Retrieval Augmented Generation, Recall@k is an average retrieval evaluation metric that measures the percentage of cases where relevant context appears among the top k model retrieval hits, reported for k values of 1, 2, 3, 4, 5, 10, and 15. In BERGEN: A Benchmarking Library for Retrieval-Augmented Generation, R@5 measures retrieval performance based on whether relevant information appears within the top five retrieved results. In GEAR: Graph-enhanced Agent for Retrieval-augmented Generation, Recall@k measures the percentage of questions whose correct entries appear within the top 5, 10, or 15 retrieved passages, computed cumulatively each iteration. In GEAR: Graph-enhanced Agent for Retrieval-augmented Generation, retrieval recall correlates positively with question answering performance, and GEAR has a 21% relative improvement in R@15 over HippoRAG w/ IRCoT on MuSiQue. In Knowledge Graph Retrieval-Augmented Generation for LLM-based Recommendation, Recall@k is an evaluation metric that evaluates whether the target item is ranked within the top k predictions, with k set to 3 and 5.

Recall@k in GEAR: Graph-enhanced Agent for Retrieval-augmented Generation

Zhili Shen · 2025 · the work’s page · read it where Recall@k first appears

Abstract written by a model

Recall@k measures retrieval performance as the percentage of questions whose correct entries appear within the top 5, 10, or 15 retrieved passages, computed cumulatively each iteration. It is used to compare recall ranks: Diverse Triple Beam Search improves it across datasets, while GEAR shows stronger mean or median recall in specified multi-hop settings.

Experimental Setup .. Baselines / Implementation Details

Recall@k is used to report the percentage of questions for which the correct entries are found within the top-k retrieved passages, with k set to 5, 10, and 15. The unit also analyzes the selected recall ranks in Appendix D.

Discussion / What makes GEAR work? .. Is GEAR efficient?

Diverse Triple Beam Search consistently improves recall across datasets and recall ranks. GEAR has higher mean recall than HippoRAG w/ IRCoT on 2-hop questions and exceeds its median performance across both 3-hop subdivisions.
