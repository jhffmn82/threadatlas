retrieved similar commit in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

A retrieved similar commit serves as an exemplar for generating an accurate message for the current code diff. Because its own message may not match the current diff’s content or intent, RACE uses it only to guide a neural model, avoiding extra or incorrect retrieved information.

Narrative, section by section

2 sections; each heading opens the text

Abstract

The retrieved similar commit is used as an exemplar to support the generation of an accurate commit message. Its commit message may not always accurately describe the content or intent of the current code diff.

Experimental Results / How does RACE perform compared with .. 5.4

RACE treats a retrieved similar commit message as an exemplar rather than directly using it as the final output. The exemplar guides the neural model toward the correct message while avoiding extra or incorrect information in the retrieved result.
