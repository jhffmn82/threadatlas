  • In Active Retrieval Augmented Generation: Active retrieval augmented generation is a generic framework and method for long-form generation that actively decides when and what to retrieve during generation. It interleaves retrieval with generation: starting from user input, a query formulation function creates queries that reflect future generation intents; the system retrieves when necessary knowledge is unavailable, then generates until another retrieval or the end. At each new step it discards previously retrieved documents and conditions the next generation only on current-step documents. Its central purpose is to avoid unnecessary or inappropriate retrieval while obtaining needed information. It is implemented by FLARE methods, including forward-looking active retrieval, and is shown effective on four tasks and datasets.

active retrieval augmented generation in Active Retrieval Augmented Generation

Zhengbao Jiang · 2023

Active retrieval augmented generation is a generic framework and method for long-form generation that actively decides when and what to retrieve during generation. It interleaves retrieval with generation: starting from user input, a query formulation function creates queries that reflect future generation intents; the system retrieves when necessary knowledge is unavailable, then generates until another retrieval or the end. At each new step it discards previously retrieved documents and conditions the next generation only on current-step documents. Its central purpose is to avoid unnecessary or inappropriate retrieval while obtaining needed information. It is implemented by FLARE methods, including forward-looking active retrieval, and is shown effective on four tasks and datasets.
