relation extraction

task · 3 works · 4 quoted facts · 2 connections
Also called: RE, extracting relations between entities from text, relation extraction model, useful relation

Abstract written by a model

In Robust Retrieval Augmented Generation for Zero-shot Slot Filling, relation extraction is described as the weakest component in many knowledge base population pipelines for extracting relations between entities from text. In REANO: Optimising Retrieval-Augmented Reader Models through Knowledge Graph Generation, relation extraction is a knowledge graph generation component that infers relations among entities using transformer backbone models. In HYBGRAG: Hybrid Retrieval-Augmented Generation on Textual and Relational Knowledge Bases, relation extraction is refined through corrective feedback when relations used for retrieval are judged incorrect.
