Keyphrase Generation in Retrieval-Augmented Multilingual Keyphrase Generation with Retriever-Generator Iterative Training

Yifan Gao, Qingyu Yin, Zheng Li, Rui Meng, Tong Zhao, Bing Yin, Irwin King, Michael R. Lyu · 2022

Keyphrase Generation is a task of automatically predicting keyphrases from long text, using neural language generation to model phrase importance and semantics rather than merely extract substrings. Existing work has focused mainly on English, while this work extends investigation to multiple other languages. Methods have evolved through attention, structural and decoding mechanisms, alignment, and pre-trained language models; retrieval can improve accuracy. Evaluation uses exact-match precision, recall, and F1 over predicted and gold keyphrase sets across languages. Results show supervised methods outperform unsupervised ones, multilingual Transformer outperforms Copy-RNN, and better retrieved English keyphrases improve performance.

5 sections; each heading opens the text

Abstract

Keyphrase generation automatically predicts keyphrases given a piece of long text. The paper extends this task to a multilingual setting.

Introduction

Keyphrase generation automatically predicts keyphrases for a piece of long text. Existing work has focused mostly on English datasets, while this unit investigates generation in multiple other languages.

Related Work

Keyphrase generation uses neural language generation to produce keyphrases based on phrase importance and semantics rather than extracting substrings. Subsequent work improves it through attention, extra structure, reinforcement learning, GANs, hierarchical decoding, exclusion mechanisms, dynamic alignment, and pre-trained language models.

Datasets .. Baselines and Ablations

It is evaluated using exact-match precision, recall, and F1, with lowercasing and other post-processing permitted. The metrics are computed from predicted and gold keyphrase sets and averaged across languages.

Results and Analyses / Main Results .. Case Study

Supervised approaches consistently outperform unsupervised approaches in keyphrase generation. The multilingual Transformer has a large advantage over Copy-RNN, and better retrieved English keyphrases improve generation performance.
