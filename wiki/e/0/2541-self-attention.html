self-attention in DRAGIN: Dynamic Retrieval Augmented Generation based on the Information Needs of Large Language Models

Weihang Su, Yichen Tang, Qingyao Ai, Zhijing Wu, Yiqun Liu · 2024

Self-attention is a Transformer-based LLM mechanism that allocates attention to tokens. It measures token influence to detect real-time information needs and formulate queries: following-token attention signals retrieval needs, while preceding-token attention identifies context for the next token; reliance on it is a primary limitation.

attention in TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text

Songshuo Lu · 2025

Attention is a mechanism used by transformers. It compares a current generated token’s query with context keys using scaled dot products, masks and normalizes the scores, then computes the current output as a weighted sum of context value vectors; cross-attention between retrieved fragments may be unnecessary.

Narrative, section by section

2 sections; each heading opens the text

3 / Methodology .. 3.4 / The TurboRAG Pipeline

Attention uses a query from the current generated token and keys and values from the context, with scores formed by scaled query-key dot products. The scores are masked and normalized before the current output is computed as a weighted sum of value vectors.

5 / Conclusion and Discussion .. Limitations

TurboRAG avoids inter-document cross-attention when combining retrieved text fragments. The findings raise questions about whether computationally intensive cross-attention between fragments is necessary when direct query-document interactions suffice.
