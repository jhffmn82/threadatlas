Cross-Lingual Dense Passage Retrieval is a retrieval method and model in the RAMKG framework. Given a non-English, often low-resource, passage, it uses a query encoder to search indexed English passage encodings with KNN and FAISS, returning the top related English passages. Alignment training on parallel or mined pseudo-parallel passage pairs maps corresponding multilingual passages nearby. The retrieved passages’ associated English keyphrases then support generation in the current language.

Abstract

The cross-lingual dense passage retrieval module finds relevant English passages for a given non-English passage. The associated English keyphrases from those passages are then used to support generation in the current language.

Related Work

Cross-Lingual Dense Passage Retrieval is shown as the retrieval component in the RAMKG framework. It finds the top m English passages associated with a passage input and provides their keyphrases to the generator.

Model .. 4.3

Cross-lingual dense passage retrieval encodes English passages offline and converts a non-English source passage into a query vector for nearest-neighbor search. It is trained to map corresponding passages in different languages into nearby vector regions using parallel or mined pseudo-parallel passage pairs.
