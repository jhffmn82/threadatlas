Kendall rank correlation coefficient

metric · 3 works · 6 quoted facts · 1 connection
Also called: Kendall’s Tau, Kendall’s Tau binary, Kendall’s Tau continuous, Kendall’s Taus, Kendall’s tau, Kendall’s τ

Abstract written by a model

In RACE: Retrieval-Augmented Commit Message Generation, Kendall’s Tau is calculated pairwise among four volunteers to assess agreement, with values ranging from 0.73 to 0.95. In ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems, Kendall’s τ is a ranking correlation metric that compares concordant and discordant pairs and evaluates RAG-system ranking accuracy. In RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems, Kendall’s tau measures agreement between GPT-4-turbo rankings and ground-truth rankings on a scale from 0 to 1.

Kendall rank correlation coefficient in ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems

Jon Saad-Falcon · 2024 · the work’s page · read it where Kendall rank correlation coefficient first appears

Abstract written by a model

Kendall’s τ is a ranking correlation metric that compares concordant and discordant pairs between correct and ARES rankings. Ranging from 0.0 to 1.0, success is above 0.9. It evaluates RAG-system ranking accuracy: ARES exceeds RAGAS in pseudo-system experiments and reaches 0.91 context relevance and 0.97 answer relevance for existing systems.

Narrative, section by section written by a model

2 sections; each heading opens the text

Experiments / 4.1 .. 4.3

The Kendall rank correlation coefficient, or Kendall's tau, measures the correlation between the correct ranking and the ARES ranking by comparing concordant and discordant pairs. A value greater than 0.9 is considered successful, with the coefficient ranging from 0.0 to 1.0.

Results & Analysis / 5.1 .. 5.4

Kendall’s tau measures how accurately methods rank RAG systems. ARES averages 0.065 higher than RAGAS for context relevance and 0.132 higher for answer relevance in the pseudo-system experiments, and it averages 0.91 for context relevance and 0.97 for answer relevance when ranking existing RAG systems.
