Abstract written by a model

A query context is generated from an OpenQA question by pretrained language models without external supervision, as an answer, answer-containing sentence, or relevant passage title. It enriches query semantics and increases overlap with positive passages. Multiple diverse, complementary contexts can be generated and their retrieval results fused to improve accuracy, though hallucinated content may add noise. Future extensions include more contexts, sampling, and testing mutual enhancement among contexts from one generator.

Generation-Augmented Retrieval / Task Formulation .. Generative Reader

A query context is a generated answer, answer-containing sentence, or relevant passage title used to augment an OpenQA question. Multiple complementary query contexts can improve retrieval accuracy, although hallucinated content may introduce noise.

Experiment Results .. Efﬁciency of GAR

A query context can be an answer, sentence, or title generated from a question. Different query contexts are complementary, and fusing their retrieval results consistently improves performance.

Conclusion .. Future Extensions

Generated relevant contexts enrich query semantics and improve retrieval accuracy. Future work may generate multiple contexts, use sampling instead of greedy decoding, or investigate whether contexts generated by the same generator can mutually enhance one another.
