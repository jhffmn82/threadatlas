RA-RAG

method · 1 work · 43 quoted facts · 11 connections
Also called: RA-RAG (Ours), Reliability-Aware RAG, Reliability-Aware RAG (RA-RAG), our framework, reliability estimation method
  • In Retrieval-Augmented Generation with Estimation of Source Reliability: RA-RAG, or Reliability-Aware RAG, is a new multi-source retrieval-augmented generation framework and method for sources with heterogeneous reliability. Its central function is to estimate each source’s reliability automatically before deployment through iterative cross-source fact-checking, without manual fact-checking, then use those estimates during inference. It performs source-level retrieval, prioritizing documents that are both reliable and relevant, and selectively retrieves from the top-κ reliable and relevant sources through κ-Reliable and Relevant Source Selection. This selective retrieval is important because it reduces computational overhead, supports efficient scaling as source counts grow, and can retain performance close to using all sources with only a small subset. After retrieval, RA-RAG filters responses, clusters them semantically, and aggregates information using Weighted Majority Voting. Sources estimated as more reliable receive higher weights, so the framework can accurately estimate a correct answer even when incorrect answers occur more frequently. Final reliability-based weights are incorporated into inference. The framework is presented first as a way to obtain robust information from mixed-quality sources, then unfolds through reliability estimation before deployment, reliability-aware retrieval, and weighted aggregation for answer generation. It focuses on short-form question answering but is presented as extending to long-form and multi-hop question answering. Experimental records report that it estimates real-world source reliability effectively, particularly for news-related claims; consistently outperforms evaluated baselines under the Beta prior; remains robust as adversarial sources increase under adversary-hammer settings; and achieves performance comparable to optimal Oracle WMV while using fewer sources. Performance is stable from κ = 4 across NQ, TQA, and HotpotQA. A stated limitation is that specialized topics remain challenging when cross-verification references are limited.

RA-RAG in Retrieval-Augmented Generation with Estimation of Source Reliability

Jeongyeon Hwang, Junyoung Park, Hyejin Park, Dongwoo Kim, Sangdon Park, Jungseul Ok · 2025

RA-RAG, or Reliability-Aware RAG, is a new multi-source retrieval-augmented generation framework and method for sources with heterogeneous reliability. Its central function is to estimate each source’s reliability automatically before deployment through iterative cross-source fact-checking, without manual fact-checking, then use those estimates during inference. It performs source-level retrieval, prioritizing documents that are both reliable and relevant, and selectively retrieves from the top-κ reliable and relevant sources through κ-Reliable and Relevant Source Selection. This selective retrieval is important because it reduces computational overhead, supports efficient scaling as source counts grow, and can retain performance close to using all sources with only a small subset. After retrieval, RA-RAG filters responses, clusters them semantically, and aggregates information using Weighted Majority Voting. Sources estimated as more reliable receive higher weights, so the framework can accurately estimate a correct answer even when incorrect answers occur more frequently. Final reliability-based weights are incorporated into inference. The framework is presented first as a way to obtain robust information from mixed-quality sources, then unfolds through reliability estimation before deployment, reliability-aware retrieval, and weighted aggregation for answer generation. It focuses on short-form question answering but is presented as extending to long-form and multi-hop question answering. Experimental records report that it estimates real-world source reliability effectively, particularly for news-related claims; consistently outperforms evaluated baselines under the Beta prior; remains robust as adversarial sources increase under adversary-hammer settings; and achieves performance comparable to optimal Oracle WMV while using fewer sources. Performance is stable from κ = 4 across NQ, TQA, and HotpotQA. A stated limitation is that specialized topics remain challenging when cross-verification references are limited.

Reliability-Aware RAG (RA-RAG) estimates source reliability automatically through cross-source fact-checking before deployment and aggregates responses according to the estimated reliability during inference. It uses response filtering, semantic clustering, weighted majority voting, and κ-Reliable and Relevant Source Selection.

Experiments / Experimental setups .. Ablation studies and analysis

RA-RAG is evaluated for aggregating information from multiple sources with heterogeneous reliability. It consistently outperforms the baselines, approaches Oracle WMV performance while using fewer sources, and remains robust as adversarial sources increase.

Conclusion

RA-RAG is a multi-source RAG framework that estimates source reliability and incorporates it into retrieval and answer generation. It is presented as applicable beyond short-form question answering to long-form and multi-hop question answering.

Limitations

The reliability estimation method effectively estimates the reliability of real-world sources, especially for news-related claims with abundant fact-checking sources. Applying it to specialized topics remains challenging because of limited references for cross-verification.
