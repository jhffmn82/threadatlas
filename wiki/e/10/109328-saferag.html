SafeRAG in SafeRAG: Benchmarking Security in Retrieval-Augmented Generation

Xun Liang, Simin Niu, Zhiyu Li, Sensen Zhang, Hanyu Wang, Feiyu Xiong, Jason Zhaoxin Fan, Bo Tang, Jihao Zhao, Jiawei Yang, Shichao Song, Mengwei Wang · 2025

SafeRAG is a Chinese security benchmark for single-modal, unstructured textual retrieval-augmented generation (RAG), designed to assess RAG vulnerabilities and robustness against data injection attacks. It uses the SafeRAG dataset to simulate attack scenarios across 14 representative RAG components and systematically evaluates retriever and generator risks throughout the pipeline. The benchmark examines four critical attack tasks, noise, conflict, toxicity, including implicit toxic attacks, and DoS, at the knowledge-base, retrieved-context, and filtered-context stages. It introduces improved or novel strategies: silver noise, inter-context conflict, soft ad, and white DoS. Evaluation combines model-based and rule-based methods, using F1 score for correct, incorrect, and average outputs, Attack Success Rate, and Retrieval Accuracy; detailed results are shown in Table 4. SafeRAG exposes critical gaps in existing defenses and provides insights into robustness against data injection attacks. Its scope ends with stated limitations: it does not evaluate model backdoor attacks, multimodal RAG, or structured retrieval scenarios.

SafeRAG: Benchmarking Security in Retrieval-Augmented Generation / Abstract

SafeRAG is a benchmark designed to evaluate the security of retrieval-augmented generation. Its authors use the SafeRAG dataset to simulate attack scenarios and report vulnerabilities across 14 representative RAG components.

Introduction

SafeRAG is introduced as a RAG security evaluation benchmark that evaluates retriever and generator risks across different stages of the RAG pipeline. It applies four improved attack tasks and includes lightweight attack-specific datasets and metrics.

Related Work / RAG Security Evaluation Dataset .. RAG Security Evaluation Metric

SafeRAG evaluates noise, conflict, toxicity, and DoS attacks at the knowledge base, retrieved context, and filtered context stages. It uses model-based and rule-based evaluation with F1, Attack Success Rate, and Retrieval Accuracy, and targets Chinese domain-specific question answering.

Conclusion

SafeRAG is introduced as a benchmark designed to assess the security vulnerabilities of RAG against data injection attacks. It evaluates noise, conflict, toxicity, and DoS attack tasks.

Limitations

SafeRAG primarily evaluates vulnerabilities in retrieval-augmented generation pipelines caused by data injection attacks. It does not assess model backdoor attacks or multimodal and structured retrieval scenarios, but it provides the first Chinese security benchmark for retrieval-augmented generation and offers insights into robustness against data injection attacks.
