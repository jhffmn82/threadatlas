Visual RAG

method · 1 work · 14 quoted facts · 4 connections
Also called: Visual Retrieval Pipeline, VisualRAG, vision-based retrieval, visual RAG, visual RAG pipeline, visual retrieval

Abstract written by a model

In VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation, Visual RAG is a pipeline that extracts and analyzes visual elements from PDFs, creates page-level visual embeddings, retrieves relevant pages with ColQwen2, and provides them as visual context to multimodal LLMs for answer generation. In VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation, VisualRAG is evaluated as an end-to-end QA approach and improves over Text RAG for Qwen2-VL and ChatGPT-4o, while Gemini scores 39.80 with Visual RAG. In VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation, visual retrieval uses LLM-based late-interaction multi-vector models, with ColPali and ColQwen2 outperforming text baselines for source-document identification at k=5.

Visual RAG in VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation

Manan Suri, Puneet Mathur, Franck Dernoncourt, Kanika Gowswami, Ryan A. Rossi, and Dinesh Manocha · 2025 · the work’s page · read it where Visual RAG first appears

Abstract written by a model

Visual RAG is a pipeline for PDFs that extracts and analyzes images, charts, and diagrams, creates page-level visual embeddings, and uses ColQwen2 to retrieve query-relevant pages. With a context window k = 5 based on an ANLCS threshold of 0.7, it gives retrieved pages to multimodal LLMs as visual context, then applies Evidence Curation, Chain-of-Thought, and answer generation. It consistently outperforms Textual RAG, especially on SlideVQA.

VisDoMRAG / 5.1 .. 5.2

The visual RAG pipeline extracts and analyzes graphical elements such as images, charts, and diagrams. It creates page-level visual embeddings, retrieves relevant pages, and supplies them as visual context to multimodal LLMs.

Results / 7.1 .. 7.3

Visual RAG consistently outperforms Textual RAG on the evaluated datasets because the data is predominantly visually rich. It is particularly advantageous on SlideVQA, where slides often lack extensive textual descriptions of visualizations.
