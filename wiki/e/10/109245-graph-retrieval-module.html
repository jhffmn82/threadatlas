graph retrieval module

system · 1 work · 3 quoted facts · 4 connections
Also called: KG, knowledge graph

Abstract written by a model

A system that accepts extracted entities, relations, or domains, builds connected ego-graphs, retrieves reasoning paths from topic entities, and serves HYBGRAG and ReAct when text lacks useful information.

graph retrieval module is in one work on this site, HYBGRAG: Hybrid Retrieval-Augmented Generation on Textual and Relational Knowledge Bases. This is the abstract a model wrote of it from that work.
