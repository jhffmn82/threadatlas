multi-source RAG framework

topic · 1 work · 4 quoted facts · 4 connections
Also called: multi-source RAG

Abstract written by a model

Multi-source RAG is a retrieval-augmented generation framework that partitions documents by source, generates source-specific responses, and aggregates them using source reliability. It addresses heterogeneous relevance and truthfulness by cross-checking sources and iteratively estimating reliability, and is evaluated across independently constructed sources.

multi-source RAG framework is in one work on this site, Retrieval-Augmented Generation with Estimation of Source Reliability. This is the abstract a model wrote of it from that work.

Problem Formulation / Standard RAG .. Multi-source RAG with source reliability

The multi-source RAG framework partitions the database into document sets associated with distinct sources. It generates a response from each source's retrieved documents and aggregates the source-specific responses using source reliability.

Method: RA-RAG .. Iterative reliability estimation

Multi-source RAG is the setting whose challenges RA-RAG addresses by cross-checking information across multiple sources and aggregating their responses according to estimated reliability.

G

It is evaluated across independently constructed sources whose relevance and truthfulness can differ.
