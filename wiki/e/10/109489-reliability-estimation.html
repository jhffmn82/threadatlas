reliability estimation in Retrieval-Augmented Generation with Estimation of Source Reliability

Jeongyeon Hwang, Junyoung Park, Hyejin Park, Dongwoo Kim, Sangdon Park, Jungseul Ok · 2025

Reliability estimation is an iterative method for estimating the probability that documents retrieved from each source are correct, without manual fact-checking. Embedded in retrieval-augmented generation, it supports Reliability-Aware RAG by guiding retrieval and aggregation with source reliability. It cross-checks information across sources through fact-checking queries. The method begins by assigning every source a weight of 1. It then repeatedly estimates answers to the queries with WMV and updates each source’s reliability according to its agreement with those estimated answers, stopping when weights converge or a maximum iteration count is reached. It extends WMV and uses κ-RRSS for scalable inference as source counts increase. It is applied to real-world sources and evaluated on collected and augmented data, while also assessing response accuracy. A key limitation is that unreliable, low-coverage sources can produce misaligned responses that distort weights and favor adversaries unless filtering is used. In the reported inference setting, wall-clock time stays relatively stable, from 1.21 seconds with 5 sources to 1.82 seconds with 1,000 sources.

Introduction

Source reliability estimation cross-checks information across multiple sources without requiring manual fact-checking. Reliability-Aware RAG uses this estimation to guide retrieval and aggregation.

Related Works

Reliability estimation is used in learning from noisy sources to assess data providers and aggregate trustworthy information. The unit identifies explicitly embedding reliability estimation in RAG systems as the contribution of RA-RAG and, to the authors' knowledge, the first such work.

Problem Formulation / Standard RAG .. Multi-source RAG with source reliability

Source reliability estimation determines the values representing the probability that retrieved documents from each source are correct. The unit identifies this estimation as a required component and notes that it is difficult because ground-truth fact-checking is labor-intensive.

Method: RA-RAG .. Iterative reliability estimation

Iterative reliability estimation initializes every source weight to 1, repeatedly estimates answers to fact-checking queries with WMV, and updates source reliability from agreement with those answers. The process stops when the weights converge or the maximum number of iterations is reached.

Real-world Application / Setup .. Experimental results

The iterative reliability estimation method is applied to real-world sources and evaluated using both collected data and datasets augmented to represent different reliability levels. It estimates source reliability while also producing responses whose accuracy is evaluated.

C

Reliability estimation is hindered by frequent misaligned responses from unreliable sources with low coverage. Without filtering, estimated weights become distorted and assign more weight to adversaries; filtering mitigates this distortion.

J / Inference phase / Reliablity estimation phase

Our method is evaluated on NQ with a Beta prior using one RTX 6000 Ada GPU. Its inference time remains relatively stable as the number of sources increases, from 1.21 seconds for 5 sources to 1.82 seconds for 1,000 sources.
