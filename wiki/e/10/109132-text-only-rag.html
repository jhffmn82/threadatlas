text-only RAG

method · 2 works · 10 quoted facts · 2 connections
Also called: Textual Retrieval Pipeline, text-only pipeline, text-only pipelines, textual RAG pipeline, traditional text-only RAG

Abstract written by a model

In VISA: Retrieval Augmented Generation with Visual Source Attribution, text-only RAG uses textual inputs and outputs for questions, retrieved documents, generated answers, and citations, typically represents them in textual form, and can require users to read entire documents to locate supporting content for document-level attribution. In VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation, the textual RAG pipeline extracts document text with Optical Character Recognition, segments it into indexable chunks, preserves source-document and page metadata, indexes chunks using a text embedding model, retrieves chunks relevant to a query, provides them and the query to a large language model, and uses Evidence Curation, Chain-of-Thought, and answer generation.
