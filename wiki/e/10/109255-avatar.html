AVATAR

object · 1 work · 4 quoted facts · 0 connections

Abstract written by a model

AVATAR is a recent LLM agent based on Claude 3 Opus that iteratively optimizes prompts through contrastive reasoning. It requires at least 500 API calls during training, serves as a self-reflective STARK baseline, and is strongest before hybrid retrieval and HYBGRAG, though first attempts may fail.

AVATAR is in one work on this site, HYBGRAG: Hybrid Retrieval-Augmented Generation on Textual and Relational Knowledge Bases. This is the abstract a model wrote of it from that work.
