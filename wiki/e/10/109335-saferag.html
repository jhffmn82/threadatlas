SafeRAG in SafeRAG: Benchmarking Security in Retrieval-Augmented Generation

Xun Liang, Simin Niu, Zhiyu Li, Sensen Zhang, Hanyu Wang, Feiyu Xiong, Jason Zhaoxin Fan, Bo Tang, Jihao Zhao, Jiawei Yang, Shichao Song, Mengwei Wang · 2025

SafeRAG is a manually constructed security evaluation dataset and framework for retrieval-augmented generation (RAG). Designed for academic and security research, it evaluates how RAG pipelines handle malicious contexts during question-answering and aims to improve RAG robustness. It unfolds from attack-scenario construction: for each of four tasks, attack texts are integrated with golden contexts, producing data with questions, golden contexts, and attack contexts. The dataset covers Noise, Conflict, Toxicity, and DoS attacks, and is defined as the union of the silver noise, inter-context conflict, soft ad, and white DoS evaluation datasets. For each data point, SafeRAG constructs multiple options and evaluates security through multiple-choice questions. It provides a threat framework for analyzing RAG-pipeline vulnerabilities caused by malicious contexts and standardizes security evaluation. It does not collect or use personally identifiable information or offensive content, though its standardized framework may inadvertently help adversaries understand testing and devise evasive strategies.

The RAG security evaluation dataset, also called the SafeRAG dataset, is a lightweight attack dataset developed for each attack task and used before RAG security evaluation. Constructed primarily manually, it evaluates retrieval-augmented generation security by triggering vulnerabilities through noise, conflict, toxicity, and DoS attacks. It includes silver noise, conflict, soft ad, and White DoS security evaluation datasets. These datasets, DSN, DICC, DSA, and DWDoS, combine attack contexts with selected or complete golden contexts; their union forms SafeRAG.
