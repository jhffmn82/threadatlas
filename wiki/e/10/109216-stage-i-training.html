Stage-II: Domain Adaptive Fine-tuning

Stage-I training in SimRAG: Self-Improving Retrieval-Augmented Generation for Adapting Large Language Models to Specialized Domains

Ran Xu, Hui Liu, Sreyashi Nag, Zhenwei Dai, Yaochen Xie, Xianfeng Tang, Chen Luo, Yang Li, Joyce C. Ho, Carl Yang, Qi He · 2025

Stage-I training is a general-domain, retrieval-oriented fine-tuning stage that precedes Stage-II domain adaptive fine-tuning. It trains an instruction-tuned LLM on general supervised fine-tuning, general instruction, context-aware question-answering, and retrieval-related data to improve context use, answer generation, query generation, and domain-specific question answering. Using one epoch, AdamW, a 5e-7 learning rate, batch size 64, and gradient accumulation 8, it improves question-answering performance and produces higher-quality synthetic question-answer pairs.

Narrative, section by section

4 sections; each heading opens the text

Related Work

Retrieval-oriented fine-tuning is the first stage of SimRAG. It includes fine-tuning on general supervised fine-tuning data, general domain question-answering data, and retrieval-related data.

Methodology / Problem Setup .. Stage-II: Domain Adaptive Fine-tuning

Stage-I retrieval-oriented fine-tuning trains an instruction-tuned LLM on general instruction, context-aware QA, and retrieval-related data. It targets improved context use, answer generation, and query generation for knowledge-intensive tasks.

Experimental Setup / Tasks and Datasets .. Implementation Details

Stage-I training uses a learning rate of 5e-7, a global batch size of 64, gradient accumulation of 8, and one training epoch. AdamW is used with β1=0.9 and β2=0.95.

Experimental Results / Main Results .. Case Studies

Stage-I performs retrieval-oriented fine-tuning, which significantly improves language-model performance on question-answering tasks compared with the original backbone. After Stage-I, SimRAG generates higher-quality synthetic question-answer pairs, including more self-contained and contextually appropriate examples.
