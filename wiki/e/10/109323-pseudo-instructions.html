Narrative, section by section

5 sections; each heading opens the text

Abstract

Pseudo-instructions are formed from document summaries and guide PIC's chunking process toward content relevant to potential user instructions.

1 / Introduction

A pseudo-instruction is a document summary used to guide segmentation when the actual distribution of user instructions is unknown. Sentence-level semantic similarity to the pseudo-instruction determines how sentences are grouped into chunks.

3 / Methodology .. 3.2 / Chunking Based on Pseudo-Instructions

Pseudo-instructions guide chunking without requiring knowledge of the real distribution of user instructions. In this methodology, document summaries serve as pseudo-instructions.

6 / Further Analysis / 6.1 / Impacts of the Pseudo-Instruction .. 6.4 / Chunk Analysis

The pseudo-instruction guides chunking so that segmented chunks better align with the possible real instruction distribution. Using a document's summary as the pseudo-instruction performs better than using a random summary, a random sentence, or the mean of sentence embeddings.

7 / Conclusions / Limitations

Pseudo-instructions derived from document summaries guide PIC in creating chunks that better align with potential user instructions.
