Abstract written by a model

PaperTab is a Wikipedia-based data split in VisDoMBench, sourced from QASPER through UDA Benchmark. It contains tables and text across 297 documents and 377 queries. Overlapping samples with SPIQA were removed, and some questions were considered for augmentation to reduce ambiguity. It supports retrieval and end-to-end QA evaluation using modified Word Overlap F1, with an example showing reasoning-chain-based correct answering.

PaperTab is in one work on this site, VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation. This is the abstract a model wrote of it from that work.
