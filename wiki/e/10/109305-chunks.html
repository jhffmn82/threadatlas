Abstract written by a model

In "Document Segmentation Matters for Retrieval-Augmented Generation," chunks are manageable document segments used for retrieval and response generation, dynamically grouped by relevance to the document topic. In "Knowledge Graph-Guided Retrieval Augmented Generation," chunks are basic document units that serve as seeds for semantic retrieval, are linked through a knowledge graph, and are expanded, filtered, and organized for language-model input. In "TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text," retrieved document chunks are processed by computing and storing each chunk’s KV cache independently for later reuse and combination across queries.

Zhitong Wang, Cheng Gao, Chaojun Xiao, Yufei Huang, Shuzheng Si, Kangyang Luo, Yuzhuo Bai, Wenhao Li, Tangjian Duan, Chuancheng Lv, Guoshan Lu, Gang Chen, Fanchao Qi, Maosong Sun · 2025 · the work’s page · read it where chunks first appears

Abstract written by a model

Chunks are manageable document segments used for retrieval and response generation. Existing chunking can produce units that are too large and irrelevant or too small to preserve semantic information. PIC addresses this by dynamically grouping one or more sentences according to relevance to the document topic, classifying chunks through similarity-score thresholds. It aims for semantic completeness, coherence, and alignment with potential user instructions, while limiting lengthy source documents' processing demands.

chunks in Knowledge Graph-Guided Retrieval Augmented Generation

Xiangrong Zhu · 2025-04-29 to 2025-05-04 · the work’s page · read it where chunks first appears

Abstract written by a model

Chunks are basic document units for retrieval and knowledge-graph association. They can contain preprocessing metadata or added context and act as seeds for semantic retrieval. Rather than remaining isolated, retrieved seed chunks are linked through a specific knowledge graph that captures fact-level relationships, then expanded, filtered, and organized. The result is diverse, intrinsically related, self-consistent, well-organized paragraphs for large language model input.

retrieved document chunks in TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text

Songshuo Lu · 2025 · the work’s page · read it where retrieved document chunks first appears

Abstract written by a model

TurboRAG is a pipeline that handles retrieved document chunks by computing and storing each chunk’s KV cache independently offline, then reusing and combining caches across queries without cross-attention. This avoids conventional concatenation before prefill and its O(k) input-length growth for k chunks.

Narrative, section by section written by a model

2 sections; each heading opens the text

1 / Introduction .. Contributions

Chunks are retrieved passages that are conventionally concatenated before prefill, increasing input length by O(k) for k chunks. TurboRAG treats chunks independently during offline KV-cache computation and reuses their caches across queries.

3 / Methodology .. 3.4 / The TurboRAG Pipeline

A document chunk is one of the top k chunks retrieved for a user query. TurboRAG computes and stores its KV cache independently, then combines the caches of the retrieved chunks without cross-attention between them.
