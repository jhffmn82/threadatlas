Abstract written by a model

SlideVQA is a multi-image, multi-hop QA dataset centered on presentation slide decks, with slides as content. It contributes 551 queries and 244 documents to VisDoMBench, excluding single-hop questions to suit multi-document retrieval. It has a substantial visual-text gap: visual models outperform text-only retrieval and generation because slides often have sparse text and poorly described visualizations. It is evaluated for retrieval and end-to-end QA; ColQwen2 reaches 97.82 source-document identification at k=5.

SlideVQA is in one work on this site, VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation. This is the abstract a model wrote of it from that work.

VisDoMBench / 4.1

SlideVQA is a multi-image, multi-hop QA dataset centered on presentation slide decks, contributing 551 queries and 244 documents to VisDoMBench. Single-hop questions were excluded because multi-hop questions were judged more likely to reference specific documents and fit the multi-document setting.

Experiments / 6.1 .. 6.2

SlideVQA is evaluated for retrieval performance and end-to-end QA. ColQwen2 provides the highest reported source-document identification score for it at k = 5, with 97.82.

Results / 7.1 .. 7.3

SlideVQA shows a substantial performance gap between visual and textual retrieval and generation approaches. Visual models significantly outperform text-only models in document retrieval, and visual RAG is especially useful because slides often contain sparse text and limited descriptions of visualizations.
