vector similarity retrieval

method · 2 works · 3 quoted facts · 1 connection
Also called: Text Retriever, VSS, VSS (Text Retrieval Module), vector similarity, vector similarity search, vector similarity-based retrieval, vector similarity-based retrieval module

Abstract written by a model

In A Survey of Graph Retrieval-Augmented Generation for Customized Large Language Models, vector similarity retrieval selects text chunks according to semantic similarity between a query and stored representations. In HYBGRAG: Hybrid Retrieval-Augmented Generation on Textual and Relational Knowledge Bases, VSS serves as a textual retriever that compares questions and documents, retrieves and ranks them, and uses an LLM reranker.
