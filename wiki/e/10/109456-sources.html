sources in Retrieval-Augmented Generation with Estimation of Source Reliability

Jeongyeon Hwang, Junyoung Park, Hyejin Park, Dongwoo Kim, Sangdon Park, Jungseul Ok · 2025

Sources are independently generated from one selected question-answering dataset and are characterized by reliability and coverage. They may provide factual or misinformation documents, contain different knowledge, and differ in whether they include relevant documents. The benchmark uses these variations to simulate diverse source quality. In experiments, filtering uses one source with pi and ri both 0.5; reliability estimation uses four adversary sources and one hammer source. RA-RAG aggregates multiple sources using WMV.

4 sections; each heading opens the text

Experiments / Experimental setups .. Ablation studies and analysis

Each source Si provides factual information with a probability determined by its reliability and contains relevant documents with a probability determined by its coverage. The benchmark generates diverse factual documents and misinformation to simulate sources with varying reliability.

C

The filtering analysis uses a single source with pi = 0.5 and ri = 0.5. The reliability-estimation experiment considers four adversary sources and one hammer source under the adversary-hammer prior.

F

Multiple sources are aggregated by RA-RAG using WMV.

G

They are constructed independently from factual or misinformation documents according to relevance and truthfulness parameters, so different sources may contain different knowledge.
