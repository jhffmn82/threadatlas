Corrective RAG

method · 1 work · 7 quoted facts · 3 connections
Also called: Corrective retrieval augmented generation

Abstract written by a model

Corrective RAG is a method sharing HYBGRAG’s backbone and retriever bank but using different critics. It starts with text retrieval, validates references as correct, ambiguous, or incorrect, invokes knowledge-graph retrieval for incorrect references, and generates a final chain-of-thought answer. Its implementation uses a pre-trained LLM rather than a fine-tuned retrieval evaluator.

Corrective RAG is in one work on this site, HYBGRAG: Hybrid Retrieval-Augmented Generation on Textual and Relational Knowledge Bases. This is the abstract a model wrote of it from that work.

appendix

Corrective RAG shares HYBGRAG's backbone but uses a different critic. Its implementation uses a pre-trained LLM rather than a fine-tuned retrieval evaluator; it begins with text retrieval, validates whether the reference is correct, ambiguous, or incorrect, and uses graph retrieval when the reference is incorrect before generating a chain-of-thought answer.
