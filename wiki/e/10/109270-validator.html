Abstract written by a model

Validator is a component that uses one API call and performs yes-or-no binary classification. It checks whether retrieved documents meet question requirements, using reasoning paths in an extracted ego-graph as context; it can reject text-retrieved documents, assess alignment in STARK, and determine whether generated predictions answer questions in CRAG.

validator is in one work on this site, HYBGRAG: Hybrid Retrieval-Augmented Generation on Textual and Relational Knowledge Bases. This is the abstract a model wrote of it from that work.
