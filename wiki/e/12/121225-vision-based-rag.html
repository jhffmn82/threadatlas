vision-based RAG

topic · 1 work · 5 quoted facts · 2 connections
Also called: vision-based RAG pipelines, vision-based RAG setup, vision-based RAG systems

Abstract written by a model

Vision-based RAG is a RAG pipeline that represents retrieved documents as screenshot images and accepts textual user queries. It uses VLMs to process questions with document screenshots, leveraging structures and visual content such as tables, graphs, and images. Its generation can use VISA to return an answer, relevant document, and supporting visual region. It is evaluated amid challenges of richer responses, multi-section or multi-document evidence, cross-domain variation, and candidate-set scaling.

2 / 2.1 .. 2.2

It represents retrieved documents as screenshot images and uses VLMs to process textual questions together with those images. Compared with text-only RAG, it can leverage document structures and visual information such as tables, graphs, and images.

3 / 3.1 .. 3.3

Vision-based RAG systems use textual user queries and document screenshots as image inputs. Their generation component can use VISA to provide an answer together with the relevant document and supporting visual region.

Limitations

Vision-based RAG systems are the setting in which VISA is evaluated for answer generation and content grounding. The unit identifies challenges for these systems involving richer responses, multi-section or multi-document evidence, cross-domain document variation, and candidate-set scaling.
