  • In TableRAG: A Retrieval Augmented Generation Framework for Heterogeneous Document Reasoning: TableRAG is an SQL-based, SQL-driven framework for heterogeneous document-based and table-based question answering. It unifies textual understanding, text retrieval, and precise manipulation of tabular data, dynamically moving between retrieved text and SQL-executed table reasoning while preserving table structural integrity. Its workflow begins with offline database construction, including text chunking into 1,000-token segments with 200-token overlap. Online, it performs iterative reasoning for at most five iterations: context-sensitive query decomposition, text retrieval, SQL programming and execution, selectively for tabular subqueries, and compositional intermediate answer generation. During recall it retains 30 candidates and reranks them to select 3, then combines retrieved textual chunks with SQL execution results. TableRAG uses SQL as a symbolic-execution interface for tables, which is presented as central to its execution efficiency and reasoning accuracy. It develops HeteQA and is evaluated on HybridQA, WikiTableQuestion, and HeteQA using Claude-3.5-Sonnet, DeepSeek-V3, and Qwen-2.5-72B. It surpasses evaluated baselines, including retrieval-augmented generation and ReAct across most domains, on both single-source and multi-source data; it achieves state-of-the-art performance for heterogeneous document question answering. It requires fewer execution steps and has lower latency than ReAct: approximately 63.55% of instances finish in fewer than five steps and another 30.00% in exactly five, with only a marginal unsolved proportion. Reported total latency is 13.50 seconds on WikiTQ and 24.57 seconds on HeteQA. It also has the lowest assessed failure rate and consistently yields valid responses within five iterations. Performance is weaker for Culture with the Qwen backbone, and effectiveness depends closely on underlying LLM capabilities; substantial computational resources may be needed for competitive results.

TableRAG in TableRAG: A Retrieval Augmented Generation Framework for Heterogeneous Document Reasoning

Xiaohan Yu, Pu Jian, Chong Chen · 2025

TableRAG is an SQL-based, SQL-driven framework for heterogeneous document-based and table-based question answering. It unifies textual understanding, text retrieval, and precise manipulation of tabular data, dynamically moving between retrieved text and SQL-executed table reasoning while preserving table structural integrity. Its workflow begins with offline database construction, including text chunking into 1,000-token segments with 200-token overlap. Online, it performs iterative reasoning for at most five iterations: context-sensitive query decomposition, text retrieval, SQL programming and execution, selectively for tabular subqueries, and compositional intermediate answer generation. During recall it retains 30 candidates and reranks them to select 3, then combines retrieved textual chunks with SQL execution results. TableRAG uses SQL as a symbolic-execution interface for tables, which is presented as central to its execution efficiency and reasoning accuracy. It develops HeteQA and is evaluated on HybridQA, WikiTableQuestion, and HeteQA using Claude-3.5-Sonnet, DeepSeek-V3, and Qwen-2.5-72B. It surpasses evaluated baselines, including retrieval-augmented generation and ReAct across most domains, on both single-source and multi-source data; it achieves state-of-the-art performance for heterogeneous document question answering. It requires fewer execution steps and has lower latency than ReAct: approximately 63.55% of instances finish in fewer than five steps and another 30.00% in exactly five, with only a marginal unsolved proportion. Reported total latency is 13.50 seconds on WikiTQ and 24.57 seconds on HeteQA. It also has the lowest assessed failure rate and consistently yields valid responses within five iterations. Performance is weaker for Culture with the Qwen backbone, and effectiveness depends closely on underlying LLM capabilities; substantial computational resources may be needed for competitive results.

Abstract

TableRAG is an SQL-based framework that unifies textual understanding with complex manipulations over tabular data. It iteratively performs context-sensitive query decomposition, text retrieval, SQL programming and execution, and compositional intermediate answer generation, and it outperforms existing baselines on public datasets and HeteQA.

TableRAG is an SQL-based framework that dynamically transitions between textual understanding and complex tabular manipulation. It uses an offline database construction phase and an online iterative reasoning process involving query decomposition, text retrieval, SQL programming and execution, and intermediate answer generation.

TableRAG preserves table structural integrity and facilitates heterogeneous reasoning through offline database construction and online iterative inference. It uses SQL execution for tabular reasoning and combines execution results with retrieved textual chunks.
