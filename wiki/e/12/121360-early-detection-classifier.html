Early Detection Classifier in DioR: Adaptive Cognitive Detection and Contextual Retrieval Optimization for Dynamic Retrieval-Augmented Generation

Hanghui Guo, Jia Zhu, Shimin Di, Weijie Shi, Zhangze Chen, Jiajie Xu · 2025

Early Detection Classifier is a component of DioR that assesses, before generation, whether a large language model can answer a question independently. An RNN trained on Wikipedia question-answer examples labeled hallucination or non-hallucination uses IG Attribution Entropy features to assess confidence. If confidence is lacking, DioR triggers contextual retrieval optimization. In ablation experiments, removing early detection eliminates advance assessment and lowers performance relative to DioR.

Narrative, section by section

3 sections; each heading opens the text

Introduction

The Early Detection Classifier assesses whether the language model can answer a question independently before generation. When it finds that the model lacks confidence in its response, DioR triggers contextual retrieval optimization.

Proposed Method: DioR / Adaptive cognitive detection / Is LLM confident in answering this? .. Post-retrieval

The RNN classifier is trained on question-answer examples labeled as hallucination or non-hallucination, together with IG features. It estimates whether retrieval should be triggered before generation based on the LLM's confidence in answering a question.

Experiment / Experimental Setups .. Ablation Experiment

Early detection assesses the LLM’s ability to answer in advance. Removing it eliminates this assessment and lowers performance relative to DioR in the ablation experiment.
