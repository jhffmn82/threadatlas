  • In RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems, attribution links generated answers to supporting sources and evaluates evidential support across attributed question answering, citation generation, collaborative work, and automatic LLM evaluation.
  • In OG-RAG: Ontology-grounded retrieval-augmented generation for large language models, context attribution lets users trace generated responses to relevant context; OG-RAG makes this easier and faster, and a human user study found its contexts more supportive, verified faster, and enabled responses to be attributed 30% faster and better.

context attribution in OG-RAG: Ontology-grounded retrieval-augmented generation for large language models

Kartik Sharma · 2025-11-04/2025-11-09

Context attribution lets users trace generated responses to relevant context. OG-RAG is designed to make it easier and faster, and a human user study found that participants rated its contexts as more supportive than RAG contexts, verified them faster, and attributed responses 30% faster and better. The evidence is limited to this study, so larger-scale studies are needed.

Narrative, section by section

3 sections; each heading opens the text

Introduction

Context attribution allows users to trace generated responses back to relevant context. OG-RAG is designed to make this attribution easier and faster, with the evaluations reporting that users attribute responses 30% faster and better.

Experiments / Query answering .. Ontology sensitivity

Context attribution is evaluated through a human study of whether contexts support LLM-generated responses. Participants rated OG-RAG contexts as providing more support and verified them faster than RAG contexts.

Limitations

Context attribution was the focus of the evidence gathered in the user study. The study's findings were considered aligned with the scope of the work, but the text notes that larger-scale studies would provide more robust conclusions.
