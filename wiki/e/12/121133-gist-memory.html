gist memory in GEAR: Graph-enhanced Agent for Retrieval-augmented Generation

Zhili Shen · 2025

Gist memory is an agent component that stores proximal triples as aggregated evidence from completed retrievals. Initially empty, it updates each iteration and supports summarising information, later reading and reasoning, query re-writing, termination, and final passage-linking operations using commonly validated practices.

1 section; each heading opens the text

Retrieval with Synchronised Graph .. Reasoning for Termination / Query Re-writing / After Termination

Gist memory stores an array of proximal triples representing aggregated evidence from retrieved passages. It is initially empty, is updated after each iteration, and is supplied to later read, reasoning, query re-writing, and final passage-linking operations.
