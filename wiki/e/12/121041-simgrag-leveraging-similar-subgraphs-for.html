Abstract written by a model

This is an ACL 2025 paper, “SimGRAG: Leveraging Similar Subgraphs for Knowledge Graphs Driven Retrieval-Augmented Generation,” by Yuzheng Cai, Zhenyue Guo, Yiwen Pei, Wanrui Bian, and Weiguo Zheng of Fudan University. It addresses knowledge-graph-driven retrieval-augmented generation (KG-driven RAG), which uses knowledge graphs to help large language models reduce hallucinations and outdated knowledge, but faces difficulty aligning natural-language queries with graph structures. The paper introduces Similar Graph Enhanced Retrieval-Augmented Generation (SimGRAG). Given a query, an LLM first produces a query-aligned pattern graph. SimGRAG then finds structurally compatible knowledge-graph subgraphs through graph isomorphism and ranks them with Graph Semantic Distance (GSD), based on node and relation embeddings. Unknown entities or relations may be represented by unique identifiers and omitted from distance calculation. The highest-ranked retrieved subgraphs are verbalized as triples and provided to an LLM to generate the answer. The approach is intended to be plug-and-play, to avoid oracle entities, produce concise contexts, and work with human-understandable knowledge graphs. To make retrieval practical, SimGRAG uses semantic embeddings to filter candidate nodes and relations before search. Its top-k algorithm constructs mappings from the pattern graph to the knowledge graph and selects subgraphs with the smallest GSD. An optimized version prunes partial mappings whose lower-bound GSD cannot improve current results and greedily finds promising subgraphs earlier, while preserving the top-k algorithm’s results. The experiments cover Knowledge Graph Question Answering and Fact Verification on MetaQA, PathQuestions, WorldCup2014, and FactKG. Without additional training, SimGRAG reports 98.0, 98.4, and 97.8 Hits@1 on MetaQA 1-hop, 2-hop, and 3-hop questions, respectively, and 86.8% accuracy on FactKG; it is reported to outperform existing KG-driven RAG baselines. Optimized retrieval takes 0.74 seconds per FactKG query, while the 12-shot configuration averages 14.2 seconds total latency. Ablations examine few-shot examples, retrieval k, and LLM choice. The paper concludes that pattern-based alignment, GSD, and efficient top-k subgraph retrieval improve KG-driven RAG. It notes dependence on LLM capability, difficulty with industrial domain-specific graph structures, and entity-linking challenges when embedding models lack domain training; fine-tuning and specialized KG schemas in prompts may help.

Abstract

The paper studies KG-driven RAG and introduces Similar Graph Enhanced Retrieval-Augmented Generation (SimGRAG). SimGRAG aligns query texts with knowledge graph structures through query-to-pattern generation by an LLM and pattern-to-subgraph retrieval using graph semantic distance (GSD). Its optimized retrieval algorithm identifies top-k subgraphs within 1 second on a 10-million-scale knowledge graph. Experiments show that SimGRAG outperforms state-of-the-art KG-driven RAG methods in question answering and fact verification.

Introduction

The unit explains how knowledge-graph-driven Retrieval-Augmented Generation can reduce hallucinations and outdated knowledge in large language models while presenting challenges in query-to-graph alignment. It introduces SimGRAG, which uses a large language model to generate a query-aligned pattern graph, retrieves semantically and structurally matching subgraphs using Graph Semantic Distance, and supplies verbalized subgraphs to a large language model for answer generation. SimGRAG is designed for plug-and-play use with human-understandable knowledge graphs, avoids requiring oracle entities, produces concise contexts, and scales to large knowledge graphs. The text reports that experiments across multiple knowledge-graph-driven tasks show SimGRAG outperforming state-of-the-art baselines.

Related Work

The unit reviews how large language models (LLMs) handle knowledge graph tasks, including knowledge graph construction, completion, and embedding, and how they are integrated with Graph Neural Networks. It explains Retrieval-Augmented Generation as a way to address hallucination and outdated knowledge by retrieving information from external databases. It introduces Graph Retrieval-Augmented Generation as the integration of graphs into RAG pipelines and focuses on knowledge graph-driven RAG using existing manually constructed knowledge graphs. It compares methods including KAPING, KG-GPT, KELP, and G-Retriever for indexing, retrieving, and generating from knowledge graphs.

Preliminaries

The unit defines a knowledge graph (KG) as a set of triples consisting of entity nodes and relations. It describes Knowledge Graph Driven Retrieval-Augmented Generation as generating an answer to a user query by using large language models together with retrieved evidence from a KG. The task includes applications such as Knowledge Graph Question Answering and Fact Verification. It also defines an embedding model as transforming textual input into an embedding vector and specifies the L2 distance between two vectors.

The SimGRAG Approach / Query-to-Pattern Alignment .. Verbalized Subgraph-Augmented

The SimGRAG Approach aligns query text with knowledge graph structures through query-to-pattern alignment and pattern-to-subgraph alignment. A large language model generates a pattern graph P, after which graph isomorphism identifies structurally compatible subgraphs S in the knowledge graph G and Graph Semantic Distance ranks them using node and relation embeddings. Unknown entities or relations can be represented with unique identifiers and excluded from the distance calculation. Verbalized Subgraph-Augmented Generation supplies the top-k retrieved subgraphs as triples to the large language model, which generates an answer to the original query.

Semantic Guided Subgraph Retrieval addresses the cost of brute-force subgraph search by using semantic embeddings to filter candidate nodes and relations. The Top-k Retrieval Algorithm constructs mappings from the pattern graph P to the knowledge graph G and returns the top-k subgraphs with the smallest Graph Semantic Distance (GSD). The Optimized Retrieval Algorithm prunes partial mappings whose lower-bound GSD cannot improve the current results and uses a greedy strategy to find promising subgraphs earlier. The optimized method is stated to preserve the results of the Top-k Retrieval Algorithm while accelerating retrieval.

Experiments .. Overall Latency

The unit evaluates Knowledge Graph Question Answering and Fact Verification methods on MetaQA, PathQuestions, WorldCup2014, and FactKG. SimGRAG, a KG-driven retrieval-augmented generation method without additional training, achieves strong results, including 98.0, 98.4, and 97.8 Hits@1 on MetaQA 1-hop, 2-hop, and 3-hop questions and 86.8% accuracy on FactKG. Ablations show that performance varies with the number of few-shot examples, the retrieval parameter k, and the selected large language model. The unit also analyzes errors, retrieval efficiency, and latency, reporting 0.74 seconds per FactKG query for optimized retrieval and 14.2 seconds average latency for the 12-shot SimGRAG configuration.

Conclusion

The paper investigates KG-driven RAG and introduces SimGRAG, an approach for aligning query texts with knowledge graph structures. SimGRAG uses an LLM to generate a pattern graph aligned with the query text and introduces Graph Semantic Distance (GSD) to measure alignment between the pattern and underlying knowledge graph subgraphs. It also provides an optimized algorithm for efficiently retrieving the top-k subgraphs with the smallest GSD. Experiments show that SimGRAG consistently outperforms existing KG-driven RAG approaches.

Limitations

The unit describes limitations of SimGRAG, whose performance depends heavily on the capabilities of the large language model used in query-to-pattern alignment and verbalized subgraph-augmented generation. SimGRAG assumes that its input knowledge graph aligns with human cognition, but industrial domain-specific knowledge graphs may use structures that make pattern generation and alignment difficult. The text notes that LLM fine-tuning and including a specialized KG schema in prompts may improve alignment with such graphs. It also identifies entity linking as challenging in domain-specific knowledge graphs when the embedding model has not been trained on relevant data.
