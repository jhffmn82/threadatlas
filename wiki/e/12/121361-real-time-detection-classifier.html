Real-time Detection Classifier

object · 1 work · 5 quoted facts · 2 connections
Also called: MLP classifier, MLP-based hallucination detector, MLPC, Real-time Detection, Real-time Detection module, real-time detection

Abstract written by a model

Real-time Detection Classifier is a component of DioR that monitors generation for hallucinations. Trained on Wikipedia articles, extracted entities, and generated text, its MLP predicts whether generated tokens are hallucinations. When hallucinations are identified, DioR triggers contextual retrieval optimization. It determines when retrieval occurs; removing it instead triggers retrieval below 0.5 token probability and decreases performance.

Real-time Detection Classifier is in one work on this site, DioR: Adaptive Cognitive Detection and Contextual Retrieval Optimization for Dynamic Retrieval-Augmented Generation. This is the abstract a model wrote of it from that work.
