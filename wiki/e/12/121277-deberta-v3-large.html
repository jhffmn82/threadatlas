DeBERTa-v3-Large

model · 1 work · 16 quoted facts · 8 connections
Also called: 400M parameter DeBERTa model, DeBERTa, DeBERTa model, NLI model for RAG evaluation, NLI-based RAG evaluation model, base model, fine-tuned model

Abstract written by a model

DeBERTa-v3-Large is a 400M-parameter NLI model fine-tuned on RAGBench for RAG evaluation. It uses separate prediction heads on context tokens for Context Relevance and Utilization and on response tokens for Adherence; sentence-level annotations are broadcast to tokens during training, and relevant, utilized, and adherent spans are predicted at a 0.5 threshold. It is trained for three epochs on a Google Cloud Platform A-100 GPU instance, with distinct initial learning rates for base layers and heads, warmup, and linear decay. Across RAGBench domain subsets, it performs competitively with billion-parameter LLM judges and commercial RAG evaluation systems, and is reported to outperform LLM judges in hallucination and attribution detection.

DeBERTa-v3-Large is in one work on this site, RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems. This is the abstract a model wrote of it from that work.

Related Work .. Finetuned RAG evaluation models

The NLI-based RAG evaluation model is trained and evaluated using RAGBench. It is reported to outperform LLM judges in hallucination and attribution detection and to excel on the proposed RAG evaluation metrics.

RAG Case Study .. Estimating Context Relevance is Difficult

DeBERTa-v3-Large is fine-tuned from an NLI checkpoint with separate prediction heads for the RAG metrics. The resulting model achieves competitive performance with billion-parameter LLM judges across numerous RAGBench domain subsets.

Conclusion

A 400M-parameter DeBERTa model fine-tuned on RAGBench data performs competitively with billion-parameter LLM judges and commercial RAG evaluation systems.

DeBERTa model training

DeBERTa is trained for 3 epochs on a Google Cloud Platform A-100 GPU instance. Its base model layers and heads use different initial learning rates, with warmup and a linear decay rate.
