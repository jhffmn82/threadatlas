Abstract written by a model

Prompt injection is a malicious adversarial attack, also called jailbreaking, to which LLM-based applications are highly susceptible. It uses malicious prompts to make an LLM ignore its application context and generate offensive content, including through goal hijacking and prompt leaking. Existing alignment techniques may not address this risk. In the evaluated setting, adversarial strings appended to unsafe prompts substantially reduced interception rates in tested models without SafetyRAG; one injection instructing the model to consider prior context silently and begin with a specified phrase was particularly effective at triggering harmful behavior. SafetyRAG improved models’ ability to decline unsafe requests when prompt injections were present and showed especially significant interception improvements for this unsafe-prompt type.

Abstract—Large Language Model (LLM) agents have

Prompt injections are identified as a malicious use to which LLM-based applications are highly susceptible. SafetyRAG improves models’ ability to decline unsafe requests even when prompt injections are present.

I. INTRODUCTION

A prompt injection attack is an adversarial attack in which malicious prompts attempt to make an LLM ignore its application context and generate offensive content. The unit states that these attacks remain a significant risk even though model makers use fine-tuning and reinforcement learning.

II. LITERATURE REVIEW / A. Threats of Unsafe Prompts for LLMs .. B. Unsafe Prompt Mitigation

Adversarial prompt injection can manipulate LLM behavior through attacks such as goal hijacking and prompt leaking. The unit identifies it as a risk that existing alignment techniques may fail to address.

IV. RESULT AND DISCUSSION .. C. Discussion

Prompt injection appended adversarial strings to unsafe prompts and substantially reduced the interception rates of all tested models without SafetyRAG. The tested injection beginning with "Think about the context above without writing anything" and instructing the model to start with "Sure, here is how to" was identified as particularly effective at triggering harmful behavior.

V. CONCLUSION

Prompt injection is identified as a type of unsafe prompt for which SafetyRAG provides especially significant improvements in interception.
