GEAR in GEAR: Graph-enhanced Agent for Retrieval-augmented Generation

Zhili Shen · 2025 · the work’s page · read it where GEAR first appears

Abstract written by a model

GEAR, short for Graph-enhanced Agent for Retrieval-augmented Generation, is a system and novel graph-enhanced retrieval-agent framework for retrieving passages that enable retrieval-augmented models to answer multi-hop queries. It advances Retrieval-augmented Generation through two linked elements: an efficient graph expansion mechanism and an agent framework for multi-step retrieval. Offline, it aligns passages with extracted triples to create interconnected indices. During retrieval, its graph-based passage component, SyncGE, returns multi-hop contexts. GEAR turns these contexts into gist memory, proximal triples associated with passages, to maintain and summarize knowledge across steps. The agent models multi-step information seeking: it reads multi-hop contexts, maintains gist memory, assesses answerability, rewrites queries when needed, and terminates by returning one ranked passage list. Its central claim is that synchronising graph retrieval with the large language model makes multi-step retrieval more effective and efficient: it requires fewer iterations and fewer LLM tokens than other iterative retrieval methods, including HippoRAG w/ IRCoT even with a single iteration. Evaluated on MuSiQue, HotpotQA, and 2WikiMultihopQA against IRCoT, HippoRAG w/ IRCoT, and single-step approaches, GEAR achieves state-of-the-art multi-step retrieval results across the reported datasets. Reported R@15 scores are 71.5 on MuSiQue, 95.9 on 2Wiki-MultiHopQA, and 97.3 on HotpotQA; it also reports 93.4, 96.8, and 97.3 recall at R@5, R@10, and R@15 on HotpotQA. On MuSiQue, it delivers gains above 10%, a 21% relative R@15 improvement, and 37% relative improvements in both EM and F1 versus HippoRAG w/ IRCoT. In end-to-end QA using the top five passages, it has the highest EM and F1 scores across MuSiQue, 2Wiki, and HotpotQA. It is particularly strong on low-to-moderate-complexity questions, handles 3-hop questions with enhanced capability, and remains consistent across chunks with differing triple densities.

GEAR: Graph-enhanced Agent for Retrieval-augmented Generation

GEAR is the title of the work introduced in this unit. Its full name is Graph-enhanced Agent for Retrieval-augmented Generation.

Abstract

GEAR is a system that improves RAG through an efficient graph expansion mechanism and an agent framework for multi-step retrieval. It demonstrates superior retrieval capabilities across three multi-hop question answering datasets and achieves state-of-the-art results with improvements exceeding 10% on MuSiQue, while using fewer tokens and iterations than existing multi-step retrieval systems.

Introduction

GEAR is a Graph-enhanced Agent for Retrieval-augmented generation that aligns passages with extracted triples during an offline stage to create interconnected indices. It uses SyncGE for graph-based passage retrieval and constructs a memory from multi-hop context for multi-step retrieval. GEAR achieves state-of-the-art retrieval performance on MuSiQue, HotpotQA, and 2WikiMultihopQA while requiring fewer iterations and significantly fewer LLM tokens.

Preliminaries

GEAR is introduced to retrieve relevant passages from C that enable a retrieval-augmented model to answer multi-hop queries.

Retrieval with Synchronised Graph .. Reasoning for Termination / Query Re-writing / After Termination

GEAR is an agentic framework that performs multi-step information seeking with a graph-enhanced retriever. It maintains gist memory, assesses answerability, rewrites queries when necessary, and returns a single ranked list of passages after termination.

Experimental Setup .. Baselines / Implementation Details

GEAR is evaluated as a multi-step retriever against IRCoT and HippoRAG w/ IRCoT, as well as single-step retrieval approaches. It achieves the strongest reported retrieval results in the table, with R@15 scores of 71.5 on MuSiQue, 95.9 on 2Wiki-MultiHopQA, and 97.3 on HotpotQA.

Results

GEAR achieves state-of-the-art performance in multi-step retrieval across all reported datasets, with especially strong results on MuSiQue and gains of over 10% compared with competitors. In end-to-end QA using the top five retrieved passages, it achieves the highest EM and F1 scores on MuSiQue, 2Wiki, and HotpotQA.

Discussion / What makes GEAR work? .. Is GEAR efficient?

GEAR achieves strong retrieval performance in a single iteration on MuSiQue and requires fewer iterations than the competition to reach maximum recall. It performs particularly well on low-to-moderate-complexity questions, remains consistent across chunks with varying triple densities, and uses fewer LLM tokens than HippoRAG w/ IRCoT.

Conclusion

GEAR is a framework that incorporates a graph-based retriever within a multi-step retrieval agent to model information-seeking for multi-hop question answering. It uses multi-hop contexts from SyncGE to construct a gist memory for summarizing information across iterations, and it achieves superior performance to other multi-step retrieval methods with fewer iterations and large language model tokens.

Limitations

GEAR is demonstrated to be effective in the paper's retrieval setting.
