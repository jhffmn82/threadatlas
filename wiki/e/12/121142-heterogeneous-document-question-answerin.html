Heterogeneous document question answering is a task that takes extensive documents containing unstructured text and structured tables and aims to answer user questions correctly. Abstract

Heterogeneous document question answering is the task targeted by TableRAG, which unifies textual understanding and tabular manipulation for this setting. TableRAG establishes a new state-of-the-art for the task according to the reported experiments.

1

Heterogeneous document-based question answering requires reasoning over both unstructured text and structured tabular data. The unit describes it as challenging because tables contain interdependent rows and columns, whereas natural language texts are sequential.

2

It is defined as a task involving extensive documents that contain textual and tabular information. Its objective is to produce the correct answer to a user question.
