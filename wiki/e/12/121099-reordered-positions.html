reordered positions in TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text

Songshuo Lu · 2025

Reordered positions is an approach for handling positional encodings in TurboRAG’s concatenated key caches. It assigns contiguous indices across document chunks so cached-key positional differences match original token offsets. During inference, it applies RoPE to stitched key_states using apply_single_rotary_pos_emb, with negligible additional cost.

Narrative, section by section

3 / Methodology .. 3.4 / The TurboRAG Pipeline

Reordered positions assign contiguous indices across concatenated document chunks, such as [0, ..., l, l+1, ..., 2l]. TurboRAG uses them to make cached-key positional differences correspond to the original concatenated token offsets.

B / Positional-Encoding Options in

Reordered Positions applies RoPE at inference time instead of during precomputation. Its additional computational cost is described as negligible.
