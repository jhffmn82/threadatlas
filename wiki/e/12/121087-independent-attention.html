Independent Attention

method · 1 work · 4 quoted facts · 4 connections
Also called: attention, attention mask, attention masks, attention scores, attention weights, cross-chunk attention, self-attention, this new attention modality

Abstract written by a model

Independent Attention is a TurboRAG inference method motivated by typically negligible inter-chunk attention and documents’ focus on internal information. It prevents attention between document chunks, letting each document attend only to itself, while the query and generated answer attend to all documents by simulating retrieval and concatenation of separately computed KV caches.

Independent Attention is in one work on this site, TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text. This is the abstract a model wrote of it from that work.

1 / Introduction .. Contributions

The unit reports that inter-chunk attention weights are typically negligible and that documents primarily attend to their internal information. TurboRAG therefore uses independent attention in which each document can attend only to itself, while the query can still focus on relevant documents.

3 / Methodology .. 3.4 / The TurboRAG Pipeline

Independent Attention prevents cross-attention between multiple document chunks during inference. It allows the query and generated answer to attend to all documents while simulating retrieval and concatenation of separately computed KV caches.
