Adaptive Cognitive Detection

method · 1 work · 4 quoted facts · 2 connections
Also called: Adaptive cognitive detection, Early Detection, Real-time Detection, adaptive cognitive detection

Abstract written by a model

Adaptive Cognitive Detection is a component and technical aspect of DioR that decides whether retrieval should begin before generation and monitors generation for likely hallucinations. It uses two classifiers trained on hallucination-detection datasets constructed from the Wiki dataset: an RNN classifier provides early retrieval-trigger detection based on LLM cognitive characteristics, and an MLP classifier supports real-time detection during output generation. In ablation experiments, its early- and real-time-detection components are tested; removing them reduces performance.

Adaptive Cognitive Detection is in one work on this site, DioR: Adaptive Cognitive Detection and Contextual Retrieval Optimization for Dynamic Retrieval-Augmented Generation. This is the abstract a model wrote of it from that work.
