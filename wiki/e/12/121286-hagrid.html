HAGRID

object · 1 work · 4 quoted facts · 0 connections
Also called: Hagrid

Abstract written by a model

HAGRID is a general-knowledge dataset built on MIRACL, using Wikipedia context and expert-composed questions. Relevant documents are passed to an LLM to produce responses; because its original data already contains LLM-generated responses, RAGBench uses them directly.

HAGRID is in one work on this site, RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems. This is the abstract a model wrote of it from that work.
