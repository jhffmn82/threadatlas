document screenshot retrieval

Also called: Document Screenshot Retrieval, document screenshot embedding retrieval paradigm, document screenshot retriever, visual-based retrievers

Abstract written by a model

Document screenshot retrieval indexes original document screenshots with a vision-language model, avoiding explicit processing such as HTML parsing or OCR. It unfolds from visual query-to-screenshot cosine-similarity retrieval through the Document Screenshot Embedding model toward source attribution via VISA.

opening

Document screenshot retrieval is described as a paradigm that uses a vision-language model to encode document screenshots for retrieval while dropping the document processing module. VISA extends this visual approach from retrieval toward source attribution.

opening .. 3.4

Document screenshot retrieval directly indexes original document screenshots instead of requiring explicit document processing such as HTML parsing or OCR. In this unit, it is enabled through the Document Screenshot Embedding model, which performs query-to-screenshot cosine similarity search.
