Abstract written by a model

EManual is a customer-support dataset in RAGBench built from a TV manual and annotator-written questions. It centers on 659 questions about a Samsung Smart TV and remote and 261 manual chunks, which are embedded, retrieved as up to three contexts per question, and used to generate responses.

EManual is in one work on this site, RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems. This is the abstract a model wrote of it from that work.

RAGBench Construction / Component Datasets .. Data Splits

EManual contributes customer-support data from a TV manual and questions written by annotators. It represents a customer-support use case in RAGBench.

RAGBench Dataset Details .. ExpertQA [25]

EManual contains 659 human-authored questions about a Samsung Smart TV and remote, with a manual segmented into 261 chunks. RAGBench embeds the manual segments into a vector database, retrieves up to three context documents per question, and generates LLM responses.
