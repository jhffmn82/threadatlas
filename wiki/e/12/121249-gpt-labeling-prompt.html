Abstract written by a model

GPT Labeling Prompt is a prompt template for annotation generation: it directs a reviewer to identify answer sources, assess sentence-level and overall document support, and return a JSON object matching a specified schema.

GPT Labeling Prompt

The GPT Labeling Prompt instructs a reviewer to evaluate an answer against one or more documents and return a structured assessment. It specifies the required JSON schema and criteria for sentence-level and overall support.
