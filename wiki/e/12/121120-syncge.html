SyncGE in GEAR: Graph-enhanced Agent for Retrieval-augmented Generation

Zhili Shen · 2025 · the work’s page · read it where SyncGE first appears

Abstract written by a model

SyncGE is GEAR’s graph-based passage retrieval component and proposed graph retriever. It uses a large language model only to locate initial triples or nodes, then uses a generic semantic model to expand a triple sub-graph through diverse triple beams. These beams link multi-hop passages and synchronize information from passages with triples. It retrieves triples that interconnect passages returned by a base retriever, aligns expanded triples with source passages, and combines the resulting and initial passages through Reciprocal Rank Fusion. Across evaluated single-step retrieval settings, it consistently improves corresponding base retrievers and contributes to state-of-the-art performance on MuSiQue and HotpotQA. It outperforms HippoRAG in many configurations, surpasses HippoRAG with IRCoT on MuSiQue without multiple iterations and with almost 2.9 million fewer tokens, and has lower recall variation across differing triple densities or chunk triple counts.

Introduction

SyncGE is GEAR’s graph-based passage retrieval component. It uses an LLM to locate initial triples and then expands the triple sub-graph with a generic semantic model by exploring diverse triple beams that link multi-hop passages.

Retrieval with Synchronised Graph .. Reasoning for Termination / Query Re-writing / After Termination

Synchronised Graph Expansion retrieves a sub-graph of triples that interconnect the source passages returned by the base retriever. It aligns expanded triples with source passages and combines the resulting passages with the initial passages using Reciprocal Rank Fusion.

Experimental Setup .. Baselines / Implementation Details

SyncGE is the proposed graph retriever and is compared with BM25, SBERT, a hybrid retriever, and HippoRAG. Across the single-step comparisons, SyncGE improves retrieval over the corresponding base retrievers, with the hybrid plus SyncGE configuration reaching R@15 scores of 61.2 on MuSiQue, 82.4 on 2Wiki-MultiHopQA, and 95.2 on HotpotQA.

Results

SyncGE contributes to state-of-the-art single-step retrieval performance on MuSiQue and HotpotQA. It consistently improves results over setups using NaiveGE and outperforms HippoRAG in many configurations across sparse, dense, and hybrid base retrievers.

Discussion / What makes GEAR work? .. Is GEAR efficient?

SyncGE improves every base retriever across all evaluated datasets, and its superior performance indicates the effectiveness of using LLMs to locate initial nodes. Its recall performance also has lower variation across ranges of triple density than NaiveGE and HippoRAG w/ IRCoT.

Conclusion

SyncGE is GEAR's graph retriever. It uses the large language model to synchronize information from passages with triples and expands the graph by exploring diverse beams of triples that link multi-hop contexts.
