Abstract written by a model

RAGBench is an explainable, comprehensive, large-scale benchmark dataset for Retrieval-Augmented Generation Systems. It contains 100k real-world RAG examples across five source domains, biomedical research, general knowledge, legal contracts, customer support, and finance, and is intended to train and benchmark powerful RAG evaluation models. Its central contribution is explainable labeling for holistic evaluation and actionable feedback: annotations cover context relevance, answer faithfulness or adherence, context utilization, and answer completeness, including utilization and completeness as new evaluation metrics. These labels, automatically generated with an LLM and reported to correlate highly with human judgments, support more precise diagnosis of RAG systems’ strengths and weaknesses and iterative improvement of production applications. The benchmark unfolds by standardizing 12 publicly released academic and industry component datasets into a consistent retrieval-augmented generation format: PubMedQA, CovidQA-RAG, HotpotQA, MS Marco, HAGRID, ExpertQA, DelucionQA, EManual, TechQA, FinQA, TAT-QA, and CUAD. It reframes datasets as RAG tasks by retrieving or supplying context and generating responses, while retaining existing ExpertQA responses. Construction varies domains, document counts, context lengths from 100 to 11k tokens, and response-generation models. It uses OpenAI embeddings and FAISS for PQA-U context retrieval, and generates responses with GPT-3.5 and Claude 3 Haiku at temperature 1.0. The resulting data are divided into non-overlapping train, validation, and test splits; component datasets include 1% to 20% hallucinated responses. RAGBench is used to assess retriever relevance, response adherence, and response completeness, including benchmarking LLM evaluators and training and testing a fine-tuned DeBERTa judge. Released as a labeled dataset on Hugging Face, with inference and evaluation code on GitHub, it provides standardized benchmarks and methodologies intended to advance more mature RAG evaluation systems.

RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems

RAGBench is presented as an explainable benchmark for Retrieval-Augmented Generation Systems.

Abstract

RAGBench is introduced as the first comprehensive, large-scale RAG benchmark dataset, containing 100k examples across five industry-specific domains and various RAG task types. Its examples come from industry corpora such as user manuals, and its explainable labels support holistic evaluation and actionable feedback for production applications.

Introduction

RAGBench is proposed as a comprehensive dataset for training and benchmarking RAG evaluation models. It contains data from multiple domains and metrics for context relevance, answer faithfulness, context utilization, and answer completeness.

Related Work .. Finetuned RAG evaluation models

RAGBench is introduced as a benchmark for developing mature evaluation systems that assess different parts of RAG systems across dimensions such as retriever relevance, response adherence, and response completeness. It is also used to train and evaluate an NLI model for RAG evaluation.

RAGBench Construction / Component Datasets .. Data Splits

RAGBench standardizes 12 open-book question-answering and RAG-adapted datasets into a consistent retrieval-augmented generation format. It varies source domain, number of context documents, context token length, and response-generation model, and divides the data into non-overlapping train, validation, and test splits.

RAGBench Statistics .. Alignment with Human Judgements

RAGBench component datasets contain between 1% and 20% hallucinated responses. Its annotations include Adherence, Relevance, Utilization, and derived Completeness labels.

RAG Case Study .. Estimating Context Relevance is Difficult

RAGBench is used to benchmark LLM evaluators and to train and test the fine-tuned DeBERTa judge. Its component datasets include PubMedQA, CovidQA-RAG, HotpotQA, MS Marco, HAGRID, ExpertQA, DelucionQA, EManual, TechQA, FinQA, TAT-QA, and CUAD.

Conclusion

RAGBench is introduced as a large-scale dataset composed of real-world RAG examples for training and benchmarking RAG evaluation models. Its labels are generated automatically with an LLM, and this approach shows high correlation with human judgments.

Appendix / RAGBench Code and Data

RAGBench data is released on Hugging Face. Its inference and evaluation code is published on GitHub.

RAGBench Dataset Details .. ExpertQA [25]

RAGBench is sourced from publicly released academic and industry datasets. It reframes many component datasets as RAG tasks by retrieving or providing context documents and generating responses with an LLM; its resulting databases and examples use methods including OpenAI embeddings and FAISS retrieval.
