Abstract written by a model

In Knowledge Graph-Guided Retrieval Augmented Generation, KG-based context organization is a post-processing stage and module in KG2RAG that filters expanded and retrieved chunks, scores maximum-spanning-tree relevance to the user query with cross-encoder reranking, and uses weighted graph components, relevance-based ordering, and depth-first search to form semantically coherent paragraphs with the knowledge graph as a skeleton before sending context to LLMs. In Knowledge Graph-Guided Retrieval Augmented Generation, KG-based context organization module is a KG2RAG context-organization function that filters and arranges expanded subgraphs into weighted undirected connected components, constructs maximum spanning trees, ranks them with a cross-encoder, and selects text representations under a chunk limit.

KG-based context organization in Knowledge Graph-Guided Retrieval Augmented Generation

Xiangrong Zhu · 2025-04-29 to 2025-05-04 · the work’s page · read it where KG-based context organization first appears

Abstract written by a model

KG-based context organization is a post-processing stage and module in KG2RAG. It filters expanded and retrieved chunks to retain relevant information, scores maximum-spanning-tree relevance to the user query with cross-encoder reranking, and uses weighted graph components, relevance-based ordering, and depth-first search to form semantically coherent paragraphs with the knowledge graph as a skeleton before sending context to LLMs. Its collaboration with KG-guided chunk expansion supports KG2RAG’s effectiveness; removing it increases retrieved chunks and reduces retrieval quality.

KG-based context organization selects and arranges retrieved chunks so that relevant information is preserved efficiently. Removing it greatly increases the average number of retrieved chunks and reduces retrieval quality, while retaining similar response quality in the reported ablation.

KG-based context organization is a module in KG2RAG that organizes retrieved chunks into well-organized paragraphs using knowledge-graph guidance. The ablation study confirms that it contributes to KG2RAG's effectiveness in collaboration with KG-guided chunk expansion.

KG-based context organization module in Knowledge Graph-Guided Retrieval Augmented Generation

Xiangrong Zhu · 2025-04-29 to 2025-05-04 · the work’s page · read it where KG-based context organization module first appears

Abstract written by a model

KG-based context organization is a KG2RAG context-organization function that delivers relevant, important knowledge in well-organized paragraphs. Acting as a filter and arranger, it converts an expanded subgraph into weighted undirected connected components, constructs maximum spanning trees, ranks them with a cross-encoder, and selects text representations under a chunk limit.
