Abstract

Each hyperedge in OG-RAG encapsulates a cluster of factual knowledge grounded using a domain-specific ontology. An optimization algorithm retrieves a minimal set of hyperedges for a given query.

OG-RAG .. Relevant Hyeredges as Context

A hyperedge is an arbitrary set of hypernodes and represents a true fact grounded in domain-specific data. During retrieval, hyperedges are selected to cover the greatest number of relevant hypernodes, producing the retrieved context.
