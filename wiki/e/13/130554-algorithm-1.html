Abstract written by a model

Algorithm 1 is a retrieval algorithm with question decomposition: it generates sub-queries, combines them with the original query, retrieves top-k candidates for each, aggregates them globally, reranks the merged set, and returns the highest-scoring relevant passages.

Algorithm 1 is in one work on this site, Question Decomposition for Retrieval-Augmented Generation. This is the abstract a model wrote of it from that work.

Algorithm 1 generates sub-queries, forms a query set containing the original and decomposed queries, retrieves the top-k candidates for each, and aggregates them into a global candidate set. It then reranks the candidates and returns the highest-scoring top-k passages as R′(q).
