Hybrid GraphRAG in A Survey of Graph Retrieval-Augmented Generation for Customized Large Language Models

Qinggang Zhang, Shengyuan Chen, Yuanchen Bei, Zheng Yuan, Huachi Zhou, Zijin Hong, Hao Chen, Yilin Xiao, Chuang Zhou, Junnan Dong, Yi Chang, Xiao Huang · 2025-09-29

Hybrid GraphRAG is a GraphRAG approach and one of three survey categories. It combines Knowledge-based GraphRAG and Index-based GraphRAG, using graph structures as knowledge carriers and indexing tools. It links key-information graph nodes to raw text chunks, preserving detailed context while supporting knowledge graphs and logical reasoning for complex reasoning.

Narrative, section by section

3 sections; each heading opens the text

I. INTRODUCTION

Hybrid GraphRAG combines the strengths of Knowledge-based GraphRAG and Index-based GraphRAG. It is intended to provide more advanced support for complex reasoning by using both structured knowledge and graph-based retrieval of raw text.

II. OVERVIEW

Hybrid GraphRAG is identified as one of the survey’s three distinct categories for classifying GraphRAG approaches.

IV. KNOWLEDGE ORGANIZATION .. C. Hybrid GraphRAG

Hybrid GraphRAG uses graph structures both as knowledge carriers and as indexing tools. It links graph nodes containing key information to corresponding text chunks, combining logical reasoning with access to detailed contextual information.
