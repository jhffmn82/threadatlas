Index-based GraphRAG in A Survey of Graph Retrieval-Augmented Generation for Customized Large Language Models

Qinggang Zhang, Shengyuan Chen, Yuanchen Bei, Zheng Yuan, Huachi Zhou, Zijin Hong, Hao Chen, Yilin Xiao, Chuang Zhou, Junnan Dong, Yi Chang, Xiao Huang · 2025-09-29

Index-based GraphRAG is a graph-based indexing architecture for chunked raw text that retains the original textual form. It organizes passages through semantic, keyword, or domain-specific connections, including links from high-level topics to facts and text. These graph connections improve lookup, retrieval efficiency, and navigation: relevant topic or passage nodes are found, their raw text chunks are retrieved, and the chunks are supplied for language-model knowledge injection and subsequent processing.

Narrative, section by section

3 sections; each heading opens the text

I. INTRODUCTION

Index-based GraphRAG uses graphs as indexing tools while retaining the original textual form. It organizes text chunks through semantic connections to improve lookup, retrieval efficiency, and navigation across raw textual information.

III. WHAT IS GRAPHRAG / A. Traditional RAG Pipeline .. D. Traditional RAG vs GraphRAG

A GraphRAG knowledge index uses a graph as an indexing tool over chunked textual data. It can link high-level topic nodes to text through fact linking, combining efficient topic retrieval with access to detailed textual knowledge.

IV. KNOWLEDGE ORGANIZATION .. C. Hybrid GraphRAG

Index-based GraphRAG uses graph structures to index and retrieve relevant raw text chunks for subsequent processing by language models. Its graphs can connect passages through semantic similarities, keyword similarities, or domain-specific relations.
