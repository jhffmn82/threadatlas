Background

A factual-block captures a localized subject–attribute–value relationship in a specific context. It preserves distinct valid values associated with the same ontology entity without overwriting or flattening their contextual differences.

OG-RAG .. Relevant Hyeredges as Context

A factual block is a nested structure produced by mapping document information onto an ontology. It is flattened into a set of factual blocks so the information can be processed more efficiently without significant loss of detail.
