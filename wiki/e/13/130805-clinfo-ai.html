1 section; each heading opens the text

Modular RAG

Clinfo.ai is a RetA LLM system proposed by Lozano et al. that uses four LLMs in a chain. The system performs index searches on PubMed or Semantic Scholars, classifies relevance, summarizes articles using the user query, and guides the final output with task-specific prompts.
