question decomposition pipeline in Question Decomposition for Retrieval-Augmented Generation

Paul J. L. Ammann · 2025-07-28/2025-07-29

The question decomposition pipeline is a proposed retrieval pipeline for multi-hop question answering that augments RAG with question decomposition and reranking. It focuses on retrieval and evidence selection: it decomposes an original query into subqueries, retrieves documents for each, aggregates, merges, and deduplicates the results, reranks the candidate passages, and sends only the top-k passages to the language model. It uses k = 10 across datasets and is evaluated on established multi-hop benchmarks. Its main limitation is single-shot operation: subqueries are generated once and are not updated from retrieved evidence, limiting adaptive multi-step reasoning for more complex tasks. The system is released on GitHub for reproducibility.

Narrative, section by section

4 sections; each heading opens the text

Introduction

The proposed RAG pipeline integrates question decomposition with reranking for multi-hop question answering. It aggregates results from all subqueries and uses reranking to distill them into a concise set of highly relevant passages.

RAG with Question Decomposition .. QD Module / Reranker Module

The proposed pipeline decomposes the original query, retrieves documents for each resulting query, merges and deduplicates the results, reranks the candidate set, and passes the top-k passages to the language model.

Experiments / Datasets .. HotpotQA

The question decomposition pipeline is evaluated on established multi-hop question answering benchmarks, with emphasis on improving evidence selection during retrieval. It combines query decomposition with retrieval and, in one configuration, reranking.

Limitations

The single-shot pipeline generates subqueries once and does not update them based on retrieved evidence.
