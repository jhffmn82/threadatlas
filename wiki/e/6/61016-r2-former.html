R2-Former in R2AG: Incorporating Retrieval Information into Retrieval Augmented Generation

Fuda Ye, Shuangyin Li, Yongqi Zhang, Lei Chen · 2024

R2-Former is a lightweight, trainable, pluggable Transformer-based model in the R2AG pipeline between retrievers and LLMs. It bridges their semantic gap by mapping list-wise retrieval features into a higher-dimensional space, adding positional embeddings, encoding them with self-attention so unified features interact, and outputting essential retrieval information as additional embeddings for the LLM. It uses QDM loss.

Introduction

R2-Former is a lightweight, trainable model placed between the retriever and the LLM. It transforms and captures essential retrieval information so that it can be provided to the LLM through additional embeddings.

R2AG / Problem Formulation and Overview .. Training Strategy

The R2-Former is a trainable, Transformer-based module that bridges retrievers and LLMs. It maps list-wise retrieval features into a higher-dimensional space, adds positional embeddings, applies self-attention, and outputs retrieval information for the LLM.
