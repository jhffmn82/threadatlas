Generating and Ranking (GR) framework

object · 1 work · 7 quoted facts · 3 connections
Also called: GR architecture, GR framework

Abstract written by a model

Generating and Ranking (GR) is a distractor generation architecture and state-of-the-art Distractor Generation approach. It first generates a small, diverse candidate set using a knowledge base or language model, then ranks candidates with semantic rules and linguistic features, significantly improving distractor quality over traditional rule-based methods.

Generating and Ranking (GR) framework is in one work on this site, Enhancing Distractor Generation for Multiple-Choice Questions with Retrieval Augmented Pretraining and Knowledge Graph Integration. This is the abstract a model wrote of it from that work.
