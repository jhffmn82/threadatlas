filter module

object · 1 work · 9 quoted facts · 8 connections
Also called: a filter module, filter, noise filter, noise filters
  • In An Information Bottleneck Perspective for Effective Noise Filtering on Retrieval-Augmented Generation: A trained filter module used in retrieval-augmented generation to find relevant content. It maps a query and retrieved passage to a compressed representation, maximizing ground output while minimizing passage content through mutual-information objectives. Trained by supervised fine-tuning and improvable with DPO, it can discard entirely irrelevant passages using an [IS_DISCARD] flag. It achieves impressive compression rates, significantly outperforms baseline methods, but has suboptimal noise compression.

filter module in An Information Bottleneck Perspective for Effective Noise Filtering on Retrieval-Augmented Generation

Kun Zhu, Xiaocheng Feng, Xiyuan Du, Yuxuan Gu, Weijiang Yu, Haotian Wang, Qianglong Chen, Zheng Chu, Jingchang Chen, Bing Qin · 2024

A trained filter module used in retrieval-augmented generation to find relevant content. It maps a query and retrieved passage to a compressed representation, maximizing ground output while minimizing passage content through mutual-information objectives. Trained by supervised fine-tuning and improvable with DPO, it can discard entirely irrelevant passages using an [IS_DISCARD] flag. It achieves impressive compression rates, significantly outperforms baseline methods, but has suboptimal noise compression.

Abstract

A filter module can identify relevant content, but the text states that it achieves suboptimal noise compression.

Noise Filtering .. Reinforcement Learning

The noise filter maps a query and retrieved passage to a compressed representation. It is trained through supervised fine-tuning on selected candidate compressions and can be improved with DPO; it also includes an [IS_DISCARD] flag for cases where discarding the filtering output is preferable.

Conclusion

They are used in retrieval-augmented generation and are evaluated and optimized using the information bottleneck principle.
