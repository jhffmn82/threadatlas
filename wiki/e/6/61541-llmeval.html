LLMeval

metric · 1 work · 17 quoted facts · 6 connections
Also called: LLMEval, LLMEval metric, LLMeval: LLM-based Answer Equivalence Evaluation

Abstract written by a model

LLMeval is a simple LLM-based answer-equivalence evaluation metric in BERGEN for judging whether a generated response answers a question relative to a reference answer. It gives SOLAR-10.7B-Instruct-v1.0 a question, reference answer, candidate answer, and evaluation prompt in zero-shot evaluation, then converts its correctness judgment into a binary label; unexpected output tokens default to false. vLLM speeds inference, while extracted logits provide a continuous score comparable to directly generating one token. Reported alongside Match and used for SOLAR-10.7B on KILT NQ with retrievers and DeBERTa-v3 re-ranking, it is also used for multilingual RAG performance. Among tested metrics, it correlates most closely on average with GPT-4-as-a-judge and better overall with character 3-gram recall than other surface-based metrics, though that correlation is relatively low because it can assess valid answers across languages. It is recommended with Match and Recall for zero-shot RAG evaluation.

LLMeval is in one work on this site, BERGEN: A Benchmarking Library for Retrieval-Augmented Generation. This is the abstract a model wrote of it from that work.

Benchmarking Library BERGEN .. 4.7

LLMeval is a simple LLM-based metric used by BERGEN to judge whether a generated response answers a question compared with a reference answer. It uses SOLAR-10.7B-Instruct-v1.0 in a zero-shot instruction-based evaluation and produces binary relevance judgments.

Experiments .. 5.6

LLMeval has the closest average correlation to GPT-4-as-a-judge among the tested metrics. It is used for the remainder of the experiments and is recommended, along with Match and Recall, for zero-shot RAG evaluation.

E

LLMeval is a reported evaluation metric for generated answers. It is listed alongside Match in the zero-shot experiments and alongside R@5 in the retrieval and reranker comparisons.

F

LLMeval evaluates generated answers by providing a question, reference answer, and candidate answer to an LLM and converting the judgment into a binary label. Outputs that do not match the expected response format are treated as false.

H

LLMeval is used as a task metric for multilingual RAG performance. Its correlation with character 3-gram recall is relatively low overall because LLMeval assesses answer validity even when the response is not written in the same language as the query or gold label.
