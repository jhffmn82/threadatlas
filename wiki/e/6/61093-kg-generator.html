KG Generator

object · 1 work · 10 quoted facts · 7 connections
Also called: KG, KG Generation, KG generator, KG_Generator, Knowledge Graph Generator, knowledge graph generator

Abstract written by a model

KG Generator is a TRACE component that creates a knowledge graph from retrieved documents. It uses an LLM with in-context learning to generate knowledge triples independently for each document, receiving a document and outputting identified triples. For Wikipedia documents, it treats the title as an entity and extracts entities in the text and their relationships with that title. It primarily generates triples between titles and text entities rather than between all entities, simplifying the task and mitigating the lost-in-the-middle issue. Its prompts use demonstrations from 50 manually labelled training documents per dataset, with E5-Mistral retrieving three similar examples. It is evaluated through sentence- and document-based variants; sentences perform better on all three reported datasets.

KG Generator is in one work on this site, TRACE the Evidence: Constructing Knowledge-Grounded Reasoning Chains for Retrieval-Augmented Generation. This is the abstract a model wrote of it from that work.

Abstract

The Knowledge Graph Generator creates a knowledge graph from retrieved documents as part of TRACE.

TRACE / Overall Framework .. Answer Generation

The KG generator uses an LLM with in-context learning to extract knowledge triples from each document. For Wikipedia documents, it treats the title as an entity and identifies entities in the text and their relationships with the title entity.

Limitations

The KG generator primarily generates KG triples between document titles and entities within the texts. It does not generate triples between all possible entities, simplifying the task.

Prompts / Prompt for Generating KG Triples .. Prompt for Generating Answers / Demonstration Data / Experimental Details

The KG generator independently generates KG triples for each document in the retrieved document set. It receives a document and outputs all possible KG triples identified within it.

Baselines

The KG Generator is evaluated through variants using sentences and documents. Using sentences performs better than using documents on all three reported datasets.

Additional Implementation Details

The KG generator uses demonstrations obtained from 50 manually labelled training documents from each dataset. E5-Mistral retrieves the top three most similar documents from the labelled set for each document.
