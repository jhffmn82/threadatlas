MCQ dataset

dataset · 1 work · 4 quoted facts · 0 connections
Also called: MCQ, MCQ datasets, MCQ-all, MCQ-train

Abstract written by a model

MCQ dataset is a cross-domain cloze-style dataset covering science, vocabulary, common sense, and trivia. It uses a shared 2321/258 train/test split, with training data further divided 9:1 for development. On it, the best-performing model raises F1@3 from 14.80 to 16.47.

MCQ dataset is in one work on this site, Enhancing Distractor Generation for Multiple-Choice Questions with Retrieval Augmented Pretraining and Knowledge Graph Integration. This is the abstract a model wrote of it from that work.
