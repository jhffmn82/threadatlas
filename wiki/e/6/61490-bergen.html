Abstract written by a model

BERGEN is an open-source Python benchmarking library and modular framework for Retrieval-Augmented Generation (RAG). It standardizes easy, reproducible end-to-end RAG experiments and is intended to streamline the many configurations needed to train and evaluate RAG systems. Built on Hugging Face Hub and configured with Hydra, it covers data downloading and preprocessing, indexing, retrieval, reranking, generation, training, and evaluation; it also uses Pyserini for BM25 retrieval and vLLM for generation. BERGEN supports retrievers including BM25, SPLADE, CoCondenser, RetroMAE, BGE, RepLLaMA, and BGE-M3; reranking with Cross-Encoder, MiniLM, and DeBERTa-v3; and LLMs including Llama 2, Llama 3, SOLAR, Mixtral, Gemma, TinyLlama, and Upstage/SOLAR-10.7B-Instruct-v1.0. It supports numerous evaluation datasets, analyzes existing RAG metrics and datasets, and enables full fine-tuning and QLoRA. Its study compares state-of-the-art retrievers, rerankers, LLMs, datasets, and metrics in question answering, described as the largest RAG study to the authors’ knowledge. BERGEN then extends to multilingual experimentation, using MKQA, XOR-TyDi QA, and Wikimedia Wikipedia, and presents a zero-shot multilingual RAG baseline across 12 non-English languages. Designed to be extendable, it provides data and runs for reproducibility, while planned additions include further retrieval models, LLMs, and datasets.

front matter

BERGEN is presented as a benchmarking library for Retrieval-Augmented Generation. The work is authored by David Rau, Hervé Déjean, Nadezhda Chirkova, Thibault Formal, Shuai Wang, Stéphane Clinchant, and Vassilina Nikoulina.

Abstract

BERGEN is an end-to-end library for reproducible research that standardizes RAG experiments. It is presented as the outcome of a study of best practices for systematic RAG evaluation and is available as an open-source library.

Introduction

BERGEN is introduced as a Python library for easy and reproducible end-to-end RAG experiments. It supports comparisons of datasets, metrics, retrievers, rerankers, and LLMs, including multilingual datasets.

Related Work

A unified framework is proposed as necessary for systematically training and evaluating RAG systems. The unit presents such a framework as a way to streamline the many different experimental configurations.

Benchmarking Library BERGEN .. 4.7

BERGEN is an open-source Python library designed to standardize and simplify reproducible Retrieval-Augmented Generation experiments. It supports end-to-end data downloading, preprocessing, indexing, retrieval, reranking, generation, training, and evaluation, with extensibility through Hugging Face resources and Hydra configuration files.

Experiments .. 5.6

BERGEN is used to conduct a large RAG study comparing retrievers, rerankers, LLMs, datasets, and metrics. It supports multilingual experiments and analyses of retrieval, model size, evaluation, and fine-tuning.

6 .. Limitations

BERGEN is a library for benchmarking RAG systems. It provides a modular and extendable framework, alongside data and runs, for systematically evaluating RAG pipelines; the authors plan to add more retrieval models, large language models, and datasets.

H

BERGEN is extended with components for multilingual datasets and experimentation with multilingual RAG in 12 non-English languages. The unit presents a zero-shot multilingual RAG baseline covering retrieval, generation, prompting, datasets, datastores, and evaluation.
