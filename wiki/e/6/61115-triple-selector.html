triple selector in TRACE the Evidence: Constructing Knowledge-Grounded Reasoning Chains for Retrieval-Augmented Generation

Jinyuan Fang · 2024 · the work’s page · read it where triple selector first appears

Abstract written by a model

The triple selector is a large language model with in-context learning that builds coherent reasoning chains by selecting knowledge-graph triples one at a time. It receives a question, existing knowledge triples, and a candidate set, using a prompt and a multiple-choice task to mitigate hallucination. It outputs logits for a triple distribution, or, as a black-box model without accessible logits, only an option token such as “A” or “B” to select each triple.

Narrative, section by section written by a model

2 sections; each heading opens the text

Limitations

The triple selector provides logits that TRACE uses to define a triple distribution. If it is used as a black-box LLM, its logits may not be accessible; TRACE can then use its option token output to select one triple at each step.
