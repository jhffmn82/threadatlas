Knowledge Augmented Generation in Enhancing Distractor Generation for Multiple-Choice Questions with Retrieval Augmented Pretraining and Knowledge Graph Integration

Han-Cheng Yu, Yu-An Shih, Kin-Man Law, Kai-Yu Hsieh, Yu-Chen Cheng, Hsin-Chih Ho, Zih-An Lin, Wen-Chuan Hsu, Yao-Chung Fan · 2024

Knowledge Augmented Generation is a knowledge augmentation and candidate augmentation method for distractor generation, extended from prior work. It uses Knowledge Graphs as auxiliary tools to retrieve knowledge triplets, aiming to improve distractor relevance, create more challenging multiple-choice options, and improve use of structured knowledge. The method starts with keywords from the question, answer, and candidate set to retrieve relevant triplets, then re-ranks them to select triplets for generation. It augments a text-to-text generator’s input with the question, answer, and selected triplets, conditioning the model to generate distractors. It improves several baseline results, but its effectiveness depends on triplet selection: retrieved knowledge can introduce noise, and combining it with RAP did not consistently produce additive improvements. Its current design therefore has room to improve relevant-triplet selection.

Introduction

Knowledge-augmented generation builds on a candidate augmentation strategy from a state-of-the-art distractor-generation method. It retrieves knowledge triplets from a knowledge graph and provides them as auxiliary information to a text-to-text distractor-generation model.

2 / 2.1 .. 2.3

Knowledge Augmented Generation uses Knowledge Graphs to enhance NLP tasks, including question answering, question generation, and distractor generation. The proposed approach applies Knowledge Graphs as auxiliary tools to improve distractor relevance, create more challenging multiple-choice options, and improve the model's use of structured knowledge.

3 / 3.1 .. 3.2.3

Knowledge Augmented Generation incorporates knowledge triplets into Distractor Generation through triplet retrieval and re-ranking. It conditions a generation model on the question, answer, and selected knowledge triplets.

4 / 4.1 / Sciq dataset .. 4.6

Knowledge Augmented Generation retrieves relevant knowledge-graph triplets using keywords from the question, answer, and candidate set, then augments the generator input with selected triplets.
