The CODERAG-BENCH .. 2.4

CodeSearchNet contributes its Python split as a code retrieval task. It searches for the correct implementation of a natural-language query from a pool of functions collected from GitHub repositories, with retrieval quality measured using NDCG@10.

Canonical RACG / 3.1 .. 3.4

CodeSearchNet is used in the retrieval evaluation and efficiency analysis. Average retrieval scores exclude CodeSearchNet, while a sampled Python portion is used to measure latency and storage.
