Abstract written by a model

CodeSearchNet is a code retrieval dataset whose Python split searches GitHub functions for the implementation matching a natural-language query. It contributes a retrieval task measured by NDCG@10 and supports efficiency analysis through sampled Python latency and storage measurements; average retrieval scores exclude it.

CodeSearchNet is in one work on this site, CODERAG-BENCH: Can Retrieval Augment Code Generation?. This is the abstract a model wrote of it from that work.

The CODERAG-BENCH .. 2.4

CodeSearchNet contributes its Python split as a code retrieval task. It searches for the correct implementation of a natural-language query from a pool of functions collected from GitHub repositories, with retrieval quality measured using NDCG@10.
