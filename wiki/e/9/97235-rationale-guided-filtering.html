rationale-guided filtering in Rationale-Guided Retrieval Augmented Generation

Jiwoong Sohn · 2025

Rationale-guided filtering is a method for selecting useful retrieved information before it reaches a base LLM. It trains a Flan-T5 filtering model on question-document labels derived from differences in rationale perplexity with and without retrieved documents, estimating each snippet’s utility. It removes distracting or irrelevant evidence, including in a COPD exacerbation case, improves Llama-3-8B-Instruct, surpasses Adaptive-RAG by 1.3% on MedQA, and achieves similar results while avoiding GPT-4o API costs.

Narrative, section by section

3 sections; each heading opens the text

Introduction

Rationale-guided filtering uses a Flan-T5 model trained from labels based on differences in rationale perplexity with and without retrieved documents. The filter estimates snippet informativeness for the base language model and removes potentially distracting evidence.

3 / 3.1 .. 3.4

Rationale-guided filtering removes distractors by evaluating retrieved documents before they are presented to the LLM. It labels documents as helpful or not helpful using model performance and perplexity differences.

5 / 5.1 .. 5.3

Rationale-guided filtering uses the perplexity of an LLM’s rationale to annotate question-document pairs. It substantially improves Llama-3-8B-Instruct’s performance, surpasses Adaptive-RAG, and removes irrelevant information in the COPD exacerbation case.
