Introduction

Canonical documents are manually annotated references used to evaluate retrieval-augmented code generation systems. Providing them gives code generation models substantial benefits in various scenarios.

Canonical RACG / 3.1 .. 3.4

Canonical documents are used to estimate an upper bound for RACG and generally improve generation results. Their benefits are strongest for basic programming problems, unfamiliar libraries, and GPT-4o on SWE-bench-Lite.
