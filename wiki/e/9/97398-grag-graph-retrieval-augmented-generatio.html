Yuntong Hu, Zhihan Lei, Zheng Zhang, Bo Pan, Chen Ling, Liang Zhao · 2025

This document presents Graph Retrieval-Augmented Generation (GRAG), by Yuntong Hu, Zhihan Lei, Zheng Zhang, Bo Pan, Chen Ling, and Liang Zhao. GRAG extends Retrieval-Augmented Generation for networked documents, where relevant evidence is not merely isolated text but interconnected textual graphs whose nodes and edges have text attributes. The paper argues that Large Language Models can use textual attributes but do not inherently capture complex topology, while exhaustive search for an optimal subgraph is NP-hard. GRAG frames the task as retrieving an optimal query-relevant textual subgraph from a graph and supplying it, with the query, to an LLM for generation. Its retrieval stage uses a divide-and-conquer process: it indexes K-hop ego-graphs with pre-trained language-model embeddings, ranks them by cosine similarity to the query, merges the top-N candidates, and applies Textual Subgraph Soft Pruning. Two multilayer perceptrons assign query-dependent scaling factors to nodes and edges, reducing redundant material and yielding a tailored subgraph with linear complexity. For generation, GRAG supplies complementary text and graph views. The text view turns retrieved ego-graphs into hierarchical descriptions that distinguish tree edges from additional edges. The graph view applies a Graph Neural Network to the softly pruned graph, and an MLP aligns graph embeddings with the LLM text-vector space. The resulting graph and text embeddings are concatenated with the query context for generation. Experiments on GraphQA, using WebQSP for knowledge-graph question answering and ExplaGraphs for common-sense reasoning, find that GRAG outperforms standard RAG retrievers and LLM baselines in graph multi-hop reasoning. Without LLM fine-tuning, it reaches 0.7236 Hit@1 on WebQSP and 0.9223 accuracy on ExplaGraphs; frozen LLMs with GRAG outperform fine-tuned LLMs on all reported tasks. Ablations emphasize the value of graph-aware retrieval, graph encoding, soft pruning, and hierarchical descriptions. Two-hop ego-graphs generally beat one-hop versions, but overly large subgraphs or too many retrieved entities can add irrelevant information and impair generation. The paper closes by noting that GRAG depends on effective initial node ranking and pruning, so performance can suffer when graph structure or node importance is hard to estimate.

This document presents Graph Retrieval-Augmented Generation (GRAG), by Yuntong Hu, Zhihan Lei, Zheng Zhang, Bo Pan, Chen Ling, and Liang Zhao of the Department of Computer Science at Emory University. GRAG extends Retrieval-Augmented Generation for networked documents represented as textual graphs, whose nodes and edges carry text. Rather than retrieving isolated documents by text similarity, it retrieves query-relevant textual subgraphs so that Large Language Models can use both content and graph topology for multi-hop reasoning. The paper first situates GRAG among prompt tuning, LLM-based graph work, and graph retrieval methods, arguing that text-trained LLMs do not inherently capture complex graph structure. It formalizes the task as finding an optimal textual subgraph for a query and supplying it to an LLM to improve output relevance. GRAG’s retrieval uses a divide-and-conquer approach: it indexes and ranks K-hop ego-graphs with a pre-trained language model, selects the top-N neighborhoods by cosine similarity to the query, merges them, and applies soft pruning. Soft pruning uses two Multilayer Perceptrons to assign query-dependent scaling factors to nodes and edges; elements less relevant to the query are masked toward zero. This produces a tailored subgraph with linear complexity. For generation, GRAG creates complementary views. Its text view turns retrieved ego-graphs into hierarchical descriptions using BFS and pre-order traversal while retaining extra edges. Its graph view uses a Graph Neural Network and learned relevance scaling factors to encode the pruned subgraph, then aligns graph embeddings with the language model token space. These graph embeddings are combined with query and description text embeddings to guide generation through hard and soft prompts. Experiments on GraphQA, using WebQSP and ExplaGraphs, report that GRAG outperforms standard RAG retrievers, LLM baselines, and fine-tuned Llama2-7b models on reported metrics. Ablations indicate that graph-aware retrieval, graph encoding, pruning, and descriptions matter; 2-hop ego-graphs generally beat 1-hop graphs, while excessive retrieval adds irrelevant information. The conclusion emphasizes stronger detailed multi-hop reasoning and lower training cost because frozen LLMs can outperform fine-tuned models. The main limitation is dependence on effective initial node ranking and pruning when graph structure or node importance is hard to estimate.
