Self-aware Re-ranking in SEAKR: Self-aware Knowledge Retrieval for Adaptive Retrieval Augmented Generation

Zijun Yao · 2025

Self-aware Re-ranking is an adaptive integration strategy in SEAKR that asks the large language model to read multiple recalled snippets. It evaluates contexts formed with each top N knowledge snippets using a self-aware uncertainty score, prioritizes and selects the piece that produces the least uncertainty, and uses it as augmented context. Rather than taking the first search-engine result, it de-noises retrieved knowledge; removing it reduces performance.

Narrative, section by section

3 sections; each heading opens the text

Introduction

Self-aware re-ranking asks the large language model to read multiple recalled snippets and select the knowledge that reduces its uncertainty the most. The selected knowledge is used as the augmented context.

3 .. 3.4

Self-aware re-ranking selects retrieved knowledge according to how effectively it reduces the large language model's uncertainty. SEAKR evaluates the uncertainty of contexts formed with each of the top N knowledge snippets and selects the snippet with the least uncertainty.

5 / 5.1 .. 5.4

Self-aware Re-ranking selects knowledge using the self-aware uncertainty score rather than simply choosing the first search-engine result. Removing it reduces performance, and the text characterizes it as a mechanism for de-noising retrieved knowledge.
