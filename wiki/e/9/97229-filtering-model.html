filtering model

object · 1 work · 8 quoted facts · 6 connections
Also called: filtering models, small filtering model

Abstract written by a model

The filtering model is a small Flan-T5-large model that evaluates retrieved documents before they reach the base LLM, filtering distractors and selectively augmenting informative snippets. It is trained on model-generated, perplexity-based labels and detailed signals from perplexity differences in base-LLM rationales, applying uncertainty during training rather than inference. Using QA pairs from MedQA and MedMCQA, it learns when retrieval is useful; MedMCQA training is used for MMLU-Med, where it transfers to the out-of-domain benchmark. It can train on one RTX 3090 24G GPU.

filtering model is in one work on this site, Rationale-Guided Retrieval Augmented Generation. This is the abstract a model wrote of it from that work.

2 / 2.1 .. 2.2

The filtering model is trained using more detailed signals from perplexity differences in rationales generated by the base large language model. The described method trains only a small filtering model and applies uncertainty during training rather than during inference.

3 / 3.1 .. 3.4

The filtering model evaluates whether retrieved documents are useful to the base LLM. It is trained on a perplexity-stratified dataset generated from model outputs and labels.

4 / 4.1 .. 4.3

The filtering model is trained using QA pairs from MedQA and MedMCQA and is intended to select when retrieval is useful. It is trained on MedMCQA for MMLU-Med because that dataset has no training data, and its performance transfers to the out-of-domain MMLU-Med benchmark.
