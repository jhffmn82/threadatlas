Introduction

Repository-level coding is represented by two tasks in CODERAG-BENCH. Retrieval models have particular difficulty selecting useful documents for repository-level tasks, and open retrieval provides relatively limited gains in this setting.

The CODERAG-BENCH .. 2.4

Repository-level coding problems require editing files in the context of an entire GitHub repository. CODERAG-BENCH uses RepoEval and SWE-bench-Lite for repository-level code generation and issue solving.

Canonical RACG / 3.1 .. 3.4

Repository-level challenges include RepoEval and SWE-bench-Lite. Canonical snippets improve all models on RepoEval, while SWE-bench-Lite remains difficult and shows substantial retrieval benefits mainly with GPT models.
