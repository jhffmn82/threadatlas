Abstract written by a model

In Ask in Any Modality, ColPali is an end-to-end, OCR-free document image retrieval model that embeds page patches with a vision-language backbone and filters low-similarity candidates using consensus-based multi-vector mapping. In VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation, ColPali is a late-interaction multi-vector visual retrieval model built on PaliGemma, evaluated across six datasets and achieving 96.15 average source-document identification at k=5.

Experiments / 6.1 .. 6.2

ColPali is evaluated as a late-interaction multi-vector visual retrieval model built on PaliGemma. It scores 96.93 on PaperTab, 97.71 on FetaTab, 95.28 on SciGraphQA, 93.17 on SPIQA, 97.64 on SlideVQA, and 96.15 on average for source-document identification at k = 5.
