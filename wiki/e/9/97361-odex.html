Abstract written by a model

ODEX is an open-domain coding dataset and library-use task with 945 examples spanning 79 libraries, including requests, sqlalchemy, and regex. It includes canonical library documentation, averaging 1.2 entries per example. Retrieval methods vary substantially: canonical documents generally improve generation, while programming solutions yield its largest reported gains, 3.8–4.3 points, and retrieved examples can support functionally correct library use.

ODEX is in one work on this site, CODERAG-BENCH: Can Retrieval Augment Code Generation?. This is the abstract a model wrote of it from that work.

The CODERAG-BENCH .. 2.4

ODEX is an open-domain coding dataset with 945 examples covering a broader range of 79 libraries, including requests and sqlalchemy. CODERAG-BENCH annotates library documentation as canonical documents for its examples, averaging 1.2 documentation entries per example.

Canonical RACG / 3.1 .. 3.4

ODEX is an open-domain task involving library use. Retrieval performance varies considerably across methods, and canonical documents generally improve generation, especially for some code-specific models.

RACG with Open Retrieval

ODEX benefits most from programming solutions, which provide gains of 3.8–4.3 points and can surpass the gains from canonical documentation. Retrieved examples can guide functionally correct use of libraries such as regex and requests even when they are only sometimes functionally relevant.
