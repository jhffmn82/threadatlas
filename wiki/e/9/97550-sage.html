SAGE in Mitigating the Privacy Issues in Retrieval-Augmented Generation (RAG) via Pure Synthetic Data

Shenglai Zeng, Jiankun Zhang, Pengfei He, Jie Ren, Tianqi Zheng, Hanqing Lu, Han Xu, Hui Liu, Yue Xing, Jiliang Tang · 2025

SAGE is a novel two-stage framework and paradigm for generating synthetic retrieval data. Its central goal is to preserve essential contextual and key information while mitigating privacy risks. In Stage-1, it uses attribute-based extraction and generation to create data from extracted attributes and key information. In Stage-2, agent-based iterative, interactive refinement further improves privacy protection: a privacy assessment agent evaluates generated data and a rewriting agent refines it. SAGE is evaluated for utility and privacy in RAG systems, with the complete pipeline reported as Stage-2 and compared with baselines and intermediate outputs. Code is available in the RAG-SAGE code repository.

Abstract

SAGE is a two-stage synthetic data generation paradigm. Its first stage uses attribute-based extraction and generation to preserve key contextual information, while its second stage uses agent-based iterative refinement to further enhance privacy.

Introduction

SAGE is a two-stage generation and refinement paradigm called Synthetic Attribute-based Generation with agEnt-based refinement. It generates synthetic retrieval data from extracted attributes and key information, then uses agent-based iterative refinement to improve privacy protection.

Methods

The SAGE framework generates synthetic retrieval data in two stages: attribute-based data generation and agent-based interactive refinement. It aims to preserve essential information while mitigating privacy risks.

Experiment

SAGE is evaluated for utility and privacy in RAG systems. Its complete pipeline is reported as Stage-2, and its performance is compared with multiple baselines and intermediate outputs.
