Abstract written by a model

In Ask in Any Modality, source attribution is supported by explicit evidence citations in OMG-QA and visual evidence highlighting in VISA. In VISA: Retrieval Augmented Generation with Visual Source Attribution, source attribution is a citation-generation process that links generated answers to retrieved documents for verification, with VISA offering a visually oriented alternative. In VISA: Retrieval Augmented Generation with Visual Source Attribution, source attribution allows users to check the reliability of generated outputs, though text-based citations can make relevant evidence difficult to locate in dense documents. In VISA: Retrieval Augmented Generation with Visual Source Attribution, visual source attribution links generated answers to exact supporting regions in document screenshots through bounding boxes.

visual source attribution in VISA: Retrieval Augmented Generation with Visual Source Attribution

Xueguang Ma, Shengyao Zhuang, Bevan Koopman, Guido Zuccon, Wenhu Chen, Jimmy Lin · 2025 · the work’s page · read it where visual source attribution first appears

Abstract written by a model

Visual source attribution, introduced by VISA, links generated answers to exact supporting regions in original document screenshots through bounding boxes rather than only document- or passage-level citations. It aims to provide finer-grained, visually grounded evidence and make answer verification more intuitive. Evaluation treats it as predicting the document region that supports an answer, including a Single oracle candidate setting where models are trained to associate answers with evidence regions. Results show that existing vision-language models predict bounding boxes poorly without task-specific fine-tuning and transfer poorly across datasets with differing structures, layouts, and content modalities. It also needs improved precision for long or multiple documents and zero-shot settings. Although intended to be more direct and user-friendly, its real-world utility and appropriate granularity remain uncertain without user studies.

Abstract

opening

Visual source attribution pinpoints supporting evidence directly within an original document image using a bounding box. It is presented as more direct and user-friendly than document-level or passage-level textual citation, while still requiring improvements in bounding-box precision for long documents, multiple documents, and zero-shot settings.

4 / 4.1 .. 4.2

Visual attribution is evaluated in the Single oracle candidate setting through bounding box prediction. The model is trained to associate the generated answer with the relevant evidence region in the document image.

5

Visual source attribution requires models to identify source evidence in original documents with appropriate location and granularity. The results show that existing vision-language models perform poorly at bounding-box prediction without task-specific fine-tuning.

6 / 6.1 .. 6.4

Visual source attribution is evaluated as the task of identifying the document region supporting an answer. The unit finds that this capability transfers poorly across datasets with different document structures, layouts, and content modalities.

7

Visual source attribution is the approach introduced by VISA. It provides bounding boxes to locate evidence and enables finer-grained, visually grounded attribution.

Limitations

Visual attribution is provided by VISA to make answer verification more intuitive. Its practical utility and appropriate granularity remain uncertain without user studies in real-world deployment scenarios.
