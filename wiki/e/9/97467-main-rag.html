MAIN-RAG

Abstract written by a model

MAIN-RAG, or Multi-Agent Filtering Retrieval-Augmented Generation, is a training-free, multi-agent Retrieval-Augmented Generation framework for improving RAG performance and reliability when retrieved documents contain noise. It requires neither additional labeled training data nor model fine-tuning. Its central idea is to use multiple LLM agents collaboratively: Agent-1 (Predictor), Agent-2 (Judge), and Agent-3 (Final-Predictor) identify, assess, filter, and score retrieved documents. An adaptive, query-specific judge bar adjusts judging criteria according to the retrieved documents, while inter-agent consensus supports robust document selection. After retrieval, MAIN-RAG filters noisy documents, retains and ranks relevant information, and reorders the remaining documents by relevance score before final prediction or answer generation; it can process up to twenty retrieved documents. Evaluations include ARC-Challenge, TriviaQA-unfiltered, PopQA, and a fourth QA benchmark. Across four benchmarks, it consistently outperforms traditional and training-free RAG baselines, improves answer accuracy by 2–11%, reduces irrelevant documents, and achieves superior response consistency and answer accuracy. Reported margins reach 6.1% with Mistral7B and 12.0% with Llama38B versus training-free and without-retrieval baselines. It is presented as a competitive, practical alternative to training-based solutions and may extend beyond question answering.

MAIN-RAG: Multi-Agent Filtering Retrieval-Augmented Generation

MAIN-RAG is presented as a work titled “Multi-Agent Filtering Retrieval-Augmented Generation.” Its listed authors are Chia-Yuan Chang, Zhimeng Jiang, Vineeth Rakesh, Menghai Pan, Chin-Chia Michael Yeh, Guanchu Wang, Mingzhi Hu, Zhichao Xu, Yan Zheng, Mahashweta Das, and Na Zou.

Abstract

Multi-Agent Filtering Retrieval-Augmented Generation is a training-free RAG framework that uses multiple LLM agents to collaboratively filter and score retrieved documents. It introduces adaptive filtering and inter-agent consensus to improve document selection without additional training data or fine-tuning.

1 / Introduction

Multi-Agent FIlteriNg Retrieval-Augmented Generation (MAIN-RAG) is proposed as a training-free framework for improving the performance and reliability of RAG systems. It uses multiple LLM agents to filter and score retrieved documents, applies adaptive filtering, and retains relevant documents for final generation.

3 / Multi-Agent Filtering RAG (MAIN-RAG) .. 3.3 / Adaptive Judge Bar τq

MAIN-RAG is a training-free framework that uses three LLM agents to identify and filter noisy documents after retrieval. It also reorders the remaining documents according to their relevant scores before final prediction.

4 / Experiments .. 4.6 / Case Studies of Different Adaptive Judge

MAIN-RAG is a training-free RAG framework that uses three LLM agents to filter and rank up to twenty retrieved documents before generating an answer. Across four benchmarks, it outperforms training-free and without-retrieval baselines by margins of up to 6.1% with Mistral7B and 12.0% with Llama38B.

5 / Conclusion and Future Work

MAIN-RAG is a training-free, multi-agent framework that addresses noisy document retrieval in RAG. It uses multiple LLM agents to collaboratively filter and rank retrieved documents and consistently outperforms training-free RAG baselines across various QA benchmarks.
