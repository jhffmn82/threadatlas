Abstract written by a model

CODERAG-BENCH corpus combines programming solutions, tutorials, Python library documentation, StackOverflow posts, and GitHub files into 25 million retrieval documents for evaluating 9k coding tasks.

CODERAG-BENCH corpus is in one work on this site, CODERAG-BENCH: Can Retrieval Augment Code Generation?. This is the abstract a model wrote of it from that work.
