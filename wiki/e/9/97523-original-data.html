Narrative, section by section

Abstract

Original data serves as the comparison point for synthetic retrieval data. Experiments indicate that synthetic data can provide comparable performance to original data while reducing privacy risks.

Introduction

Original data serves as the source from which related records, important attributes, and key information are identified. The proposed approach avoids directly providing original data to the large language model during retrieval and generation.

Methods

Original data supplies the examples, samples, attributes, and information used to generate synthetic data. The privacy agent also compares the original data with the generated data when assessing privacy issues.

Utility of using synthetic data

Original data serves as a baseline retrieval source. Synthetic data performs comparably to or better than it in the reported medical dialog and ODQA experiments.

Privacy of using synthetic data

Original data is used as a comparison point in the privacy attacks. Attribute-based generated data has a lower attack success rate than original data and simple paraphrasing.

Conclusions

Original data serves as the performance comparison for the generated synthetic data. The generated synthetic data achieves comparable performance when used as RAG data.
