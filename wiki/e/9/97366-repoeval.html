RepoEval

Abstract written by a model

RepoEval is a repository-level coding dataset for function completion and code generation. Its function split supports execution-based evaluation and is the reported split in CODERAG-BENCH. It evaluates completion with 2k context tokens; canonical local snippets improve models, strong retrieval can match or exceed them, while open sources add little beyond local repository context.

The CODERAG-BENCH .. 2.4

RepoEval is adopted for repository-level code generation, and all three of its splits are integrated. Only its function split is reported because it supports execution-based evaluation, and CODERAG-BENCH enables reproducible execution evaluation for that split.

Canonical RACG / 3.1 .. 3.4

RepoEval evaluates repository-level function completion with 2k context tokens. Canonical snippets improve all models by 7.5–17.2 points, and full RACG with strong retrievers can match or surpass the canonical setup.

RACG with Open Retrieval

RepoEval shows that open sources are less useful than code snippets in the local repository. Combining local and open-source contexts surpasses the no-retrieval baseline but remains comparable with using local context alone.
