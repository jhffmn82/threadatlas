Abstract written by a model

A hierarchical description is a text representation of an ego-graph. It uses indentation and nested nodes to express graph levels, retain node text or titles, and make parent-child relationships and connectivity explicit. It is produced by pre-order traversal, appending node and edge texts with a relation template, then inserting remaining edge texts, enabling lossless conversion while preserving topology.

hierarchical text descriptions in GRAG: Graph Retrieval-Augmented Generation

Yuntong Hu, Zhihan Lei, Zheng Zhang, Bo Pan, Chen Ling, Liang Zhao · 2025-07-12 · the work’s page · read it where hierarchical text descriptions first appears

Abstract written by a model

Hierarchical text descriptions generated from retrieved textual subgraphs use graph algorithms to encode topological information as hard prompts. They are important for LLM graph-related generation: removing them substantially lowers WebQSP Hit@1 to 0.4496, despite retained textual node and edge attributes and soft graph tokens.
