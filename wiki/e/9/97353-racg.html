RACG

Abstract written by a model

RACG is retrieval-augmented code generation, a new paradigm studied with CODERAG-BENCH across varied coding tasks and knowledge sources. It combines retrieved context with code generators, using Python for coding tasks, and is evaluated in retrieval, augmented-generation, and end-to-end settings. Canonical documents, including prepended top-5 retrieved documents, estimate an ideal-retriever upper bound and can substantially improve generation, with gains varying by task and generator. RACG is also tested with open retrieval from all sources, mixed retrieval across HumanEval, ODEX, and RepoEval, and different chunking strategies. Current retrieval models often fail to select useful documents for open-domain and repository-level tasks, producing suboptimal results. The work presents RACG as an initial exploration, leaving broader task, language, model, and component-method diversity open for improvement.

Introduction

Retrieval-augmented code generation is evaluated through retrieval, generation, and end-to-end settings in CODERAG-BENCH. The introduction reports that canonical documents can substantially improve generation, although current retrieval models have difficulty selecting useful documents for open-domain and repository-level tasks.

The CODERAG-BENCH .. 2.4

Retrieval-augmented code generation is addressed through CODERAG-BENCH's retrieval, augmented generation, and evaluation interface. The benchmark estimates the upper bound of such a system using ideal-retriever-oriented canonical documents.

Canonical RACG / 3.1 .. 3.4

Retrieval-augmented code generation combines retrieved context with StarCoder2-7B, DeepSeekCoder-7B, GPT-3.5-turbo, and GPT-4o. Its effectiveness varies by task and generator, with especially large gains for weaker models and for GPT-4o on SWE-bench-Lite.

RACG with Open Retrieval

RACG is evaluated with open retrieval from all sources and with mixed retrieval across HumanEval, ODEX, and RepoEval. Its performance is also studied under different chunking strategies.

Related Work

RACG is presented as a setting for studying retrieval-augmented code generation across varied coding tasks and knowledge sources. CODERAG-BENCH is built to enable systematic studies of RACG.

6

Retrieval-augmented code generation is the subject of CODERAG-BENCH, which evaluates it across various coding tasks and retrieval sources. The experiments show that retrieving external documents can benefit it, although current limitations lead to suboptimal results.

Limitations

Retrieval-augmented code generation is proposed as a new paradigm, but the work describes it as an initial exploration. Its task and language diversity, backbone models, and methods for each component remain open to improvement.
