K-RagRec

framework · 1 work · 38 quoted facts · 17 connections
Also called: K- RagRec

Abstract written by a model

K-RagRec is a knowledge retrieval-augmented framework for large language model recommendation. It augments recommendation generation with reliable, up-to-date knowledge and structure information from external item knowledge graphs, while avoiding long context input through expressive graph encoding. Its five components are hop-field knowledge sub-graph semantic indexing, popularity selective retrieval, knowledge sub-graph retrieval, knowledge sub-graph re-ranking, and knowledge-augmented recommendation. It first constructs a vector database by coarse- and fine-granularity indexing of knowledge sub-graphs, using a graph neural network and a pretrained language model; SentenceBert encodes entities, relations, and query attributes. A popularity selective policy determines items to retrieve, then it retrieves the top three most similar sub-graphs for each item and reranks five sub-graphs to prioritize relevant results. A GNN Encoder encodes retrieved sub-graph structure, and a projector aligns the sub-graphs with the LLM semantic space, providing them as soft prompts to a frozen large language model. Implemented with PyTorch and run on two NVIDIA A6000-48GB GPUs, it is effective on three real-world datasets. It outperforms GraphToken w/ RAG and G-retriever with prompt tuning across evaluated datasets and backbones, achieves its best performance with LoRA fine-tuning, and is efficient compared with KG-Text on MovieLens-1M with LLama-2-7b, where it records 1.06 seconds per inference.

Knowledge Graph Retrieval-Augmented Generation for LLM-based Recommendation / Abstract

K-RagRec is a retrieval-augmented framework proposed to facilitate recommendation generation by incorporating structure information from an external knowledge graph. Extensive experiments demonstrate its effectiveness.

1

K-RagRec is a knowledge retrieval-augmented recommendation framework that retrieves relevant knowledge from item knowledge graphs for recommendation generation. It indexes knowledge sub-graphs at coarse and fine granularities, selectively retrieves items based on popularity, reranks the results, and uses a GNN and projector to align them with the LLM.

3 / 3.1 .. 3.8

K-RagRec is a recommendation framework with five components: hop-field knowledge sub-graph semantic indexing, popularity selective retrieval, knowledge sub-graph retrieval, knowledge sub-graph re-ranking, and knowledge-augmented recommendation. It uses graph neural networks and an MLP projector to provide retrieved knowledge as soft prompts to a frozen large language model.

4 / 4.1 / 4.1.1 .. 4.5

K-RagRec is evaluated as a knowledge-graph retrieval framework for large language model recommendation. It outperforms the compared prompt-tuning retrieval baselines across the reported datasets and backbones in most metrics, achieves the best results when combined with LoRA fine-tuning, and records 1.06 seconds per inference on MovieLens-1M with LLama-2-7b.

5

K-RagRec augments the recommendation capability of large language models by retrieving reliable and up-to-date knowledge from knowledge graphs. It uses a graph neural network and a pretrained language model for semantic indexing, applies popularity selective retrieval, and performs expressive graph encoding of retrieved knowledge sub-graphs.
