tree

structure · 2 works · 1 quoted fact · 1 connection
Also called: Tg, hierarchical tree structure, tree structures
  • In GRAG: Graph Retrieval-Augmented Generation, the tree has parent-child connections between nodes in a hierarchical structure, lacks additional edges connecting nodes within the same level or across multiple levels, and is obtained as part of the ego-graph conversion.
  • In GRAG: Graph Retrieval-Augmented Generation, the tree is a partially ordered set rooted at the ego node, obtained from an ego-graph using BFS, whose nodes and edges are organized through pre-order traversal.
