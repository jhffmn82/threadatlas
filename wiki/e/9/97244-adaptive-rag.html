Adaptive-RAG in Rationale-Guided Retrieval Augmented Generation

Jiwoong Sohn · 2025

Adaptive-RAG is a retrieval-augmented generation filtering-model method that assesses query complexity from changes in an LLM’s response correctness, applies only to correctly answered queries, and overlooks retrieved documents’ nuanced effects beyond accuracy.

Narrative, section by section

1 section; each heading opens the text

2 / 2.1 .. 2.2

Adaptive-RAG assesses query complexity based on changes in the correctness of an LLM's response. It can only be used for queries that are answered correctly and overlooks nuanced effects of retrieved documents beyond basic accuracy.
