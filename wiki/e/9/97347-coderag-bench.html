Also called: CODERAG-BENCH:, testbed
  • In CODERAG-BENCH: Can Retrieval Augment Code Generation?: CODERAG-BENCH, titled “Can Retrieval Augment Code Generation?”, is a comprehensive, holistic, Python-focused benchmark for retrieval-augmented code generation. Authored by Zora Zhiruo Wang, Akari Asai, Xinyan Velocity Yu, Frank F. Xu, Yiqing Xie, Graham Neubig, and Daniel Fried, it aggregates existing code-generation tasks and retrieval sources into a unified interface for retrieval, augmented generation, and evaluation. It spans six programming tasks and the categories of basic programming, open-domain coding, repository-level coding, and code retrieval, ranging from line- and function-level problems to repository-level problems. Its central contribution is reproducible, reliable evaluation of retrieval, code generation, and end-to-end retrieval-augmented code generation, using NDCG for retrieval and pass@k for generation, with ground-truth annotations and execution-based evaluation. It contains 9k coding tasks, 25 million retrieval documents, HumanEval, manually annotated canonical reference documents, and an open datastore supporting retrieval from different sources and chunking strategies; 200–800-token chunks are often best. The benchmark is evaluated with 10 retrieval models and 10 generation models. It is intended as a solid testbed for systematic studies and future work, while primarily focusing on Python and leaving areas such as code debugging under-explored.
