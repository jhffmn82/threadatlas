The CODERAG-BENCH .. 2.4

Basic programming problems are interview-style tasks that mainly require Python built-in operations and pose algorithmic challenges. CODERAG-BENCH includes HumanEval, MBPP, and LiveCodeBench in this category.

Canonical RACG / 3.1 .. 3.4

Basic programming problems include HumanEval and MBPP. Retrieved contexts often help weaker generators, with StarCoder2-7B showing especially large improvements on MBPP.
