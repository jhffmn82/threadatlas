Also called: canonical datastore, datastore, open datas- tore, open datastore, retrieval pool

Abstract written by a model

The retrieval datastore is a code-retrieval source formed from programming solutions, online tutorials, library documentation, StackOverflow posts, and GitHub repositories or files. In CODERAG-BENCH, retrieval may use this canonical datastore alone or any datastore, depending on the evaluation setup.

retrieval datastore is in one work on this site, CODERAG-BENCH: Can Retrieval Augment Code Generation?. This is the abstract a model wrote of it from that work.
