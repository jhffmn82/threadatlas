Abstract written by a model

Open retrieval is a CODERAG-BENCH setup that retrieves documents from any datastore rather than only canonical sources. It is evaluated alongside canonical retrieval, improving some results through Stack Overflow on HumanEval and programming solutions on ODEX, but proving less useful than local repository context on RepoEval.

Open retrieval is a CODERAG-BENCH setup in which documents can be retrieved from any datastore. Final RAG performance is evaluated under this setup as well as under canonical retrieval.

RACG with Open Retrieval

Open retrieval uses documents from all sources rather than only a canonical source. It improves results in some settings, especially through Stack Overflow posts on HumanEval and programming solutions on ODEX, but is less useful than local repository context on RepoEval.
