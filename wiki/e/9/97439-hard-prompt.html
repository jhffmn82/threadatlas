Abstract written by a model

In GRAG: Graph Retrieval-Augmented Generation, hard prompts concatenate the query and hierarchical description of the textual subgraph, then are provided to the large language model. In GRAG: Graph Retrieval-Augmented Generation, the hard prompt concatenates a query with a hierarchical description of a textual subgraph as [q, Dg], then a language model’s text embedder converts it into text embeddings. In GRAG: Graph Retrieval-Augmented Generation, hard prompts provide text-token representations of retrieved textual subgraphs to the Large Language Model and are formed from hierarchical text descriptions that preserve topological information in textual form.
