Syntax-Aware Retrieval Augmented Code Generation / Abstract

It has shown potential in neural machine translation, but applying it directly to code generation introduces retrieval noise and search overhead.

1

The token-level retriever integrates external knowledge into a pretrained model and allows the model to be updated by switching the retrieval datastore without fine-tuning model parameters. Its use in kNN-MT can introduce irrelevant retrieved tokens into generated code.
