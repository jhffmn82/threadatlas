Abstract written by a model

Token-level retrieval integrates external knowledge into a pretrained model and can be updated by switching the retrieval datastore without fine-tuning. It shows potential in neural machine translation, but direct code generation introduces retrieval noise, irrelevant tokens, and search overhead.
