incremental learning in Syntax-Aware Retrieval Augmented Code Generation

Xiangyu Zhang, Yu Zhou, Guang Yang, Taolue Chen · 2023

Incremental learning is a scenario for continuously updating trained code-generation models. Retraining with new data needs huge resources and may cause catastrophic forgetting, so evaluation updates only a datastore. Adding 0k–95k mined CoNaLa data improves kNN-TRANX on three criteria and, without neural-network fine-tuning, yields competitive performance against learning-based methods.

Narrative, section by section

3 sections; each heading opens the text

4 / 4.1 .. 4.3

Incremental learning is described as necessary for continuously updating trained code-generation models, but it consumes substantial computing resources. Using new data for incremental learning can also cause catastrophic forgetting, motivating datastore-only updates in the adaptation evaluation.

opening

Incremental learning is examined by updating the datastore with 0k, 10k, 50k, or 95k mined data from the CoNaLa dataset. The updates improve kNN-TRANX on all three evaluation criteria.

6

Incremental learning enables kNN-TRANX to achieve competitive performance against learning-based methods. The experiments use external data to incrementally update the datastores without fine-tuning the neural network.
