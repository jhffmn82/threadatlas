semantic datastore in Syntax-Aware Retrieval Augmented Code Generation

Xiangyu Zhang, Yu Zhou, Guang Yang, Taolue Chen · 2023

The semantic datastore is a kNN-TRANX seq2tree-model datastore for AST-node retrieval. Built separately from the syntactic datastore according to AST node type, it stores context representations as keys and target primitives as values. After grammar rules determine the next node type, kNN-TRANX queries it when the next token is expected to carry semantic information. In the reported experiment it has 518k entries, Kpri = 64, potentially infinite vocabulary-dependent token types, and relatively scarce semantic knowledge per vocabulary. Its growth continues to improve generated-code quality. It can be updated independently without neural-network fine-tuning; with Only Semantics true, it alone is updated with external data.

The semantic datastore is configured with Kpri = 64 and stores semantic information separately from syntactic information. Generated-code quality continues to improve as the semantic datastore grows, which the text attributes to the relative scarcity of semantic knowledge.

The semantic datastore contains 518k entries in the reported experiment, with vocabulary-dependent token types and relatively scarce knowledge per vocabulary. Updating only the semantic datastore can still improve performance.

The semantic datastore is one of the datastores provided for the kNN-TRANX seq2tree model. It can be updated without fine-tuning the neural network, and when Only Semantics is true, it is the only datastore updated with external data.
