Abstract written by a model

In “Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory,” it is described as a retrieval-augmented translation model that retrieves training-set memories through search engines and incorporates them via an external memory network. In “Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory,” it is one of the three text-generation tasks used to evaluate Selfmem. In “Syntax-Aware Retrieval Augmented Code Generation,” it is described as a machine-translation approach that has advanced the non-parametric k-nearest-neighbour machine-translation approach by adding token-level retrieval to standard neural machine-translation models.

Abstract written by a model

A retrieval-augmented translation model retrieves training-set memories through search engines, incorporates them via an external memory network, and uses generative and discriminative reranking as primary approaches. It develops from early retrieval and memory integration to work on encoding, joint retriever-generator training, granularity, and diversity.
