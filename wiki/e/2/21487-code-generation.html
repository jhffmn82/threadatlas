code generation in CODERAG-BENCH: Can Retrieval Augment Code Generation?

Zora Zhiruo Wang, Akari Asai, Xinyan Velocity Yu, Frank F. Xu, Yiqing Xie, Graham Neubig, and Daniel Fried · 2025

Code generation is a crucial NL-to-code task typically performed from natural-language queries and parametric knowledge. It has advanced rapidly but lacks external context for unfamiliar, evolving, and private code bases. The records evaluate it with pass@1, comparing no context with ground-truth canonical documents; documents improve most setups, especially basic problems, unfamiliar libraries, and some repository tasks. Retrieval can greatly help, but retrieval and generation limitations prevent optimal results.

Narrative, section by section

Abstract

Code generation benefits when models receive high-quality retrieved contexts, although the unit identifies limitations in retrieving and effectively using those contexts.

Introduction

Code generation from natural language has advanced rapidly with language models, but most systems do not integrate external context. This limits their performance with unfamiliar libraries, evolving public libraries, and private code bases that were absent from training.

Canonical RACG / 3.1 .. 3.4

Code generation is evaluated without additional context and with ground-truth documents using pass@1. Adding canonical documents improves most setups, particularly on basic programming problems, unfamiliar libraries, and some repository-level tasks.
