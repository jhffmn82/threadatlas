binary relevance token in LI-RAGE: Late Interaction Retrieval Augmented Generation with Explicit Signals for Open-Domain Table Question Answering

Weizhe Lin · 2023

A relevance token is prefixed to the reader’s generated answer. At inference time, it indicates whether the table used for answering is reliable, allowing irrelevant tables to be filtered when multiple tables are retrieved. This design improves TableQA performance; removing it lowers NQ-TABLES Token F1 and EM by about 3.6% and E2E-WTQ accuracy by 8.4%.

Narrative, section by section

2 sections; each heading opens the text

Abstract

It is embedded as a prefix to the answer generated by the reader. It allows inference-time determination of whether the table used to answer the question is reliable, enabling filtering.

Results and Discussions / Main Results .. Remarks of Design Rationale

Relevance tokens improve TableQA performance by allowing irrelevant tables to be dropped when multiple tables are retrieved. Removing them reduces performance by around 3.6% in Token F1 and EM on NQ-TABLES and by 8.4% in E2E-WTQ accuracy.
