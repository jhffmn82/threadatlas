BertranX

model · 1 work · 12 quoted facts · 3 connections
Also called: BertranX†, BertranX†1, base model, base seq2tree model

Abstract written by a model

BertranX is a state-of-the-art seq2tree model based on TRANX. It uses BERT as an encoder to process input natural language and a grammar-based decoder with ASDL action sequences to generate ASTs. Trained on annotated data and 100,000 mined data, it serves as the underlying/base model for kNN-TRANX and as an experimental baseline on CoNaLa and Django. Full BertranX achieves 34.18 BLEU, 36.09 CodeBLEU, and 5.8 EM on CoNaLa; on Django it reaches 79.86 BLEU, 78.85 CodeBLEU, and 79.77 EM. Its cleaned-2k/mined-5k variant scores lower.

BertranX is in one work on this site, Syntax-Aware Retrieval Augmented Code Generation. This is the abstract a model wrote of it from that work.
