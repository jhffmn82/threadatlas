kNN-TRANX inference

process · 1 work · 3 quoted facts · 3 connections
Also called: inference, model inference, model inferring, process of model inference

Abstract written by a model

kNN-TRANX inference is a syntax-constrained token-level retrieval process: it generates a context representation and neural network distribution, queries a datastore for a k-nearest-neighbor distribution, then weights both to predict a target token. Extra datastore searches can substantially lengthen inference.

kNN-TRANX inference is in one work on this site, Syntax-Aware Retrieval Augmented Code Generation. This is the abstract a model wrote of it from that work.

kNN-TRANX inference has three phases: generating a context representation and neural network distribution, querying a datastore for a k-nearest-neighbor distribution, and combining the two distributions to predict the target token.

Limitations

Inference may take considerably longer when extra datastores require similarity searches at each time step.
