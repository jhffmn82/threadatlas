ColBERT in LI-RAGE: Late Interaction Retrieval Augmented Generation with Explicit Signals for Open-Domain Table Question Answering

Weizhe Lin · 2023

ColBERT is a Latent Interaction retrieval model, first proposed by Khattab and Zaharia (2020). It uses question and table encoders to represent both at token level, then scores relevance through interactions among their token embeddings. In the proposed approach, it is very effective for table retrieval despite not being pretrained for tables.

Narrative, section by section

3 sections; each heading opens the text

Introduction

ColBERT is used as a Latent Interaction model in the proposed approach. The unit reports that it is very effective for table retrieval even though it was not pretrained for tables.

Methodology / Table Retrieval .. Learned Table Relevance

ColBERT consists of a question encoder and a table encoder that represent questions and tables at the token level. It scores relevance through interactions between all question and table token embeddings.

Indexing and Dynamic Retrieval

ColBERT was proposed as the first version by Khattab and Zaharia (2020).
