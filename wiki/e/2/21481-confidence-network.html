Confidence Network in Syntax-Aware Retrieval Augmented Code Generation

Xiangyu Zhang, Yu Zhou, Guang Yang, Taolue Chen · 2023

Confidence Network combines neural network and k-nearest-neighbor distributions, using meta-k weights to estimate sigmoid-based confidence for their weighted combination.

Narrative, section by section

1 section; each heading opens the text

3 / 3.1 .. 3.2

The confidence network estimates the confidence of the k-nearest-neighbor and neural network distributions. It uses both distributions and the meta-k weights to calculate a sigmoid-based confidence value for their weighted combination.
