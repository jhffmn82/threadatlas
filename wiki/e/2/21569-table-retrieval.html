table retrieval in LI-RAGE: Late Interaction Retrieval Augmented Generation with Explicit Signals for Open-Domain Table Question Answering

Weizhe Lin · 2023

Table retrieval is a research area and task that finds the gold table for a question from a table corpus. It builds on machine-learning methods that represent table features and structure, uses token-level question-table interactions, and returns the K highest-scoring tables. In contrastive experiments, DPR and LI are fine-tuned on each dataset before joint retriever-reader training. Performance is measured with Recall@K: a retrieved row or column counts as a hit when it belongs to the gold table. CLTR and T-RAG results are not directly comparable across different corpus setups.

Related Work

Table retrieval has benefited from machine learning methods that extract deep table features with Transformers, model complex tabular structure, or linearize tables with interleaving tokens to preserve structure.

Methodology / Table Retrieval .. Learned Table Relevance

Table retrieval finds the gold table for a question from a table corpus. It uses token-level question-table interactions and returns the K highest-scoring tables.

Experimental Setup

The table retrieval component is evaluated with DPR and LI in contrastive experiments. The retrievers are fine-tuned on each dataset before joint retriever-reader training, and their performance is measured with Recall@K.

CLTR and T-RAG Evaluation

Retrieval is evaluated with Recall@K rather than Precision@K because each question has only one gold table. Retrieval results from systems using different table-corpus setups are not directly comparable.
