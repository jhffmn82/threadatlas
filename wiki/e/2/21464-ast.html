Also called: AST nodes, AST representations, ASTs, abstract syntax tree, abstract syntax tree (AST)

Abstract written by a model

AST is a hierarchical tree-like code representation generated from code snippets. It represents each snippet through grammar-constrained construction or sequences of actions: rules for structural nodes and primitives for semantic nodes. Seq2tree models generate ASTs, and BertranX describes them with ASDL-based action sequences.

AST is in one work on this site, Syntax-Aware Retrieval Augmented Code Generation. This is the abstract a model wrote of it from that work.
