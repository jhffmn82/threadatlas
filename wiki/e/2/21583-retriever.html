retriever in LI-RAGE: Late Interaction Retrieval Augmented Generation with Explicit Signals for Open-Domain Table Question Answering

Weizhe Lin · 2023

Retriever is a component in research TableQA pipelines that selects a small set of whole tables from a corpus for a reader. It begins by linearizing each table into a token-level, structure-aware sequence with separation tokens and encoding tables and questions with transformer-based models. It computes question-table relevance, usually with a Dense Passage Retriever variant; the proposed approach instead uses late interaction and larger multi-dimensional embeddings in LI-RAGE than DPR-RAGE. It is trained with contrastive loss and in-batch negatives, then jointly refined end-to-end with the reader using RAGE loss and explicit table-level signals. During joint training, scores are dynamically adjusted to support answer generation, and it outputs the K top-scoring tables for each question.

Narrative, section by section

5 sections; each heading opens the text

Abstract

It usually uses a variant of the Dense Passage Retriever to compute similarities between questions and tables. It is also jointly trained with the reader using explicit table-level signals.

Introduction

The retriever chooses a small set of tables from the entire candidate pool for the reader to process. The unit proposes using a Latent Interaction model and RAGE loss to improve retrieval and provide explicit table-level guidance during joint training.

Related Work

The work focuses mainly on the retriever and explores techniques for explicitly refining it during end-to-end TableQA. Its approach uses late interaction rather than single-vector embeddings and retrieves whole tables instead of decomposed rows and columns.

Methodology / Table Retrieval .. Learned Table Relevance

The retriever is trained with contrastive loss and in-batch negative sampling, treating other tables in the batch as negatives. During joint training, its scores are dynamically adjusted to better support answer generation.

A / Table Linearization

The retriever component linearizes the input table into a sequence. It interleaves separation tokens among table elements to make the input structure-aware.
