seq2tree model in Syntax-Aware Retrieval Augmented Code Generation

Xiangyu Zhang, Yu Zhou, Guang Yang, Taolue Chen · 2023

seq2tree is a code generation model that generates abstract syntax trees rather than target code snippets. AST construction rules ensure syntactic correctness and can filter retrieval noise. It is pre-trained with training data to generate decoder context representations; during inference it produces representations and neural network distributions for current code fragments, gaining improved generalizability.
