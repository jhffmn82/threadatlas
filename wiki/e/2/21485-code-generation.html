code generation in Syntax-Aware Retrieval Augmented Code Generation

Xiangyu Zhang, Yu Zhou, Guang Yang, Taolue Chen · 2023

Code generation produces target code from natural language to improve programmers’ development efficiency. Evaluated on CoNaLa and Django, it compares kNN-TRANX with several systems; token-level retrieval yields stronger performance, especially on challenging tasks, alongside AST-based generation, reliability, test-case selection, and pre-training.

The code-generation experiments compare kNN-TRANX with TRANX, Reranker, Ext-codegen, TAE, BertranX, REDCODER, and CodeT5. Token-level retrieval improves code-generation performance, with more evident gains on challenging tasks.
