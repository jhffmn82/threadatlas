Django dataset

Also called: Django

Abstract written by a model

Django is a publicly available code-generation dataset of 18,805 examples, each pairing one line of Python code with comments. About 70% are simple tasks, including variable assignment, method definition, and exception handling. It is used to evaluate kNN-TRANX and ablation variants with BLEU, CodeBLEU, and EM; kNN-TRANX improves BLEU by 4.2% and scores 83.20 BLEU, 81.66 CodeBLEU, and 82.16 EM. It also examines datastore size and knowledge reductions.

Django dataset is in one work on this site, Syntax-Aware Retrieval Augmented Code Generation. This is the abstract a model wrote of it from that work.
