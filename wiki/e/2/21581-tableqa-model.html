Abstract written by a model

TableQA model is a sequence-to-sequence Transformer-based model that takes a question and retrieved table, generates an answer per table, and returns the answer with highest probability or confidence.

TableQA model is in one work on this site, LI-RAGE: Late Interaction Retrieval Augmented Generation with Explicit Signals for Open-Domain Table Question Answering. This is the abstract a model wrote of it from that work.
