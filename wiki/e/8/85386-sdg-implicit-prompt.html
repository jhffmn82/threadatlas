SDG-implicit prompt

Also called: SDG-implicit, SDG-implicit prompt version

Abstract written by a model

The SDG-implicit prompt is a prompt version used in SDG Target Detection. It masks SDG framing by replacing target references with environmental policies or policies and target IDs with random identifiers; it more often favors ranked passages, with varying model precision and recall results.

SDG-implicit prompt is in one work on this site, SDG target detection in environmental reports using Retrieval-augmented Generation with LLMs. This is the abstract a model wrote of it from that work.
