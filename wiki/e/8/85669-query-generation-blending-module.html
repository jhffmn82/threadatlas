Query Generation Blending module in BlendFilter: Advancing Retrieval-Augmented Large Language Models via Query Generation Blending and Knowledge Filtering

Haoyu Wang · 2024-11

Query Generation Blending is a query generation method that enhances an original query with external knowledge and Large Language Model internally memorized knowledge. It forms a composite of the original, externally augmented, and internally augmented queries, then uses them to retrieve additional knowledge documents and support comprehensive information gathering. Combining all three increases Recall; removing any reduces performance, with the internally augmented query especially important when BM25 is used.

Abstract

Query generation blending integrates external and internal knowledge augmentation with the original query to support comprehensive information gathering.

1

The Query Generation Blending module enhances input queries through diverse augmentation strategies and forms a composite of queries. It uses original, external knowledge-augmented, and internal knowledge-augmented queries to retrieve more comprehensive information.

3 .. 3.4

Query generation blending enhances the original query with external knowledge and the Large Language Model's internally memorized knowledge. The enhanced queries are then used to retrieve additional knowledge documents.

4 .. 4.8

Query blending combines the original query, an externally knowledge-augmented query, and an internally knowledge-augmented query. Removing any one of these queries reduces performance, and the internally augmented query is especially important when BM25 is used.
