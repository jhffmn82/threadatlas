internal knowledge-augmented query

object · 1 work · 4 quoted facts · 3 connections
Also called: Internal Knowledge Augmentation, internal knowledge augmentation, internal knowledge-augmented, internal knowledge-augmented queries, internally augmented query, qin

Abstract written by a model

Internal knowledge-augmented query uses an LLM’s memorized knowledge to generate a detailed response, concatenates it with the original query, and is used with original and externally augmented queries for retrieval. It supplies pertinent information and affects model performance, especially with BM25.

internal knowledge-augmented query is in one work on this site, BlendFilter: Advancing Retrieval-Augmented Large Language Models via Query Generation Blending and Knowledge Filtering. This is the abstract a model wrote of it from that work.
