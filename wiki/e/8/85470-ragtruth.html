RAGTruth dataset in RAG-HAT: A Hallucination-Aware Tuning Pipeline for LLM in Retrieval-Augmented Generation

Juntong Song, Xingguang Wang, Juno Zhu, Yuanhao Wu, Xuxin Cheng, Randy Zhong, and Cheng Niu · 2024-11

RAGTruth is a substantial open-source, word-level hallucination evaluation dataset tailored to RAG. It covers several common tasks and contains 2,965 unique RAG tasks. Used for model training, system evaluation, and regenerated answers from a selected LLM, it supplies hallucinated text spans but lacks detailed hallucination descriptions.

Dataset

RAGTruth is a substantial, word-level hallucination evaluation resource tailored for RAG and covering several common tasks. It is used for both model training and system evaluation because it is described as the largest available open-source dataset specifically designed for the RAG task.

Methodology / Hallucination Detection Model Training / 4.1.1 .. Data Source Extension

The RAGTruth dataset supplies text spans identified as hallucinations but does not provide detailed hallucination descriptions. It contains 2,965 unique RAG tasks and is also used with regenerated answers from the selected LLM.
