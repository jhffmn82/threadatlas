LightRAG in LightRAG: Simple and Fast Retrieval-Augmented Generation

Zirui Guo, Lianghao Xia, Yanhua Yu, Tu Ao, Chao Huang · 2025

LightRAG is a novel, proposed open-source RAG framework and model that integrates graph-based text indexing, vector representations, a comprehensive knowledge graph, and dual-level retrieval. It is designed to improve the comprehensiveness, contextual understanding, speed, quality, efficiency, and cost of information retrieval and generation, while remaining responsive as data changes. It begins by segmenting documents, extracting entities and relationships, generating profiled key-value pairs, and deduplicating graph data to construct a knowledge graph. It then combines low-level and high-level retrieval to rapidly obtain relevant graph information, and uses a large language model to generate answers from retrieved information. Its incremental update capability integrates newly extracted entities and relationships without rebuilding the entire index, enabling quick adaptation to new information and reduced computational costs. In evaluation on four Ultra-Domain benchmark datasets, it generally achieves higher win rates than NaiveRAG, RQ-RAG, HyDE, and GraphRAG, especially for large datasets, complex queries, and Diversity; it has an 84.8% win rate against NaiveRAG on Legal Overall. The retrieval process uses fewer than 100 tokens for keyword generation and retrieval and requires one API call. It also identifies potential enhancements through multi-modal and time-aware frameworks for timely, contextually accurate insights.

Abstract

LightRAG is a framework that incorporates graph structures into text indexing and retrieval. It uses dual-level retrieval, graph and vector representations, and an incremental update algorithm to improve contextual retrieval, response times, and adaptation to changing data; experiments report gains in retrieval accuracy and efficiency.

Introduction

LightRAG is proposed as a graph-empowered RAG model that combines graph-based text indexing, vector representations, and a dual-level retrieval framework. It is designed to improve retrieval comprehensiveness and efficiency while adapting quickly to new data without rebuilding the entire index.

The LightRAG Architecture / Graph-based Text Indexing .. Complexity Analysis of LightRAG

LightRAG constructs a knowledge graph from segmented documents by extracting entities and relationships, generating profiled key-value pairs, and deduplicating graph data. It uses dual-level retrieval and a large language model to generate answers from retrieved information.

Evaluation / Experimental Settings / RAG Performance Comparison (RQ1) .. Case Study

LightRAG is evaluated on four Ultra-Domain benchmark datasets against NaiveRAG, RQ-RAG, HyDE, and GraphRAG. It generally achieves higher win rates, particularly on large datasets, complex queries, and the Diversity metric. Its retrieval process uses fewer than 100 tokens and a single API call, and it integrates newly extracted entities and relationships without reconstructing the existing graph.

Related Work / Retrieval-Augmented Generation .. Large Language Model for Graphs

LightRAG addresses limitations in graph-based Retrieval-Augmented Generation by enabling rapid updates and expansions of the knowledge graph. It uses a dual-level retrieval paradigm to rapidly retrieve relevant graph information, improving retrieval efficiency and response speed.

Conclusion .. Limitations

LightRAG integrates graph-based indexing and a comprehensive knowledge graph to improve the efficiency and comprehension of information retrieval. It supports dual-level retrieval, incremental updating, and potential enhancements through multi-modal capabilities and time-awareness.
