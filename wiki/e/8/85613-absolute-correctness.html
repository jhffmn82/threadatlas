Absolute Correctness in HyPA-RAG: A Hybrid Parameter Adaptive Retrieval-Augmented Generation System for AI Legal and Policy Applications

Rishi Kalra, Zekun Wu, Ayesha Gulley, Airlie Hilliard, Xin Guan, Adriano Koshiyama, Philip Treleaven · 2024-11-16

Absolute Correctness is a refined correctness metric based on LLamaIndex, using a 1-to-5 scale: 1 incorrect, 3 partially correct, and 5 fully correct. Binary evaluation uses threshold 4 and averages whether responses reach it. In PA-RAG, 2-class scores 4.2491 and 3-class scores 4.2528, both above fixed k = 10. The highest reported value is 4.2528 for k, Q; a reranker lowers it to 4.2342, and a knowledge graph reduces it by 0.1301.

Performance Evaluation / Dataset Generation .. Classifier Results

Absolute Correctness uses a 1-to-5 scale based on LLamaIndex, where 1 is incorrect, 3 is partially correct, and 5 is fully correct. The binary Correctness Score averages whether responses reach at least 4.

RAG System Architecture / Parameter-Adaptive RAG (PA-RAG) .. RAG Results

The 2-class and 3-class PA-RAG configurations achieve absolute correctness scores of 4.2491 and 4.2528, respectively. These improve on the best fixed k = 10 score of 4.0595 by approximately 0.1896 and 0.1933.

System Ablation Study

Absolute Correctness is 4.2528 for k, Q configuration and 4.2342 for k, Q + reranker configuration. Adding a knowledge graph in the k, K, S configuration reduces Absolute Correctness by 0.1301.

Overall Results and Discussion

Absolute correctness is measured on a 1-5 scale. The highest reported value is 4.2528 for k, Q, while adding a reranker to that configuration produces 4.2342.
