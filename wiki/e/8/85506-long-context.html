Abstract written by a model

Long Context is a method that passes all documents’ text as context for a sample. It scores below Text RAG, Visual RAG, and VisDoMRAG because high token counts hinder finding localized evidence, and performance declines substantially as pages increase.

Experiments / 6.1 .. 6.2

Long Context passes the text content of all documents for a sample as context. Across the listed LLMs, its average scores are lower than those of Text RAG, Visual RAG, and VisDoMRAG.

Results / 7.1 .. 7.3

Long Context methods are less effective in this setup because they must process high token counts while locating specific, localized evidence. Their performance drops substantially as the number of pages increases.
