Query Complexity Classifier

object · 1 work · 5 quoted facts · 1 connection
Also called: classifier, domain-specific query complexity classifier, query complexity classifier

Abstract written by a model

Query Complexity Classifier is a domain-specific classifier for adaptive parameter selection in HyPA-RAG. It categorises user queries by whether they require one, two, or three or more contexts, helping minimise unnecessary token usage. Fine-tuned DistilBERT reports the highest F1 scores: 0.90 for three classes and 0.92 for two. Trained on noisy synthetic domain data, it may generalise poorly to unseen queries because of possible LLM structural biases.

Introduction

The domain-specific query complexity classifier supports adaptive parameter selection in HyPA-RAG. It is used to minimise unnecessary token usage by selecting parameters according to query complexity.

Performance Evaluation / Dataset Generation .. Classifier Results

The Query Complexity Classifier categorizes queries according to the number of contexts required: one, two, or three or more. It supports adaptive hyperparameter selection, and fine-tuned DistilBERT achieves the highest reported F1 scores, 0.90 for three classes and 0.92 for two classes.

Limitations and Future Work

The classifier was trained on domain-specific synthetically generated data. Although significant noise was injected, the data may contain the LLM's unconscious structural biases, potentially limiting generalisability to unseen user queries.
