  • In SDG target detection in environmental reports using Retrieval-augmented Generation with LLMs: SDG Evidence Identification is a task for finding textual evidence in environmental impact assessment reports that corresponds to a given SDG target. It takes an SDG target and one or more passages, with test collections annotating passages by binary yes/no relevance judgments. In a Retrieval-augmented Generation pipeline, report passages are retrieved for each target, supplied to a Large Language Model with unique string identifiers, and the model selects the relevant contexts. Together with SDG Target Detection, it operationalizes practitioners’ need to find correspondence between targets and textual evidence; identified passages can later feed target detection. The work develops test collections and evaluates methods. Overall, GPT-3.5 with lexically retrieved contexts performs best, especially with one example, while Llama2-13b-chat is strongest in several two-example settings. The task remains limited in the work’s capabilities.

Abstract

SDG target evidence identification is one of the two environment-analysis problems addressed in the paper. The paper develops test collections and evaluates methods for this task within a Retrieval-augmented Generation (RAG) pipeline.

1

SDG Evidence Identification is one of the two tasks addressed in the work. It concerns finding textual evidence in environmental impact assessment reports that corresponds to SDG targets.

3 / 3.1 .. 3.3

SDG Target Evidence Identification determines whether one or more passages from EIA reports provide relevant evidence addressing a given SDG target. It requests a Large Language Model to identify the correct passages using unique string identifiers supplied in the prompt.

4 / 4.1 .. 4.3

The evidence identification task retrieves report passages for each SDG target and asks an LLM to identify which provided contexts are relevant evidence.

5 .. 5.4

SDG Evidence Identification is best addressed overall with GPT-3.5 using contexts obtained through lexical retrieval. GPT-3.5 performs especially well with one example, while Llama2-13b-chat becomes strongest in several two-example settings.

6

Evidence identification remains limited in the work's capabilities. A passage identified through evidence identification for an SDG target could serve as input to a subsequent target-detection stage.
