external knowledge augmentation

topic · 1 work · 5 quoted facts · 5 connections
Also called: External Knowledge Augmentation

Abstract written by a model

External knowledge augmentation is a query refinement technique for complex questions. It first retrieves knowledge documents with the original query, prompts the Large Language Model to reason over them using Chain-of-Thought, then concatenates the resulting context with the initial query to produce an enhanced, two-hop query for document retrieval.
