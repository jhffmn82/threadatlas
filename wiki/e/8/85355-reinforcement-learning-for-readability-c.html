It takes a plain LED first-generation lay summary, uses ground truth as expected output, and applies PPO with a Gaussian-based reward to penalize large differences from the desired readability level.

Reinforcement Learning for Readability Control is used to improve the readability of scientific content so that it is comprehensible to non-specialists.

Methodology .. 2.3

RLRC takes the first generation from the plain LED model and uses the ground truth as the expected output. It applies PPO to optimize a reward based on the difference between a generated summary's readability and a desired readability level.
