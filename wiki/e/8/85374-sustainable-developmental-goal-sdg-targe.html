Abstract written by a model

An SDG target is a focused, actionable subgoal within a Sustainable Development Goal. It matters as the unit used to identify environmental-assessment passages relevant to a target. It is treated as a question: first serving as an input query to retrieve evidence, then as candidate items for a passage, which are augmented and processed so an LLM can generate the correct target identifiers.

Abstract

A Sustainable Developmental Goal (SDG) target is the target that the methods seek to identify as being addressed in a textual passage of an environmental assessment report.

1

SDG targets are focused, actionable subgoals within a given Sustainable Development Goal. Identifying textual passages that are relevant to a target is presented as a fundamental problem in environmental assessment practice.

2

An SDG target is treated as a question in the addressed tasks. After retrieved items are added, an LLM must generate an answer containing the correct SDG-target identifiers among those provided in the prompt.

3 / 3.1 .. 3.3

An SDG target serves as the input query in evidence identification, where relevant passages are retrieved from a collection. In target detection, SDG targets are candidate items retrieved for a passage and then processed through augmentation and generation.
