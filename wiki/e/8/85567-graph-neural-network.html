Abstract written by a model

In “A Survey of Graph Retrieval-Augmented Generation for Customized Large Language Models,” it extracts high-level structural features from a graph database by aggregating neighboring-node information to update node representations. In “GRAG: Graph Retrieval-Augmented Generation,” it encodes graph topological information and graph context through graph tokens, performs message passing with learned relevance scaling, and embeds retrieved context for the LLM. In “GRAG: Graph Retrieval-Augmented Generation,” it encodes topological information, controls message passing with learned node and edge relevance scaling factors, and supplies graph context to an LLM through graph tokens. In “LightRAG: Simple and Fast Retrieval-Augmented Generation,” it generates structure-aware tokens for large language models in the GNNs as Prefix category. In “SimGRAG: Leveraging Similar Subgraphs for Knowledge Graphs Driven Retrieval-Augmented Generation,” it is integrated with large language models to enhance graph-data modeling, and G-Retriever uses it to encode a retrieved knowledge-graph subgraph for prompt tuning.
