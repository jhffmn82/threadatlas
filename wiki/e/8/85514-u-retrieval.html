U-Retrieval

method · 1 work · 14 quoted facts · 5 connections
Also called: U-Retrieval method, U-Retrieval strategy, U-Retrieval technique

Abstract written by a model

U-Retrieval is MedGraphRAG's efficient retrieval technique and method, introduced to replace GraphRAG's summary-based retrieval. It combines Top-down Precise Retrieval and Bottom-up Response Refinement, balancing global context awareness with precise indexing for source retrieval and comprehensive, evidence-based, context-aware medical responses. It summarizes graphs with predefined medical tags and iteratively clusters similar graphs into a multi-layer hierarchy from broad to detailed tags. For a user query, it generates a tag-summary, navigates graph-summary layers top-down by query-tag similarity to select a target Meta-MedGraph, retrieves similar entities and each entity's nearest triple neighbors, then uses a response LLM to refine the initial response while moving back through higher-level summaries. Used with four levels for GPT-4 and five for other models, it raised ablation accuracy on MedQA, PubMedQA, and MedMCQA and contributed to new state-of-the-art results across all three benchmarks.

Abstract

U-Retrieval is a retrieval technique proposed for MedGraphRAG. It combines Top-down Precise Retrieval with Bottom-up Response Refinement to balance global context awareness with precise indexing and to support source information retrieval and comprehensive response generation.

Introduction

U-Retrieval is Medical GraphRAG's efficient retrieval strategy. It summarizes graphs with predefined medical tags, iteratively clusters similar graphs into a hierarchical tag structure, retrieves relevant graphs top-down using query-tag similarity, and refines the initial response bottom-up with higher-level tags.

Experiment / Dataset / RAG data / Repository data / Test Data .. Case Study
