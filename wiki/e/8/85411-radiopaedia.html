Radiopaedia in RadioRAG: Online Retrieval-augmented Generation for Radiology Question Answering

Soroosh Tayebi Arasteh · 2024-07-22

Radiopaedia is an established online radiological source that provides up-to-date radiology articles and information. In RadioRAG, it served as the real-time external source for context-specific data: extracted key phrases were searched, and the five most pertinent articles per keyword were selected. STA and DT reviewed these articles, split them into overlapping 1,000-token chunks, and used them as the retrieval corpus and database for answering questions. It supplied the most relevant sources for GPT-3.5-turbo answers to the first 20 RSNA-RadioQA questions. The study relied exclusively on it, raising source-dependence and repeated-query website-overload concerns; searches took about 30 seconds depending on internet speed and response time.

Narrative, section by section

6 sections; each heading opens the text

Abstract

Radiopaedia served as the real-time online source from which RadioRAG retrieved context-specific information.

1. Introduction

Radiopaedia serves as the up-to-date external information source for RadioRAG. The framework accesses Radiopaedia to gather contextually relevant source data and construct the database used for answering questions.

2. Materials and Methods / 2.1. RSNA Cases .. 2.6. Code and Data Availability

Radiopaedia was searched using the extracted key phrases, with the five most pertinent articles selected for each keyword. The selected articles were reviewed by STA and DT, segmented into chunks of 1,000 tokens with a 200-token overlap, and used as the retrieval corpus.

4. Discussion

Radiopaedia is the established online radiological source used by RadioRAG for retrieval. The study relied exclusively on Radiopaedia, which provided up-to-date information but also created concerns about source dependence and the potential for website overload from repeated queries.

appendix

Radiopaedia provided the most relevant sources listed for the RadioRAG-powered GPT-3.5-turbo answers. The sources covered radiology articles corresponding to the first 20 RSNA-RadioQA questions.

Appendix S4

Searching Radiopaedia using key-phrases took approximately 30 seconds. The time depended on internet speed and Radiopaedia's response time.
