Dataset Generation

process · 1 work · 4 quoted facts · 1 connection
Also called: data generation, dataset, synthetic data generation

Abstract written by a model

Dataset Generation is a synthetic data generation process for evaluation that uses GPT-3.5-Turbo and Giskard-style generators to create varied policy and legal questions from text chunks, then deduplicates them and has human experts review inaccuracies or incompleteness.

Dataset Generation is in one work on this site, HyPA-RAG: A Hybrid Parameter Adaptive Retrieval-Augmented Generation System for AI Legal and Policy Applications. This is the abstract a model wrote of it from that work.
