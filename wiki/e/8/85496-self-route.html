SELF-ROUTE in Retrieval Augmented Generation or Long-Context LLMs?

Zhuowan Li · 2024-11-12/2024-11-16

SELF-ROUTE is a simple method that combines retrieval-augmented generation (RAG) with long-context processing. It uses model self-reflection to first determine whether a query can be answered from retrieved chunks. In its first, RAG-and-Route step, it accepts the RAG prediction for answerable queries; when a query is deemed unanswerable, it sends the full context to long-context prediction in the second step. This routing substantially reduces computation and token use while keeping performance comparable to long-context language models: for Gemini-1.5-Pro it uses 38.6% of LC tokens. It outperforms RAG by over 5% across all three models, though performance, routing behavior, and the optimal retrieval value k vary by model, dataset, task characteristics, and requirements.

SELF-ROUTE first asks the model to determine whether a query is answerable from retrieved chunks and accepts the RAG answer when it is, otherwise sending the query to LC with the full context.
