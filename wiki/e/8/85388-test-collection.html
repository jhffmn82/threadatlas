test collection in SDG target detection in environmental reports using Retrieval-augmented Generation with LLMs

A test collection developed for SDG Evidence Identification and SDG Target Detection in this study, with related resources publicly available in a repository. It provides manual binary relevance judgments: 30 targets with six passages each for evidence identification, and 10 retrieved targets for each of 50 EIA excerpts for target detection.

The test collections contain manual binary relevance judgments. The evidence identification collection covers 30 targets with six passages per target, while the target detection collection covers 10 retrieved targets for each of 50 EIA excerpts.
