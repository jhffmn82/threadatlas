Abstract written by a model

Hybrid Parameter Adaptive RAG is a retrieval-augmented generation system and RAG implementation that integrates vector-based text chunks with a knowledge graph of entities and relationships. It combines sparse and dense retrieval, then dynamically adapts k, query rewrites, knowledge graph depth, and keyword limits, processing selected chunks and triplets in an LLM context window. Its three-class configuration achieves 0.8465 Faithfulness and 0.7918 thresholded Correctness.

Hybrid Parameter-Adaptive RAG in HyPA-RAG: A Hybrid Parameter Adaptive Retrieval-Augmented Generation System for AI Legal and Policy Applications

Rishi Kalra, Zekun Wu, Ayesha Gulley, Airlie Hilliard, Xin Guan, Adriano Koshiyama, Philip Treleaven · 2024-11-16 · the work’s page · read it where Hybrid Parameter-Adaptive RAG first appears

Abstract written by a model

Hybrid Parameter-Adaptive RAG is a system for AI legal and policy applications, tailored to mitigate common RAG failure points. It begins from Parameter-Adaptive RAG and adds a knowledge graph representing NYC Local Law 144, its primary corpus, to address missing content, incomplete answers, and failures to extract correct answers from retrieved contexts. A domain-specific query complexity classifier adaptively selects parameters, while hybrid search combines dense, sparse, and knowledge graph retrieval to improve retrieval accuracy and response fidelity. An end-to-end evaluation framework uses specific question types and metrics for robust testing. In testing on LL144, the system enhances correctness, faithfulness, and contextual precision; its 2-class configuration reaches a correctness score of 0.7770, modestly improving on fixed k = 7.
