unanswerable set classification in RE-RAG: Improving Open-Domain QA Performance and Interpretability with Relevance Estimator in Retrieval-Augmented Generation

Kiseung Kim and Jay-Yoon Lee · 2024

Unanswerable set classification detects retrieved top-25 context sets with no gold answer by treating irrelevant sets as unanswerable. A relevance estimator uses a dev-set F1-selected threshold and outperforms FiD-KD and MonoT5 in F1 on NQ and TQA through a better precision-recall balance. Classifying low-confidence sets this way substantially improves unanswerable-set performance while causing only minor loss on answerable sets; FiD-KD is less effective under this trade-off.

Narrative, section by section

3 sections; each heading opens the text

opening

Unanswerable classification is enabled when the retrieved context set is irrelevant. The text states that this can preserve most accuracy for the answerable set while minimizing negative effects.

3.4 / 4 / 4.1 .. 4.2

Unanswerable set classification identifies top-25 context sets that contain no gold answer. The relevance estimator has higher F1 than FiD-KD and MonoT5 on both NQ and TQA because it provides a better balance between precision and recall, although FiD-KD achieves higher recall.

5 / 5.1 .. 5.3

Classifying low-confidence context sets as unanswerable causes only minor answerable-set accuracy loss for the relevance estimator while substantially improving performance on unanswerable sets. The corresponding strategy is less effective with FiD-KD because preserving answerable-set accuracy reduces its unanswerability-classification ability.
