confidence

Abstract written by a model

Confidence indicates whether retrieved contexts are useful for answering a question. It is measured by a relevance estimator and guides decoding strategies: use retrieved context when appropriate, classify the query as unanswerable when confidence is low, or selectively rely on an LLM’s parametric knowledge.

Abstract

Confidence indicates whether a given context is useful for answering a question. The proposed decoding strategies use this confidence to decide whether a question is unanswerable from the retrieved contexts or whether to rely on an LLM’s parametric knowledge.

opening

Context confidence is measured by the relevance estimator to indicate whether a retrieved context set is useful for answering. It can guide the choice between using the retrieved context, classifying the query as unanswerable, and relying on parametric knowledge.

7

The RE module measures confidence in contexts. Decoding strategies use this confidence information to answer “unanswerable” or selectively use parametric knowledge when a low-confidence context set is retrieved.
