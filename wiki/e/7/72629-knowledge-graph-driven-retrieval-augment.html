knowledge graph-driven retrieval-augmented generation in SimGRAG: Leveraging Similar Subgraphs for Knowledge Graphs Driven Retrieval-Augmented Generation

Yuzheng Cai, Zhenyue Guo, Yiwen Pei, Wanrui Bian, Weiguo Zheng · 2025

Knowledge graph-driven retrieval-augmented generation is a task that integrates large language models with knowledge graphs as external knowledge sources to generate grounded answers to user queries. It retrieves evidence, such as relevant triples, entities, relations, paths, or connected subgraphs, from existing or manually constructed knowledge graphs and provides this evidence to a large language model for answer generation. It supports applications including knowledge graph question answering and fact verification. Prior approaches vary in how they retrieve and encode graph information, with limitations for complex structures noted for some methods. The paper investigates this task and proposes SimGRAG to improve alignment between query texts and knowledge graph structures, reporting consistent improvements over existing approaches.

Narrative, section by section

5 sections; each heading opens the text

Abstract

KG-driven RAG is the task studied in the paper. SimGRAG is proposed for this task and is reported to outperform state-of-the-art KG-driven RAG methods in question answering and fact verification.

Introduction

Retrieval-Augmented Generation integrates large language models with external knowledge sources to produce grounded outputs. The unit focuses on knowledge-graph-driven Retrieval-Augmented Generation, in which retrieved subgraphs are provided to a large language model for answer generation.

Related Work

Knowledge graph-driven retrieval-augmented generation uses existing manually constructed knowledge graphs for retrieval in the Retrieval-Augmented Generation pipeline. KAPING retrieves triples relevant to the query, KG-GPT segments the query and presents candidate relations to a large language model, KELP encodes knowledge graph paths but struggles with structures more complex than 2-hop paths, and G-Retriever retrieves entities and relations before constructing and encoding a connected subgraph.

Preliminaries

Knowledge Graph Driven Retrieval-Augmented Generation generates an answer to a user query by leveraging large language models and retrieved evidence from a knowledge graph. It encompasses applications including Knowledge Graph Question Answering and Fact Verification.

Conclusion

The paper investigates KG-driven RAG and proposes SimGRAG to improve the alignment between query texts and knowledge graph structures. SimGRAG is reported to consistently outperform existing KG-driven RAG approaches in extensive experiments.
