cold-start problem

topic · 1 work · 3 quoted facts · 1 connection
Also called: Cold-start Problem, cold-start issue

Abstract written by a model

Cold-start problem affects EMG-RAG when GPT-4-generated training questions differ from real user questions. It is addressed through online learning, continuously fine-tuning with recorded questions and manually written answers; online A/B testing showed improved user experience.
