Abstract written by a model

In "Retrieval augmented text-to-SQL generation for epidemiological question answering using electronic health records," BGE-LARGE-EN-V1.5 is a Hugging Face-hosted embedding model fine-tuned to compute similarity for retrieval augmentation of large language models. In "Question Decomposition for Retrieval-Augmented Generation," bge-large-en-v1.5 is a 1024-dimensional passage embedding model used to embed and index passage chunks for exact maximum inner product retrieval. In "VisDoM: Multi-Document QA with Visually Rich Elements Using Multimodal Retrieval-Augmented Generation," BGE-1.5 is evaluated as a dense text retrieval baseline.
