decoding strategies in RE-RAG: Improving Open-Domain QA Performance and Interpretability with Relevance Estimator in Retrieval-Augmented Generation

Kiseung Kim and Jay-Yoon Lee · 2024

The decoding strategies use confidence measured by a relevance estimator to judge whether retrieved context is useful for a query. When the context set is irrelevant or low-confidence, they can first classify the question as unanswerable and tell the user, or instead selectively rely on the language model’s parametric knowledge rather than unrelated contexts. Thus, answering proceeds from relevance-confidence assessment to either an unanswerable response or parametric-knowledge use.

Narrative, section by section

3 sections; each heading opens the text

Abstract

The proposed decoding strategies use confidence from the relevance estimator (RE). They can choose to tell the user that a question is unanswerable given the retrieved contexts or to rely on an LLM’s parametric knowledge instead of unrelated contexts.

opening

A decoding strategy can use the confidence of the context set measured by the relevance estimator. It may classify an irrelevant context set as unanswerable or selectively leverage the language model’s parametric knowledge for a low-confidence set.

7

The authors explore decoding strategies that use confidence information from the RE module to answer “unanswerable” or selectively use parametric knowledge when a low-confidence context set is retrieved.
