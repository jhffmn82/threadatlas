two-stage evidence retrieval in Evidence-Driven Retrieval Augmented Response Generation for Online Misinformation

Zhenrui Yue, Huimin Zeng, Yimeng Lu, Lanyu Shang, Yang Zhang, and Dong Wang · 2024

RARG evidence collection is a two-stage retrieval pipeline over more than 1M academic articles. It first performs a coarse BM25 search, then uses a fine-tuned dense retriever to rerank retrieved documents, improving relevance estimation, computational efficiency, and retrieval performance when annotated data is limited.

Narrative, section by section

2 sections; each heading opens the text

Introduction

RARG evidence collection uses a two-stage retrieval pipeline over a collection of more than 1M academic articles. The pipeline first performs a coarse search and then reranks retrieved documents to improve relevance estimation.

Methodology / Preliminary .. Response Generation

It performs coarse-to-fine ranking by first using BM25 and then using a fine-tuned dense retriever. The pipeline is designed to improve computational efficiency and retrieval performance when annotated data is limited.
