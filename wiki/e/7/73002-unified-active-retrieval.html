Unified Active Retrieval

framework · 1 work · 36 quoted facts · 11 connections
Also called: UAR, UAR (our work), UAR based, UAR framework, UAR’s, Unified Active Retrieval (UAR)

Abstract written by a model

Unified Active Retrieval (UAR) is a unified, plug-and-play active retrieval framework for Retrieval-Augmented Generation that decides whether retrieval is needed for diverse user instructions. It addresses two challenges in active retrieval by turning four orthogonal retrieval-timing criteria into classification tasks: user intent, knowledge awareness, time awareness, and self awareness. For each criterion or scenario, UAR trains a lightweight binary classifier, described as a single-layer MLP or value head, on the last-layer hidden states of a fixed LLM. The LLM remains frozen and its parameters are not changed. The classifiers determine whether to retrieve; when retrieval is activated, retrieved information is appended to the original instruction, while unnecessary retrieval is avoided. Its central result is multifaceted, comprehensive retrieval-timing judgment with negligible or minimal extra inference cost and no loss of model capabilities. UAR reports the highest overall active retrieval accuracy on the Active Retrieval Benchmark for 7B and 13B models, downstream overall scores of 50.49 and 53.26 respectively, and better results than existing work, including FLARE across all AR-Bench scenarios. Its criterion accuracies are 91.88 for intent-aware, 90.38 for knowledge-aware, 86.69 for time-aware, and 72.32 for self-aware retrieval. However, UAR has lower accuracy than the corresponding single classifiers in all evaluated scenarios, with self awareness a bottleneck. Across downstream tasks, UAR avoids much unnecessary retrieval on DROP and GSM8K, retrieves almost perfectly for time-sensitive TAQA questions, and selectively retrieves for TriviaQA and WebQuestions. It outperforms always-retrieval and never-retrieval on WebQuestions; on TriviaQA, it performs best with fewer reference documents, can match always-retrieval with more documents, and requires fewer retrieval calls.

Abstract

Unified Active Retrieval contains four orthogonal criteria cast as plug-and-play classification tasks. It provides multifaceted retrieval timing judgements with negligible extra inference cost and significantly outperforms existing work on retrieval timing judgement and downstream task performance.

Introduction

Unified Active Retrieval (UAR) is a framework for deciding whether to retrieve for diverse user instructions. It uses lightweight binary classifiers over the last-layer hidden states of a fixed LLM, supports four retrieval criteria, avoids changing the LLM's parameters, and is reported to outperform existing methods on retrieval-timing accuracy and downstream tasks.

3 .. 3.3

Unified Active Retrieval is a plug-and-play framework that trains lightweight classifiers while keeping the large language model’s parameters fixed. It determines whether retrieval is needed across different scenarios and appends retrieved information to the original instruction when retrieval is activated.

4 / 4.1 .. 4.7

UAR achieves the highest overall active retrieval accuracy on the Active Retrieval Benchmark for both 7B and 13B models, with strong performance across all four scenarios. It also achieves the best overall downstream performance, avoiding most unnecessary retrieval on DROP and GSM8K, invoking retrieval almost universally for TAQA, and selectively retrieving for TriviaQA and WebQuestions.

5 / 5.1 .. 5.3

UAR has lower accuracy than the corresponding single classifiers in all evaluated scenarios, with the self-aware classifier acting as a performance bottleneck. On WebQuestions, UAR outperforms both always-retrieval and never-retrieval, while on TriviaQA it performs best with fewer reference documents and approaches always-retrieval performance as the document number increases.

6

UAR is a unified active retrieval framework for retrieval-augmented generation. It incorporates four orthogonal criteria into plug-and-play classification tasks, enabling comprehensive retrieval timing judgments with minimal inference cost and no loss of model capabilities. Experiments show that it significantly outperforms existing methods on AR-Bench and downstream tasks.
