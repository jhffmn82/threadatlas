Also called: MDP for Selecting Memories on EMGs, MDPs

Abstract written by a model

MDP is a memory selection model for graph traversal, using reinforcement learning to optimize relevant memories: states compare question, graph, relation, and memory similarities; actions include-and-continue or stop searches.

MDP is in one work on this site, Crafting Personalized Agents through Retrieval-Augmented Generation on Editable Memory Graphs. This is the abstract a model wrote of it from that work.

The MDP models graph traversal for selecting memories relevant to a question. Its states use similarities among question entities, graph entities, relations, questions, and memories; its actions either include and continue from a memory or stop the current search.
