Scout Bot

object · 1 work · 13 quoted facts · 1 connection
Also called: Scout, Scout bot

Abstract written by a model

Scout Bot is a production enterprise chatbot and bot for answering questions about financial earnings from public sources, including EDGAR databases for SEC filings. It manages about 4,000 multimodal documents, text, tables, PDFs, and HTML, and uses an open source vector database, LangChain, Ragas, selectable LLM models, and a custom web UI. For complex questions, it added an agent mechanism for query decomposition and orchestration. A fine-tuning experiment with e5-large embeddings showed no significant improvement.

Scout Bot is in one work on this site, FACTS About Building Retrieval Augmented Generation-based Chatbots. This is the abstract a model wrote of it from that work.
