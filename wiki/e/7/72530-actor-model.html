Abstract written by a model

Actor model begins initialized from the supervised fine-tuned reference model, then PPO trains it to improve estimated reward; it generates evidence-based responses for inference.

actor model is in one work on this site, Evidence-Driven Retrieval Augmented Response Generation for Online Misinformation. This is the abstract a model wrote of it from that work.

opening

The actor model is the active generation model trained with PPO to improve response quality according to the estimated reward. It is initialized with the supervised fine-tuned reference model's weights and is used for inference after reinforcement learning.
