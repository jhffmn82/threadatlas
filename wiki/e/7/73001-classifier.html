classifier in Unified Active Retrieval for Retrieval Augmented Generation

Qinyuan Cheng · 2024

A lightweight classifier, implemented as a fully connected single-layer MLP with two outputs, is trained for each active retrieval criterion. It takes the last input-token hidden state to make a two-class prediction. Used as a value head, it is efficient but performs slightly below whole-large-language-model fine-tuning for self-aware classification.

3 .. 3.3

A classifier is trained for each active retrieval criterion using the model’s hidden states. Each classifier is a single-layer MLP that takes the last input-token hidden state and produces a two-class output.

5 / 5.1 .. 5.3

The value head is used as a lightweight classifier. It performs slightly below whole-large-language-model fine-tuning for self-aware classification but preserves the efficiency of the framework.

Limitations

The classifier is based on a single-layer MLP network.
