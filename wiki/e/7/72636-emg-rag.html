EMG-RAG in Crafting Personalized Agents through Retrieval-Augmented Generation on Editable Memory Graphs

Zheng Wang, Zhongyang Li, Zeren Jiang, Dandan Tu, Wei Shi · 2024

EMG-RAG is a solution and RAG method for personalized agents that combines Retrieval-Augmented Generation with an Editable Memory Graph (EMG) and is optimized with Reinforcement Learning. It addresses data collection, editability, and selectability challenges. EMG-RAG first constructs and edits personalized memory graphs, using EMG to capture complex relationships between memories. It then selects essential and activated memories, retrieves relevant memories, and uses them for large language model generation. Training uses warm-start and policy gradient; its implementation uses Python 3.7, Faiss for index construction, TransE for entity and relation embeddings, and CPT-Text for question and memory embeddings. It supports question answering, autofill forms, reminders, travel-related user services, and continuous edits. Evaluations report performance approximately 10% above the best existing approach and outperform M-RAG; for GPT-4 question answering, it achieves 88.06 ROUGE-L and 75.99 BLEU.

Abstract

EMG-RAG combines Retrieval-Augmented Generation with an Editable Memory Graph to support personalized agents. It is optimized using Reinforcement Learning and improves performance by approximately 10% over the best existing approach in experiments on a real-world dataset.

EMG-RAG is proposed as a solution for the data collection, editability, and selectability challenges of personalized agents. It combines an Editable Memory Graph with retrieval-augmented generation and reinforcement learning for adaptive memory selection.

EMG-RAG is evaluated across question answering, autofill forms, user services, and continuous edits. It outperforms the reported baselines, including M-RAG, and benefits from capturing relationships between memories, selecting essential memories, activated nodes, and policy-gradient training.
