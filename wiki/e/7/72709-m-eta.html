M-ETA

topic · 1 work · 4 quoted facts · 3 connections
Also called: M-ETAs, Manual Entity Translation Accuracy

Abstract written by a model

M-ETA, or Manual Entity Translation Accuracy, is an entity-level translation accuracy metric. It checks whether automatic target text contains one or more manually curated valid names for each entity, measuring translation of challenging entity names. In the evaluation, NLLB-200 and GPT-4 reach 17.9% and 25.3% baseline averages, while KG-MTNLLB reaches 41.1%. It is useful for evaluating KG-MT but is not comprehensive for overall system comparison.

M-ETA is in one work on this site, Towards Cross-Cultural Machine Translation with Retrieval-Augmented Generation from Multilingual Knowledge Graphs. This is the abstract a model wrote of it from that work.

4 .. 4.3

M-ETA, or Manual Entity Translation Accuracy, measures translation quality at the entity level. It checks whether an automatic translation contains one or more manually curated valid names for each entity in the target language.

5

M-ETA measures performance on the translation of challenging entity names in this evaluation. NLLB-200 and GPT-4 obtain the strongest baseline averages at 17.9% and 25.3%, respectively, while KG-MTNLLB reaches 41.1%.

Limitations

M-ETA is a simple metric that measures translation quality at the entity level. It is useful for evaluating KG-MT but cannot alone compare the overall performance of different systems.
