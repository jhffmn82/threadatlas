3 .. 3.3

Explicit knowledge integration appends a special [KG] token and mappings from source-language entity names to target-language entity names to the source text. The Machine Translation model then uses these explicitly provided translations when generating the target text.

6

Explicit knowledge integration incorporates retrieved knowledge directly and is described as more straightforward. However, it increases the source-text length, which is undesirable because many Transformer-based attention mechanisms are quadratic with respect to input length.
