Abstract written by a model

RARG evidence-based response generation is a component that produces responses to misinformation using collected scientific evidence. It takes an input claim and retrieved evidence documents, included in the prompt, and uses fgen to generate counter-responses. The generation model is first trained end-to-end on MisinfoCorrect, then tuned with reinforcement learning from human feedback toward human preferences. Its reward considers evidence use and response quality through refutation, factuality, politeness, claim relevance, and evidence relevance. It is evaluated cross-domain on Constraint and ANTiVax.

Introduction

RARG evidence-based response generation uses collected evidence to produce responses to misinformation. Its language models are aligned through reinforcement learning from human feedback, with a reward design intended to maximize evidence use while maintaining response quality.

Methodology / Preliminary .. Response Generation

It uses the input claim and retrieved evidence as model input and generates a response. The generation model is first trained end-to-end and then tuned toward human-preferred responses.

Experiments / Experiment Design .. Response Generation Results

The response generation component uses retrieved documents as part of the input prompt to generate counter-responses. It is evaluated for refutation, factuality, politeness, and relevance to the input claim and evidence.
