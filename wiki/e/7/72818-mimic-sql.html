Abstract written by a model

MIMIC-SQL is a dataset based on MIMIC-III comprising 10,000 template-generated patient-specific and patient-count questions using logical and basic mathematical operations. It uses direct string matching for concept retrieval, does not adhere to OMOP-CDM, and has limited query diversity affecting text-to-SQL generalizability testing.
