Editable Memory Graph

Also called: EMG, EMG structure
  • In Crafting Personalized Agents through Retrieval-Augmented Generation on Editable Memory Graphs: Editable Memory Graph is a three-layer data structure and multilayered structure for managing users’ personal memories, with the user as the root node. Its Memory Type Layer and Memory Subclass Layer form a tree organized by business scopes, and its memory graph is entity-based, capturing complex relationships among memories. It supports insertion, deletion, replacement, and dynamic user edits, as well as efficient retrieval and selection of essential memories within relevant partitions. Combined with Retrieval-Augmented Generation and a frozen large language model in EMG-RAG, it addresses data collection, editability, and selectability; removing activated nodes reduces question-answering performance.

Editable Memory Graph in Crafting Personalized Agents through Retrieval-Augmented Generation on Editable Memory Graphs

Zheng Wang, Zhongyang Li, Zeren Jiang, Dandan Tu, Wei Shi · 2024

Editable Memory Graph is a three-layer data structure and multilayered structure for managing users’ personal memories, with the user as the root node. Its Memory Type Layer and Memory Subclass Layer form a tree organized by business scopes, and its memory graph is entity-based, capturing complex relationships among memories. It supports insertion, deletion, replacement, and dynamic user edits, as well as efficient retrieval and selection of essential memories within relevant partitions. Combined with Retrieval-Augmented Generation and a frozen large language model in EMG-RAG, it addresses data collection, editability, and selectability; removing activated nodes reduces question-answering performance.

The Editable Memory Graph is combined with Retrieval-Augmented Generation in EMG-RAG. This combination is optimized to address data collection, editability, and selectability.

The Editable Memory Graph is a three-layer data structure for managing personal memories. Its first two layers form a tree organized by business scopes, while its third layer is a user memory graph that captures relationships among memories and supports efficient editing and retrieval within relevant partitions.
