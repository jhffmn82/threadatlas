Abstract written by a model

Low-confidence context sets, identified by relevance-estimator confidence, drive classification strategy: small language models may answer unanswerably, while large models may switch to parametric knowledge; the RE module supplies relevance and confidence for decoding decisions.

A low-confidence context set can trigger either an unanswerable response in a small language model or a switch to parametric knowledge in a large language model. These sets are identified using the confidence score derived from the relevance estimator.

7

The RE module measures the relative relevance and confidence of contexts. Decoding strategies can use this confidence information when a low-confidence context set is retrieved.
