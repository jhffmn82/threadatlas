NVBot platform

platform · 1 work · 18 quoted facts · 8 connections
Also called: NVBot, flexible generative-AI based Chatbot platform, in-house built generative-AI chatbot platform

Abstract written by a model

NVBot is NVIDIA's in-house generative-AI chatbot platform, on which three bots are built. It is modular and pluggable, allowing developers to choose large language models, vector databases, embedding models, agents, and RAG evaluation frameworks for each use case. It supplies shared security, guardrails, authentication, authorization, user-experience, and monitoring components, supports citizen development, and enables multiple enterprise chatbots to coexist and be orchestrated.

NVBot platform is in one work on this site, FACTS About Building Retrieval Augmented Generation-based Chatbots. This is the abstract a model wrote of it from that work.

CASE STUDY

The NVBot platform is NVIDIA's in-house generative-AI chatbot platform on which all three bots are built.

BUILDING FLEXIBLE ARCHITECTURES FOR

NVBot is a modular platform with a pluggable architecture that lets developers choose LLMs, vector databases, embedding models, agents, and RAG evaluation frameworks for specific use cases. It provides shared capabilities for security, guardrails, authentication, authorization, user experience, monitoring, and other common features, while supporting citizen development and the orchestration of multiple chatbots.

RELATED WORK

Our work presents a reference architecture for a flexible generative-AI based Chatbot platform.
