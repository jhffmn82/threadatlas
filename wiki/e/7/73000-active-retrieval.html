Active Retrieval in Unified Active Retrieval for Retrieval Augmented Generation

Active Retrieval is the determination of whether and when external information should be retrieved for a particular instruction in RAG, rather than retrieving for every instruction or never using retrieval augmentation. It is crucial to RAG because selective retrieval can preserve model versatility, reduce retrievals, and avoid interference from low-quality results. Earlier methods use knowledge-aware criteria based on factual relevance or self-aware criteria based on LLM self-awareness, but they commonly rely on one criterion, specialized procedures, and a single scenario, increasing latency and failing in complex real-world situations. UAR broadens the decision to multiple criteria: user intent, factual knowledge requirements, time sensitivity, and internal knowledge. Its results and evaluation across scenarios support multifaceted decisions and improved retrieval-timing judgments.

6 sections; each heading opens the text

Abstract

Active Retrieval concerns determining whether retrieval should be used for an instruction. Existing methods often rely on a single criterion and use specialized procedures, which can complicate RAG systems and increase response latency.

Introduction

Active retrieval concerns determining the correct timing for retrieval instead of applying retrieval to every instruction. Earlier approaches generally use either knowledge-aware or self-aware criteria, whereas UAR expands this decision to include user intent, factual knowledge requirements, time sensitivity, and the model's internal knowledge.

2 / 2.1 .. 2.3

Active retrieval retrieves information selectively rather than for every instruction. It can preserve model versatility, reduce the number of retrievals, and prevent interference from low-quality retrieval results, although current methods mostly consider a single scenario and struggle with complex real-world situations.

3 .. 3.3

Active retrieval determines whether external information should be retrieved for a particular instruction. In UAR, it is used selectively to improve effectiveness while avoiding unnecessary retrieval.

4 / 4.1 .. 4.7

Active retrieval methods determine when external retrieval is needed rather than always using or never using retrieval augmentation. The results show that methods relying on a single criterion struggle across different retrieval scenarios, supporting multifaceted decision-making.

6

Active retrieval methods are evaluated for retrieval timing accuracy across different scenarios. UAR is presented as a framework that improves active retrieval judgments.
