Abstract written by a model

Retrieval memory is selected or retrieved text supplied as additional generator input for subsequent rounds. Used in translation, summarization, and dialogue baselines, it resembles model output more than training data during inference; self-memory generally outperforms it and has greater reference similarity in translation analysis.
