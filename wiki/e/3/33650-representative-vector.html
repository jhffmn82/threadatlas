Representative Vector

method · 1 work · 5 quoted facts · 2 connections

Abstract written by a model

Representative Vector selects chunks that fit within T, clusters chunks in high-dimension vector space using k-means, and extracts the chunk nearest each centroid. It stores closest indices and the resulting representative Document list, yielding one representative chunk from each cluster within a maximum affordable token limit.

Representative Vector is in one work on this site, Retrieval Augmented Generation and Representative Vector Summarization for Large Unstructured Textual Data in Medical Education. This is the abstract a model wrote of it from that work.
