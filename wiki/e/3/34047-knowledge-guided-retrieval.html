Knowledge-Guided Retrieval

process · 1 work · 8 quoted facts · 2 connections
Also called: KGR, knowledge-guided retrieval

Abstract written by a model

Knowledge-Guided Retrieval, a core innovation of KG-RAG, converts student queries into semantic vectors using text-embedding-v2, then traverses a knowledge graph to retrieve directly related content and connected concepts. It extracts expanded, richly interconnected context, provides it with similarity-based context and the query to the Large Language Model, and enhances reasoning-process explainability.

Knowledge-Guided Retrieval is in one work on this site, How to Build an Adaptive AI Tutor for Any Course Using Knowledge Graph-Enhanced Retrieval-Augmented Generation (KG-RAG). This is the abstract a model wrote of it from that work.
