Narrative, section by section

2 sections; each heading opens the text

II. FOUNDATIONS OF KG-RAG

Knowledge-Guided Retrieval traverses a Knowledge Graph in response to a query to extract expanded context. This context is provided to the Large Language Model along with similarity-based context and the query.

III. AI TUTOR DESIGN: THE KG-RAG SOLUTION

Knowledge-guided retrieval converts student queries into semantic vectors using text-embedding-v2 from Alibaba Cloud. It then traverses the knowledge graph to retrieve directly related content and connected concepts for response generation.
