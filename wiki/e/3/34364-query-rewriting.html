  • In GEAR: Graph-enhanced Agent for Retrieval-augmented Generation, query re-writing uses the original query, accumulated gist memory, and previous reasoning output to generate an updated next query for the retriever when another iteration is required.

Query rewrites are an adaptive parameter in Parameter-Adaptive RAG, with their number adjusted to query complexity: 3 for simpler queries, 5 for more complex queries, and 7 for the most complex in the 3-class model. Combined with adaptive top-k selection and reranking, they substantially improve faithfulness and factual consistency, while marginally reducing Answer Relevancy.

RAG System Architecture / Parameter-Adaptive RAG (PA-RAG) .. RAG Results

Parameter-Adaptive RAG dynamically adjusts the number of query rewrites according to query complexity. In the 2-class model, simpler queries use 3 rewrites and more complex queries use 5, while the 3-class model uses 7 rewrites for the most complex queries.

System Ablation Study

Query rewriting, when combined with adaptive top-k selection and reranking, improves Faithfulness but marginally reduces Answer Relevancy compared with varying k alone.

Overall Results and Discussion

Query rewrites are an adaptive parameter evaluated in the ablation study. Their inclusion substantially improves faithfulness compared with the k baseline.
