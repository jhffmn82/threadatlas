Query Classification

module · 1 work · 7 quoted facts · 6 connections
Also called: Query Classification Module, classification module, classifying queries, query classification, query classification method, query classification module
  • In Searching for Best Practices in Retrieval-Augmented Generation: Query Classification is a module in RAG Workflow that determines whether retrieval augmentation is necessary. It classifies 15 task types by information completeness: queries entirely supported by user-given information are sufficient, while insufficient queries may need retrieval. This selective process avoids unnecessary retrieval operations. Its contribution is examined by removing it, and evaluation reports higher average RAG scores, from 0.428 to 0.443, plus lower latency, from 16.41 to 11.58 seconds per query. It is recommended for Best Performance and Balanced Efficiency practices.

Narrative, section by section

4 sections; each heading opens the text

RAG Workflow / Query Classification

Query classification determines whether a query requires retrieval augmentation. It categorizes tasks as “sufficient” when they are entirely based on user-given information and “insufficient” when retrieval may be necessary.

Searching for Best RAG Practices

The impact of removing Query Classification is investigated to assess its contribution.

Comprehensive Evaluation .. Results and Analysis

The query classification module distinguishes queries that require retrieval from those containing complete information. It increased the average overall score from 0.428 to 0.443 and reduced latency from 16.41 to 11.58 seconds per query.

Discussion / Best Practices for Implementing RAG .. Multimodal Extension

The query classification module is recommended in both the Best Performance Practice and the Balanced Efficiency Practice.
