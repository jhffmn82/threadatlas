ARES judge

software · 1 work · 12 quoted facts · 6 connections
Also called: ARES judges, LLM judge, LLM judges, LLM-judge, fine-tuned LLM judge, fine-tuned LLM judges, fine-tuned judges, judge model, judge models, judges, lightweight LM judges

Abstract written by a model

ARES judge is a set of three lightweight, fine-tuned LLM judge models for evaluating individual RAG components: context relevance, answer faithfulness, and answer relevance. Each separate DeBERTa-v3-Large model uses a binary classifier head to classify query–document–answer triples as positive or negative for its metric. The judges are trained with contrastive learning using synthetically generated queries and answers. ARES may use different LLMs for other languages. Its conclusion proposes stronger synthetic datasets, more sophisticated fine-tuned judges, and GPT-4 to replace human labeling.

ARES judge is in one work on this site, ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems. This is the abstract a model wrote of it from that work.

3 sections; each heading opens the text

opening

ARES defines three separate lightweight judge models for classifying context relevance, answer faithfulness, and answer relevance. These judges are fine-tuned using a contrastive learning objective.

ARES .. 3.3

LLM judges are fine-tuned DeBERTa-v3-Large models with binary classifier heads, with a separate judge for each evaluation capability. They classify query–document–answer triples and predict context relevance, answer faithfulness, and answer relevance.

Conclusion

LLM judges are fine-tuned in ARES using synthetically generated queries and answers. The conclusion proposes exploring more robust synthetic datasets and more sophisticated LLMs as fine-tuned judges, as well as using GPT-4 as a replacement for human labeling.
