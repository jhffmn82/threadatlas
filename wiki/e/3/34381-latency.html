Also called: Latency, average latency, average time per step, latency time, response time, response times
  • In "Searching for Best Practices in Retrieval-Augmented Generation," latency is measured in seconds per query, with query classification and removing summarization reducing it in the reported configurations.
  • In "FACTS About Building Retrieval Augmented Generation-based Chatbots," latency is identified as a key trade-off in chatbot deployment, with larger models and longer contexts tending to produce slower response times.
  • In "TableRAG: A Retrieval Augmented Generation Framework for Heterogeneous Document Reasoning," latency is lower for TableRAG than for ReAct in average time per step and total time efficiency, attributed to fewer iterations and efficient symbolic SQL execution.
  • In "Question Decomposition for Retrieval-Augmented Generation," latency increases because the method generates multiple subqueries, reranks multiple candidate passages, and adds separate modules to the standard RAG stack.
