Abstract written by a model

Hybrid is a retrieval method that combines vector search with traditional keyword search, or dense retrieval with sparse retrieval, to enhance retrieval accuracy. It is evaluated among Vector Databases and Retrieval Methods. Hybrid with HyDE achieves the highest scores, including a RAG score of 0.58, while Hybrid using the original embedding or BM25 delivers comparable or notable performance with relatively low latency. For practical use and Balanced Efficiency Practice, Hybrid or Original is recommended when computational efficiency matters. Because retrieval accounts for most processing time, replacing Hybrid with Hybrid with HyDE reduces processing time.

Retrieval Methods

Hybrid search combines lexical-based and vector search, specifically sparse retrieval with dense retrieval. Hybrid Search with HyDE achieves the highest scores, while hybrid search using the original embedding offers notable performance with relatively low latency and is recommended when efficiency is prioritized.

Comprehensive Evaluation .. Results and Analysis

Hybrid combines dense retrieval with BM25 and achieved comparable performance to Hybrid with HyDE at lower latency. The evaluation recommends Hybrid or Original for practical use when computational efficiency is important.
