Selfmem is a memory approach for generation: better memory and generation can reinforce each other. Unlike traditional retrieval, which draws fixed-corpus memory by input similarity and is limited by corpus quality and retrieval space, it creates and selects generated outputs for later memory use.

Narrative, section by section

2 sections; each heading opens the text

Abstract

Better memory typically prompts better generation, while better generation can also prompt better memory. Traditional retrieval selects memory based on similarity to the input, whereas Selfmem creates and selects generated outputs for later use as memory.

Introduction

Memory is typically retrieved from a fixed corpus according to its similarity to the current input. The text states that fixed-corpus memory is constrained by corpus quality and finite retrieval space, limiting memory-augmented generation.
