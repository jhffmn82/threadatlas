BARTScore in RAGAS: Automated Evaluation of Retrieval Augmented Generation

Shahul Es, Jithin James, Luis Espinosa-Anke, Steven Schockaert · 2024

BARTScore is a factuality estimator that gauges faithfulness from token probabilities, estimating the conditional probability of generated text given input. When reference answers are available, it computes precision by generating the answer from the reference and recall by generating the reference from the answer.

2 / Estimating faithfulness using LLMs .. Automated evaluation of text generation systems

BARTScore estimates factuality using the conditional probability of generated text given the input. It can also use reference answers to estimate precision and recall through conditional generation probabilities.
