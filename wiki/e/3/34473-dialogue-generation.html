dialogue generation in Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory

Neural Information Processing Systems (NeurIPS) · 2023-12-23

Dialogue generation is a text generation task used to evaluate Selfmem. It uses a retrieval-augmented generator with optimized memory and is evaluated on DailyDialog using BLEU and Distinct scores. Its memory selector combines BLEU-1 and BLEU-2. Self-memory improves B-1 and B-2 over retrieved memory when optimized for BLEU, while optimizing D-1 and D-2 improves diversity and informativeness, revealing a BLEU–Distinct tradeoff. The shared generator and selector architecture may limit task-specific performance.

Methods / Generation as Memory .. Implementation Details

Dialogue generation is evaluated on DailyDialog. Its memory selector uses a linear combination of BLEU-1 and BLEU-2 as the selection metric, and evaluation includes BLEU and Distinct scores.

Experimental Results / Machine Translation .. Dialogue Generation

In dialogue generation, self-memory improves B-1 and B-2 over retrieved memory when memory is optimized with BLEU. Optimizing with D-1 and D-2 instead improves the system's ability to produce diverse and informative dialogue.

Limitations

The same generator and memory selector architecture is used across all text generation tasks. Task-specific model architectures, training objectives, and generation methods could further improve performance in different text generation scenarios.

dialogue generation in M-RAG: Reinforcing Large Language Model Performance through Retrieval-Augmented Generation with Multiple Partitions

Zheng Wang, Shu Xian Teo, Jieer Ouyang, Yongjun Xu, Wei Shi · 2024

Dialogue generation is a language-generation task evaluated for database partitioning and M-RAG. In experiments on DailyDialog, it uses BLEU and Distinct metrics. M-RAG improves dialogue scores by 12% over the best baseline, while M-RAG(D), optimized with Distinct, produces more diverse dialogue.
