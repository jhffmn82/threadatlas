Abstract written by a model

In ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems, model-based evaluation is presented as an inexpensive strategy for testing generative output quality, beginning with current fixed, hand-written prompts that limit adaptability and guarantee no quality. In SafeRAG: Benchmarking Security in Retrieval-Augmented Generation, model-based evaluation is used by LRII, RECALL, and SafeRAG, combined with rule-based evaluation in some settings, supporting custom safety measures and the generation of attack contexts in MAR.
