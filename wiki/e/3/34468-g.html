Also called: generation model, generator, generator Gξ, retrieval-augmented generation, retrieval-augmented generator, retrieval-augmented translator

Abstract written by a model

Gξ is a retrieval-augmented generator that uses human-written reference as memory, together with a source, to generate a target. It may be implemented through fine-tuning for a small model or few-shot prompting for an LLM, and can use joint- or dual-encoder architectures; when trainable, it is optimized with negative log-likelihood loss. Traditional retrieval favors memory most similar to the input, but fixed-corpus quality limits it. In the reported translation experiments, Gξ’s parameters remain fixed while Selfmem improves performance by supplying better input memory, using model output to train a memory selector and for uplifting.

Gξ is in one work on this site, Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory. This is the abstract a model wrote of it from that work.

Abstract

Retrieval-augmented generation uses human-written reference as memory and has advanced multiple text generation tasks. Its traditional memory retrieval approach selects content with the highest similarity to the input, but this is constrained by the quality of the fixed retrieval corpus.

Introduction

The retrieval-augmented generator creates outputs using retrieved or generated memory. It can be implemented by fine-tuning a small model with labeled data and retrieved memory or by few-shot prompting a fixed black-box LLM with retrieved in-context samples.

Methods / Generation as Memory .. Implementation Details

The retrieval-augmented generator takes a source and retrieved or selected memory as input to generate a target. It can use a joint encoder or dual encoder architecture and is optimized with negative log-likelihood when it is trainable.

Experimental Results / Machine Translation .. Dialogue Generation

Gξ is the generator whose parameters remain fixed in the translation experiments. Selfmem improves its performance by providing better input memory.
