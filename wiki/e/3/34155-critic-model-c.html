critic model C in SELF-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection

Akari Asai, Zeqiu Wu, Yizhong Wang, Avirup Sil, Hannaneh Hajishirzi · 2023-10-17

Critic model C is a large language model initialized from a pre-trained model and partly supervised with GPT-4-prompted examples. Trained to generate reflection tokens, it assesses retrieval need, passage relevance, output support, and response utility. Offline, it inserts these tokens into the corpus to augment generator training data; it is unnecessary at inference.

Narrative, section by section

2 sections; each heading opens the text

INTRODUCTION

The critic model inserts reflection tokens into the original corpus offline. It is partly supervised using examples of inputs, outputs, and reflection tokens collected by prompting GPT-4.

SELF-RAG: LEARNING TO RETRIEVE, GENERATE AND CRITIQUE / 3.1 / PROBLEM FORMALIZATION AND OVERVIEW .. 3.3 / SELF-RAG INFERENCE

Critic model C is trained to predict reflection tokens that assess retrieval need, passage relevance, output support, and response utility. It is used offline to augment the generator training data and is not required at inference time.
