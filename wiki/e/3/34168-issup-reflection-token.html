ISSUP reflection token

object · 1 work · 3 quoted facts · 3 connections
Also called: ISSUP, ISSUP =No support, ISSUP score

Abstract written by a model

ISSUP is a reflection token that assesses whether verification-worthy content in a generated segment is fully, partially, or not supported by a passage. It measures output support; increasing its inference-time weight improves citation precision but lowers MAUVE, while removing it from critique-guided beam search hurts ASQA performance.

ISSUP reflection token is in one work on this site, SELF-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection. This is the abstract a model wrote of it from that work.

The ISSUP reflection token indicates whether the verification-worthy content of a generated segment is fully supported, partially supported, or unsupported by a passage.

RESULTS AND ANALYSIS / 5.1 / MAIN RESULTS .. 5.2 / ANALYSIS

ISSUP measures how well an output is supported by a text passage and can be assigned greater weight during inference. Increasing its weight improves citation precision but lowers MAUVE, while removing ISSUP from critique-guided beam search hurts ASQA performance.
