end-to-end evaluation framework for RAG in RAGAS: Automated Evaluation of Retrieval Augmented Generation

Shahul Es, Jithin James, Luis Espinosa-Anke, Steven Schockaert · 2024

RAGAS is an evaluation process for RAG architectures and a toolkit intended to support it without ground-truth human annotations. It evaluates retrieval quality, faithful use of retrieved passages, and generation quality through faithfulness, answer relevance, and context relevance. The framework is evaluated on the WikiEval Dataset by comparing its metrics with human assessments.

Narrative, section by section

4 sections; each heading opens the text

Abstract

RAG evaluation is challenging because it must consider retrieval quality, the ability of an LLM to use retrieved passages faithfully, and the quality of the generation itself. RAGAS is proposed to enable this evaluation without ground-truth human annotations.

4

The proposed framework is evaluated using the WikiEval Dataset. Its metrics are compared with human assessments of faithfulness, answer relevance, and context relevance.

7

The proposed evaluation framework assesses faithfulness, answer relevance, and context relevance. It is intended to support the development and evaluation of RAG systems without requiring ground truth.

8

The toolkit is aimed at providing this framework.
