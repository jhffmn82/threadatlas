Also called: EXAM metric

Abstract written by a model

EXAM is a metric for evaluating RAG systems. It estimates correctly answered exam questions by a simulated QA reader from generated responses, requiring each query to have several associated sub-questions and thereby imposing a burden not imposed by ARES.

EXAM is in one work on this site, ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems. This is the abstract a model wrote of it from that work.

EXAM evaluates RAG systems by estimating how many exam questions a simulated reader, represented as a QA system, can answer correctly from a generated response. It requires queries with several associated sub-questions, creating a burden that ARES does not impose.
