It frames clinical medicine as knowledge-intensive and argues that clinicians and medical students need efficient retrieval from large knowledgebases. RAG connects large language models to a modifiable non-parametric knowledgebase to address hallucinations and outdated information. In the Python, langchain-based program docGPT, documents are retrieved, including through OCR, split into chunks, embedded, and stored in a FAISS vector database for similarity queries. RVS then uses vector quantization and k-means clustering to select representative chunks, followed by keyword generation and mapping; these materials prompt a large language model, with gpt-3.5-turbo as the default, to produce answers and abstractive summaries. docGPT also visualizes embeddings in two dimensions with t-distributed Stochastic Neighbor Embedding, using clusters and keywords, and can create word clouds and scatter plots. Retrieval Augmented Generation and Representative Vector Summarization for Large Unstructured Textual Data in Medical Ed

S. S. Manathunga and Y. A. Illangasekera discuss the use of large language models and Retrieval Augmented Generation in medical education. The unit explains that Retrieval Augmented Generation connects language models to a modifiable non-parametric knowledgebase, helping address hallucinations and outdated information. It introduces RAG-assisted Representative Vector Summarization, which selects representative text chunks and combines extractive and abstractive methods to summarize large documents. The approach is implemented in the Python program docGPT, which can also generate keyword-based visualizations such as word clouds and scatter plots.

2 / 2.1 .. 2.2.2

This unit describes the workflow implemented in docGPT for retrieving, representing, and summarizing content from unstructured documents. Retrieval extracts text, including through OCR, splits it into chunks, embeds the chunks, and stores them in a FAISS vector database for similarity-based querying. Summarization selects representative chunks using vector quantization with the k-means clustering algorithm, then applies keyword generation and mapping to reduce the content further. The resulting prompt is provided to a large language model, including the default gpt-3.5-turbo model, to generate answers.

3 / 3.1 .. 3.2

The AI for Medicine unit describes how document embeddings are reduced to two dimensions with t-distributed Stochastic Neighbor Embedding and plotted by cluster and keyword to show document content. It explains that mapped summaries support final abstractive summaries and key-point lists. In the Evaluation section, responses from ChatGPT and docGPT were compared for clinical medicine and general pharmacology using reference materials from Kumar and Clark Clinical Medicine and British National Formulary 82. The unit reports that docGPT produced more targeted and accurate retrieval answers, and it compares RVS with retrieve-stuff-summarize methods for summarizing the two ebooks.

RVS is implemented in docGPT, a document intelligence program. docGPT is written in Python using the langchain framework. The source code is available at https://github.com/ssm123ssm/docGPT-pharm.

Clinical medicine is described as a knowledge-intensive domain in which clinicians and medical students need efficient methods to retrieve information from large knowledgebases. The proposed retrieval augmented generation workflow and representative vector summarization for large documents are presented as useful approaches for this need. The workflow was tested on medical reference books and use cases related to medical education. The text states that retrieval augmented generation and representative vector summarization can also be adopted in other domains.
