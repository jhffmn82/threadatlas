Abstract written by a model

JRC-Acquis is an evaluation dataset for neural machine translation containing parallel legislative text from European Union Law. It is used to test retrieval-augmented translation and Selfmem across Spanish-English, English-Spanish, German-English, and English-German directions. Selfmem achieves state-of-the-art results and is further analyzed on En→De for memory components, candidate-pool quality, and token frequency.
