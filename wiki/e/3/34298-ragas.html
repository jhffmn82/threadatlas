RAGAS in ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems

Jon Saad-Falcon · 2024

RAGAS is an open-source automated RAG evaluation framework. It uses a language model, including GPT-3.5 as judge, and a handful of heuristic hand-written prompts to assess retrieved-information relevance, generated-response faithfulness, and accuracy. It is used as a baseline for context relevance, answer relevance, and RAG system ranking, but its prompts offer little adaptability to new settings such as new corpora. Across reported experiments, ARES improves on RAGAS in evaluation precision, accuracy, scoring, and ranking.

opening

RAGAS is identified as an open-source RAG evaluation framework that prompts an LM to assess retrieved-information relevance and generated-response faithfulness and accuracy. ARES is reported to improve on RAGAS in evaluation precision and accuracy.

Related Work

RAGAS evaluates RAG systems using a handful of heuristic, hand-written prompts. These prompts offer little adaptability to new RAG evaluation settings, such as new corpora, and RAGAS substantially underperforms ARES in the reported evaluation.

Results & Analysis / 5.1 .. 5.4

RAGAS is used as a baseline for evaluating context relevance, answer relevance, and RAG system ranking. ARES outperforms it across the reported settings, averaging 0.065 higher Kendall’s tau for context relevance and 0.132 higher for answer relevance in the pseudo-system experiments.

Conclusion

RAGAS is an existing automated evaluation framework that ARES outperforms when scoring and ranking RAG systems.

RAGAS in RAGAS: Automated Evaluation of Retrieval Augmented Generation

Shahul Es, Jithin James, Luis Espinosa-Anke, Steven Schockaert · 2024

RAGAS is a framework for automated, reference-free evaluation of Retrieval Augmented Generation systems, especially when ground-truth human annotations or reference answers are unavailable. It evaluates RAG architectures by estimating correctness through proxies and assessing the usefulness of retrieved passages. Its central quality aspects are faithfulness, answer relevance, and context relevance, covering retrieval, faithful use of retrieved context, and generation quality. It integrates with llama-index and Langchain, supports different large language models when they produce structured JSON output, and offers metrics and datasets through an easy-to-use Python API, including an evaluate function for selected metrics. Its predictions align more closely with human annotators than two baselines and are especially aligned for faithfulness and answer relevance; JSON-formatted outputs make scores more consistent. RAGAS is presented as useful to developers without ground truth, while relying heavily on LLMs. Its concluding concern is careful review of LLM suitability, favoring open models over paid-API products where possible, and encouraging fair systems built on RAGAS.

Narrative, section by section

6 sections; each heading opens the text

Abstract

RAGAS, or Retrieval Augmented Generation Assessment, is introduced as a framework for reference-free evaluation of Retrieval Augmented Generation pipelines. It provides metrics for assessing retrieval, faithful use of retrieved context, and generation quality.

opening

RAGAS is a framework for the automated assessment of retrieval augmented generation systems. It focuses on settings where reference answers may be unavailable and estimates proxies for correctness as well as the usefulness of retrieved passages. RAGAS integrates with llama-index and Langchain so developers can use it within standard RAG workflows.

5 .. 5.1

RAGAS evaluates faithfulness, answer relevance, and context relevance. Its predictions are more closely aligned with human annotators than the two baselines, and its scores are more consistent when outputs are JSON formatted.

6

RAGAS provides access to metrics and datasets through an easy-to-use Python API. It includes an evaluate function for evaluating a dataset with selected metrics.

7

RAGAS is an implementation of faithfulness, answer relevance, and context relevance. It is described as easy to use and able to provide valuable insights to RAG system developers without ground truth, and its predictions on WikiEval closely aligned with human judgments, especially for faithfulness and answer relevance.

opening

RAGAS relies heavily on LLMs to evaluate its different components. It is expected to prioritize careful review of LLM suitability, ideally favoring open models over full-fledged products behind paid APIs, and to encourage fair systems built on top of RAGAS.

Ragas in Ragas: Automated Evaluation of Retrieval Augmented Generation

Shahul Es, Jithin James, Luis Espinosa-Anke, Steven Schockaert · 2025-04-28

Ragas is a framework for reference-free, automated evaluation of retrieval augmented generation systems. It integrates with llama-index and Langchain, enabling evaluation within standard RAG workflows when reference answers or ground truth are unavailable. Its central contribution is metrics that assess retrieval usefulness, faithful use of context, and generation quality through faithfulness, answer relevance, and context relevance. In experiments, its proposed metrics achieved accuracies of 0.95 for faithfulness, 0.78 for answer relevance, and 0.70 for context relevance, with predictions aligning with human judgements. It concludes as an easy-to-use implementation that gives developers valuable insights and supports faster evaluation cycles.
