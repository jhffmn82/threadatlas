memory selector in Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory

Neural Information Processing Systems (NeurIPS) · 2023-12-23

Memory selector is a selector that chooses one model output from a generated candidate pool as memory for the next generation round. It evaluates candidates with a model-free metric—BLEU for translation or ROUGE for summarization—and is trained with Kullback-Leibler divergence to match metric-derived candidate-score distributions.

Introduction

The memory selector chooses one generated output to serve as memory for the subsequent generation round. It is trained using a specific performance metric.

Methods / Generation as Memory .. Implementation Details

The memory selector chooses one candidate from a candidate pool using a model-free metric such as BLEU or ROUGE. It is trained to match a metric-derived distribution with its predicted distribution using KL divergence.
