memory selector

Also called: Sθ, selector

Abstract written by a model

Memory selector is a selector that chooses one model output from a generated candidate pool as memory for the next generation round. It evaluates candidates with a model-free metric, BLEU for translation or ROUGE for summarization, and is trained with Kullback-Leibler divergence to match metric-derived candidate-score distributions.

memory selector is in one work on this site, Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory. This is the abstract a model wrote of it from that work.
