Selfmem in Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory

Neural Information Processing Systems (NeurIPS) · 2023-12-23

Selfmem is a novel, general iterative retrieval-augmented generation framework and a memory optimization method for retrieval-augmented text generation. It has two complementary components: a retrieval-augmented generator and a memory selector. Starting with generated candidates, the generator creates an unbounded memory pool; the selector chooses one output as self-memory for the next round. Selfmem then regenerates candidates, repeatedly improving memory and the candidate pool until validation performance converges, before producing a final hypothesis. It combines primal and dual problems, uplifts a generation model with its own output, and improves Gξ by changing input memory while keeping generator parameters fixed. It supports fine-tuned small models and few-shot LLMs, and is evaluated on neural machine translation, abstractive summarization, and dialogue generation. It improves translation across four JRC-Acquis directions, achieves state-of-the-art results there, reaches ROUGE-1 of 50.3 on XSum and 62.9 on BigPatent, and can optimize memory for BLEU or dialogue diversity. Its self-memory augmentation performs particularly well on long-tail inputs. Selfmem surpasses strong baselines and improves generation quality, but its memory-selection process requires more computational resources.

Abstract

Selfmem is a framework that iteratively uses a retrieval-augmented generator to create an unbounded memory pool and a memory selector to choose one output as memory for the next generation round. It is evaluated on translation, summarization, and dialogue generation under fine-tuned small-model and few-shot LLM settings.

Introduction

Selfmem is a framework that iteratively uses a retrieval-augmented generator to create an unbounded memory pool and a memory selector to choose an output as memory for the next generation round. It combines the primal and dual problems and achieves improvements in machine translation, abstractive text summarization, and dialogue generation.

Methods / Generation as Memory .. Implementation Details

Selfmem combines a retrieval-augmented generator with a memory selector. It iteratively generates candidate pools, selects memory, and regenerates candidates until validation performance converges before producing a final hypothesis.

Experimental Results / Machine Translation .. Dialogue Generation

Selfmem improves translation performance across four JRC-Acquis directions and two trainable architectures while keeping the generator parameters fixed and changing only the input memory. It also improves summarization and dialogue generation, and can optimize memory for either BLEU or dialogue diversity.

Further Analysis

Selfmem improves itself through an iterative process in which better memories improve generation and the resulting higher-quality outputs improve the candidate pool for subsequent selection. Its self-memory augmentation performs particularly well on long-tail inputs.

Conclusion

Selfmem is proposed as a general framework for retrieval-augmented text generation. It combines the primal and dual problems and uplifts a generation model with its own output.

Limitations

Selfmem greatly improves generation quality compared with other retrieval-augmented generation models. However, it requires more computational resources for the memory selection process.
