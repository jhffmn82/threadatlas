ARES in ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems

Jon Saad-Falcon · 2024

ARES is an automated evaluation framework and system for retrieval-augmented generation systems. It evaluates RAG pipelines component by component along three quality dimensions: context relevance, answer faithfulness, and answer relevance. Its central approach is a three-stage process: it takes an in-domain passage set, at least five few-shot in-domain query-and-answer examples, and a human preference validation set of roughly 150 or more annotated datapoints; generates synthetic queries and answers from corpus passages; fine-tunes lightweight judges, using DeBERTa-v3-Large as a pretrained basis; and applies those judges with prediction-powered inference to score and rank RAG systems with confidence intervals. Synthetic data reduces the human annotation needed, while the validation annotations help rectify prediction errors and provide statistical confidence. ARES ranks systems without external APIs and is reported to outperform RAGAS in context and answer relevance accuracy and in ranking across almost all tested settings. It was evaluated across eight knowledge-intensive tasks in KILT, SuperGLUE, and AIS, including real RAG systems and mock systems, and can distinguish hallucinated from faithful answers. It remains effective under several domain shifts, though performance declines for cross-lingual, text-to-code, and extraction-task shifts. Its limitations include reliance on roughly 150–300 human annotations, substantial GPU-based hardware, and evaluation so far only on English datasets. Its code and datasets are publicly available on Github.

ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems

ARES is presented as an Automated Evaluation Framework for Retrieval-Augmented Generation Systems.

Abstract

ARES is an Automated RAG Evaluation System that evaluates retrieval-augmented generation systems on context relevance, answer faithfulness, and answer relevance. It creates synthetic training data, finetunes lightweight LM judges, and uses prediction-powered inference with a small set of human-annotated datapoints to mitigate prediction errors. ARES accurately evaluates systems across eight knowledge-intensive tasks in KILT, SuperGLUE, and AIS and remains effective across domain shifts.

opening

ARES is the Automated RAG Evaluation System, designed to generate tailored LLM judges for each component of a RAG pipeline. It evaluates context relevance, answer faithfulness, and answer relevance, and uses prediction-powered inference to provide scores and statistical confidence intervals.

Related Work

ARES is presented as a method for evaluating RAG systems. It is contrasted with EXAM because it does not require queries with several associated sub-questions, and it is reported to substantially outperform RAGAS in the evaluation.

ARES .. 3.3

ARES uses an in-domain passage set, a human preference validation set of approximately 150 or more annotated datapoints, and at least five few-shot in-domain query-and-answer examples. It generates synthetic data, trains LLM judges, and uses those judges with prediction-powered inference to evaluate and rank RAG systems.

Experiments / 4.1 .. 4.3

ARES uses synthetic queries and answers generated with FLAN-T5 XXL, a DeBERTa-v3-Large fine-tuned judge, and few-shot prompts to rank RAG systems without relying on external APIs. Its effectiveness is tested on mock systems with known performance levels for context relevance and answer relevance, using Kendall's tau and prediction accuracy.

Results & Analysis / 5.1 .. 5.4

ARES ranks RAG systems more accurately than RAGAS and the GPT-3.5 judge across the evaluated KILT and SuperGLUE datasets, with PPI improving its fine-tuned LLM judge. It also scores existing RAG systems effectively, achieves strong AIS results, and generalizes across several KILT and SuperGLUE domain shifts, although its performance declines for cross-lingual, text-to-code, and extraction-task shifts.

Conclusion

ARES is presented as a novel automated evaluation framework for retrieval-augmented generation. It fine-tunes lightweight LLM judges on synthetically generated queries and answers, evaluates RAG system components separately, requires minimal human annotations, and accurately scores and ranks systems across eight datasets, outperforming RAGAS.

Limitations

ARES relies on a small human preference validation set of roughly 150–300 annotations, with more annotations providing benefits. It also requires substantial GPU-based hardware, and its evaluation has so far used only English datasets.
