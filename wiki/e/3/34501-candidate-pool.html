Methods / Generation as Memory .. Implementation Details

The candidate pool consists of outputs generated by the generator in candidate mode. The selector is trained and used to choose memory from this pool.

Further Analysis

Oracle selection experiments show improvements in the candidate pool's oracle, quartile, average, and minimum scores across iterations. This supports the finding that improved memory selection produces a higher-quality candidate pool for the next round.
