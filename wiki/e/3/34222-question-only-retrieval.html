Question-Only Retrieval

topic · 1 work · 3 quoted facts · 1 connection
Also called: QOR, Question-Only Retrieval (QOR), question-only retrieval

Abstract written by a model

Question-Only Retrieval is a realistic MIRAGE evaluation setting for medical question answering, included alongside RAG. It requires retrieval using questions without answer options, aiming to better reflect real-world conditions from the setup through system evaluation.

Question-Only Retrieval is in one work on this site, Benchmarking Retrieval-Augmented Generation for Medicine. This is the abstract a model wrote of it from that work.
