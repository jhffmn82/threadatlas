human preference validation set

object · 1 work · 5 quoted facts · 6 connections
Also called: annotated set, our human preference validation set, small human preference validation set, validation set

Abstract written by a model

The human preference validation set is a dataset of roughly 150–300 annotated datapoints. It includes positive and negative examples for context relevance, answer faithfulness, and answer relevance. ARES uses it to evaluate judge fine-tuning, rank RAG systems with domain-targeted LLM judges, and calibrate prediction-powered inference for confidence intervals. The records emphasize that more datapoints are beneficial.

human preference validation set is in one work on this site, ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems. This is the abstract a model wrote of it from that work.
