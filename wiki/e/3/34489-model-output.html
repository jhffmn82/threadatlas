model output in Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory

Neural Information Processing Systems (NeurIPS) · 2023-12-23

Model output serves as self-memory for improved subsequent and final generation, including retrieval-augmented generation. In Selfmem, output creates unbounded generated memory; a memory selector refines it, then the refined output becomes memory for the next round and is more similar to the reference than retrieval memory.

Narrative, section by section

2 sections; each heading opens the text

Abstract

Self-memory is the model's own output used as memory for improved subsequent generation. Selfmem enables the model to leverage self-memory.

Introduction

Model output is used to create unbounded generated memory in Selfmem. The generator's output is refined by the memory selector and then used as memory in the next round.
