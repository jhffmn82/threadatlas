context relevance in ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems

Jon Saad-Falcon · 2024

Context relevance is a RAG evaluation criterion and capability that measures whether a retrieved passage or information is pertinent to answering a test question. ARES evaluates it with a dedicated judge, using unrelated passages as weak negatives and same-document or BM25-similar passages as strong negatives. Mock datasets provide positive and negative query-passage matches to test system ranking. In reported experiments, it is a primary criterion: ARES outperforms RAGAS and GPT-3.5 in context-relevance ranking accuracy and averages a Kendall’s tau of 0.91 on existing RAG systems. It concludes as a component-level ARES score.

context relevancy in RAGAS: Automated Evaluation of Retrieval Augmented Generation

Shahul Es, Jithin James, Luis Espinosa-Anke, Steven Schockaert · 2024

Context relevance is a quality aspect, dimension, and metric for judging whether retrieved context is sufficiently focused and contains only the information needed to answer a question. It penalises redundant or less relevant material because long, unfocused passages raise costs and can make information, especially in the middle, harder for LLMs to use. It is computed as extracted relevant sentences divided by total context sentences. In the evaluation, it was tested by adding related but less relevant sentences through Wikipedia back-links, or by using ChatGPT where pages lacked back-links. It identifies crucial information, is one of three quality aspects, and is considered the hardest dimension to evaluate, particularly for long contexts.

Context Relevance in RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems

Robert Friel · 2025-01-16

Context Relevance is a retriever quality metric for evaluating documents retrieved by a RAG system with respect to an input query. It measures the fraction of retrieved context that is relevant, identifying document sentences or documents that contain useful, necessary information for answering the question; removing such documents would affect answerability. It is calculated for individual context documents and can be aggregated over all documents in an example. Low Context Relevance indicates retriever inefficiency. Evaluation requires deriving the correct answer and then determining which context supports it, making it generally harder to predict than Utilization. RAGAS evaluates it with an LLM judge, while ARES fine-tunes smaller NLI models. In DelucionQA(40), GPT-4 span-level labels reached F1 0.76 and accuracy 0.78 against human judgements. Across sampled examples, average scores rank simulated RAG systems: binary relevance rankings show high Kendall’s tau, whereas continuous scores may agree less because they reflect retrieved-context length differences.
