Also called: AIS attribution benchmark

Abstract written by a model

AIS is an answer-faithfulness attribution benchmark including Wizards of Wikipedia and CNN/Daily Mail, used to test ARES in real RAG systems, where it nears correct scores with 200 validation annotations.

AIS is in one work on this site, ARES: An Automated Evaluation Framework for Retrieval-Augmented Generation Systems. This is the abstract a model wrote of it from that work.

Results & Analysis / 5.1 .. 5.4

AIS is used to test whether ARES can evaluate answer faithfulness in real RAG systems. On the selected datasets, ARES comes within 2.5 accuracy points of the correct scores while using 200 human preference annotations for validation.
