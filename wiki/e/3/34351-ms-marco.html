Abstract written by a model

In BERGEN: A Benchmarking Library for Retrieval-Augmented Generation, MS MARCO is identified as a human-generated machine reading comprehension dataset. In RAG-HAT: A Hallucination-Aware Tuning Pipeline for LLM in Retrieval-Augmented Generation, Marco is a reading comprehension dataset whose question–document pairs support hallucination-suppression training and whose unused portions provide question-answering samples for a preference dataset. In RAG-Studio: Towards In-Domain Adaptation of Retrieval Augmented Generation Through Self-Alignment, MS MARCO provides source material for four domain-specific datasets, including ten Bing-retrieved passages and a human-generated answer for each question. In Searching for Best Practices in Retrieval-Augmented Generation, the MS MARCO Passage ranking dataset is used for MS MARCO experiments. In RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems, MS Marco is an open-domain question-answering dataset providing ten Bing-retrieved passages per question.

MS Marco in RAGBench: Explainable Benchmark for Retrieval-Augmented Generation Systems

Robert Friel · 2025-01-16 · the work’s page · read it where MS Marco first appears

Abstract written by a model

MS Marco is an open-domain question-answering dataset of general-knowledge web pages and real-world Bing user queries. It provides ten Bing-retrieved passages per question. RAGBench samples its train, validation, and test splits, replaces human answers with LLM-generated responses, and reports a 13% hallucination rate.
