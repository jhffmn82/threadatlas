query augmentation in BlendFilter: Advancing Retrieval-Augmented Large Language Models via Query Generation Blending and Knowledge Filtering

Haoyu Wang · 2024-11

Query augmentation is an input enrichment approach and LLM retrieval-process integration category for complex task inputs. It enriches original queries with information and keywords from internal LLM databases or external sources to facilitate retrieval. It can achieve state-of-the-art performance through collective use of retrieved knowledge during answer generation without training another rewriting model, but single-source augmentation may overlook the original query and limit performance.

Narrative, section by section

2 sections; each heading opens the text

1

Query augmentation enriches an original input with additional information and keywords to facilitate retrieval. It is described as achieving state-of-the-art performance because it processes retrieved knowledge collectively during answer generation and does not require training an additional language model for query rewriting.

2

Query augmentation enriches queries with knowledge from internal LLM databases or external sources. The approach may rely on a single augmentation source and can overlook the original query, limiting overall performance.
