critic module in HYBGRAG: Hybrid Retrieval-Augmented Generation on Textual and Relational Knowledge Bases

Meng-Chieh Lee, Qi Zhu, Costas Mavromatis, Zhen Han, Soji Adeshina, Vassilis N. Ioannidis, Huzefa Rangwala, Christos Faloutsos · 2025

The critic module evaluates retrieved references and the router’s decisions to improve question routing. It contains an LLM validator and an LLM commenter: the validator checks retrieved results, while the commenter provides feedback on incorrect or missing entities and relations. It can identify whether a phrase is a textual aspect rather than a topic entity by comparing ego-graph intersections. Its feedback helps HYBGRAG refine routing and outperform hybrid retrieval alone. Ablation variants alter validators, commenters, and oracles; the full design performs best.

4 sections; each heading opens the text

3 / 3.1 .. 3.3

The critic module addresses Challenge 2 by evaluating retrieved references and helping the router improve its question routing. It is divided into an LLM validator and an LLM commenter.

4 .. 4.1.2

The critic module validates retrieved results and provides feedback about incorrect or missing entities and relations. Its feedback enables HYBGRAG to refine question routing and improves performance over the hybrid retrieval module alone.

opening .. 4.3

The critic module evaluates the router's decisions and provides feedback for refinement. In an example, it recognizes that “optical TALU implementations in electronic circuits” is more likely a textual aspect than a topic entity because its ego-graph does not intersect with the ego-graph for “Netaji Subhash Engineering College.”

B / B.1 .. B.2

The critic module is examined through an ablation study comparing variants with different validators, commentors, and oracles. HYBGRAG performs best when all of its design choices are included.
