  • In Retrieval-Augmented Generation with Estimation of Source Reliability: κ-RRSS, or κ-Reliable and Relevant Source Selection, is an algorithm and source-selection process for Weighted Majority Voting. Given a query, a set of sources with reliability scores, a language model, a retriever, falign as a filtering function, and κ, it selects a small set of reliable, relevant sources. It sorts sources by descending reliability, obtains an answer for each using the language model and retriever, filters the answer with falign, excludes IDK answers, and continues until it has κ non-IDK sources. The resulting set of κ sources is intended to reduce inference overhead while maintaining robust performance. It improves computational efficiency in token consumption, API calls, inference cost, and wall-clock time, and supports scalability as source counts increase. In evaluation using 9 sources on NQ, TQA, and HotpotQA, varying κ produced only marginal accuracy differences; performance was stable from κ = 4 while computational overhead was significantly reduced. κ-RRSS also outperformed κ-RSS in accuracy across tested source counts and was compared with RA-RAG without κ-RRSS.

κ-RRSS in Retrieval-Augmented Generation with Estimation of Source Reliability

Jeongyeon Hwang, Junyoung Park, Hyejin Park, Dongwoo Kim, Sangdon Park, Jungseul Ok · 2025

κ-RRSS, or κ-Reliable and Relevant Source Selection, is an algorithm and source-selection process for Weighted Majority Voting. Given a query, a set of sources with reliability scores, a language model, a retriever, falign as a filtering function, and κ, it selects a small set of reliable, relevant sources. It sorts sources by descending reliability, obtains an answer for each using the language model and retriever, filters the answer with falign, excludes IDK answers, and continues until it has κ non-IDK sources. The resulting set of κ sources is intended to reduce inference overhead while maintaining robust performance. It improves computational efficiency in token consumption, API calls, inference cost, and wall-clock time, and supports scalability as source counts increase. In evaluation using 9 sources on NQ, TQA, and HotpotQA, varying κ produced only marginal accuracy differences; performance was stable from κ = 4 while computational overhead was significantly reduced. κ-RRSS also outperformed κ-RSS in accuracy across tested source counts and was compared with RA-RAG without κ-RRSS.

Introduction

κ-reliable and relevant source selection selects a small number of sources that are both reliable and relevant for Weighted Majority Voting. It is intended to improve robustness while maintaining computational scalability.

Method: RA-RAG .. Iterative reliability estimation

κ-Reliable and Relevant Source Selection iterates through sources in descending order of reliability and selects the first κ sources whose filtered responses are not IDK. It reduces inference overhead while aiming to maintain robust performance.

Experiments / Experimental setups .. Ablation studies and analysis

κ-RRSS selects a small subset of sources using both estimated reliability and query relevance. Performance is stable starting at κ = 4, while the method substantially reduces computational overhead as the number of sources grows.

B

κ-RRSS sorts sources in descending order by reliability score, obtains an answer for each source using the language model and retriever, applies falign, and adds non-IDK answers until κ sources have been selected.

E

κ-RRSS is evaluated with different values of κ using 9 sources on the NQ, TQA, and HotpotQA datasets. The results indicate stable performance from κ = 4 and show that it preserves model performance while significantly reducing computational overhead.
