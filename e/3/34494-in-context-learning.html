In-Context Learning

topic · 6 works · 12 quoted facts · 10 connections
Also called: ICL, demonstrations, in-context demonstrations, in-context examples retrieval framework, in-context learning, in-context learning approach, standard ICL
  • In-context learning is used in “Lift Yourself Up: Retrieval-augmented Text Generation with Self-Memory” through three translation demonstrations per run, with performance improving when more similar examples are selected.
  • In-context learning improves TA-ARE’s adaptive retrieval in “RetrievalQA: Assessing Adaptive Retrieval-Augmented Generation for Short-form Open-Domain Question Answering” through four Yes and No demonstrations.
  • In-context learning is presented in “Unsupervised Information Refinement Training of Large Language Models for Retrieval-Augmented Generation” as a prompting method that uses a few examples before a query.
  • In-context learning is the approach used by RALM in “RE-RAG: Improving Open-Domain QA Performance and Interpretability with Relevance Estimator in Retrieval-Augmented Generation” to provide concatenated context to LLMs.
  • In-Context Learning enhances reasoning in multimodal RAG without retraining in “Ask in Any Modality,” using retrieved content as few-shot examples.
  • In-context learning is described in “A Survey of Graph Retrieval-Augmented Generation for Customized Large Language Models” as an indirect knowledge integration strategy for closed-source LLMs.

In-context learning is an indirect knowledge integration strategy for closed-source LLMs, proceeding by first choosing a prompt format, then optimizing responses using retrieved content and questions.

Narrative, section by section

1 section; each heading opens the text

VI. KNOWLEDGE INTEGRATION .. C. Integration Enhancement Strategies.

In-context learning provides an indirect integration strategy for closed-source large language models that cannot be jointly trained or fine-tuned end to end. It involves choosing a prompt format and optimizing the model's response using retrieved content and questions.
