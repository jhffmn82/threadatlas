Also called: code generation approach kNN-TRANX, kNN-TRANX†, novel code generation approach, our model, our proposed approach, previous kNN generative model, proposed approach, this approach
  • In Syntax-Aware Retrieval Augmented Code Generation: kNN-TRANX is a token-level retrieval augmented code generation method and kNN generative model built on the BertranX seq2tree model. Rather than generating code snippets directly, it generates abstract syntax trees. It is designed to address limitations of neural-retrieval-in-the-loop code generation by building two smaller, separate datastores: a syntactic datastore and a semantic datastore. The separation avoids noise from combining action types; syntax constraints and retrieval filtering guide datastore retrieval. kNN-TRANX has datastore-building and model-inferring components, uses FAISS to accelerate retrieval, and combines kNN probability with neural-network probability through a meta-k network and a confidence network. It uses kNN-box, trains the meta-k and confidence networks with AdamW at learning rate 3e-4, and runs on a single NVIDIA 2080Ti. Evaluation on the public CoNaLa and Django datasets reports effectiveness. On CoNaLa, it achieves 37.29 BLEU, 39.04 CodeBLEU, and 7.4 exact match; on Django, it achieves 83.20 BLEU, 81.66 CodeBLEU, and 82.16 exact match. It outperforms BertranX on reported measures, including on CoNaLa by +3.11 BLEU, +2.95 CodeBLEU, and +1.6 EM, and improves syntax match score. Its model-only configuration with no external data has 32.25 BLEU, 32.08 CodeBLEU, 4.2 EM, and 0.2G extra storage. As datastore knowledge is updated, performance improves. It supports incremental learning and rapid adaptation by switching either datastore without fine-tuning the neural network; 95k external data yields BLEU comparable to training-based BertranX. Additional datastores, however, can increase inference time and storage requirements.

kNN-TRANX in Syntax-Aware Retrieval Augmented Code Generation

Xiangyu Zhang, Yu Zhou, Guang Yang, Taolue Chen · 2023

kNN-TRANX is a token-level retrieval augmented code generation method and kNN generative model built on the BertranX seq2tree model. Rather than generating code snippets directly, it generates abstract syntax trees. It is designed to address limitations of neural-retrieval-in-the-loop code generation by building two smaller, separate datastores: a syntactic datastore and a semantic datastore. The separation avoids noise from combining action types; syntax constraints and retrieval filtering guide datastore retrieval. kNN-TRANX has datastore-building and model-inferring components, uses FAISS to accelerate retrieval, and combines kNN probability with neural-network probability through a meta-k network and a confidence network. It uses kNN-box, trains the meta-k and confidence networks with AdamW at learning rate 3e-4, and runs on a single NVIDIA 2080Ti. Evaluation on the public CoNaLa and Django datasets reports effectiveness. On CoNaLa, it achieves 37.29 BLEU, 39.04 CodeBLEU, and 7.4 exact match; on Django, it achieves 83.20 BLEU, 81.66 CodeBLEU, and 82.16 exact match. It outperforms BertranX on reported measures, including on CoNaLa by +3.11 BLEU, +2.95 CodeBLEU, and +1.6 EM, and improves syntax match score. Its model-only configuration with no external data has 32.25 BLEU, 32.08 CodeBLEU, 4.2 EM, and 0.2G extra storage. As datastore knowledge is updated, performance improves. It supports incremental learning and rapid adaptation by switching either datastore without fine-tuning the neural network; 95k external data yields BLEU comparable to training-based BertranX. Additional datastores, however, can increase inference time and storage requirements.

Syntax-Aware Retrieval Augmented Code Generation / Abstract

It is a token-level retrieval augmented code generation method that searches smaller datastores tailored for code generation. It uses syntax constraints for datastore retrieval, and experiments on two public datasets confirm its effectiveness.

1

The code generation approach kNN-TRANX generates abstract syntax trees instead of code snippets directly. It uses grammar rules, separate datastores, retrieval filtering, and a learnable confidence parameter to combine kNN and neural probabilities, improving results on CoNaLa and Django.

3 / 3.1 .. 3.2

kNN-TRANX consists of datastore building and model inferring components. It uses separate syntactic and semantic datastores, syntax-constrained retrieval, a meta-k network, and a confidence network to combine retrieved and neural predictions.

4 / 4.1 .. 4.3

kNN-TRANX uses BertranX as its base seq2tree model and creates separate syntactic and semantic datastores. It achieves 37.29 BLEU, 39.04 CodeBLEU, and 7.4 exact match on CoNaLa, and 83.20 BLEU, 81.66 CodeBLEU, and 82.16 exact match on Django, outperforming BertranX on all reported measures.

opening

kNN-TRANX outperforms BertranX in the reported CoNaLa and Django results and improves as datastore knowledge is updated. Without additional datastore data, kNN-TRANX† can also outperform BertranX†, while 95k external data yields BLEU comparable to training-based BertranX.

6

kNN-TRANX provides syntactic and semantic datastores for a seq2tree model and outperforms the baselines. It can switch datastores without fine-tuning the neural network and achieves competitive performance through incremental learning. In the canonical incremental adaptation results, updating the datastores with 95k external data reaches 34.04 BLEU and 34.69 CodeBLEU when only semantics is false, and 33.89 BLEU and 34.43 CodeBLEU when only semantics is true.

Limitations

The proposed approach enhances the generalizability of the seq2tree model and enables rapid updates by switching datastores. Incorporating additional datastores can increase inference time and storage requirements.
