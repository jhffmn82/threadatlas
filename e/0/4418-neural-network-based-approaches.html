neural network-based approaches in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

Neural network-based approaches learn code-diff semantics and translate code diffs into commit messages. They include Seq2Seq, structure- and semantics-aware models, pointer-generator networks, and Transformer-based decoders. An encoder-decoder is trained with cross-entropy and AdamW, though end-to-end neural models generally underperform IR-based approaches across four metrics. Performance differs by programming language, while the proposed framework significantly improves four neural network models.

Narrative, section by section

4 sections; each heading opens the text

Related Work

Neural-based approaches learn code-diff semantics and translate code diffs into commit messages. They include Seq2Seq models, models incorporating code structure and semantics, pointer-generator networks for out-of-vocabulary words, and Transformer-based decoders.

Proposed Approach / Retrieval module .. Generation module

The encoder-decoder neural network is trained on the commit message generation dataset to learn code diff semantics and generate commit messages. Cross-entropy is used as its loss function and AdamW is used for optimization.

Experimental Results / How does RACE perform compared with .. 5.4

End-to-end neural models generally perform worse than IR-based approaches on average across the four metrics. The evaluated models are CommitGen, CoDiSum, NMTGen, and PtrGNCMsg.

Conclusion .. Limitations

Four neural network models receive significant performance improvements from the proposed framework.
