GEN

Also called: generation approaches, generation model GEN, generation module, pretrained GEN
  • In Retrieval-Augmented Controllable Review Generation: GEN is a pretrained generation module integrated with REFLECT that uses selected or sampled reference reviews as inductive biases to generate rating-consistent review text from input attributes. It follows an encoder-decoder framework: a bidirectional LSTM with attention pooling encodes references, attribute embeddings are attended over, and a multilayer perceptron initializes a two-layer LSTM decoder. A copying mechanism can copy reference words. At inference it greedily chooses the highest-probability word. Its weights remain fixed during RL training, and performance drops when trained with REFLECT-retrieved references.

GEN in Retrieval-Augmented Controllable Review Generation

Jihyeok Kim · 2020-12-08/2020-12-13

GEN is a pretrained generation module integrated with REFLECT that uses selected or sampled reference reviews as inductive biases to generate rating-consistent review text from input attributes. It follows an encoder-decoder framework: a bidirectional LSTM with attention pooling encodes references, attribute embeddings are attended over, and a multilayer perceptron initializes a two-layer LSTM decoder. A copying mechanism can copy reference words. At inference it greedily chooses the highest-probability word. Its weights remain fixed during RL training, and performance drops when trained with REFLECT-retrieved references.

Narrative, section by section

4 sections; each heading opens the text

AT2T .. SL-REFLECT

GEN is the pretrained generation component integrated with REFLECT. It uses the selected references as inductive biases for generating review text from the attributes.

RL-REFLECT .. Stabilizing Training of RL

GEN generates a review using the sampled reference set. Its pretrained weights are kept fixed during RL training to keep the training cost low.

GEN .. Training GEN

GEN uses an encoder-decoder architecture with a copying mechanism. It encodes references and input attributes, generates words with a two-layer LSTM, and can copy words from reference texts. During inference, it greedily selects the word with the highest output probability.

Experiments .. Analysis on Rating Consistency

GEN generates reviews using retrieved references and is evaluated with coarse- and fine-grained REFLECT models trained using supervised learning or reinforcement learning.
