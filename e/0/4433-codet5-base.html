CodeT5-base in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

CodeT5-base is a pre-trained Seq2Seq-based model fine-tuned on the commit message generation dataset. It supplies encoder weights for code diff encoders and its decoder for the model. Its 32,100-word vocabulary is expanded by nine special tokens to 32,109. It is the best pre-trained baseline on average before RACE, which improves its average BLEU, Meteor, Rouge-L, and Cider results.

Narrative, section by section

2 sections; each heading opens the text

Experimental Setup / Dataset .. Evaluation metrics / Baselines

CodeT5-base supplies the encoder weights used to initialize the code diff encoders and the decoder used in the model. Its original vocabulary is expanded with nine special tokens for the token-level change actions, producing a vocabulary size of 32,109.

Experimental Results / How does RACE perform compared with .. 5.4

CodeT5-base performs best among the pre-trained baselines on average before RACE is applied. The RACE framework improves its average BLEU, Meteor, Rouge-L, and Cider results by 16%, 10%, 8%, and 32%, respectively.
