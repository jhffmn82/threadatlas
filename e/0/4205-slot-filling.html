Slot filling in Robust Retrieval Augmented Generation for Zero-shot Slot Filling

Michael Glass, Gaetano Rossiello, Md Faisal Mahbub Chowdhury, Alﬁo Gliozzo · 2021

Slot filling is a Knowledge Base Population sub-task that fills a missing value in an entity query of the form [ENTITY, SLOT, ?]. It recognizes a predetermined set of relations for an entity, explores a corpus for occurrences of that entity, gathers slot fillers from surrounding context, and populates infobox-like structures, sometimes with evidence text explaining predictions. Common pipelines use relation extraction; recent end-to-end approaches use retrieval-based language models. The task is developed through retrieval of relevant passages for head-and-relation queries and prediction of the ground-truth tail entity, including dense passage retrieval with hard negatives and robust training. Zero-shot work uses pre-trained transformers and language models as knowledge sources, while retrieval-augmented systems can provide textual provenance. Evaluation measures answer accuracy, token-level F1 with partial credit for overlapping tokens, and whether evidence supports generated slot fillers, including KILT benchmarks and a zero/few-shot TACRED variant.

Slot filling asks a system to fill a missing value for an entity query of the form [ENTITY, SLOT, ?] using evidence from relevant passages. The paper presents a novel zero-shot approach to this task.

Introduction

Slot filling is a sub-task of Knowledge Base Population. It recognizes a predetermined set of relations for an entity and uses them to populate infobox-like structures.

Slot filling fills out an infobox for an entity, sometimes providing evidence text to explain predictions. The unit presents KGI as an end-to-end slot filling system and discusses its evaluation on KILT benchmarks and a zero/few-shot TACRED variant.

Zero-shot slot filling is presented as a task enabled by pre-trained transformers and language models used as sources of knowledge. Retrieval-augmented systems such as RAG and REALM can provide textual provenance for generated slot fillers.
