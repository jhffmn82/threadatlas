MCMD in RACE: Retrieval-Augmented Commit Message Generation

Ensheng Shi, Yanlin Wang, Wei Tao, Lun Du, Hongyu Zhang, Shi Han, Dongmei Zhang, and Hongbin Sun · 2022

MCMD is a large-scale dataset for evaluating RACE across Java, C#, C++, Python, and JavaScript. It draws commits from the top-100 starred GitHub repositories for each language, retaining 450,000 randomly sampled commits per language after removing redundant and noisy messages. The study then excludes multi-file commits and unparseable files, compares results with 11 approaches, and reports significantly better RACE performance on four metrics.

MCMD is a large-scale dataset containing commits from the top-100 starred GitHub repositories for Java, C#, C++, Python, and JavaScript. It retains 450,000 randomly sampled commits per programming language after filtering redundant and noisy messages, and the study further filters out multi-file commits and files that cannot be parsed.
