GNN Encoder in Knowledge Graph Retrieval-Augmented Generation for LLM-based Recommendation

Shijie Wang, Wenqi Fan, Yue Feng, Shanru Lin, Xinyu Ma, Shuaiqiang Wang, Dawei Yin · 2025

GNN Encoder is a technology in K-RagRec that aggregates neighbor information into hop-level knowledge sub-graph representations, encodes retrieved and re-ranked sub-graphs, and is trained with a second graph neural network. A projector aligns representations with the LLM’s semantic space for knowledge-augmented recommendation.

Narrative, section by section

2 sections; each heading opens the text

1

The GNN in K-RagRec encodes retrieved knowledge sub-graphs, and a projector aligns their representations with the semantic space of the LLM. This allows the LLM to use structural information from the graphs for knowledge-augmented recommendation.

3 / 3.1 .. 3.8

A graph neural network first aggregates neighbor information to create hop-level knowledge sub-graph representations. A second graph neural network encodes the re-ranked sub-graphs for use in the recommendation process, and both graph neural networks are trained.
