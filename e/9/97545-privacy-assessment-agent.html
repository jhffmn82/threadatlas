privacy assessment agent in Mitigating the Privacy Issues in Retrieval-Augmented Generation (RAG) via Pure Synthetic Data

Shenglai Zeng, Jiankun Zhang, Pengfei He, Jie Ren, Tianqi Zheng, Hanqing Lu, Han Xu, Hui Liu, Yue Xing, Jiliang Tang · 2025

The privacy assessment agent evaluates Stage-1 generated data against original data for privacy information, personally identifiable information, and content enabling linkage to personal information. It gives the re-writing agent feedback and advice, repeating assessment and revision until the generated data is considered safe.

Narrative, section by section

2 sections; each heading opens the text

Introduction

The privacy assessment agent evaluates whether generated data contains privacy information, including personally identifiable information or content that could enable linkage of personal information. It provides feedback to guide the rewriting agent.

Methods

The privacy agent receives Stage-1 generated data and original data to assess privacy issues, including personally identifiable information and linkable personal information. It provides advice to the re-writing agent and repeats its assessment until the data is considered safe.
