rationale-based query formulation in Rationale-Guided Retrieval Augmented Generation

Jiwoong Sohn · 2025

Rationale-based query formulation is a method for clinical document-snippet retrieval that replaces an initial medical question with an LLM-generated step-by-step rationale. It identifies key problem components and expands brief or complex questions into precise, informative queries. The initial natural-language query is excluded to avoid retriever length limits and reduced performance. Higher-quality rationales retrieve fewer non-informative documents and generally improve baseline LLM performance, with GPT-4o-generated queries performing best in the reported comparison.

Introduction

Rationale-based query formulation uses a model-generated rationale as the retrieval query instead of the initial medical question. The rationale helps identify key problem components and expands brief questions.

3 / 3.1 .. 3.4

Rationale-based query formulation uses an LLM-generated step-by-step rationale as the search query. The initial query is excluded from document-snippet searches because combining it with the rationale can exceed retriever length limits and reduce performance.

5 / 5.1 .. 5.3

Rationale queries generally improve baseline LLM performance by refining complex medical questions into more precise and informative queries. Higher-quality rationale queries reduce retrieval of non-informative documents, with GPT-4o-generated queries performing best in the reported comparison.
