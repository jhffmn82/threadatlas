  • In SimGRAG: Leveraging Similar Subgraphs for Knowledge Graphs Driven Retrieval-Augmented Generation: SimGRAG, or Similar Graph Enhanced Retrieval-Augmented Generation, is a KG-driven retrieval-augmented generation method for effectively aligning query text with knowledge graph structures without additional training. It unfolds in three steps. First, query-to-pattern alignment uses a large language model to generate a query-aligned pattern graph. Second, pattern-to-subgraph alignment retrieves matching knowledge-graph subgraphs by combining graph isomorphism with embedding-based Graph Semantic Distance; an optimized algorithm identifies top-k subgraphs within 1 second on a 10-million-scale knowledge graph. Third, verbalized subgraph-augmented generation uses the query and retrieved, verbalized subgraphs as evidence to produce an answer. The method is intended to support complex graph patterns, concise contexts, scalable retrieval, and plug-and-play use on human-understandable knowledge graphs. In extensive experiments it consistently outperforms existing state-of-the-art KG-driven RAG approaches in question answering and fact verification, including GEAR on FactKG, and is robust across large language models. Reported results include 86.8% accuracy on FactKG and 0.74-second optimized retrieval per FactKG query. Its main limitation is dependence on the underlying large language model: lower-quality or less capable models can substantially reduce performance, particularly for complex queries. Its plug-and-play usability also assumes that the input knowledge graph aligns with human cognition.

SimGRAG in SimGRAG: Leveraging Similar Subgraphs for Knowledge Graphs Driven Retrieval-Augmented Generation

Yuzheng Cai, Zhenyue Guo, Yiwen Pei, Wanrui Bian, Weiguo Zheng · 2025

SimGRAG, or Similar Graph Enhanced Retrieval-Augmented Generation, is a KG-driven retrieval-augmented generation method for effectively aligning query text with knowledge graph structures without additional training. It unfolds in three steps. First, query-to-pattern alignment uses a large language model to generate a query-aligned pattern graph. Second, pattern-to-subgraph alignment retrieves matching knowledge-graph subgraphs by combining graph isomorphism with embedding-based Graph Semantic Distance; an optimized algorithm identifies top-k subgraphs within 1 second on a 10-million-scale knowledge graph. Third, verbalized subgraph-augmented generation uses the query and retrieved, verbalized subgraphs as evidence to produce an answer. The method is intended to support complex graph patterns, concise contexts, scalable retrieval, and plug-and-play use on human-understandable knowledge graphs. In extensive experiments it consistently outperforms existing state-of-the-art KG-driven RAG approaches in question answering and fact verification, including GEAR on FactKG, and is robust across large language models. Reported results include 86.8% accuracy on FactKG and 0.74-second optimized retrieval per FactKG query. Narrative, section by section

6 sections; each heading opens the text

Abstract

SimGRAG, or Similar Graph Enhanced Retrieval-Augmented Generation, addresses the alignment of query texts and knowledge graph structures through query-to-pattern and pattern-to-subgraph stages. It uses an optimized retrieval algorithm to identify top-k subgraphs within 1 second on a 10-million-scale knowledge graph.

Introduction

SimGRAG is introduced as a method for aligning query text with knowledge-graph structures. It generates a query-aligned pattern graph, retrieves matching subgraphs using Graph Semantic Distance, and uses the query and verbalized subgraphs to generate an answer. The method is intended to support complex graph patterns, plug-and-play deployment on human-understandable knowledge graphs, concise contexts, and scalable retrieval.

The SimGRAG Approach / Query-to-Pattern Alignment .. Verbalized Subgraph-Augmented

The SimGRAG Approach decomposes alignment between query text and knowledge graph structures into query-to-pattern alignment and pattern-to-subgraph alignment. It combines graph isomorphism with embedding-based semantic distance and uses retrieved subgraphs as evidence for answer generation.

Experiments .. Overall Latency

SimGRAG is evaluated as a KG-driven retrieval-augmented generation method without additional training. It achieves 98.0, 98.4, and 97.8 Hits@1 on MetaQA 1-hop, 2-hop, and 3-hop tasks, 88.7 and 78.6 Hits@1 on PathQuestions 2-hop and 3-hop tasks, 98.1 Hits@1 on WorldCup2014, and 86.8% accuracy on FactKG. Its optimized retrieval takes 0.74 seconds per FactKG query, while average latency is 9.0 seconds with 4-shot prompting and 14.2 seconds with 12-shot prompting.

Conclusion

SimGRAG uses an LLM to generate a pattern graph aligned with the query text. It uses Graph Semantic Distance to align the desired pattern with subgraphs in the knowledge graph and includes an optimized algorithm for retrieving the top-k most similar subgraphs.

Limitations

SimGRAG depends closely on the capabilities of the large language model used in its query-to-pattern alignment and verbalized subgraph-augmented generation steps. Its performance can substantially degrade with lower-quality LLMs, especially for complex queries, and its plug-and-play usability assumes that the input knowledge graph aligns with human cognition.
