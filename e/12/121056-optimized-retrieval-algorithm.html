Optimized Retrieval Algorithm

Optimized Retrieval Algorithm in SimGRAG: Leveraging Similar Subgraphs for Knowledge Graphs Driven Retrieval-Augmented Generation

Yuzheng Cai, Zhenyue Guo, Yiwen Pei, Wanrui Bian, Weiguo Zheng · 2025

The Optimized Retrieval Algorithm is an optimized retrieval algorithm and SimGRAG retrieval component for efficiently identifying top-k subgraphs on a 10-million-scale knowledge graph. It first uses vector search to obtain candidate nodes and relations, then retrieves subgraphs by graph semantic distance. It derives a lower bound for completing partial mappings and safely prunes branches exceeding the current top-k queue threshold, preserving the Top-k Retrieval Algorithm’s results. On FactKG’s DBpedia knowledge graph, it averages 0.74 seconds per query.

Semantic Guided Subgraph Retrieval / Top-k Retrieval Algorithm .. Optimized Retrieval Algorithm

The Optimized Retrieval Algorithm derives a lower bound on the Graph Semantic Distance achievable by completing a partial mapping. It safely prunes branches whose bound exceeds the largest distance currently in the top-k priority queue and is stated to produce the same results as the Top-k Retrieval Algorithm.

Experiments .. Overall Latency

Semantic guided subgraph retrieval first uses vector search to obtain candidate nodes and relations, then retrieves subgraphs according to graph semantic distance. Its optimized implementation reduces retrieval time substantially, with FactKG times of 0.59 seconds for vector search, 0.15 seconds for optimized retrieval, and 0.74 seconds in total.
