context-sensitive query decomposition in TableRAG: A Retrieval Augmented Generation Framework for Heterogeneous Document Reasoning

Xiaohan Yu, Pu Jian, Chong Chen · 2025

Context-sensitive query decomposition is a TableRAG component that identifies textual and tabular roles in a query and, through iterative reasoning, formulates subqueries using retrieved table content and linked schemas. Conditioning on retrieved schemas supports structurally aware decomposition and overall performance; flawed intermediate decomposition can cause reasoning failures.

3 / 3.1 .. 3.3

Context-sensitive query decomposition identifies the respective roles of textual and tabular modalities in a query and formulates subqueries during iterative reasoning. It uses retrieved table content and linked table schemas to support structurally aware decomposition.

5 / 5.1 / 5.1.1 .. 5.3

Context-sensitive query decomposition conditions decomposition on the retrieved table schema. Removing it in the ablation study lowers performance, showing that it contributes to the overall TableRAG architecture.

7 / 7.1 .. 7.2

Flawed intermediate query decomposition is described as a source of reasoning failures. TableRAG uses context-aware query decomposition, while ReAct lacks that mechanism.
