OG-RAG

method · 1 work · 60 quoted facts · 22 connections
Also called: OG-RAG: Ontology-Grounded Retrieval-Augmented Generation, Ontology-Grounded Retrieval Augmented Generation, Ontology-Grounded Retrieval Augmented Generation method, Proposed OG-RAG, ontology-grounded retrieval-augmented generation
  • In OG-RAG: Ontology-grounded retrieval-augmented generation for large language models: OG-RAG is an ontology-grounded retrieval-augmented generation method for adapting large language models to domain-specific, fact-based query answering. It uses a domain-expert-defined semantic schema to map unstructured domain documents into ontology-grounded factual blocks; GPT-4o is used to fill domain-specific ontology values from chunked document parts and generate JSON-LD. These blocks form a hypergraph. For each query, OG-RAG uses a greedy optimization algorithm to retrieve a minimal, adjustable-detail set of relevant hyperedges, hypernodes, and flattened context for the language model. The approach is intended to make retrieval interpretable and verifiable, combining structured fact-based and rule-based reasoning with neural flexibility, while giving control over how context is retrieved and used. In experiments on agriculture, including Soybean and Wheat, and news, it generally outperforms RAG, RAPTOR, and GraphRAG across retrieval and answering measures. Reported results include 55% higher correct-claim context recall, 110% higher correct-entity recall, 40% better answer correctness, 16% better answer relevance, and 27% higher fact-based reasoning accuracy; it matches RAPTOR on News context recall. It also reduces human fact-verification time by 28.8% on average and lets users attribute responses to supporting context about 30% faster, with 29.6% more human-attributed support. It is nearly as query-efficient as RAG and faster than RAPTOR and GraphRAG in preprocessing and querying. Performance remains largely preserved until about half of ontology information is removed, though answer relevance is slightly lower for Wheat and Soybean with GPT-4o and Llama-3-70B. Code is released on GitHub by Microsoft. The method is presented as applicable to healthcare, law, agriculture, journalism, research, industrial workflows, and knowledge work.

Narrative, section by section

8 sections; each heading opens the text

Abstract

OG-RAG is an Ontology-Grounded Retrieval Augmented Generation method that anchors retrieval processes in domain-specific ontologies. It constructs a hypergraph from domain documents, retrieves a minimal set of hyperedges using an optimization algorithm, and reportedly improves accurate-fact recall, response correctness, attribution speed, and fact-based reasoning accuracy over baseline methods.

Introduction

Ontology-Grounded Retrieval Augmented Generation (OG-RAG) integrates domain-specific ontologies into retrieval-augmented generation for fact-based adaptation. It uses ontology-grounded hypergraph representations and a greedy algorithm to retrieve a minimal set of hyperedges as compact LLM context. Evaluations in agriculture and news report improvements in fact recall, response correctness, context attribution, and fact-based reasoning.

Related Work

OG-RAG leverages a domain experts-defined semantic schema and ontology to ground unstructured documents for domain-specific retrieval. It provides interpretable retrieval contexts and combines structured fact-based reasoning with the flexibility of LLMs.

Background

OG-RAG is presented as an ontology-grounded retrieval-augmented generation approach. It maps domain-specific documents to an ontology, generates JSON-LD through GPT-4o's structured output capability, and uses relevant hypernodes and context in a flattened hypergraph to answer queries.

OG-RAG .. Relevant Hyeredges as Context

Ontology-Grounded Retrieval Augmented Generation integrates ontologies and ontology-driven hypergraph retrieval into the retrieval process. It maps domain-specific documents into ontology-grounded factual blocks, constructs a hypergraph, and retrieves relevant hyperedges as context for large language models.

Experimental Setup

OG-RAG is evaluated for domain-specific query answering in agriculture and news. Its retrieved contexts achieve higher or equal Context Recall than the listed baselines across the reported datasets, with scores of 0.84 for Soybean, 0.95 for Wheat, and 0.82 for News.

Experiments / Query answering .. Ontology sensitivity

OG-RAG generally outperforms RAG, RAPTOR, and GraphRAG in context recall, context entity recall, answer correctness, similarity, and relevance across the evaluated datasets. It reduces human fact-verification time and increases human-attributed context support, supports deductive reasoning from predefined agricultural rules, and remains effective until about half of the ontology information is dropped.

Conclusion

OG-RAG is a hypergraph-based retrieval method for domain adaptation using ontology-grounded retrieval-augmented generation. Experiments on agriculture and news datasets show that it improves factual accuracy, accelerates answer attribution, and strengthens rule-based reasoning.
