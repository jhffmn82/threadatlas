QD in Question Decomposition for Retrieval-Augmented Generation

Paul J. L. Ammann · 2025-07-28/2025-07-29

QD is a question decomposition module for RAG that uses prompting and an instruction-tuned language model to generate sub-queries while retaining the original query for retrieval. It takes 16.7 seconds per query, improves MultiHop-RAG retrieval, and has mixed results on HotpotQA.

Narrative, section by section

2 sections; each heading opens the text

RAG with Question Decomposition .. QD Module / Reranker Module

The question decomposition module uses a prompting function and an instruction-tuned language model to generate a set of sub-queries. It retains the original query alongside the generated sub-queries for retrieval.

opening .. Efficiency

QD improves retrieval performance over Naive RAG on MultiHop-RAG, reaching 0.655 Hits@4 and 0.810 Hits@10. On HotpotQA, it slightly improves answer metrics but lowers supporting-fact and joint F1, precision, and EM relative to Naive RAG.
