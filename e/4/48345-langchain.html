LangChain

software · 3 works · 5 quoted facts · 4 connections
Also called: LangChain framework, LangChain module
  • In "Retrieval-Augmented Generation Approach: Document Question Answering using Large Language Model," LangChain handled document loading, splitting, embeddings, memory, prompting, output interpretation, and connection to FAISS for efficient retrieval.
  • In "BERGEN: A Benchmarking Library for Retrieval-Augmented Generation," LangChain was presented as a RAG library and documentation resource offering generic application modules for production-ready high-level RAG development and cited for language-model frameworks.
  • In "RadioRAG: Online Retrieval-augmented Generation for Radiology Question Answering," LangChain supported retrieval by comparing embedded queries with database vectors and retrieving the three most similar vectors.
