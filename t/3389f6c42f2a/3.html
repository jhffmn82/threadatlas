Problem Formulation This work focuses on tackling multi-hop questions. We denote a multi-hop question and its answer as q and a, respectively. Each question is associated 8473 with a set of N documents: Dq = {d1, d2, . . . dN}, which are obtained with a retriever model. Follow- ing previous work (Trivedi et al., 2023), the docu- ments are often retrieved from Wikipedia, where each document comprises a title and a text. Given the question q and the document set Dq, the goal is to correctly generate the answer a. 3
